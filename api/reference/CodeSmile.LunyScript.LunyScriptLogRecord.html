Examples

var record = new LunyScriptLogRecord(LunyScriptLogSeverity.Error, LunyScriptLogAreas.Core,
    "a block threw", instance.Program.ScriptType.Name, blockTypeName, block.Location);
LunyScriptLog.Write(record);

Remarks

The console and runtime debugger read these fields directly to filter records and open captured authored source. LunyScriptLog formats Unity-console output; the LunyScript console displays the same record through its own reader.

The record retains value types and existing references. Names, messages and exception details are supplied by the producer; retaining a record does not format those fields.
