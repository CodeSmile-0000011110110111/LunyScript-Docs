What one group of documents holds: its family and its roles. A SaveGroupSlot saves a SaveGroup of this schema as one archive file, so every document of the group is replaced together or none is, and a load reads them all or fails.

Examples

static readonly SaveRole World = SaveRole.Single("World", WorldSchema);
static readonly SaveRole Players = SaveRole.Keyed("Players", PlayerSchema);
static readonly SaveGroupSchema Slot = new SaveGroupSchema("arena.slot", World, Players);

Remarks

Fixed roles, changing members. The roles never change for an acquisition; a keyed role's members do. Every save stores the complete membership the group holds: a member a previous save stored and this group does not hold is gone after the save succeeds. A member has no save or delete of its own, and a group holds no group.

Versions stay with documents. Each member document keeps its own schema version and migration steps; a load migrates each as a single document's load does. A role added later reads an older archive when it is Optional or Keyed; a Single role the archive lacks fails the load as Incomplete.
