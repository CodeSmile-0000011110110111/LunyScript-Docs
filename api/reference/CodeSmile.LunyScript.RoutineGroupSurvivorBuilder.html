Struct RoutineGroupSurvivorBuilder

A concurrent group whose unfinished children the enclosing routine activation owns after the group publishes its result. The routine advances those children during its following steps and cancels them when that routine activation ends or is cancelled.

public readonly struct RoutineGroupSurvivorBuilder
Expand Details ...

Examples

var arrival = InParallel(moveCamera, fadeMusic).UntilOneFinishes().OthersKeepRunning();
On.Ready(Routine("Arrival").Run(arrival, fadeInArrivalPanel));

Remarks

In these examples, fadeInArrivalPanel is a multi-frame UI transition. While that following step runs, the unfinished camera movement or music fade continues.

Properties

Canceled

A condition that is true once this group was cancelled before it produced a result. Cancellation is neither a success nor a failure, so Succeeded and Failed are both false for the same group.
