Struct StateBuilder

Namespace
CodeSmile.LunyScript

ApiSource.dll

What machine.State(state) returns: the state's Enter, Update and Exit lists, written in that order and each at most once, or an internal transition with When(ConditionBlock, string, int).

public readonly struct StateBuilder
Expand Details ...

Examples

Phases.State(Angry).Enter(Speed.Set(3)).Update(Transform.RotateBy(0, 90, 0)).Exit(Speed.Set(1));
Phases.State(Angry).When(HitTaken).Do(HitTaken.Set(false), Flashes.Inc());

Remarks

Enter runs when the machine enters the state, and the Routine, Choose or Run it starts belongs to the state: the machine advances that work on its own tick and cancels it when it leaves the state. Update runs once per pass in which no transition is chosen, after that work. Exit runs when the machine leaves the state. Each list runs its blocks at once, so a Wait or an InParallel group in one is refused when the script type is built.

When(ConditionBlock, string, int)

An internal transition: while this state is current and the condition is true, the transition's Do runs and nothing else. The state keeps the work it started, and neither Exit nor Enter runs. The pass ends with it.
