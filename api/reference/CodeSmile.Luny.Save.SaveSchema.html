What one kind of document holds: its schema family, its version, its fields, the migration steps that convert an older stored version, and whether it reads documents of format 1, which name no family. Each method returns a new schema and leaves this one as it was, so a schema kept in a static readonly field never changes after it is built.

Examples

// A Unity type holding a static field carries [NoAutoStaticsCleanup]: the schema never changes, so nothing resets it.
[NoAutoStaticsCleanup]
public sealed class Saves : MonoBehaviour
{
    static readonly SaveField<Double> BestScore = SaveField.Number("BestScore");
    static readonly SaveField<String> PilotName = SaveField.Text("PilotName", 64);
    static readonly SaveSchema Progress = new SaveSchema("demo.progress", 2, BestScore, PilotName)
        .Migration(new ProgressVersion1To2()).ReadsFormat1();
}

Remarks

The family names what the document is. A save writes it into the file, and a load refuses a stored document of another family even when its fields happen to fit, so the settings of one game never load as the progress of another. A family is 1 to 64 letters, digits, dashes, underscores and dots, such as "demo.progress", and stays the same when the C# that saves it is renamed.

Format 1 files read only by declaration. Documents saved before families existed are format 1 and name none; a schema reads them only when it declares ReadsFormat1(), which binds them to its family. The next save writes format 2.

Each field is a SaveField object declared once; its name is the key stored in the file. A repeated name, a version below 1, a step from a version the schema cannot have and two steps from one version throw a LunySaveException where they are written; a schema whose steps leave a version without a step between the oldest one and the current one is refused where it is first used.

ReadsFormat1()

Declares that a stored document of format 1, which LunySave 1 and LunyScript write and which names no family, is a document of this schema's family. Without it a load refuses such a file as Unsupported. The next save writes format 2.
