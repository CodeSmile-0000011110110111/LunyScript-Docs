Struct InputWatchBuilder

What When.Input(action) returns. Its three methods register the blocks that run on a frame where the action reported that occurrence.

public readonly struct InputWatchBuilder
Expand Details ...

Examples

When.Input(Fire).Performed(Shots.Add(1.0));
When.Input(Fire).Canceled(Charging.Set(false));

Remarks

An occurrence is polled once per frame, after the frame-update blocks, and is never replayed. The backend is asked whether it happened during the frame that is running, which is where When.Var(x).Changed is polled too. An occurrence that happened while no frame ran is gone; docs/execution-model.md, "Player input", states the whole contract.

Two calls naming the same action and the same occurrence register two watches, in the order they were written, the way two On.FrameUpdate calls do.
