A declared choice: the name of one scored selector, which Choose(handle).Highest(...) opens and which a diagnostic and the runtime inspector call it by.

public readonly struct Choice
Expand Details ...

Examples

Needs = Define.Choice();
On.Ready(Choose(Needs).Highest(Option(WorkScore).Then(Work), Option(RestScore).Then(Rest)));

Remarks

Needs = Define.Choice(); declares one; the declaration starts no selector. Choose(Needs) opens the selector, once per declaration. Each instance holds its own selection and hold state for it. docs/proposals/declared-identity-handles.md is the contract.
