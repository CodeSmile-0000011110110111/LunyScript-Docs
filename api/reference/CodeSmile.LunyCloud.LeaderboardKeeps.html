Enum LeaderboardKeeps

Namespace
CodeSmile.LunyCloud
Assembly
ApiSource.dll

Which score a leaderboard keeps for an account when the account submits again: the update rule configured on the service's dashboard. The client cannot read that configuration, so the game declares it; the file backend applies it and the journal names it.

public enum LeaderboardKeeps : byte
Expand Details ...

Fields

Best = 0

The best score so far, by the board's LeaderboardRanks; Unity's "keep best".

Latest = 1

The most recent score; Unity's "keep latest".

Sum = 2

The sum of every score submitted; Unity's "sum". A score sent twice counts twice, which is why a score whose sending may have reached the service is never sent again.

Examples

var weekly = new LeaderboardSpec("Weekly", LeaderboardKeeps.Best, LeaderboardRanks.HighestFirst);
