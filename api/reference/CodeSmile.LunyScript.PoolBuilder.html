Struct PoolBuilder

What Define.Pool(name).From(prefab) returns: a pool declaration that converts to its Pool handle, or takes a hard cap, a prewarm count and a default placement first.

public readonly struct PoolBuilder
Expand Details ...

Examples

Guards = Define.Pool(nameof(Guards)).From(Enemy).HardCap(8).Prewarm(4);

Remarks

The hard cap counts every entry: idle, in use and still returning. With no HardCap the pool grows as far as spawns ask. At the cap a spawn is refused; the pool never takes an entry back from a use and never creates an object outside itself.

Prewarm prepares inactive entries and runs nothing. No script on an entry starts until its first checkout, which delivers On.Created and then On.Spawned; every later checkout delivers On.Spawned alone.
