Struct MathFactory

Namespace
CodeSmile.LunyScript

The core numeric functions, written as Math.Abs(...) inside a script's Build(). Every member returns an expression that is evaluated each time the block holding it runs; none of them writes anything.

public readonly struct MathFactory
Expand Details ...

Examples

On.FrameUpdate(Distance.Set(Math.Clamp(Distance + Step, 0.0, 100.0)));

Remarks

Every function here has a second, writing form on the variable itself. The API semantics board's C01 answer, 2026-09-13, requires both: Math.Abs(Offset) computes a magnitude and leaves Offset alone, while Offset.Abs() writes the magnitude back into Offset. Reach for the expression when the result feeds something else and for the write when the variable is the destination.

What this surface holds, and what it deliberately does not. The board's C04 answer is a small core plus named packages: Abs, Min, Max, Clamp, Floor, Ceiling, Truncate, Round and Lerp are the core, and remap, easing, curve, spatial and trigonometric functions live in separate first-party Math packages that this one does not carry. That is an organisation choice rather than a refusal to own them.

The five arithmetic operators are not members here. Addition, subtraction, multiplication, division and remainder are written + - * / %, which is their expression form; Health.Add, Subtract, Multiply, Divide and Remainder are their writing form. A Math.Subtract would be a third spelling of something C# already spells.

Clamp(NumberValueBlock, NumberValueBlock, NumberValueBlock, string, int)

A number held between two bounds. The bounds are applied in order, the minimum first and the maximum second, so a reversed pair produces the maximum rather than throwing. A NaN value stays NaN and a NaN bound applies to nothing, because every comparison against a NaN is false; IsNaN(NumberValueBlock, string, int) is what asks about one.

Lerp(NumberValueBlock, NumberValueBlock, NumberValueBlock, string, int)

A number a stated fraction of the way from one value to another. The fraction is not limited: 2.0 is twice the distance past the destination and -1.0 is the same distance before the origin.
