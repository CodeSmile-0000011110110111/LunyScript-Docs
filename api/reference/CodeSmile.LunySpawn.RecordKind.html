What a SpawnRecord reports. Its fields say which of the record's fields each kind fills.

public enum RecordKind : byte
Expand Details ...

Fields

Admitted = 4

A member was admitted as Use at the recorded position.

BatchSkipped = 11

A repeat group's batch was skipped because the previous batch still had members waiting.

CohortCompleted = 14

A cohort completed: Count members, Value the game seconds from first admission to last end, Target the authored clear target and Reason the CohortSample.

CohortStarted = 3

A cohort of Group started: Count members, Reason the tier, Value the frequency factor and Target the game time of the next batch (0 for a finite group).

Dropped = 7

Pending members were dropped: Count of them; Reason is 0 for an optional member's passed deadline, 1 for a stop, 2 for a quota revision.

Expired = 6

A required member's deadline passed: the run fails.

GroupStopped = 10

A group stopped: Reason is 0 for its stop signal, 1 for its source's end, 2 for its phase's end, 3 for the run's end.

ParticipantsChanged = 12

The participant count changed to Count.

PhaseEntered = 1

A run entered Phase.

PhaseExited = 2

A run's phase succeeded: Reason is the index of the first term that held, or -1 when every term was needed.

PressureChanged = 13

A run's timing factor (Value) or tier (Reason) changed for future cohorts.

Refused = 5

An attempt was refused: Reason is the SpawnRefusal, the position the candidate's when HasPose.

RunEnded = 15

A run ended: Reason is the RunEnd and Count its detail.

RunReleased = 16

A released run's slot was freed.

RunStarted = 0

A run started: Count is the seed, Value the participant count.

SignalLatched = 9

A signal latched: Reason is its index in the recipe.

UseEnded = 8

A use ended: Reason is the UseEnd.

Examples

if (record.Kind == RecordKind.CohortCompleted) Console.WriteLine(record.Value);
