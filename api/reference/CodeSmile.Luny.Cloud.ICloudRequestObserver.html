Interface ICloudRequestObserver

Namespace
CodeSmile.Luny.Cloud
Assembly
ApiSource.dll

Told about one CloudRequest: asked whether to send it at the moment it would be sent, and told when it ended. Both calls happen inside Tick(), on the main thread, so a caller reacts to an outcome in the same frame the client observed it. Set with Observer.
