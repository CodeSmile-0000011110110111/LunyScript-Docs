Net.Send: the one way a peer without authority asks the authority to do something.

public readonly struct NetSendFactory

Examples

Net.Send.ToAuthority(nameof(RequestReady))

Remarks

There is no "send to everyone" and no "send to one peer" in this milestone. A message goes to the authority over the object it was sent from, because that is the peer allowed to change the object's state, and state reaches the other peers as a synchronised variable rather than as a second message. That keeps one direction of travel: a request goes up to the authority, and state comes back down through the cadences.

Methods

ToAuthority(string, string, int)

Builds a block that sends one named message to the peer with authority over this object. The message carries its name and no payload.

public Block ToAuthority(string messageName, string callerFilePath = null, int callerLineNumber = 0)

Examples

On.FrameUpdate(If(!Net.HasAuthority).Then(Net.Send.ToAuthority(nameof(RequestReady))));

Remarks

Sending while offline does nothing: there is no authority to send to, and that is a state rather than a mistake. Sending on the peer that already has authority delivers the message to itself, so a script does not need two paths for "ask" and "do".

Exceptions

LunyScriptUsageException

The name is null or whitespace. A name that no On.Message in this script receives is refused too, at the end of Build() rather than here, because the receive may be written below the send.
