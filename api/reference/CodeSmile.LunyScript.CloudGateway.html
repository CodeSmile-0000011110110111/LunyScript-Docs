Class CloudGateway

CodeSmile.LunyScript

The one place C# reaches the cloud client a runner's scripts use: which backends it talks to, where its score queue is kept, and the CloudClient itself for C# reads and diagnosis. The runner ticks the client once per frame, before any instance runs, so an outcome reaches the watches of the same frame.

Remarks

Before services are named, requests wait, as they did on the shipped gateway. With the Cloud Save package installed, the default runner in Play Mode and in a player is given the supplied Unity backends and a score queue kept in the player's data folder, unless the project setting turns the supplied Cloud Save provider off; a backend named here replaces the supplied ones until the first sign-in starts. docs/proposals/lunycloud.md L17.

A runner a test creates with new ScriptRunner() gets no services and an in-memory score queue.
