Enum ScriptServices

Services required by composed nodes, independently of their execution contexts.

[Flags]
public enum ScriptServices
Expand Details ...

Fields

Clock = 8

The owning runner's clock; available in both contexts.

EditorPlacementDemo = 32

Provisional selected-placement demo target access; not a general editor service API.

EditorUndo = 16

Explicit editor effects with Undo; not provided by the scene-free host.

None = 0

Slots and pure calculations need no external service.

RuntimeCamera = 512

The runtime camera gateway, which every View and Camera block needs.

RuntimeCloud = 2

The runtime cloud gateway, including its pre-provider queue.

RuntimeDocuments = 1024

The runtime document gateway, which every Progress and Settings save and load needs.

RuntimeInput = 256

The runtime input gateway, which every Input read and every When.Input watch needs.

RuntimeNavigation = 2048

The runtime navigation gateway, which every Navigation block needs.

RuntimeNetwork = 4

The runtime network gateway.

RuntimeObjectLifetime = 64

Runtime object creation, activation, deactivation and destruction. A host provides it by implementing IScriptObjectLifetime.

RuntimeObjectSpawning = 128

Runtime object production from a prefab. A host provides it by implementing IScriptObjectSpawner. It is separate from RuntimeObjectLifetime because a host can own an object's lifetime without having a scene to put a new instance in.

RuntimeTransform = 1

Runtime spatial effects; editor Undo effects are separate.
