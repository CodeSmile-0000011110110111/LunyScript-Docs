Why a use ended. Any end clears the member (the captain's Q29 answer: absence is completion); only Defeated is evidence for the clear-speed controller.

public enum UseEnd : byte
Expand Details ...

Fields

AdmissionRefused = 6

The world refused the admission after some of the object's components began the use; they end it with this cause and the use never became ready. The session itself never reports it.

Defeated = 0

Combat committed the object's defeat; the use ends at the next boundary (Q39).

PhaseEnded = 2

Its phase ended with End.

Removed = 1

The object was destroyed or deactivated by something other than the session.

RunCancelled = 3

Its run was cancelled.

RunReleased = 4

Its terminal run was released.

SessionEnded = 5

The session ended.

Examples

host.ReportEnded(use, UseEnd.Defeated);
