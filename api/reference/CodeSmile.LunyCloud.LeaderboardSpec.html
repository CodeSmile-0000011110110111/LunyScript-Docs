Class LeaderboardSpec

Namespace
CodeSmile.LunyCloud

A leaderboard as the game declares it: the service's board id, the update rule and the sort order configured on the dashboard (C23 A). Immutable.

public sealed class LeaderboardSpec

Inheritance
object

Examples

Remarks

A queued score captures the spec it was submitted with, so a score that waits across a restart is sent with the rules it was submitted under, the "configured score meaning" the 2026-09-09 queue contract captures.
