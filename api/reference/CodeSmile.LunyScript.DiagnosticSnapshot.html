Methods

Preview(DiagnosticNode)

What a condition or value node says about this snapshot's stored values, computed from this snapshot's own copy of them.

public DiagnosticPreview Preview(DiagnosticNode node)

Parameters

Type Name Description
DiagnosticNode
node

A node of the catalog of the program this snapshot's lifetime runs.

Returns

DiagnosticPreview

The value the node has now, a Flag for a condition, or why it has none.

Examples

var live = snapshot.Preview(catalog.Nodes[3]); var isTrue = live.IsAvailable && live.Value.Flag;

Remarks

The reading was built with the program, from built-in conditions and values that read only the script's variables, its internal storage and literals, and it reads Values and nothing else: computing it runs no block, no condition, no value and no script code, and changes nothing. It is what the node would say at the runner boundary this snapshot was read at, Sequence. NodeOutcomes keeps what the script's own run of a condition's If recorded, which can be older and can differ.

A node whose PreviewUnavailableReason is not null, and every node of an unavailable snapshot, has an unavailable preview with that reason. A forced If does not change its condition's preview. Each call evaluates the reading again; nothing is cached.

Exceptions

LunyScriptUsageException

node is null or belongs to another program's catalog.
