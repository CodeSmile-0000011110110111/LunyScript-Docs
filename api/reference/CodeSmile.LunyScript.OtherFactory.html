The Other surface inside Build(): the other collider of the contact event currently running.

public readonly struct OtherFactory
Expand Details ...

Examples

On.CollisionEnter(If(Other.HasTag("Player")).Then(Score.Add(1.0)));
On.TriggerStay(HitAt.Set(Other.WorldPosition));

Remarks

Usable only inside On.CollisionEnter, On.CollisionStay, On.CollisionExit, On.TriggerEnter, On.TriggerStay and On.TriggerExit. The same members exist on all six, because they are properties of the other collider, which both Unity callbacks name. A read outside those events throws when the block runs. Collision-only Unity fields are not members here; docs/proposals/physics-contact-events.md states why.

ConditionBlock

Examples

On.CollisionEnter(If(Other.HasTag("Player")).Then(Score.Add(1.0)));

Remarks

Uses Unity's CompareTag on a live collider, which allocates nothing. A tag that is not in the project's Tag Manager is a Unity error, the same as in a handwritten OnCollisionEnter.

Exceptions

LunyScriptUsageException

tag is null or whitespace, or this surface was read outside Build().
