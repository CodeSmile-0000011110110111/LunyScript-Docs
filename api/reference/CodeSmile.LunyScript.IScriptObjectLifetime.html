Interface IScriptObjectLifetime

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The part of a host that can activate, deactivate, create and destroy objects. A host that provides it declares RuntimeObjectLifetime by implementing this interface; a host that does not cannot run a script containing an Object block, and the spawn is refused with a message naming the missing service.

public interface IScriptObjectLifetime
Expand Details ...

Examples

var lifetime = (IScriptObjectLifetime)instance.Host;
lifetime.SetActive(false);

Remarks

It is a second interface rather than four more members on IScriptHost for the reason IScriptHostCapabilities is a second interface: the scene-free editor host owned by EditorScriptSession has no object to activate or destroy, and four members it can only refuse would make every implementation carry them. AGENTS.md rule 53 and docs/editor-foundation.md own that boundary.

It names no GameObject, Transform or Component, so the core stays testable without a scene and the type ban of AGENTS.md rule 24 still holds.

Remarks

The created object carries no LunyScript script, so it raises no LunyScript observation and cannot re-enter the runner. This allocates, and it is AGENTS.md rule 31's first boundary, spawn.

DestroyObject()

Destroys the object this host names.

void DestroyObject()

Remarks

Called on an owned object when its owner despawns, and on the script's own object when Object.Despawn() ends it. Like SetActive(bool) it is called outside the runner's dispatch, because Unity raises OnDisable and OnDestroy synchronously inside it.

SetActive(bool)

Activates or deactivates the object.

void SetActive(bool active)

Parameters

Type Name Description
bool
active

True to activate, false to deactivate.

Remarks

On a real GameObject this is SetActive, and Unity raises the component callbacks that follow from it synchronously inside this call. ScriptRunner therefore calls it outside its own dispatch, never from inside a block.
