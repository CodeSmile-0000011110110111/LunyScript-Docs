A handle to one AudioClip input of a script: an audio clip the object's Inspector assigns. Returned by Bind.AudioClip() at build time, or assigned before Build() by [Asset] on the property.

public readonly struct AudioClip

Examples

Remarks

This is LunyScript's type, with Unity's name. A script imports only CodeSmile.LunyScript, so AudioClip there is this handle and the script compiles without an engine reference. The Inspector field accepts a UnityEngine.AudioClip, and C# on the object reads the assigned asset with LunyScriptBehaviour.GetAsset. A file that imports both namespaces writes UnityEngine.AudioClip for Unity's type.

The declared name is the input's durable identity. A value stored on a host is matched to the input by that name. A generated property gives the input its member's name, and .As(name) names it explicitly. Renaming it orphans what a scene stored for the old name.

An object that assigns none gets the short low tone asset placeholder.

A handle is valid only inside the Build that declared it, for the reason Var<T> states: it carries a slot index and nothing that identifies its program.
