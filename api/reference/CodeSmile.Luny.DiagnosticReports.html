Remarks

The Editor and a development player compile with DEBUG, and the default is true there. A player compiled with LUNY_DIAGNOSTICS also defaults to true. A release player defaults to false. Setting Enabled replaces that default until the next static cleanup, which runs when Play Mode ends with domain reload disabled.

A report checks this flag before it allocates a list, a key or a message. A string passed into a log method is built before that method runs, so the check surrounds the call. Product results, refusals and exceptions a caller reads are not reports.
