The Unity Leaderboards backend: scores, pages, one player's entry and past seasons behind ICloudCall, so the client polls and nothing awaits. The service applies the update rule and the order configured on its dashboard; the declared Keeps and Ranks are not sent.

Remarks

Needs the board created on the dashboard under the declared id, and a signed-in account, which UgsCloudBackend provides. A Submit's details are sent as the entry's metadata object, and an entry read returns them. A page is read with GetScoresAsync, this account's entry with GetPlayerScoreAsync, another player's with GetScoresByPlayerIdsAsync, and the past seasons with GetVersionsAsync.

Rank. LunyCloud's Rank is the place, 1 for the top entry. This backend adds 1 to the service's rank, which Unity's samples show starting at 0. The package's own documentation does not state the base and it was not checked against the live service when this was written; docs/proposals/lunycloud.md L23 records the assumption and how to check it.
