A handle to one declared document: a named, versioned set of variables that Progress.Save and Progress.Load, or Settings.Save and Settings.Load, keep in the user's local storage. Declared with Define.Document(nameof(X)) inside Build().

public readonly struct Document
Expand Details ...

Examples

Career = Define.Document(nameof(Career)).Field(nameof(BestWave), BestWave);
On.Ready(Progress.Load(Career).As(LoadingCareer));
On.FrameUpdate(If(Career.IsDirty).Then(SaveHint.Set("Unsaved progress")));

Remarks

The four observations are conditions on the object that runs the script: IsDirty, Unsynced, HasOmissions and Omitted(field). Each is built inside Build(), from the handle the same build declared. docs/proposals/local-documents.md is the contract.

Properties

HasOmissions

True when the last successful load omitted at least one declared field, because the stored document lacked it or held a value the field cannot hold. Omitted fields keep their values.

public ConditionBlock HasOmissions { get; }

public bool IsDeclared { get; }

IsDirty

True when a field holds a value other than the one the last successful save wrote or the last successful load read, or when the last load omitted a field. Before any save or load, each field is compared with its declared starting value.

public ConditionBlock IsDirty { get; }

Property Value

ConditionBlock

Unsynced

True when this object has saved the document or loaded a stored copy of it, and no cloud upload has confirmed that copy. This version uploads no document, so nothing clears it.
