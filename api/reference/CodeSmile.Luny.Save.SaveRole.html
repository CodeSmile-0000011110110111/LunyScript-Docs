Class SaveRole

Namespace
CodeSmile.Luny.Save

One role of a SaveGroupSchema: a name, the SaveSchema of its documents, and how many it holds. Declare each role once, in a static readonly field, and pass that object to the group schema and to every Set(SaveRole, SaveDocument) and TryGet(SaveRole, out SaveDocument).

public sealed class SaveRole
Expand Details ...
Inheritance
object
SaveRole

Examples

static readonly SaveRole World = SaveRole.Single("World", WorldSchema);
static readonly SaveRole Players = SaveRole.Keyed("Players", PlayerSchema);
static readonly SaveGroupSchema Slot = new SaveGroupSchema("arena.slot", World, Players);

Remarks

The role's name is the name of its documents in the archive, so keep it when the C# is renamed. A keyed role's key is 1 to 128 letters, digits, dashes, underscores and dots, case sensitive.
