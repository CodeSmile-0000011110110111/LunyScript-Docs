What Define.Overlaps(name) returns: a declaration that takes the project's default capacity, or states its own with Capacity(int, string, int).

public readonly struct OverlapsDefineBuilder
Expand Details ...

Examples

Nearby = Define.Overlaps(nameof(Nearby));
Crowd = Define.Overlaps(nameof(Crowd)).Capacity(32);

Remarks

The default capacity is the project setting Collision result capacity, 8 unless Edit, Project Settings, LunyScript changes it, as the runner that builds the script captured it.
