What an asset-load backend provides to AssetGateway: one load of a provider-qualified key, returned as an operation the gateway polls once per frame. Script code never sees this type; it sees Asset.Load and When.Operation.

public interface IAssetLoadProvider
Expand Details ...

Examples

runner.AssetGateway.UseProvider(new FakeAssetLoadProvider());

Remarks

Two implementations exist. FakeAssetLoadProvider is an in-memory table for tests, the same role FileCloudSaveProvider has for Cloud Save. ResourcesAssetLoadProvider reads Unity Resources folders behind the start boundary. Bound Inspector loads do not use a provider: the object is already on the instance.
