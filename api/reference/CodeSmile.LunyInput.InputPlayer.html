One player of a LocalInput: whether somebody holds the index, their actions as typed handles, leaving, and their binding overrides. A view that allocates nothing, so reading it every frame is free.

public readonly struct InputPlayer
Expand Details ...

Examples

var player = input.Player(1);
var move = player.Vector2("Move");
if (player.IsPresent) transform.position += (Vector3)move.Value * Time.deltaTime;

Remarks

Find each action once, in Awake or Start, and keep the handle: a find compares the name with every action of the asset, and a handle's reads ask no device. Finding the same action again returns the same handle. With players a LocalInput pairs, every index has its actions from the start, so a handle found before anybody paired starts reading the moment somebody does.

Identity

The identity of the person on this index, or 0 for nobody.

public long Identity { get; }

Property Value

long

Examples

if (player.Identity != m_LastIdentity) Respawn();

Remarks

It changes when a different person takes the index, and stays the same when the same person's device is lost and regained. No two people get the same identity from one LocalInput. It is the InputUser id with players a LocalInput pairs or PlayerInput components, and 1 for player 0 of the one-player setup.

Remarks

The player keeps the index and the Identity while the device is lost. The next press on a device nobody holds goes to them first, whether it is the same device plugged back in or another one, and with pairing open or closed.
