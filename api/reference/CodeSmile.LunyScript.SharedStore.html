The identity of one shared-variable store: the default store, or a named one such as the current level.

public readonly struct SharedStore
Expand Details ...

Examples

public const String CurrentLevel = nameof(CurrentLevel);
LevelKills = Define.Number(nameof(LevelKills), 0).Shared(CurrentLevel);

Remarks

A store is a category, not a required token on every shared value. .Shared() with no argument is the default store. .Shared(CurrentLevel) names this identity, usually from a const String.
