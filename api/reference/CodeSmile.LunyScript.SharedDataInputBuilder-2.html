What Bind.Data(schema).Shared() returns: one copy of the schema on a shared store, complete once it is assigned or named.

public readonly struct SharedDataInputBuilder<TValue, THandle> where TValue : struct where THandle : struct, ILunyScriptDataVariables

Type Parameters

Expand Details ...

Examples

LootTuning = Bind.Data(LootStats.Schema).Shared();
On.Ready(Gold.Set(LootTuning.GoldWeight));

Remarks

Every script that declares the same name on the same store reads and writes one set of variables, such as LootTuning.GoldWeight. Each object shows the Inspector field; the first that spawns with an asset assigned fills the copy, the others may leave it empty, and one whose asset holds other values is refused. docs/proposals/custom-data-and-file-inputs.md, "One shared copy of a data asset", is the contract.

As(string)

Declares the shared copy under an explicit name, which a hand-written property or a local needs. Every script that shares the copy names it the same.

Exceptions

LunyScriptUsageException

The name is empty or taken, this declaration was used already, a field of the schema is of a kind a shared store does not hold, or another script shares the name with another schema.
