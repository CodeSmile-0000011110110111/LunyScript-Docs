Struct CloudFactory

Namespace
CodeSmile.LunyScript

The Cloud surface inside Build(): uploads a declared document to the signed-in player's Cloud Save data, downloads it back, and deletes the cloud copy. Each start is one attempt on an operation handle, bound with .As(handle), which is required; the outcome arrives through When.Cloud(handle) and When.Operation(handle). AGENTS.md rule 50.

Examples

On.Ready(Cloud.Load(Career).As(Downloading));
On.Message(RunEnded, Cloud.Save(Career).As(Uploading));

Remarks

A document is one stored value under its name, the layout Progress writes. Requests for one document run one at a time in the order their blocks ran; LunyScript sets no deadline, because the provider owns the timing. Sign-in is the gateway's job, not the script's: the first request starts it, and requests made before the service is ready are queued, not thrown; AGENTS.md rule 51. docs/proposals/cloud-documents.md is the contract.

Delete(Document, string, int)

Starts deleting the document's cloud copy. The attempt succeeds when no copy is left, whether or not one existed. The fields and the local copy are not touched.

Load(Document, string, int)

Starts downloading the document. A copy at an older version is migrated first; then every field it holds is written together and the attempt succeeds. The local copy is not rewritten. A document never uploaded fails as NotFound, and every field keeps its value.

Save(Document, string, int)

Starts uploading the document: every field's value when the block runs, stored as one value that replaces the cloud copy. A document can be saved locally as well; the upload does not change IsDirty, and once the cloud confirms it, Unsynced is false unless a field was edited since the block ran.
