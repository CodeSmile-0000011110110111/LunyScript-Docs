Struct CloudFactory

The Cloud surface inside Build(): builds the start blocks for Cloud Save. A start block enqueues and returns in the same call; the outcome arrives through When.Cloud(key). AGENTS.md rule 50.

public readonly struct CloudFactory

Examples

On.Ready(Cloud.Load("progress"));
When.Cloud("progress").Loaded(progress, Cloud.Save("progress", progress + 1.0));

Remarks

Sign-in is the gateway's job, not the script's: the first request starts it, and requests made before the service is ready are queued, not thrown; AGENTS.md rule 51. Values are Number in this version; docs/proposals/slice-transform-and-cloud.md states the surface and what it defers.

Load(string, string, int)

Builds a block that starts loading a key's value. The value arrives through When.Cloud(key).Loaded(into, ...); a missing key fails as NotFound through When.Cloud(key).Failed.

Save(string, NumberValueBlock, string, int)

Builds a block that starts saving a value under a key.

public Block Save(string key, NumberValueBlock value, string callerFilePath = null, int callerLineNumber = 0)

Parameters

key string

The key. Validated here, at build time.

value NumberValueBlock

The value to store, evaluated each time the block runs, so saving a variable saves what it holds at that moment.

callerFilePath string

Supplied by the compiler. It records the line this block was written on, so a later failure names that line rather than LunyScript's own source.

callerLineNumber int

Supplied by the compiler.

Returns

Block

A block to place in an event list.

Examples

When.Var(score).Changed(Cloud.Save("score", score));

Exceptions

LunyScriptUsageException

key is null or whitespace, or value is null.
