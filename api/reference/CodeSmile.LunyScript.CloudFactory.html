The Cloud surface inside Build(). It carries the build in progress and nothing else: LunyCloud's LunyScript adapter, CodeSmile.Luny.Cloud.LunyScriptAdapter, adds the verbs Save, Load, Delete and CommitIs as extension methods in this namespace, so a script writes Cloud.Save(Career).As(Uploading) with no using line. Remarks

The surface stays in the core so the spelling stays where scripts already read it; the cloud work, from the block to the backend, is in Assets/CodeSmile/LunyCloud. docs/proposals/lunycloud.md L01 records the decision. An assembly definition whose scripts call a verb of this surface, of AccountFactory or of LeaderboardFactory references CodeSmile.Luny.Cloud.LunyScriptAdapter; without that reference the compiler reports CS1061 on Cloud.Save. Scripts outside an assembly definition see the adapter, which is auto-referenced.
