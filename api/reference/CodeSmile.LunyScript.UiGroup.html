BindEnabled(ConditionBlock, string, int)

Keeps this group enabled while enabled is true and disabled while it is false. The element is written once it resolves, and again on each frame where the condition's value changed. A bind is declared once in Build() and never placed in an event.

public void BindEnabled(ConditionBlock enabled, string callerFilePath = null, int callerLineNumber = 0)
