Remarks

A save copies the document's values when it is accepted, so changing the document afterwards changes nothing it stores. On an idle path it has ended when the call returns; behind a request that waits, such as a script's save of the same file in the next frame, it is Pending and runs by itself once that request ended. A save writes a complete copy beside the file, flushes it and replaces the file in one rename, so a failed save leaves the previous copy as it was.
