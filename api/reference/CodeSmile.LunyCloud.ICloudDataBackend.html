LunyScript API Reference

Interface ICloudDataBackend

Namespace
CodeSmile.LunyCloud
Assembly
ApiSource.dll

The data service a backend provides: JSON values under player data keys, read-only game data items, and player files. Every address the client passes has a key that follows CloudKeys, and every call is made on the main thread for a signed-in account.

public interface ICloudDataBackend
Expand Details ...

Examples

var call = backend.SaveData(CloudAddress.PlayerData("Career"), "{\"Best\":12}");

Remarks

A value is one JSON text per key, the settled answer "one stored value for the whole document"; a backend stores and returns it and never reads its fields. Keys are case sensitive.
