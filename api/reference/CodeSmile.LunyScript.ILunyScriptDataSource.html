Interface ILunyScriptDataSource

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What the generator implements on a class that carries LunyScriptDataFieldAttribute fields, so that a data input copies them without reflection.

public interface ILunyScriptDataSource
Expand Details ...

Examples

var read = source.ReadNumber("SomeValue", out var value);

Remarks

The Inspector assigns such an object to a Bind.Data or Bind.Number().FromDataField input; each object running the script copies the values into its own variables when it spawns.
