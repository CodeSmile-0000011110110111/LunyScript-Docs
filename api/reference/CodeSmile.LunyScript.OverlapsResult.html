Every collider one overlap found, up to a capacity: what Define.Overlaps declares and an overlap's Into(overlaps) writes.

public readonly struct OverlapsResult
Expand Details ...

Examples

Nearby = Define.Overlaps(nameof(Nearby));
On.FixedUpdate(Collision.SphereOverlap().Radius(5).InLocalSpace().Into(Nearby));
On.Update(Alert.Set(Nearby.Count > 0));

Remarks

An entry is a collider with no contact point, normal or travel, so it has WorldPosition only. When more colliders qualify than the capacity holds, Overflowed is true and the kept ones are in Unity's order, not the nearest. Entries are read the two ways a Define.List is read: ForEach(overlaps).Do(entry => ...) and At(NumberValueBlock, string, int). Each object running the script holds its own result, emptied by an overlap that finds nothing and by a pooled respawn. docs/proposals/collision-queries.md is the family.
