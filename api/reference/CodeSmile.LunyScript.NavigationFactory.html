Struct NavigationFactory

CodeSmile.LunyScript

The Navigation surface inside Build(): moves an actor along a route around obstacles, holds and stops it, and reads the route, the movement and where a move ended.

public readonly struct NavigationFactory
Expand Details ...

Examples

On.Ready(Navigation.MoveTo(Post).As(Patrol));
On.FrameUpdate(Navigation.MoveTo(PlayerPosition).As(Chase));
When.Operation(Chase).Succeeded(If(Navigation.Arrived(Chase)).Then(Attack.Set(true)));
On.Message(Stun, Navigation.Pause());

Remarks

Navigation is not Motion. Motion.MoveTo steps in a straight line and stops at the first wall; Navigation.MoveTo asks the installed navigation backend for a route and the actor's agent follows it. Speed, acceleration and stopping distance stay on the agent.

Each move is an attempt on an operation handle. The destination is read once, when the block runs; a chase is a MoveTo the author runs again. A repeat of the pending request coalesces; any other MoveTo on a pending handle ends that attempt as cancelled and starts the next one. A partial route is followed to its reachable end unless RequireComplete() is written. docs/proposals/navigation.md is the family.
