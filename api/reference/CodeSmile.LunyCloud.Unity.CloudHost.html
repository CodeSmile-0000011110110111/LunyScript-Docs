Class CloudHost

Namespace
CodeSmile.LunyCloud.Unity
Assembly
ApiSource.dll

A scene component that owns one CloudClient for C# with no script: it names the supplied Unity backends and a score queue file when the client is first read, and ticks the client every frame. A game that runs LunyScript scripts reads the default runner's client through CloudGateway instead, which the runner ticks.
