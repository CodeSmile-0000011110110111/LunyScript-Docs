Remarks

.NET 10 seam. The implementation today writes into a fixed-capacity Unity.Collections.FixedString, because FixedString64Bytes.Append(Int32) formats digits into a stack buffer and allocates nothing. The .NET 10 counterparts are System.ISpanFormattable, System.Text.Unicode.Utf8.TryWrite and String.Create, none of which is usable while .NET Standard 2.1 is a target. Replacing: String.Format, System.Text.StringBuilder, string interpolation, Int32.ToString() on the run-time path.

Fixed-capacity text still writes FixedString slots directly. AllocatingTextSink is the consumer of this interface: a text variable declared with allocating storage writes through it.
