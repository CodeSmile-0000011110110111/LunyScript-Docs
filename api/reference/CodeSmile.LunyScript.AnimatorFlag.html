A handle to one Bool parameter of the Animator on the object a script runs on. Returned by Animator.Flag(name) at build time. The product word for Unity's Bool is Flag.

public readonly struct AnimatorFlag
Expand Details ...

Examples

var grounded = Animator.Flag("Grounded");
On.FrameUpdate(grounded.Set(Grounded));
On.FrameUpdate(If(grounded).Then(AirTime.Set(0.0)));

Remarks

The handle converts to a condition, so If(grounded) compiles the way If(Alive) does for a Flag variable. It does not convert to a C# bool: if (grounded) does not compile, and if (grounded.IsTrue()) throws, AGENTS.md rule 38.
