Struct TextSlot

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Where one text variable lives on every instance of a program, and how many bytes it holds. The capacity is part of the handle because each capacity is a separate array on the instance.

public readonly struct TextSlot

Examples

var playerName = Var.DefineText("playerName", TextCapacity.Bytes64);
