One group of a phase as C# writes it: what it spawns (a prefab binding key), where (a placement binding key), how many for one to four participants, and its timing. From(RecipeSpec) validates it with the rest of the recipe.

Remarks

Keys are resolved by the host when a run starts: the prefab key names a prefab binding and the placement key a marker or area in the scene. A finite group spawns one cohort; a repeat group spawns one batch per interval until it is stopped, and needs a positive interval, a live cap and a stop (a signal, the end of a source group, or a phase bounded by elapsed time).
