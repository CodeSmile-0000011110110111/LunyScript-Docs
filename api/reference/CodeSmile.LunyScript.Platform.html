LunyScript API Reference

Namespace CodeSmile.LunyScript.Platform

Classes

AllocatingTextSink

The runtime ITextSink for a text variable declared with allocating storage: a bounded UTF-8 buffer on the heap, allowed to allocate when the content changes and not when the same content is written again.

GameClockRules

What a time scale is allowed to be, and the one refusal message every caller that checks it raises.

UnityTimeSource

The time source a running game uses: Unity's own frame clock, read once per call from UnityEngine.Time, with Unity's Time.timeScale as the game's time scale.

Structs

XorshiftRandomSource

The runtime IRandomSource: an explicit-state xorshift32 generator whose sequence is a function of its seed alone.

Interfaces

IAsyncOperation

One in-flight request owned by the services gateway. Script code never sees this type; it sees a status variable and an outcome event. This interface exists so that the gateway has exactly one place that knows how asynchronous work is represented.

IDocumentCodec

The only place LunyScript converts between a saved document and the values in a script's variable slots. The cloud-save provider and any future file provider both go through it.

IGameClock

A clock that drives a running game, so it carries the game's time scale and can be paused as well as read. Time.Scale, Time.IsPaused, Time.SetScale, Time.Pause and Time.Resume reach the clock through this interface.

IRandomSource

The only place LunyScript draws a random number. A script's randomness is seeded per run so that a failing test can be replayed with the seed it printed.

ITextSink

The only place LunyScript turns a value into text. A text variable writes through this interface, so no block formats a managed string of its own.

ITimeSource

The only place LunyScript reads the passage of time. Blocks and the runner take an ITimeSource instead of calling UnityEngine.Time or System.DateTime.UtcNow directly.

Enums

OperationFailure

Every failure a service call can produce, classified once by the gateway so that no script and no block ever sees an exception type. See AGENTS.md section 9.
