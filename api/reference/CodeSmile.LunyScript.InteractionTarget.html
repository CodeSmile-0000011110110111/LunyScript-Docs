Struct InteractionTarget

What Interaction.Target(prompt) returns: this object as a target, whose prepared parts the three clauses name. Each clause is optional and written once.

public readonly struct InteractionTarget
Expand Details ...

Examples

Interaction.Target("Pick up").Volume(Volume).Visual(Visual).Effect(Glow);

Remarks

The target is declared when Interaction.Target is called, so this handle is not a block and is not placed in an event list. Each clause takes a Bind.Object() binding, which the object's Inspector assigns or the Interaction Setup window prepares. docs/proposals/interaction.md is the contract.

Methods

Effect(ObjectBinding, string, int)

Names the prepared child that is active only while at least one player focuses this target, such as a glow, a particle system or a sound that plays when it is enabled. It is deactivated when the object spawns and when the last player stops focusing, which resets what it plays.

Visual(ObjectBinding, string, int)

Names the child the focus style moves while players focus this target: it rises, grows and turns as the object's InteractionStyle asset says, and returns to where it was when nobody focuses it. Adds that InteractionStyle input to the object's Inspector.

Volume(ObjectBinding, string, int)

Names the object whose colliders, and its children's, a focus ray must reach to focus this target, instead of this object's own. A trigger collider there is focusable and blocks nothing.
