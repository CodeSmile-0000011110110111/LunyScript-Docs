Interface IScriptAssetInputs

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The part of a host that carries the assets an author assigned to one object, so that two objects running the same script can hold different assets.

public interface IScriptAssetInputs

Examples

var assigned = (host as IScriptAssetInputs)?.AssignedAsset(nameof(GateScript.OpenSound));

Remarks

It is a second interface rather than a member on IScriptHost for the reason IScriptObjectLifetime is one: a host that carries no assignments answers nothing to every name, and a member every implementation could only answer null to would be a member every implementation has to carry. A host that does not implement this is a host that assigns nothing, which resolves every input to its declared source or its type's asset placeholder rather than failing.

A value is matched to an input by the input's declared name. That is the settled api-asset-inspector-binding-mechanism-identity answer of 2026-09-12: the name is the durable identity, so the order the inputs are declared in can change and a stored value still reaches the same input.

It names no GameObject, Transform or Component, so the type ban of AGENTS.md rule 24 still holds. UnityEngine.Object is what an asset is, and it is what the host component serializes.

Remarks

Called once per declared input when the object spawns, and never afterwards. The caller checks the type, so an implementation returns what it holds rather than testing it.
