One binding whose control path differs from the action asset's: which binding, and the path it uses instead. What ReadOverrides(List<BindingOverride>) lists and ApplyOverrides(IReadOnlyList<BindingOverride>, List<BindingOverride>) applies, so a game can store a player's rebound controls and apply them again later.

public readonly struct BindingOverride
Expand Details ...

Examples

var entry = new BindingOverride("Player/Fire/0c8e0f5a-8f7d-4c1b-9d52-0e4b5f4d8a11", "<Keyboard>/e");

Remarks

The key is map/action/binding-id, and the binding id, the Input System's GUID of the binding, is the part that finds the binding again: an action renamed in the asset keeps its stored overrides.
