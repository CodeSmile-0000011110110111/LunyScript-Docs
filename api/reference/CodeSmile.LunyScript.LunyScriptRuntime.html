Remarks

This is the one mutable static in the runtime core, and it carries the attribute that resets it. AGENTS.md rule 17 forbids mutable static state and rule 18 names [AutoStaticsCleanup] as the mechanism for the unavoidable one: with domain reload disabled, a static keeps its value from the previous Play session, and this attribute is what puts it back. Gate 3 in docs/gates.md measured the attribute working on this editor version.

The type is partial because Unity's code generator emits a second partial declaration holding the generated reset method; a non-partial declaration fails to compile with error CS0260.

A test that wants its own runner creates one directly with new ScriptRunner() and never touches this type. Nothing here is needed to run blocks.

Reset()

Drops the default runner and destroys its driver object, so the next caller gets a fresh runner. A test calls this between cases; the driver calls NotifyDriverDestroyed(LunyScriptDriverBehaviour) rather than this, so that destroying an old driver cannot drop a runner created after it.
