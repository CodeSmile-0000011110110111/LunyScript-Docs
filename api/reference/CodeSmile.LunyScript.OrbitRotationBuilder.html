What RotateAround(point).By(rotation) returns: the orbit, waiting for the one thing a caller has to say about it.

public readonly struct OrbitRotationBuilder

Examples

On.FrameUpdate(Transform.RotateAround(0.0, 0.0, 0.0).By(0.0, 1.0, 0.0).KeepRotation());

Remarks

This builder converts to no block. An orbit that moves the object and an orbit that also turns it are two different behaviours, and the captain's answer to API-semantics row T05 on 2026-09-13 is that the caller names which one; AGENTS.md rules 41 and 42.
