Enum SaveFailure

Namespace
CodeSmile.Luny.Save
Assembly
ApiSource.dll

Why a LunySave request was refused: the code of its SaveRefusal. None while the request is pending and after it succeeded.

public enum SaveFailure : byte
Expand Details ...

Fields

Canceled = 8

The owner of the request was destroyed while the request waited, so it ended without running.

Ended = 7

The owner of the slot was destroyed before the request was made, so the slot no longer saves or loads. Acquire the path again with a living owner.

Incomplete = 9

A group load found the archive without a member its schema requires.

None = 0

Pending, or succeeded.

NotFound = 1

No document or group is stored at the path: the first load of a new game.

Timeout = 5

A packaged load did not end within its 30 seconds of real time.

Unavailable = 6

The location cannot be used: a folder on the path is a symbolic link or another reparse point, or the file system denies access to it. The stored copy, if any, is unchanged.

Unknown = 4

The file system failed in a way LunySave cannot classify, such as a full disk, a file another program holds open or a folder in a document's place. Message carries the system's own message.

Unreadable = 2

The stored bytes are not a readable document or group: not UTF-8, not JSON, not the document layout, or an archive whose members do not match its manifest.

Unsupported = 3

The stored copy is of another schema, of a newer version than the schema's, of format 1 when the schema does not read format 1, no migration step starts from the stored version, a step rejected the document or threw, or the migrated document lacks a declared field.

Examples

if (loading.Refusal.Code == SaveFailure.NotFound) StartNewGame();
