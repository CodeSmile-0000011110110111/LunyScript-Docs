Struct BehaviorTree

Namespace
CodeSmile.LunyScript

A declared behaviour tree. Start(string, int) starts or restarts one activation, Stop(string, int) interrupts it, and four conditions read what it reached.

public readonly struct BehaviorTree
Expand Details ...

Examples

var open = Behavior("Open").Root(InOrder(Check(HasKey), Task(Opening.Set(true))).UntilOneFails());
On.Message(Use, open.Start());
On.Update(If(open.Failed).Then(Locked.Set(true)));

Remarks

The runner advances an active tree once per frame, after the object's On.Update blocks, state machines, routines, Run work and Choose selectors. The root descends through immediate work in one advance, so a tree of Checks and immediate Tasks finishes in the advance that starts it. When the root finishes, the activation ends and its result is kept until the next Start: a finished tree does not start again by itself.

The handle keeps its build directly and holds no CodeSmile.LunyScript.BuilderLease; only an unfinished builder step holds one. A tree is a declared handle: Start() placed in two event lists starts the one tree.

Properties

Failed

A condition that is true once the last activation's root finished Failed, until the next Start. It is false before the first Start, while an activation runs, and after a Stop that interrupted one.

IsActive

A condition that is true while an activation of this tree is running: from Start until the root finishes or a Stop interrupts it.

public ConditionBlock IsActive { get; }

Property Value

ConditionBlock

Examples

On.Update(If(PlayerNear & !greet.IsActive).Then(greet.Start()));

Remarks

It reads the same state as Running. With one explicit Start per activation, a tree is active exactly while its root's work is pending.

Methods

Start(string, int)

The block that starts one activation of this tree. An activation that is running is interrupted first, its running nodes each doing their own cleanup, and a kept result is cleared. The tree is first advanced in the frame's tree pass, which follows On.Update.

Stop(string, int)

The block that interrupts an activation of this tree. Its running nodes each do their own cleanup and the tree is left without a result. A tree that finished keeps its result, and one that is not active is left as it is.
