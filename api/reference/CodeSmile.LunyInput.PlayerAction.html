One player's action, found by name in the action asset: whether it is pressed, the phases it received in the frame that is running, the control it is bound to, and its rebinding. ButtonAction, NumberAction, Vector2Action and Vector3Action add the value.

Remarks

Every read allocates nothing and asks no device. It returns what the action last received, recorded while the Input System processed input, so FixedUpdate and Update read the same.

The three phases are the action's own, as its interactions report them: a button starts and performs on the press and cancels on the release, a Hold interaction starts on the press and performs when the hold time is reached, a stick starts when it leaves rest and performs on every change, and a pass-through action only performs. PerformedThisFrame is true during the whole frame in which the Input System processed the phase, in FixedUpdate, Update and LateUpdate, whether input is processed before each frame or before each fixed step, and false in every later frame. A press and a release in one frame make all three true in that frame.

After the LocalInput is disposed, or after the action's asset was destroyed, every read returns the resting value and no phase.

Rebind()

Starts listening for the control that becomes this action's binding. The next control the player presses replaces every binding of the action; Escape cancels.

Remarks

The action reads nothing while the capture listens, and the capture ends by itself; read its Status. A composite action, such as a 2D vector of four keys, is rebound one part at a time through Part(string), and its own capture ends at once as Composite. One player rebinds one control at a time.
