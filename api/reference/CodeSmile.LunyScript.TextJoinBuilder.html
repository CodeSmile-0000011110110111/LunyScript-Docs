What Text.Join(separator) returns. Its only member is Part, so a join with no part does not compile where a text is expected.

public readonly struct TextJoinBuilder
Expand Details ...

Examples

On.Update(Augments.Set(Text.Join(", ").Part(RingVolley, "Ring volley").Part(MineLayer, "Mine layer").Else("none")));

Remarks

The two join builders are a typestate: Text.Join(...) offers only Part, and TextJoinPartBuilder offers Part, Else and the conversion to a TextFormat. Collapsing them into one type would turn a join with no part from a compiler error into a text that is always empty; AGENTS.md rule 41.

Both carry the build lease Text.Join opens, which Else and the conversion to a TextFormat close, so a join started and never finished is refused when Build() ends, naming its line, and one written as a statement is error LUNY004. A join is therefore started while a script's Build() runs; AGENTS.md rule 42.
