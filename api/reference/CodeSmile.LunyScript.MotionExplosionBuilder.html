Methods

Upwards(NumberValueBlock, string, int)

Measures the push direction from a point this many world units below the centre, so the body is thrown upward as well as outward. The centre and the radius stay where they are, so this changes which way the body is pushed and not whether it is. Unity's upwardsModifier; without this clause it is 0.
