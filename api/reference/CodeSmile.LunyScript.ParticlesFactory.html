Struct ParticlesFactory

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The Particles surface inside Build(): starts, pauses, stops, clears and bursts an authored Unity ParticleSystem, and reads whether it is playing or alive. Its own members target the system on the object the script runs on; For(AssetInput, string, int) targets the system on a declared GameObject input.

public readonly struct ParticlesFactory
Expand Details ...

Examples

On.Ready(Particles.Play());
When.Input(fire).Performed(Particles.For(MuzzleFlash).Emit(12));
On.Disabled(Particles.Stop().AndClear());

Remarks

Unity owns the effect: modules, sub-emitters, renderer and the look stay on the component, and playOnAwake is authored there. A target with no ParticleSystem is reported once per script type and declaration, and the object still runs. This family does not drive a Visual Effect Graph. docs/proposals/particles.md is the family.

Properties

IsAlive

Whether the ParticleSystem on this object or a child still has particles or will produce more, which is Unity IsAlive(true). This is the completion test: after Stop() it stays true until the last particle dies.

public ConditionBlock IsAlive { get; }

IsPlaying

Whether the ParticleSystem on this object is playing, which is Unity isPlaying. False while it is paused, after its last particle died, and when the object has no ParticleSystem.
