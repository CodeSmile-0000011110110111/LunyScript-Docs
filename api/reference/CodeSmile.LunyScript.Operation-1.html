Struct Operation<T>

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

A typed operation handle. The attempt, generation, deadline and classified outcome are the same surface as Operation. A typed payload is filled by a later family that owns the result type.

public readonly struct Operation<T>

Type Parameters

T

The result type a later family stores on success.
