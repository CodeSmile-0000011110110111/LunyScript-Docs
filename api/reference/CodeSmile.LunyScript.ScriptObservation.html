One C# observation of one variable of one script incarnation, returned by Observe(in Number, Action<double>) and its siblings. The caller owns it and ends it with Dispose().

Remarks

This is the settled contract-instance-access observation: it has an explicit disposable owner and ends on target invalidation. It ends by itself when the observed incarnation ends, when its callback is a method of a Unity object that has been destroyed, and when its callback throws, which is reported once. The runner checks it once per frame, after every script's On.LateUpdate, and calls the callback only when the value differs from the previous check. The check allocates nothing.
