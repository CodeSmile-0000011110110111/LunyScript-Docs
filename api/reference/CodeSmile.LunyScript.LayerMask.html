A set of the project's layers that a Collision query searches: what Define.LayerMask makes and a query's Layers(mask) takes.

public readonly struct LayerMask
Expand Details ...

Examples

var water = Define.LayerMask("Water");
var props = Define.LayerMask(8, 9);
On.FixedUpdate(Collision.SphereOverlap().Radius(5).InLocalSpace().Layers(water).Into(Nearby));

Remarks

The name is Unity's, and the namespace is LunyScript's, as for Vector3: inside a script, LayerMask is this type. It holds the layer bits the names or indices stood for when the script type was built, so no query reads a layer name while the game runs. A default value names no layer and a query refuses it.
