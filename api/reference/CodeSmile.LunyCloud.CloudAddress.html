A typed place a request reads or writes: a key in the player's data, an item of the game's published data, a player file or a leaderboard. Requests for one address run one at a time in the order they were made; requests for different addresses do not wait for each other. Keys are case sensitive.

public readonly struct CloudAddress
Expand Details ...

Examples

var slot = CloudAddress.PlayerData("SlotTwo");

Remarks

The settled answer C04 A: distinct player-document, game-item and file sources under common verbs. A game data address is read only to the client, so CloudData.Save and Delete(in CloudAddress) refuse it.
