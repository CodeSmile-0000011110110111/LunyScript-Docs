What the compiler was told when this assembly was built. Read by tests and by the release gate, so that a claim about release behaviour can name the compilation it was measured in.

public static class CompilationFacts
Expand Details ...
Inheritance
object
CompilationFacts

Examples

LunyScriptLog.Info(LunyScriptLogAreas.Core, $"DEBUG defined: {CompilationFacts.DebugDefined}");

Remarks

Unity defines DEBUG in the Editor and in every development player, and the Test Runner's Player mode builds a development player. A player built without BuildOptions.Development is therefore the only compilation this project can produce where DEBUG is absent, which is what the release gate builds.
