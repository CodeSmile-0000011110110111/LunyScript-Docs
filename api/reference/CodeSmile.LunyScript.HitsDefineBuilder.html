Struct HitsDefineBuilder

What Define.Hits(name) returns: a declaration that takes the project's default capacity, or states its own with Capacity(int, string, int).

public readonly struct HitsDefineBuilder
Expand Details ...

Examples

Pierced = Define.Hits(nameof(Pierced));
Walls = Define.Hits(nameof(Walls)).Capacity(16);

Remarks

The default capacity is the project setting Collision result capacity, 8 unless Edit, Project Settings, LunyScript changes it, as the runner that builds the script captured it.
