On.Authority: the two events a script gets when this peer starts or stops being the one that may write the object's synchronised variables.

public readonly struct OnAuthorityFactory
Expand Details ...

Examples

On.Authority.Gained(isReady.Set(false));
On.Authority.Lost(chargeLevel.Set(0.0));

Remarks

Authority is never hidden, and these are how a script reacts to it changing rather than polling for it. AGENTS.md rule 45. The runner raises them when the answer it refreshes at the top of each tick differs from the previous tick's, so an object that is spawned with authority gets Gained(params Block[]) on its first networked tick, and one whose session ends gets Lost(params Block[]).

Nothing in this milestone transfers authority at run time. These events exist so that a script written now is written against the change rather than against a value that happens not to move yet; the API that requests a transfer is a later proposal.
