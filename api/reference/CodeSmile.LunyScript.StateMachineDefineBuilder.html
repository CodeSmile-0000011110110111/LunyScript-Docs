Struct StateMachineDefineBuilder

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What Define.StateMachine(name) returns. Its one call, WithStates, names the machine's states and returns the machine and the states together, so one line declares all of them.

public readonly struct StateMachineDefineBuilder
Expand Details ...

Examples

(Phases, Calm, Angry, Defeated) = Define.StateMachine(nameof(Phases))
    .WithStates(nameof(Calm), nameof(Angry), nameof(Defeated));

Remarks

A state exists only in the machine that declared it, so the states are declared on the machine's own line. The line assigns a tuple, and the generator writes one property per name: StateMachine Phases and a State for each state. WithStates takes one to sixteen names, one overload per count, so a line whose names and handles differ in number does not compile.
