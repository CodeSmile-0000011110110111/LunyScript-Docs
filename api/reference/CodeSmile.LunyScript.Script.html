Examples

public sealed partial class CountdownScript : Script
{
    [Variable(3)] public Var<Number> Health { get; private set; }
    [Variable(true)] public Var<Flag> Alive { get; private set; }
    protected override void Build()
    {
        On.FrameUpdate(If(Alive).Then(Health.Add(-1.0)).Else(Alive.Set(false)));
    }
}

Audio

Plays clips and controls authored Unity audio components. It hides UnityEngine.AudioSource inside a Script the same way Transform hides UnityEngine.Transform. Available only inside Build().

protected AudioFactory Audio { get; }

Property Value

AudioFactory

Examples

On.CollisionEnter(Audio.PlayOneShot(BreakClip));
On.Ready(Audio.For(MotorSource).Play());

Remarks

A one-shot plays on a runner-owned pooled voice. A bound source is the AudioSource already on an object. Mixer writes are a third surface. docs/proposals/audio.md is the family.

Motion

Builds blocks that move a kinematic or CharacterController body, push a dynamic body, or relocate the object. Available only inside Build().

protected MotionFactory Motion { get; }

Property Value

MotionFactory

Examples

On.FixedUpdate(Motion.MoveTo(Pad).AtSpeed(4.0));
On.FixedUpdate(Motion.AddForce(Thrust).InWorldSpace());

Remarks

Motion is not Transform. Transform.MoveBy writes pose immediately, with no physics. Motion.MoveBy is component-directed and refuses a dynamic Rigidbody. Dynamic bodies use AddForce, AddImpulse, SetVelocity and StopMotion. Relocation that is not traversed movement is TeleportTo.

Other

The other collider of the contact event currently running. Available only inside Build(), and the blocks it builds run only inside a contact event.

protected OtherFactory Other { get; }

Property Value

OtherFactory

Examples

On.CollisionEnter(If(Other.HasTag("Player")).Then(Score.Add(1.0)));
On.TriggerStay(HitAt.Set(Other.WorldPosition));

Remarks

The same members exist on all six contact events, because they are properties of the other collider. A read outside those events throws when the block runs. docs/proposals/physics-contact-events.md is the surface.

Sets this script type's default process mode. Inherit, the default, walks the Unity transform parent chain and is Pausable when the walk ends.
