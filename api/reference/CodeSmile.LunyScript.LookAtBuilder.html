What LookAt returns: the facing, about the world up unless WithUp(NumberValueBlock, NumberValueBlock, NumberValueBlock, string, int) names another direction.

public readonly struct LookAtBuilder

Examples

On.FrameUpdate(Transform.LookAt(TargetX, TargetY, TargetZ));

Remarks

The captain's answer to API-semantics row T04 on 2026-09-13: the world up is the default and WithUp overrides it. A point the object already stands on, or a direction to it that is parallel to the up direction, names no rotation, and the block writes nothing rather than inventing one.
