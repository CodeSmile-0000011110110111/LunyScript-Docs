Interface IScriptTrackingTarget

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The one thing a camera needs from the object a script runs on: something it can be told to follow or aim at. A host that can supply one implements this interface.

public interface IScriptTrackingTarget

Examples

var target = host is IScriptTrackingTarget tracked ? tracked.TrackingTarget : null;

Remarks

It is a second interface rather than another member on IScriptHost for the reason IScriptObjectLifetime is one: the scene-free editor host has no scene object to hand a camera, and a member on the main interface would make every host claim it has one. A host that does not implement this refuses the self-targeted camera blocks with a message naming the host, the way a host without IScriptObjectLifetime refuses the Object blocks.

The type is UnityEngine.Object and not a Transform. The core may not name Unity's object model outside GameObjectHost; AGENTS.md rule 24. What the object actually is, and what a camera backend does with it, is the adapter's business.
