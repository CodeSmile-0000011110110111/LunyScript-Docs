The Resources backend for Asset.Load of an AssetSource.Resources key. The read happens inside the provider call, which is a start boundary, and the gateway observes the completed operation on its next poll. Blocks never name UnityEngine.Resources.

Examples

Remarks

Resources.Load without a type is used so a missing key and a type mismatch can be classified separately: nothing under the key is NotFound, something of another type is Denied.
