One row of the declared-input table a host component serializes: the name of a declared input and the asset this object assigns to it, or, for a scene input, the scene.

[Serializable]
public struct AssetInputAssignment
Expand Details ...

Examples

var row = new AssetInputAssignment(nameof(GateScript.OpenSound), clip);

Remarks

The row carries the name and not the declaration's position, because the settled api-asset-inspector-binding-mechanism-identity answer makes the declared name the durable identity. Reordering the declarations in a script therefore keeps every scene's assignments, and renaming one leaves the row addressing a name nothing declares any more.

It is a struct so that the serialized array costs one allocation rather than one per row, and its fields are serialized by name, which is why they are read through NameFieldName and AssetFieldName rather than by a literal written a second time.

A scene input's row stores the scene by path and GUID, not as an object reference. A scene asset is an Editor type that a built player does not carry, so an object reference to one would be empty in the game. The path is what the runner loads by; the GUID is what the Inspector finds the scene asset by after the file was moved.
