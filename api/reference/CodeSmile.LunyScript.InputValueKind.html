Enum InputValueKind

What one input action produces. The four kinds are the ones the accepted design names: Button, Number, Vector2 and Vector3.

public enum InputValueKind
Expand Details ...

Fields

Button = 0

A pressed or not-pressed action, which also carries an analogue press value.

Number = 1

A one-component axis, read as a Number.

Vector2 = 2

A two-component axis pair. Its value is a Vec3 whose third component is zero, because this version has no two-component value type.

Vector3 = 3

A three-component axis triple, read as a Vec3.

Examples

var kind = InputValueKind.Vector2;

Remarks

The kind is part of the declaration, not something read off the backend, which is what makes a mismatch detectable: an action declared Vector2 whose configured action produces a button is refused and reported rather than read as something it is not.
