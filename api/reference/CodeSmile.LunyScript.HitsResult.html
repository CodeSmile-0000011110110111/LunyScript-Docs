Every collider one cast touched, up to a capacity, nearest first: what Define.Hits declares and a cast's Into(hits) writes.

public readonly struct HitsResult
Expand Details ...

Examples

Pierced = Define.Hits(nameof(Pierced)).Capacity(16);
On.FixedUpdate(Collision.RayCast().InLocalSpace().Length(50).Into(Pierced));
On.FrameUpdate(Walls.Set(Pierced.Count));

Remarks

A collider the shape starts inside is an entry at distance 0 whose Point is the cast's start; without ExcludeSelf() a local cast therefore lists this object's own collider first. When more colliders qualify than the capacity holds, Overflowed is true and the nearest ones are kept. Entries are read the two ways a Define.List is read: ForEach(hits).Do(entry => ...) and At(NumberValueBlock, string, int). Each object running the script holds its own result, emptied by a miss and by a pooled respawn. docs/proposals/collision-queries.md is the family.
