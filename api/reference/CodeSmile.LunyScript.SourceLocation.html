Where in a user's script a block was authored: the file and the line of the Build() call that created it.

public readonly struct SourceLocation
Expand Details ...

Examples

// Transform.MoveBy captures the caller's file and line, so this block knows it came from here.
On.FrameUpdate(Transform.MoveBy(0.02, 0, 0));

Remarks

This is captured at build time and never at failure time, because at failure time the user's line is not on the call stack at all. A block is composed inside Build(), which runs once per script type at launch, and is executed later by ScriptRunner; by the moment it logs or throws, the only frames on the stack are LunyScript's own. [CallerFilePath] and [CallerLineNumber] on the block factory methods are what put the authored line into the block, and this struct is what the block holds.

Construction allocates nothing. [CallerFilePath] hands the compiler's own path literal, which lives in the assembly's string table, so this struct stores that reference and an int and does no string work. The project-relative form a user reads is produced by ProjectRelativePath(), which allocates and is called only when a diagnostic is actually produced. That split is what lets every block carry a location without touching the allocation rule; AGENTS.md rule 29.

A block built by a C# operator carries Unknown: an operator cannot declare the optional parameters the caller attributes need. health + 1.0 therefore has no location of its own, and the block that consumes it does.

ProjectRelativePath()

The path with forward slashes and everything above the project's Assets folder removed, which is the form Unity's console resolves to an asset.

public string ProjectRelativePath()

Returns

string

The project-relative path, or an empty string when this location is unknown.

Examples

var path = location.ProjectRelativePath();   // "Assets/CodeSmile/.../SliceScript.cs"

Remarks

This allocates and is not for the run-time path. It runs when a diagnostic is produced, which is a failure path or a log call, never per frame; AGENTS.md rule 29. A path with no Assets segment is returned with its separators normalised and nothing removed, because a package or a test fixture can legitimately live elsewhere.

ToUnityStackFrame(string)

The location written as one Unity stack frame, which is the form Unity's console prints a frame in.

public string ToUnityStackFrame(string frameLabel)

Parameters

Type Name Description
string
frameLabel

What to name the frame, in Unity's Type:Method() shape.

Returns

string

The frame line, or an empty string when this location is unknown.

Examples

var frame = location.ToUnityStackFrame("CountdownScript:Build()");

Remarks

The format is Unity's own, produced by UnityEngine.StackTraceUtility.ExtractFormattedStackTrace: Namespace.Type:Method() (at path:line). Writing the authored location in that format is what lets LunyScriptException present it as the topmost frame, so that the Console prints the user's own line first. It does not move the row's double-click target, which Unity takes from the live call stack at log time; docs/console-navigation.md.
