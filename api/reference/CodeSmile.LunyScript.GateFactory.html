Remarks

Gate.Open(name, categories) and Gate.Close(name) are runtime blocks. A gate suppresses its categories for every script on the runner. Two open gates union their categories. The same name opened twice is a reference count. The script that opened a gate releases its hold when it despawns.

Pause is a separate system. Opening a gate skips no script, and pausing opens no gate.
