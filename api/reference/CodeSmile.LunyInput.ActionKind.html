Enum ActionKind

Namespace
CodeSmile.LunyInput

What a player action produces, which decides how its value is read and which actions of the action asset may be found as it.

public enum ActionKind
Expand Details ...

Fields

Button = 0

A pressed state and an analogue press from 0 to 1; found for an action of type Button or whose expected control type is Button.

Number = 1

One number, 0 at rest; found for an action whose expected control type is Axis or Analog, or a value action that names no control type.

Vector2 = 2

Two components; found for an action whose expected control type is Vector2, Stick or Dpad.

Vector3 = 3

Three components; found for an action whose expected control type is Vector3.

Examples

var lookup = input.Player(0).TryFind("Fire", ActionKind.Button, out var fire);
