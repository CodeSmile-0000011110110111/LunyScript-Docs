Remarks

A load from the player's data folder runs in its path's order and has ended when the call returns on an idle path. A load from StreamingAssets on Android and the web downloads the file and ends in a later frame by itself: nothing has to read it for it to finish, and its download is released when it ends. It fails as Timeout after 30 seconds of real time, and is canceled when its owner is destroyed first.

A load that fails hands back no document. A load that succeeds hands back a SaveDocument holding every field the stored copy could give; Omitted(SaveField) names the others, which hold no value, so the caller's own values for them stay as they were. A record, list or map is loaded whole or omitted whole: one bad value inside it omits the field and OmissionReason(SaveField) names its path, such as "Items[3].Count". A stored copy of an older version is migrated first and must then give every field, or the load fails as Unsupported. A load never writes the stored file.
