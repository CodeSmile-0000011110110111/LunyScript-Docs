Interface ICloudQueueStore

Namespace
CodeSmile.LunyCloud
Assembly
ApiSource.dll

Where the score queue keeps its waiting scores between sessions, so "a Submit that cannot be sent waits in a bounded queue on the device, survives a restart, and is sent later for the same account" (2026-09-09). The client reads it once when it is named and writes the whole queue, a few hundred bytes of JSON, at each change; never per frame.

public interface ICloudQueueStore
Expand Details ...

Examples

cloud.UseQueueStore(new MemoryCloudQueueStore());

Remarks

CloudQueueFile in the Unity layer stores it through LunySave under the player's data folder; MemoryCloudQueueStore keeps it for one session, which is what a client without a store uses.
