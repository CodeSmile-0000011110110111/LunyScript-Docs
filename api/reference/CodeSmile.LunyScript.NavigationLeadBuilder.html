Struct NavigationLeadBuilder

CodeSmile.LunyScript

What Navigation.Lead(follower) returns: a lead along a route, incomplete until To(Vector3ValueBlock, string, int) names the destination, then WithinDistance and As.

public readonly struct NavigationLeadBuilder
Expand Details ...

Examples

On.Ready(Navigation.Lead(Follower).To(Exit).WithinDistance(6).As(Escort));

Remarks

A chain that no As finishes is refused when Build() finishes, naming the builder type and the authored line.
