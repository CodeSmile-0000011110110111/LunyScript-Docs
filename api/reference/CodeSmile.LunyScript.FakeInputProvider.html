An input backend that holds its actions and their values in memory, with no device, no window and no Input System package.

public sealed class FakeInputProvider : IInputProvider

object

Examples

var provider = new FakeInputProvider();
provider.AddAction(0, "Fire", InputValueKind.Button);
provider.Raise(0, "Fire", InputPhase.Performed);

Remarks

This is a second real implementation rather than a test mock, in the same way FakeNetworkProvider is: it answers every member of IInputProvider with the same rules the Input System adapter answers them with, which is what makes the input tests runnable in Edit Mode and what lets a project without the package still run a script that reads input.

A test configures it the way an action asset is configured - name the actions and their kinds - and then drives them: SetNumber(int, string, double), SetVector(int, string, double, double, double) and SetPressed(int, string, bool) write what an action holds, and Raise(int, string, InputPhase) marks an occurrence as having happened. EndFrame() clears the occurrences, which is what a real backend's next frame does.
