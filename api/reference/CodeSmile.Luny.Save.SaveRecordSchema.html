What one record holds: a name for messages and the fields every record of it holds. A record has no version of its own; the version of the document that holds it covers it. A Record(SaveRecordSchema) kind, a Record(string, SaveRecordSchema) field and a list or map of records use it.

Examples

static readonly SaveField<String> ItemId = SaveField.Text("Id", 64);
static readonly SaveField<Int64> Count = SaveField.Int64("Count");
static readonly SaveRecordSchema Item = new SaveRecordSchema("Item", ItemId, Count);

Remarks

Every declared field of a record holds a value when the document is saved. An optional field holds None. A load admits a record only when every declared field is present and holds a value of its kind; members the record does not declare are skipped.
