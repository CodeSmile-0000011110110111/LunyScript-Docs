Struct OwnedObject

A declared owned object: one slot on every instance of the script that holds an object the instance produced, with Object.Create(handle), Object.Create(prefab).Into(handle) or Object.Spawn(pool).Into(handle), and that the rest of the Object surface addresses.

public readonly struct OwnedObject
Expand Details ...

Examples

Shield = Define.Object();
On.Ready(Object.Create(Shield));
On.Disabled(Object.Deactivate(Shield));

Remarks

Shield = Define.Object(); declares one. The slot starts empty. The instance that produced its object owns it: Object.Activate, Deactivate, Destroy and, for a pooled object, Despawn take the handle, and the object ends with the instance unless its chain wrote SurvivesCaller(). A scene object a script binds with Bind.Object() is an ObjectBinding, which those calls do not take, because the script borrows that object and does not own it. docs/proposals/declared-identity-handles.md is the contract.
