Class SpawnCombatant

The Combat side of a spawned object: every use admits a fresh life in the scene's CodeSmile.LunyCombat.Unity.CombatHost scope, also when the object is a pooled copy used again (the captain's Q13 answer: a fresh Combat life for every reused combatant), and a committed defeat ends the use at the next spawn boundary, which releases the object (Q39: end on defeat). The life ends with the use when it is still alive, such as when its phase ends its survivors.

Remarks

The profile is the binding's profile text when it names one, so a tier binding can give a stronger profile to the same prefab (Q47), and this component's own profile otherwise. A missing scope or an unknown profile refuses the use, which the session records as IntegrationRefused, and logs one error per component.

A defeat is the scope's committed CodeSmile.LunyCombat.Defeat of this life; a life another caller ends is no defeat, and the member stays until its object ends. Reading the life each frame allocates nothing.

Use it instead of CodeSmile.LunyCombat.Unity.CombatActorHost on a spawned object; ActorFor(GameObject) and SpawnCombatantResolver find its actor the way CodeSmile.LunyCombat.Unity.Combat and CodeSmile.LunyCombat.Unity.CombatActorResolver find a host's.
