Class LunyScriptContractException

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Thrown when LunyScript observes that the lifecycle ownership contract was broken: the object running a script was destroyed, reparented or otherwise changed by native Unity API rather than by a LunyScript block.

Remarks

AGENTS.md rule 20 states the contract in full, including what it does not promise. Detection is best-effort: LunyScript throws where it observes a violation and does not attempt to repair the state, and it is not a goal to detect every case.
