One part of a composite binding, such as up of a 2D vector bound to four keys: the control it uses, its reset and its rebinding.

Examples

Remarks

A composite reads its value from its parts, so a player rebinds one part at a time. Find a part once through Part(string).

Methods

Rebind()

Starts listening for the control that becomes this part's binding; the capture waits for a control of the part's own kind, a key for a 2D vector part. Escape cancels, and a control another part of the same composite or another action of the asset already uses ends it as Denied.
