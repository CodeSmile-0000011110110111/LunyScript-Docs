Remarks

A listing reads each recognized file's metadata, its schema family and version or its group manifest, and nothing else: it migrates nothing, applies nothing and acquires nothing, so a slot menu can show every save, a damaged one included, before the player picks one. Each entry has its own outcome; a file that cannot be read is an entry that failed, and the other entries stay listed.

The listing is what the folder held when it ran. A save, a delete or another program can change the folder afterwards, so a load of an entry checks the file again. A folder that does not exist lists no entry; a folder the file system denies, or one that leads through a linked folder, fails the whole listing as Unavailable.
