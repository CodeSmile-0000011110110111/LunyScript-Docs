Struct RandomFactory

The Random surface inside Build(): draws from a declared randomizer that store a result. A draw consumes one sample when the block runs; later reads of the result reuse it. Define.Randomizer() declares the randomizer.

public readonly struct RandomFactory
Expand Details ...

Examples

Loot = Define.Randomizer().Seed(42);
On.Ready(Random.Number().From(Loot).In(1.0, 100.0).Into(Roll));

Remarks

Authorities draw gameplay outcomes and replicate the resulting state. Observers do not independently redraw them. Collection-slot choice waits on the collections group; this surface chooses among authored number values instead.
