Class RecipeSpec

Namespace
CodeSmile.LunySpawn
Assembly
ApiSource.dll

A spawn recipe as C# writes it: its ordered phases, the signals it declares, the signals that fail it in any phase, and the retry policy its groups default to. From(RecipeSpec) validates it into an immutable SpawnRecipe; an encounter file in Luny/Encounter/ is read into the same spec.

var recipe = SpawnRecipe.From(new RecipeSpec("room-breach")
    .Phase(new PhaseSpec("entry")
        .SucceedWhenAll(PhaseRule.GroupsClear("guards"))
        .Group(new GroupSpec("guards", "enemy.melee", "entry.east").Counts(8, 12, 16, 20).Every(0.25)))).Require();
