What Define.Leaderboard(name) returns: a board declaration that takes Keeps(LeaderboardKeeps, string, int) and Ranks(LeaderboardRanks, string, int), each once, and converts to a LeaderboardHandle when it is assigned.

Methods

Keeps(LeaderboardKeeps, string, int)

Records which score the board keeps per account, as configured on the dashboard: Best, Latest or Sum. The service applies its own configuration; the file backend applies this, and the journal names it.

Ranks(LeaderboardRanks, string, int)

Records the order the board ranks entries in, as configured on the dashboard: HighestFirst for points, LowestFirst for times.
