Class LunyCloudException

Namespace
CodeSmile.Luny.Cloud
Assembly
ApiSource.dll

A mistake in the C# that uses LunyCloud, raised where it was made: a null argument, a write to game data, which is read only to the client, a second set of services after signing in started, a leaderboard declared twice with different rules, or a completed call created as failed with no failure. The message names the call and what to change. A service outcome, such as a failed upload, is never an exception: it is a CloudRequest whose State is Failed.
