The runtime IRandomSource: an explicit-state xorshift32 generator whose sequence is a function of its seed alone.

public struct XorshiftRandomSource : IRandomSource

IRandomSource

Examples

var first = new XorshiftRandomSource(42);
var second = new XorshiftRandomSource(42);
var a = first.NextDouble();
var b = second.NextDouble();

Remarks

This is the consumer IRandomSource existed without. It does not read UnityEngine.Random, which is a static with hidden global state. It does not use System.Random either: that type's sequence is not the same on Mono, IL2CPP and CoreCLR, so a test that replayed a seed would not replay the draws. The algorithm is the xorshift32 Unity.Mathematics.Random uses; the core does not reference that package.

A seed of zero is replaced with 0x6E624EB7 before the first step, because a zero state never leaves zero. That is the same substitution Unity.Mathematics.Random's default seed is.
