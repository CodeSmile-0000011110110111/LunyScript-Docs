What Bind.Scene() returns: a scene input declaration that is complete once it is assigned or named.

Examples

Remarks

Assigning it declares the input. Arena = Bind.Scene(); converts the chain into a SceneReference, and the property the generator writes for that line gives the input the member's name. .As(name) names it explicitly. A scene input takes no source: the Inspector assigns the scene, and an object that assigns none still spawns.
