Class ScriptRunner

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Owns the built programs, the live instances and the instance pool, and runs each event kind across every instance.

public sealed class ScriptRunner
Expand Details ...
Inheritance
object
ScriptRunner

Examples

var runner = new ScriptRunner();
var program = runner.GetOrBuildProgram(new CountdownScript());
var instance = runner.Spawn(program, new FakeHost(1));
runner.RaiseReady(instance);
runner.TickFrameUpdate();

Remarks

A runner names no Unity type at all. The one place it reports a block failure goes through LunyScriptLog, which is the only class in the product that calls UnityEngine.Debug. That is what lets every block be tested in Edit Mode against FakeHost, with no scene and no frame; AGENTS.md rule 53.

Build() runs once per script type, and this cache is what makes that true. GetOrBuildProgram(ScriptBase) compiles a script type the first time it is asked for and returns the same program afterwards, so spawning a hundred objects of one script type compiles it once.

Structural changes and reentrant dispatch are refused while a runner executes authored actions. The one removal the runtime loop does make is its own: it drops an instance whose host no longer exists and steps its index back for it.

NetworkGateway

The one netcode gateway every instance this runner spawns talks to. Give it a provider before starting a session.

public NetworkGateway NetworkGateway { get; }

Property Value

NetworkGateway

Examples

runner.NetworkGateway.UseProvider(new FakeNetworkProvider());

Remarks

The runner drains this gateway twice per tick: once before the instances run, to refresh authority and apply what arrived, and once after, to send what the cadences say to send. AGENTS.md rule 45 is why the refresh is first: a block that reads Net.HasAuthority reads the answer this tick opened with, and every block in the frame reads the same one.

NetworkTicksElapsed

How many network ticks this runner has taken, whatever the frame rate is. A tick is counted only on a frame where the session is connected AND at least one instance is bound to a networked object, so a runner that has never had a session reports zero.

public int NetworkTicksElapsed { get; }

Property Value

int

Remarks

A tick is not one message. One tick produces one stream, sent in as many pieces as the backend's message budget needs, or in none at all when no channel had anything to send. Divide this into a byte total for a per-tick figure; it is not a message count.

Read by AGENTS.md rule 47's bandwidth measurement, which divides the bytes a window sent by the ticks that window took. It is a counter rather than a figure derived from elapsed time because the two are not the same: the runner's tick accumulator is driven by its own time source, and a measurement that assumed a tick rate rather than counting ticks would report a per-tick figure for a number of ticks that never happened. That mistake was made and caught on 2026-09-06, by dividing this runner's bytes by a netcode backend's tick count.

Spawn(ScriptProgram, IScriptHost, bool)

Creates or reuses an instance of a program for one host, and starts running it.

public ScriptInstance Spawn(ScriptProgram program, IScriptHost host, bool enabled = true)

Parameters

Type Name Description
ScriptProgram
program

The program to run.
IScriptHost
host

The object the blocks act on.
bool
enabled

Whether the instance's per-frame blocks run from the start. True by default, which is what a test or a direct caller wants. LunyScriptBehaviour passes false and lets Unity's own OnEnable enable it, so that the first activation delivers On.Enabled exactly once and a spawn delivers none.

Returns

ScriptInstance

The instance, enabled and not yet ready.

Examples

var instance = runner.Spawn(program, new FakeHost(1));

Remarks

A fresh instance allocates its slot arrays, which is exactly what SlotBytes predicts plus one array header per SlotArrayCount. A pooled instance allocates nothing: it is rebound to the new host and reset to the program's declared defaults.
