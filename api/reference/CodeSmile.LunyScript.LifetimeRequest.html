What an authored Object.Activate(), Object.Deactivate() or Object.Despawn() asked the runner to do to the object a script runs on.

public enum LifetimeRequest
Expand Details ...

Fields

Activate = 1

Activate the object the script runs on.

Deactivate = 2

Deactivate the object the script runs on.

Despawn = 3

End the incarnation: despawn the instance and destroy its object.

None = 0

Nothing was requested.

Examples

instance.RequestLifetime(LifetimeRequest.Deactivate);

Remarks

The request is recorded on the instance and applied by ScriptRunner after its current dispatch finishes, never inside the block that made it. Two reasons, and both are hard ones: a real SetActive or Destroy reaches LunyScriptBehaviour.OnDisable and OnDestroy synchronously, and those call back into the runner, which refuses to be re-entered during dispatch; and the settled contract-dispatch-order answer asks for these changes to be delivered between event invocations.
