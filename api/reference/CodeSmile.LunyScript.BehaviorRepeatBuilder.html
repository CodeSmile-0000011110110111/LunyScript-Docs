What Repeat(node) returns: a node that runs its child again after each finish, with no ending yet.

public readonly struct BehaviorRepeatBuilder
Expand Details ...

Examples

var watch = Repeat(Check(!IntruderNear)).UntilFails();

Remarks

Used as it is, the Repeat runs its child until its owner cancels it and never reports a result of its own. Times(NumberValueBlock, string, int), UntilFails() and UntilSucceeds() give it an ending. Every form starts at most one fresh repetition per frame: a child that finishes in the advance it began in runs again in the next frame.

Methods

Times(NumberValueBlock, string, int)

Runs the child this many times, one repetition per frame at most, and reports Succeeded only if every repetition succeeded, otherwise Failed. A failed repetition does not stop the count.

public BehaviorNode Times(NumberValueBlock count, string callerFilePath = null, int callerLineNumber = 0)
