One request a CloudClient carries out: what it asks, where, where it is, and how it ended. Made by the client's services, never by a caller; read it after each Tick(), or set an Observer to be told when it ends.

Remarks

A request allocates once, when it is made: the request boundary AGENTS.md rule 31 names. Reading it allocates nothing except Describe(). A request ends once, and its state never changes after that except a cancelled write whose backend answered later, which updates Commit (C09 A).

Methods

Cancel()

Stops waiting for the request. One still waiting is never sent: it ends as cancelled, not submitted, at the next tick. One already sent ends as cancelled now with Unknown; the backend's call is still polled, so a later request for the same address still waits for it, and its answer updates Commit. Nothing is rolled back on the service. A request that already ended is left as it is.

public void Cancel()
