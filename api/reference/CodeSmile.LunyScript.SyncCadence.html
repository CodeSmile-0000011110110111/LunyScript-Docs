How often one synchronised variable is sent. Declared per variable, because AGENTS.md rule 46 says synchronised state is declared one variable at a time and there is no networked struct and no state object to put two variables into.

public readonly struct SyncCadence
Expand Details ...

Examples

Health = Var.DefineSynced<Number>(nameof(Health), SyncCadence.OnChangeCapped(10.0), 100.0);

Remarks

The cadence is a required parameter, not a default. There is no way to declare a synchronised variable without naming what it costs, which is the compile-time half of rule 46: a never-changing player name and a per-tick value cannot share a payload, because there is nowhere to put them together.

A rate cap caps sends, not writes. The authority's own value is always current; a peer sees at most MaxPerSecond updates and therefore may hold a stale value between them. That is latency as a state, per rule 45, and it is reported rather than hidden.
