Struct MotionDisplacementBuilder

What Motion.MoveBy returns: a displacement along the object's own axes unless InWorldSpace() is written.

public readonly struct MotionDisplacementBuilder
Expand Details ...

Examples

On.FixedUpdate(Motion.MoveBy(0.0, 0.0, 0.1).InWorldSpace());

Remarks

A second space clause does not compile; the returned type offers none. API-semantics T08 applied to Motion, and AGENTS.md rule 41.

Methods
