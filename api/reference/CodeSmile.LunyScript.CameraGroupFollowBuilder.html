What Camera.FollowGroup() returns: a rig's target group that follows every local player's object, finished with For(ObjectBinding), optionally limited with Bounds(NumberValueBlock, NumberValueBlock) first.

public readonly struct CameraGroupFollowBuilder
Expand Details ...

Examples

On.Ready(Camera.FollowGroup().For(Rig));
On.Ready(Camera.FollowGroup().Bounds(20, 12).For(Rig));

Remarks

Who is in the group. The object Object.Create(prefab).ForPlayer(n) or Object.Spawn(pool).ForPlayer(n) produced, and an object whose LunyScript Behaviour's Local Player field names n, while local player n is paired, the object exists and it is active. Membership is brought up to date once per frame, after the frame's objects were created and destroyed.

What it writes. Each member goes into the rig's Cinemachine target group with weight 1 and its footprint as its radius, and comes out when it leaves the group. Targets the scene authored stay. The rig's own Follow, LookAt, framing and damping stay as authored, so the rig has to follow its target group for the group to move it.

How long. The registration belongs to the instance that ran the block, ends when that instance ends, and ends when a Camera.For(rig).Targets write reaches the same rig. Running the block again updates it. Ending it writes nothing to the rig.

CameraGroupBoundsBuilder

A builder whose For(ObjectBinding) produces the block.

Examples

On.Ready(Camera.FollowGroup().Bounds(20, 12).For(Rig));

Remarks

It constrains Motion. Every Motion.MoveBy and Motion.MoveTo of a member, in any event, is applied together with the others at the end of the tick pass, an outward step shortened to what keeps the group inside. A group walking the same way moves as one, and a player who does not move stays where it is. A Transform write, a teleport or a placement is not constrained; a group found wider than its Bounds is reported once, and Motion then lets its players close up and never spread further. The rectangle is centred on the group and moves with it. One group Bounds is in force at a time.

Both numbers are evaluated where the block runs. One that is not a finite number above zero is reported then and nothing is registered; a literal one is refused when the script type is built.

Exceptions

LunyScriptUsageException

A number is null, a literal number is not a finite number above zero, or the builder is a default one.
