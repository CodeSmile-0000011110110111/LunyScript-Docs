LunyScript API Reference

Namespace CodeSmile.Luny.Camera.Unity

Classes

CameraHost

The one persistent owner of the views LunyCamera creates: it moves to DontDestroyOnLoad, creates each view from an Inspector-assigned template, a Unity Camera with a CinemachineBrain and the Cinemachine cameras it shows, keeps those views and their identities across scene loads, binds outputs another owner keeps, and destroys what it created when it is disabled or destroyed. A second CameraHost waking while one exists is a configuration error and throws.

CameraView

One view: an output, the Unity Camera and its CinemachineBrain that render one picture, with the Cinemachine camera it shows, its share of the screen and the audience that sees it. A view is created by a CameraHost from a template, which the host owns and destroys when the view ends, or bound to an output another owner keeps, which ending the view leaves alone. UI places world labels and pointer rays through Output, and feedback reads Audience.
