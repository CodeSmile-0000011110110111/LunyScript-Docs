Struct LeaderboardHandle

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

A leaderboard, declared with Define.Leaderboard(nameof(Weekly)): the name is the service's board id, and .Keeps and .Ranks record the update rule and order configured on the dashboard (C23 A). Leaderboard.Submit(score).To(board), Leaderboard.Load(board) and Leaderboard.LoadEntry(board) use it, and Waiting counts its queued scores.

Waiting

How many scores wait for this board for this device's account, the one being sent included (C25 A): read every time the value is, from the client's queue, so a score submitted by another script, or before a restart, counts. A score leaves the count when it was confirmed, expired or failed.
