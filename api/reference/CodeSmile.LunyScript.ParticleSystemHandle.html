Struct ParticleSystemHandle

CodeSmile.LunyScript

What Particles.For(system) returns: the ParticleSystem on one declared GameObject input, with the same commands and readings the Particles surface has for the object the script runs on.

public readonly struct ParticleSystemHandle
Expand Details ...

Examples

var flash = Particles.For(MuzzleFlash);
When.Input(fire).Performed(flash.Emit(12));
On.Disabled(flash.Stop().AndClear());

Remarks

A handle is a value, not a block: it can be kept in a local and used in several events. Every object running the script addresses the object its own Inspector assigns to that input.

Properties

IsAlive

Whether the system or a child still has particles or will produce more, which is Unity IsAlive(true). After Stop() it stays true until the last particle dies.

public ConditionBlock IsAlive { get; }

Property Value

ConditionBlock

Examples

On.FrameUpdate(If(Particles.For(MuzzleFlash).IsAlive).Then(Heat.Add(Time.Delta)));

Exceptions

LunyScriptUsageException

This handle is a default one.

IsPlaying

Whether the system is playing, which is Unity isPlaying. False while it is paused, after its last particle died, and when the object has no ParticleSystem.

public ConditionBlock IsPlaying { get; }

Property Value

ConditionBlock

Examples

On.FrameUpdate(If(Particles.For(MuzzleFlash).IsPlaying).Then(Recoil.Set(true)));

Exceptions

LunyScriptUsageException

This handle is a default one.

Emit(NumberValueBlock)

Emits a burst, which is Unity Emit(count). Emit does not call Play.

public Block Emit(NumberValueBlock count)

Parameters

Type Name Description
NumberValueBlock
count

How many particles, evaluated each time the block runs. A count that is not a whole number from 0 to 2147483647 is reported once and emits nothing.

Returns

Block

A block to place in an event list.

Examples

When.Input(fire).Performed(Particles.For(MuzzleFlash).Emit(12));

Exceptions

LunyScriptUsageException

count is null, or this handle is a default one.

Stop()

Stops emission. Living particles die on their authored lifetime; .AndClear() removes them at once instead.

public ParticlesStopBuilder Stop()

Returns

A builder that is the stop as it stands, or stop-and-clear after .AndClear().
