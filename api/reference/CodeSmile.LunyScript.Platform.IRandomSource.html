The only place LunyScript draws a random number. A script's randomness is seeded per run so that a failing test can be replayed with the seed it printed.

public interface IRandomSource

Remarks

.NET 10 seam. The implementation today is XorshiftRandomSource, an explicit-state xorshift32 with no thread-static of its own. The .NET 10 counterparts are System.Random.Shared and System.Random.GetItems, neither of which is in .NET Standard 2.1. Replacing: UnityEngine.Random (a static with hidden global state, which the no-mutable- statics rule forbids anyway) and System.Random, whose sequence is not the same on Mono, IL2CPP and CoreCLR.
