What a frame modifier returns on a pool declaration: a default placement whose frame is stated, which can still take a hard cap and a prewarm count.

Prewarm(int)

How many inactive entries the pool prepares when its storage is created in a scene, which happens when the first object running this script spawns there.

public PoolFramedBuilder Prewarm(int count)

Parameters

count

count is below 1, this declaration already names one, or this builder is a default. A count above the hard cap is refused when the declaration converts to its handle.
