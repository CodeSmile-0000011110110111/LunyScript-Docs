Remarks

This file and the runner's driver are the two that name SceneManager. No block names it; a scene block reaches Unity only through SceneGateway and this provider, which is the arrangement docs/proposals/scene-flow.md states.

A scene that is not in the build fails as NotFound, in the Editor as well as in a player. Unity's Editor can load a scene that is not in the build through an Editor-only call, and using it would make an example work in the Editor and fail in the built game. The check is SceneUtility.GetBuildIndexByScenePath, before anything starts.

A replacement load is LoadSceneMode.Single, which releases every loaded scene; an additive load is LoadSceneMode.Additive. An unload names the exact Scene it ends, never a scene name, because two additive copies of one scene asset share a name.
