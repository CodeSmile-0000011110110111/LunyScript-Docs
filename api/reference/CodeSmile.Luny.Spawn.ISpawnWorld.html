Interface ISpawnWorld

Namespace
CodeSmile.Luny.Spawn

What a SpawnSession asks of the world it spawns into: try one admission, and release an object whose use ended. The Unity layer's SpawnHost implements it over prefabs, scene markers and physics; a test implements it with plain objects.

public interface ISpawnWorld
Expand Details ...

Examples

public sealed class CountingWorld : ISpawnWorld
{
    public int Live;
    public AttemptResult TryAdmit(in SpawnAttempt attempt, ref SpawnRandom random) { Live++; return AttemptResult.Admitted(0, 0, 0); }
    public void Release(SpawnUse use, UseEnd cause) => Live--;
}

Remarks

An admission reserves nothing the session has not already counted: the session checks its population limit before it calls TryAdmit(in SpawnAttempt, ref SpawnRandom). The world resolves the bindings, draws its candidate pose from the group's stream, checks the placement, prepares a fresh or pooled object, lets its components begin the use, and only then reports it admitted; a partial failure rolls back what it prepared and reports the refusal. Both calls run inside a boundary, so anything they ask of the session waits for the next one.

Methods

Release(SpawnUse, UseEnd)

Releases the object of a use that ended: returns it to its pool or destroys it, or forgets it when it is already gone. Called once per admitted use.
