The last change of one variable's value: which script, object and block changed it, and when.

public sealed class DiagnosticWrite

Examples

Remarks

A write that stores the value a variable already holds is not a change and is not recorded. An object's own variable is changed only by its own lifetime; a shared variable can be changed by any script that declares it, so Writer can name another script on another object. The Editor records changes for every instance; a player records none. This type is built when a snapshot is read; recording the change allocated nothing.
