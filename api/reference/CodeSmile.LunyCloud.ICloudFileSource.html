Interface ICloudFileSource

Namespace
CodeSmile.LunyCloud
Assembly
ApiSource.dll

The C# that produces and consumes the bytes of named player files, registered with Register(string, ICloudFileSource). A script names the file and never holds its bytes, by the captain's rule "bytes are low-level constructs" (C20 B).

public interface ICloudFileSource
Expand Details ...

Examples

sealed class ReplayRecorder : ICloudFileSource
{
    public Byte[] ReadBytes(String name) => m_Recording.ToArray();
    public void WriteBytes(String name, Byte[] content) => m_Playback = content;
}

Remarks

Both calls happen on the main thread inside Tick(). A throw fails the request as Unknown and is logged once with the exception text.
