Enum TextLength

Named byte bounds for each Text entry in a list or map. Declared per collection side at build time, because the five sizes are five distinct Unity.Collections.FixedString types and every entry on that side uses exactly one of them.

public enum TextLength
Expand Details ...

Fields

L = 512

512 storage bytes, 509 usable UTF-8 bytes. Fits 509 one-byte characters or 127 four-byte characters.

M = 128

128 storage bytes, 125 usable UTF-8 bytes. Fits 125 one-byte characters or 31 four-byte characters.

S = 64

64 storage bytes, 61 usable UTF-8 bytes. Fits 61 one-byte characters or 15 four-byte characters.

XL = 4096

4096 storage bytes, 4093 usable UTF-8 bytes. Fits 4093 one-byte characters or 1023 four-byte characters.

XS = 32

32 storage bytes, 29 usable UTF-8 bytes. Fits 29 one-byte characters or 7 four-byte characters. This is the default for a collection Text side that omits KeyLength or ValueLength.

Examples

Scores = Define.Map<Text, Number>(nameof(Scores), 8).KeyLength(TextLength.S);
Labels = Define.List<Text>(nameof(Labels), 4).ValueLength(TextLength.M);

Remarks

The default is XS, the smallest step. Each step documents both its storage byte count and how many UTF-8 characters fit: one-byte characters fill the usable payload, four-byte characters fill a quarter of it. Usable payload is three bytes less than storage: two bytes hold the length and one holds a terminating zero.

Collection text uses these named steps through KeyLength and ValueLength. Variable text still uses TextCapacity.
