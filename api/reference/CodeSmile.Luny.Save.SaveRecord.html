Class SaveRecord

Namespace
CodeSmile.Luny.Save

The values of one record of a SaveRecordSchema: what a record field, or a list or map of records, holds. Set every declared field before the document holding it is saved.

public sealed class SaveRecord
Expand Details ...
Inheritance
object
SaveRecord

Examples

var sword = new SaveRecord(Item);
sword.Set(ItemId, "sword");
sword.Set(Count, 1L);
document.Set(Items, new[] { sword });

Remarks

A set copies a record into the document, so changing the record afterwards changes nothing stored. A record a document returns, after a load or a set, is read-only (IsReadOnly): copy it with SaveRecord(SaveRecord) to change it, then set the copy.
