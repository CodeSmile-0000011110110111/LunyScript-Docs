LunyScript API Reference

Struct Number

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

A number variable of a script: a handle to one slot backed by double storage, or a constant number. Build() declares it, and its methods and operators build blocks.

public readonly struct Number
Expand Details ...

Examples

Health = Number.Define(nameof(Health), 100);
On.FrameUpdate(If(Health > 10).Then(Health.Subtract(1)).Else(Health.Set(0)));

Remarks

A Number is a handle, not the value. The same handle reads a different value on every object running the script, because each object keeps its own slot. Writing Number Five = 5; makes a constant input: it reads 5 on every object, has no slot, and a write to it such as Five.Add(1) is refused while the script type is built.

A partial script declares a number on one line inside Build(), and the generator writes the property: Health = Number.Define(nameof(Health), 100);. Define.Number is the same call, and [Variable(100)] public Number Health { get; private set; } declares it before Build() runs.

operator == builds a condition block; it does not compare handles. Use Equals(object) to compare two handles.
