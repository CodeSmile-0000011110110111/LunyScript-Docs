The Unity Gaming Services Cloud Save backend: initialises the services, signs in anonymously, and saves and loads player data, all behind IAsyncOperation so the gateway polls and nothing awaits; AGENTS.md rule 51.

Examples

LunyScriptRuntime.DefaultRunner.CloudGateway.UseProvider(new UgsCloudSaveProvider());

Remarks

Needs the project to be linked to a Unity Cloud project; the link lives in ProjectSettings/ProjectSettings.asset as cloudProjectId and organizationId. Every failure is classified once, from RequestFailedException.ErrorCode, into an OperationFailure; a failure that maps to no narrower reason is Unknown and is logged with the original message.
