The Unity Gaming Services Cloud Save backend: initialises the services, signs in anonymously, and uploads, downloads and deletes one document per key in the signed-in player's data, all behind IAsyncOperation so the gateway polls and nothing awaits; AGENTS.md rule 51.

Examples

LunyScriptRuntime.DefaultRunner.CloudGateway.UseProvider(new UgsCloudSaveProvider());

Remarks

Needs the project to be linked to a Unity Cloud project; the link lives in ProjectSettings/ProjectSettings.asset as cloudProjectId and organizationId. A document is stored as one JSON object under its key, the settled answer "One stored value for the whole document", in the player data a client may write, which Cloud Save calls the Default access class. Every failure is classified once, from RequestFailedException.ErrorCode, into an OperationFailure; a failure that maps to no narrower reason is Unknown and is logged with the original message. The package decides when a request has timed out and reports it as CommonErrorCodes.Timeout; this provider adds no deadline.
