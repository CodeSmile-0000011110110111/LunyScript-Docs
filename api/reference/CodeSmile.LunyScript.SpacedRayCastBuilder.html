A Collision.RayCast() whose frame has been named: every clause but a second space clause.

public readonly struct SpacedRayCastBuilder
Expand Details ...

Examples

On.FixedUpdate(Collision.RayCast().InLocalSpace().Into(Sight));

Remarks

A separate type from RayCastBuilder so that a second space clause does not compile, as a Transform verb's does; AGENTS.md rule 41.

Along(ScreenRay, string, int)

Sets where the ray starts and which way it travels from a screen ray: the ray's origin on the camera's near plane and its direction into the screen, read from the camera once each time the query runs.

public SpacedRayCastBuilder Along(ScreenRay ray, string callerFilePath = null, int callerLineNumber = 0)

Parameters

Type Name Description
ScreenRay
ray

A ray from Camera.ScreenRay(position) in this script's Build().
string
callerFilePath

Supplied by the compiler. Do not pass one: it records the authored line a diagnostic names.
int
callerLineNumber

Supplied by the compiler.

Returns

SpacedRayCastBuilder

This query, which takes further clauses.

Examples

On.FrameUpdate(Collision.RayCast().InWorldSpace().Along(Camera.ScreenRay(point.Value)).Into(Hover));

Remarks

Along(ray) is From(ray.Origin).Towards(ray.Direction) with one camera read, so it is written without From, Offset and Towards, and a screen ray is a world ray, so the query is not in local space. A ray the camera could not compute, for a position outside the view or without a camera, runs no query and clears the result. Length bounds the travel from the near plane.

Exceptions

LunyScriptUsageException

This builder is a default that no verb produced, the query already has a ray, an origin, an offset or a direction, or ray is a default or another script's.

Remarks
