One read of a game's content files: from the project's Luny folder in the Editor, or from StreamingAssets/GameData.luny in a player. It holds every JSON file it read, in ordinal path order, and the paths it skipped.

Remarks

A read of the project folder, and of the archive where StreamingAssets is a local folder, completes inside the call that starts it. On Android and the web the archive is read with a web request and the read completes in a later frame; IsDone turns true when it has, and reading any property finishes it then.

A read is all or nothing: one refused path, one file that is not UTF-8 or a compressed archive entry fails it as Unreadable with every refused path named in Problem, and it then holds no file. A missing folder or archive is NotFound.
