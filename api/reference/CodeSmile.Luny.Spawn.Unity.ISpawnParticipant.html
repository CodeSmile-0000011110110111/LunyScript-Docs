Interface ISpawnParticipant

Namespace
CodeSmile.Luny.Spawn.Unity
Assembly
ApiSource.dll

A component on a spawned object that takes part in each of its uses: it begins a use after the object was placed and activated, and may refuse it, and it ends the use before the object is returned to its pool or destroyed. A component that implements it resets its own state in BeginUse(in SpawnUseContext), which also covers it for pooling (the captain's Q23 answer: every component of a pooled prefab has an admitted reset or retain policy).

Examples

public sealed class Health : MonoBehaviour, ISpawnParticipant
{
    public float Current;
    public bool BeginUse(in SpawnUseContext context) { Current = 100; return true; }
    public void EndUse(UseEnd cause) { }
}

Remarks

The host calls it on fresh and on pooled objects alike, so a component behaves the same either way. A refusal rolls the admission back: every participant that began the use ends it, and the object goes back.
