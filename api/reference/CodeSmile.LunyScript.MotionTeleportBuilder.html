What Motion.TeleportTo returns: a position write, or WithRotation(RotationValueBlock, string, int) first.

public readonly struct MotionTeleportBuilder
Expand Details ...

Examples

On.FixedUpdate(Motion.TeleportTo(Spawn).WithRotation(Facing));

Remarks

The position comes from a Vec3 value or from a landmark, an object in the scene that the script declared as an asset input. Either one takes either WithRotation.

Methods

Also writes a landmark's world rotation, sampled each time the block runs. The landmark is an object in the scene that the script declared as an asset input.
