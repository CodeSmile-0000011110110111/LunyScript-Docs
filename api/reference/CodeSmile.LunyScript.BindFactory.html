The Bind surface inside Build(): declares the assets a script needs and hands back the typed handles that read them.

public readonly struct BindFactory
Expand Details ...

Examples

protected override void Build()
{
    OpenSound = Bind.Asset<AudioClip>(nameof(OpenSound));
    Sentry = Bind.Asset<GameObject>(nameof(Sentry), AssetSource.Resources<GameObject>("Enemies/Sentry"));
}

Remarks

This is a build-time surface. Every call runs once per script type, before any object exists, and constructs part of the shared Script program, which is why it may allocate; AGENTS.md rule 43. What an input holds is per object and is resolved when that object spawns.

The declared name is the input's durable identity. A value stored on a host is matched to an input by name, so the name comes from nameof and a rename orphans what a scene stored under the old one.

The attribute is the default declaration style, the way [Variable] is for variables: [Asset] public Asset<AudioClip> OpenSound { get; private set; } produces exactly the call below. These calls remain the explicit alternative.

Prefab(string)

Declares a prefab input the host supplies: the same declared input Asset<T>(string) is, narrowed so that only a prefab can satisfy it.

public Prefab Prefab(string name)

Parameters

Type Name Description
string
name

The name, which should come from nameof. Unique within the script, and what a stored value is matched against.

Returns

Prefab

The handle.

Examples

Sentry = Bind.Prefab(nameof(Sentry));

Remarks

A GameObject the host assigned that is not a prefab asset is refused, with an error naming the input, and the input then resolves as if nothing had been assigned. An Asset<GameObject> accepts a scene object; a prefab input does not, because spawning from a scene object duplicates that object instead of producing a new one from an asset.

Object.Spawn takes this handle and no other, so a spawn from an input of another kind does not compile.

Exceptions

LunyScriptUsageException

The name is null or whitespace, or this script already declares an input or a variable of that name.

Scene(string, string, int)

Declares a scene input: the typed scene identity Scene.Load, Scene.Unload and the When.Scene* watches take. The host's Inspector assigns the scene.

public SceneReference Scene(string name, string callerFilePath = null, int callerLineNumber = 0)

Parameters

string

int

Returns

SceneReference

The handle.

Examples

Arena = Bind.Scene(nameof(Arena));

Remarks

There is no source and no placeholder for a scene. Substituting a scene would change what the game is, so an object that assigns none still spawns, the missing assignment is reported once per script type, and a Scene.Load of it fails as OperationFailure.NotFound. [Asset] on a SceneReference property declares the same input.

Exceptions

LunyScriptUsageException

The name is null or whitespace, or this script already declares an input or a variable of that name.
