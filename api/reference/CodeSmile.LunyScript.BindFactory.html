The Bind surface inside Build(): declares the inputs a script needs - assets, scenes and objects in a scene - and hands back the typed handles that read them.

public readonly struct BindFactory
Expand Details ...

Examples

protected override void Build()
{
    OpenSound = Bind.AudioClip();
    Sentry = Bind.Prefab().FromResources("Enemies/Sentry");
    Witch = Bind.Object();
}

Remarks

This is a build-time surface. Every call runs once per script type, before any object exists, and constructs part of the shared Script program, which is why it may allocate; AGENTS.md rule 43. What an input holds is per object and is resolved when that object spawns.

The declared name is the input's durable identity. A value stored on a host is matched to an input by name, so the name comes from nameof and a rename orphans what a scene stored under the old one.

A line without a name gets its member's name. OpenSound = Bind.AudioClip(); in a partial script makes the generator write the OpenSound property, whose setter gives the input the name OpenSound. .As(name) names a declaration explicitly, which a hand-written property or a local needs. [Asset] on a property declares the same input.

Every handle is a LunyScript type. Texture2D(string, int), AudioClip(string, int), AudioMixer(string, int), AudioMixerGroup(string, int) and VisualTreeAsset(string, int) carry Unity's names in LunyScript's namespace, so a script that uses them compiles without an engine reference.

Examples

Witch = Bind.Object();
Enemy = Bind.Object().WithTag("Enemy").Named("Guard").LiveRebind();
Door = Bind.Object().MustExist();

Remarks

Nothing found is an ordinary state. The binding is unavailable, IsValid is false, a write through it does nothing and no object is created in its place. WithTag and Named replace the name search, MustExist() refuses to start the script when nothing is found, and LiveRebind() searches again while the binding has no object.
