Declares an asset input whose handle is assigned before Build, in declaration order.

Remarks

Place this on an Asset<T>, Prefab or SceneReference property in a partial Script subclass. Roslyn reads the attribute at compile time; LunyScript never discovers or instantiates it at runtime. This is the same arrangement VariableAttribute uses, and the generated assignments run in one declaration pass before Build().

Remove the attribute and use Bind.Asset, Bind.Prefab or Bind.Scene inside Build() to declare the same input explicitly. A scene input takes no Resources source.

Properties

Resources

The Resources-relative, extension-free key this input loads from when the host assigns nothing. Naming the provider here is what keeps the source provider-qualified at the place it is written, which is what the settled api-asset-address-identity answer requires; no other provider is tried when this one finds nothing.
