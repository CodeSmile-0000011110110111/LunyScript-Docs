The declared prefab input, such as [Asset] public Prefab Enemy.

PoolBuilder

A builder that converts to the pool handle, or takes the pool's clauses first.

Examples

Guards = Define.Pool(nameof(Guards)).From(Enemy);

Remarks

Each object resolves the input the way it resolves every declared input, so two objects of one script type in one scene with different prefabs assigned keep two storages.

Exceptions

LunyScriptUsageException

prefab was never declared, another script's Build() declared it, or this builder is a default.
