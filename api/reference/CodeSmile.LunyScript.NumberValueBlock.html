A block that produces a Number for one object: a variable read, a literal, or an arithmetic expression over other value blocks.

public abstract class NumberValueBlock : IScriptNode

Examples

NumberValueBlock doubled = health * 2.0;

Remarks

This is the type that makes health.Set(health + 5) and If((health + 5) > 10) work: + on a variable returns one of these, and both Set and the comparison operators take one. AGENTS.md rule 12: the number type is Number and there is no Single or Int32 variant.
