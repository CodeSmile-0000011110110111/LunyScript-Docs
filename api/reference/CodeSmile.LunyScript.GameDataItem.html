Struct GameDataItem

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

An item of the game's published cloud data, declared with Define.GameData(collection, key): read only to the client, so Cloud.Load(item).Into(doc) reads it and no save or delete takes it (C04, C28). In Unity Cloud Save it is a key of a custom item, which the dashboard or a server writes.

public readonly struct GameDataItem
Expand Details ...

Examples

Prices = Define.GameData("Shop", nameof(Prices));
On.Ready(Cloud.Load(Prices).Into(PriceList).As(LoadingPrices));

Remarks

The item holds a document in the layout Progress writes, {"format":1,"version":1,"fields":}, so it loads with the version, migration and omission rules every document load has.
