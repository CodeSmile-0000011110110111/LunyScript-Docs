Examples

var host = new GameObjectHost(gameObject);
var instance = runner.Spawn(program, host);

Remarks

This file and LunyScriptContactBehaviour are the two in the runtime core that name a GameObject, a Transform or a Component in a field or a parameter, and a structural test enforces that. AGENTS.md rule 24: the interface is what keeps the core testable without a scene. The contact behaviour is a second file because Unity requires a MonoBehaviour class to live in a file of the same name, and the trigger callback's Collider parameter is that signature.

The Transform is looked up once, in the constructor, and every transform call uses that cached reference instead of GameObject.transform. What the cache assumes, what invalidates it and what it was measured to save are in docs/host-transform-cache.md; read that before changing any field here.

The editor host boundary is documented in docs/editor-foundation.md.
