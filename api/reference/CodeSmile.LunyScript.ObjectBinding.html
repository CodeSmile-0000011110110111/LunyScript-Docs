A handle to one object in a scene that a script binds to: the target Object.For, Camera.For, Audio.For, Particles.For, Panel.For, Navigation.For and a landmark take. Returned by Bind.Object() at build time.

public readonly struct ObjectBinding
Expand Details ...

Examples

Witch = Bind.Object();
Guard = Bind.Object().WithTag("Enemy").Named("Guard").LiveRebind();
On.Ready(If(Witch.IsValid).Then(Object.For(Witch).Show()));

Remarks

Each object running the script resolves the binding for itself when it spawns, in this order: the object its Inspector assigns, then the first object in the spawning object's own scene, inactive objects included, whose name is the declared name. WithTag and Named replace the name search with their own conditions, which must all hold. When nothing is found, the binding is unavailable, and no object is created in its place.

An unavailable binding is an ordinary state. IsValid reads it, a write through it does nothing, and a read through it gives that read's documented default. Nothing is logged for it. Two objects that both match a search, and an assigned object that no longer exists, are reported once per incarnation of the object running the script.

A bound object ends when it is destroyed or despawned, and the binding is unavailable from then on. LiveRebind() searches again before the script's next update; MustExist() refuses to start the script when the first resolution finds nothing. The two are exclusive. Binding an object grants no lifetime ownership of it.

A handle is valid only inside the Build that declared it, for the reason Var<T> states: it carries a slot index and nothing that identifies its program.

Remarks

A binding that found nothing, and one whose object ended, answer false. The answer changes only between updates: a LiveRebind() binding searches again before the script's next update, and every block in one update sees the same answer.
