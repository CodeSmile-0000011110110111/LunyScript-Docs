What a generated reader such as EnemyScript.Reader reads from: the script type it expects and the target, checked when EnemyScript.At(target) ran inside Build().

Examples

var enemy = EnemyScript.At(Patient);   // holds a LunyScriptReadSource
On.Update(Seen.Set(enemy.Health));

Remarks

A script never writes this type; the generator writes the only code that holds one. It has no public member, so a script cannot turn it into a read by name. docs/proposals/script-communication.md is the contract.
