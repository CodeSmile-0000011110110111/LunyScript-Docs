Class ViewportLayout

Namespace

Where each view goes for each set of slots in: a table of two viewports for two slots in, placed by order of slot number, and a table of four viewports for three or four slots in, placed by slot number so a slot keeps its cell when another slot empties. One slot in takes the whole screen. The shared view takes the whole screen while nobody is in and the free cell while three slots are in. A slot is a local player's place, 1 to 4, such as LunyCoop's seat number.

Remarks

TopBottom and LeftRight are the shipped presets; another fixed arrangement is a layout built from its own two tables, in C# or from a Luny/Camera/ file of LunyData.Camera. A layout places the first four slots; Place(int, int, out Viewport) gives a slot beyond them no place, and the slots a game holds beyond the fourth stay its own to show. This is the one implementation of the fixed layouts: LunyCoop's ViewLayout and LunyScript's split screen place their views through it. Placing allocates nothing.
