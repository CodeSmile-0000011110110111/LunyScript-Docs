Class SaveDocument

Namespace
CodeSmile.LunySave

The values of one document of a SaveSchema: what Save(string, SaveDocument) writes and what a successful LoadOperation returns. Each declared field either holds a value or holds none.

public sealed class SaveDocument
Expand Details ...
Inheritance
object
SaveDocument

Examples

var document = new SaveDocument(Progress);
document.SetNumber("BestScore", m_BestScore);
document.SetText("PilotName", m_PilotName);
document.SetVector3("Position", transform.position);
var saving = m_Saves.Save("savegames/001.sav", document);

Remarks

A new document holds no value. A save refuses a document that does not hold every declared field, naming the ones it lacks, because a stored copy without them would make the next load report them as omitted. A loaded document holds every field the stored copy could give it; a field the load omitted holds none, so TryGet returns false for it and the caller's value stays what it was. Each set and read checks that the schema declares the name with that kind, and throws a LunySaveException otherwise, so a misspelt name fails where it is written.
