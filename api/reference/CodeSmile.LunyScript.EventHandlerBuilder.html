A listener On.Event(event) started: Do(params Block[]) names its blocks, and From(LunyScriptTarget, string, int) restricts it to one sender first.

public readonly struct EventHandlerBuilder
Expand Details ...

Examples

On.Event(DoorScript.Events.Opened).Do(Opened.Add(1));
On.Event(DoorScript.Events.Opened).From(FrontDoor).Do(FrontOpened.Set(true));

Remarks

Without From, the listener hears every local instance that sends the declaration, including its own. docs/proposals/script-communication.md is the contract.
