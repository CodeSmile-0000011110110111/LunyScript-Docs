Remarks

This block type is public because Unscaled() is part of the authored grammar, not because a test needs it: a script writes Time.Delta.Unscaled(), so the type Time.Delta returns has to carry that method. Its constructor is internal like every other block's, so a script still cannot build one directly.

The scaled clock is the default and real time carries the word. That is the same grammar a transform verb's frame uses - the modifier follows the verb, the common case is the default, and the unusual case is the one that is written out. It is applied to both readings and to nothing else on the Time surface: Time.Scale and Time.IsPaused are not clock readings and return types that carry no Unscaled at all, so Time.Scale.Unscaled() does not compile rather than meaning nothing.

Evaluating one reads two properties - the runner's clock and one of its four values - and allocates nothing. Both clock choices cost the same; there is no cast and no branch on anything but the two readonly fields.
