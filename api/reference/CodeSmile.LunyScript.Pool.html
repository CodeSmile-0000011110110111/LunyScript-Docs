Struct Pool

Namespace
CodeSmile.LunyScript

A handle to one declared object pool of a script: which prefab it reuses, how many entries it may hold, how many it prepares in advance, and where a spawn from it goes when the call names no placement. Returned by Define.Pool inside Build(); Object.Spawn takes it.

public readonly struct Pool
Expand Details ...

Examples

[Asset] public Prefab Enemy { get; private set; }
public Pool Guards { get; private set; }

Guards = Define.Pool(nameof(Guards)).From(Enemy).HardCap(8).Prewarm(4);
On.Ready(Object.Spawn(Guards).Into("Escort"));

Remarks

The declaration describes storage; Build() creates no object. The entries live in the scene of the object whose script spawns from the pool, under one inactive storage object per scene, and they are destroyed with that scene. Every object running the same script type in the same scene with the same prefab assigned shares one storage.

A handle is valid only inside the Build that declared it, for the reason Var<T> states: it carries a declaration index and nothing that identifies its program.
