Enum ApplicationObservation

Namespace

Which of the five application observations a runner is delivering: what Unity reported about the application as a whole, rather than about one object.

public enum ApplicationObservation
Expand Details ...

Fields

FocusGained = 2

Unity reported focus gained: OnApplicationFocus(true).

FocusLost = 3

Unity reported focus lost: OnApplicationFocus(false).

Paused = 0

Unity reported the application paused: OnApplicationPause(true).

Quitting = 4

Unity reported the application is quitting: OnApplicationQuit.

Resumed = 1

Unity reported the application resumed: OnApplicationPause(false).

Examples

runner.RaiseApplication(ApplicationObservation.Paused);

Remarks

Unity's own callbacks carry a Boolean: OnApplicationPause(true) and OnApplicationPause(false) are one method. LunyScript splits each into its own event, the way On.Authority.Gained and On.Authority.Lost are two events, because a script registers blocks and has no parameter to test; AGENTS.md rule 26 keeps event payloads off the generic path.
