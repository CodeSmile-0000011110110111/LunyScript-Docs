Struct MaterialNumber

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What Object.MaterialNumber(name) returns: one Float or Range property of a renderer's materials, declared by the name in the shader's Properties block. The members build the blocks that write it into the renderer's property block and remove it again.

public readonly struct MaterialNumber
Expand Details ...

Examples

var dissolve = Object.MaterialNumber("_Dissolve");
On.FrameUpdate(dissolve.Set(Fade));
On.Message("Revive", dissolve.Reset());

Remarks

The name is turned into Unity's property id once, while the script type is built, so the per-frame path passes an integer. The value is narrowed to Single at the host, AGENTS.md rule 13, because a material stores the property in single precision.
