Interface IPackageVersionSource

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Answers which Unity package versions this project currently has installed. Adapter admission queries it at spawn, never per frame.

public interface IPackageVersionSource
Expand Details ...

Examples

AdapterAdmission.UseVersionSource(source);

Remarks

Tests supply a map through NoteInstalled(string, string). An Editor workflow can replace that map with a source that reads the Package Manager. A player has no Package Manager; an adapter that compiled calls NoteInstalled(string, string) from the same load path as Register(Type, string, string, string, string, int), because that assembly compiles only when the package is present.
