A parsed Text.Format call: the literal pieces of the format, which value fills each hole, and how many decimal places each number hole asks for. Pass it to a text variable's Set.

public sealed class TextFormat

Examples

On.FrameUpdate(Label.Set(Text.Format("{0}/{1} hp", Health, MaxHealth)));

Remarks

The format is parsed once, here, at build time. What runs per frame appends the parsed pieces into a fixed-capacity buffer the size of the destination variable and writes that buffer into the slot, so nothing on that path allocates.
