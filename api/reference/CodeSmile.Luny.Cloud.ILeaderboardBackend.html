Interface ILeaderboardBackend

Namespace
CodeSmile.Luny.Cloud
Assembly
ApiSource.dll

The leaderboard service a backend provides: sending a score, reading a page of entries, one account's entry, and a board's past seasons. The client calls it on the main thread for a signed-in account; the score queue sends one score at a time.

public interface ILeaderboardBackend
Expand Details ...

Examples

var call = backend.Submit(weekly, 1250, null);

Remarks

A service such as Unity Leaderboards applies the board's update rule and sort order from its own configuration and ignores Keeps and Ranks; FileCloudBackend applies them.
