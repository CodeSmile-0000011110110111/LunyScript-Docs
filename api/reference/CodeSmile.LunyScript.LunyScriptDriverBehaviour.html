Remarks

One driver rather than an Update on every LunyScriptBehaviour: the runner iterates its instances itself, which is one managed call per frame instead of one per object, and it is the shape the future runtime inspector reads.

The scene-unload subscription is this component's, not a static one, because the driver object is created with DontDestroyOnLoad and therefore survives the scene unloads it has to observe, and because OnEnable and OnDisable remove the subscription without any static state for AGENTS.md rule 17 to object to. docs/host-transform-cache.md states what the sweep covers and what it was measured to find.

Properties

SceneUnloadDropCount

How many instances this driver's scene-unload sweep has dropped since it was created. Zero on a project where every managed object is destroyed through a LunyScriptBehaviour, because that component's OnDestroy despawns the instance before the scene finishes unloading.
