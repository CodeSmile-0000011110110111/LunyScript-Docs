Where a CloudRequest is: waiting its turn, sent to a backend, or ended.

public enum CloudRequestState : byte
Expand Details ...

Fields

Canceled = 4

Ended: Cancel() was called, or the caller withdrew it before it was sent.

Failed = 3

Ended: Failure says why.

Sent = 1

Handed to a backend; the client polls it once per Tick().

Succeeded = 2

Ended: the service did what was asked.

Waiting = 0

Queued: a request before it for the same address, the sign-in, or the services are not ready.

Examples

if (loading.State == CloudRequestState.Succeeded) Apply(loading.Text);
