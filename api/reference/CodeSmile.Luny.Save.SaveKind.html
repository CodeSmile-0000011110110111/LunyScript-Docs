What a stored value is: a number, a flag, a text, a Unity value, an exact 64-bit whole number, or a record, list, map or optional value built from those. A SaveField pairs a name with a kind; a list, map or optional kind names the kind of its values. SaveKind<T> carries the C# type a set takes and a read returns.

Examples

static readonly SaveField<String> ItemId = SaveField.Text("Id", 64);
static readonly SaveField<Int64> Count = SaveField.Int64("Count");
static readonly SaveRecordSchema Item = new SaveRecordSchema("Item", ItemId, Count);
static readonly SaveField<IReadOnlyList<SaveRecord>> Items = SaveField.List("Items", SaveKind.Record(Item));

Remarks

Structured values are declared, never discovered. A record is a SaveRecordSchema, a list holds values of one kind in order, and a map holds values of one kind under text keys, compared case sensitively and written in ordinal key order. LunySave never walks a C# object it was not told about.

Absence is declared too. Only an Optional<T>(SaveKind<T>) value holds "no value", stored as JSON null; an empty list or map is a present value. A stored null for any other kind, a missing member of a record and a value of another kind are what a load omits.

One version governs the whole tree. A record, list or map inside a document has no version of its own: the document's schema version covers every value in it, and a migration step changes nested values through SaveFields.
