LunyScript API Reference

Class CloudDefinitions

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The cloud declarations a script writes inside Build() with Define: a key of the player's data, a game data item, a player file, a leaderboard, and the page and entry a leaderboard read fills. LunyCloud adds them to the core's DefineFactory surface in namespace CodeSmile.LunyScript.

public static class CloudDefinitions

Inheritance
object
CloudDefinitions

Examples

Weekly = Define.Leaderboard(nameof(Weekly)).Keeps(LeaderboardKeeps.Best);
TopTen = Define.LeaderboardPage(nameof(TopTen), 10);
SlotTwo = Define.CloudKey(nameof(SlotTwo));

Remarks

Each returns a handle a hand-written property holds, the way Document and Operation handles are held: public LeaderboardHandle Weekly { get; private set; }. A page or an entry reserves its rows as internal storage of every object of the script type when Build() runs.
