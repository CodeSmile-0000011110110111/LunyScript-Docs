One authored Object.Spawn that has run and has not been applied yet: which prefab input to produce from, where the produced object goes, what it is parented to, and which owned-object slot holds it.

public readonly struct SpawnRequest
Expand Details ...

Examples

instance.RequestSpawn(new SpawnRequest(0, "Sentry", SpawnObjectBlock.NotHeld,
    SpawnObjectBlock.NoParent, SpawnPlacement.None));

Remarks

It is a struct held in a list on the runner rather than a field on the instance, because one event list may spawn several objects while LifetimeRequest is one state per instance. Adding a struct to a list that has capacity allocates nothing, so an authored spawn costs no allocation until the runner produces the object.
