Which kind of value one TextArgument carries.

public enum TextArgumentKind

Fields

Flag = 2

A flag expression, written as true or false.

None = 0

A default-constructed argument, which carries nothing and is refused where one is used.

Number = 1

A number expression.

Text = 3

A text variable, whose bytes are copied in.

Examples

var kind = TextArgumentKind.Number;
