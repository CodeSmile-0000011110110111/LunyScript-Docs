The Sync surface: which parts of an object's transform cross the network, and how often each one is sent.

public readonly struct SyncFactory
Expand Details ...

Examples

protected override void Build()
{
    Sync.Position(SyncCadence.EveryTick);
    Sync.Rotation(SyncCadence.OnChange);
    Sync.Scale(SyncCadence.Once);
}

Remarks

One call per channel, each with its own cadence, which is AGENTS.md rule 46 applied to the transform. There is no "synchronise the transform" switch, for the reason rule 46 gives for there being no networked struct: a scale that never changes would otherwise share a payload with a position that changes every tick, and the cost of the second would be paid for the first.

What the channels carry crosses as one stream per authority per network tick, not as one message per object; rule 47, and docs/netcode-bandwidth.md is the measurement that rule requires.

Position(SyncCadence)

Synchronises the object's world position.

public void Position(SyncCadence cadence)

Parameters

Type Name Description
SyncCadence
cadence

How often it is sent. Required, so that a position whose cost nobody chose cannot be synchronised.

Examples

Sync.Position(SyncCadence.EveryTick);

Remarks

The position is sent as the change since the last one sent, in 6 bytes, and as an absolute position in 12 whenever the change is too large to encode or a peer has just joined. Only the authority may move an object whose position is synchronised; a move on any other peer is refused, and the diagnostic names what to write instead.

Exceptions

LunyScriptUsageException

The cadence is unset, or this script already declared this channel.

Scale(SyncCadence)

Synchronises the object's local scale.

public void Scale(SyncCadence cadence)

Parameters

Type Name Description
SyncCadence
cadence

How often it is sent.

Examples

Sync.Scale(SyncCadence.Once);

Remarks

Sent as three half-precision values, 6 bytes. A scale that is chosen once and never changed is declared with SyncCadence.Once and then costs nothing per tick.

<p>
    <b>Each axis must be between -65504 and 65504</b>, which is what the 16-bit encoding
    holds. This channel sends the value rather than a change, so unlike a position it has no
    second form to fall back to: an object scaled outside that range has its scale sent to
    nobody, every peer keeps the last scale that was inside the range, and the runner writes
    one warning naming the object, its scale and the bound. That warning is written once for
    an object and not again: a scale that leaves the range later is refused the same way and
    in silence, because composing the message on a path that repeats would allocate.
</p>

Exceptions

LunyScriptUsageException

The cadence is unset, or this script already declared this channel.
