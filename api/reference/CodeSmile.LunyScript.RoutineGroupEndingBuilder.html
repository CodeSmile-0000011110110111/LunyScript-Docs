A concurrent group that carries an early-ending clause. Its one further call decides what happens to the children that had not finished when the group published its result.

public readonly struct RoutineGroupEndingBuilder
Expand Details ...

Examples

On.Ready(Routine("Race").Run(InParallel(reachExit, timeOut).UntilOneFinishes()));

Remarks

Without OthersKeepRunning() those children are cancelled at the moment the result is published.

Properties

Canceled

A condition that is true once this group was cancelled before it produced a result. Cancellation is neither a success nor a failure, so Succeeded and Failed are both false for the same group.

Methods

OthersKeepRunning()

Leaves the children that had not finished running when this group published its result. The enclosing routine activation owns them from that moment, advances them while it runs, and cancels them when it ends or is itself cancelled.

public RoutineGroupSurvivorBuilder OthersKeepRunning()

Returns

RoutineGroupSurvivorBuilder

The group, with that ownership clause.

Examples

var search = InParallel(searchLeft, searchRight).UntilOneSucceeds().OthersKeepRunning();

Remarks

What those children go on to report changes nothing: a published result is final.
