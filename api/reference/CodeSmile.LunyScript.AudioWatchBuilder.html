What When.Audio(voice) returns. Each method registers blocks for one end of that tracked playback.

public readonly struct AudioWatchBuilder
Expand Details ...

Examples

When.Audio(alarm).Finished(AlarmDone.Set(true));

Remarks

A watch is polled once per frame, after the frame-update blocks. Natural end is recorded on the audio tick, which runs after watches, so Finished runs on the next frame. Stop and a play that never started record their end during the block, so those watches can run in the same frame.
