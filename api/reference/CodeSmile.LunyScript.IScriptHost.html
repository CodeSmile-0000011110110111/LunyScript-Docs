LunyScript API Reference

Interface IScriptHost

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The object a script runs on, as the blocks see it. Blocks reach the object through this interface and never through a GameObject, a Transform or a Component.

public interface IScriptHost
Expand Details ...

Examples

var host = new FakeHost(instanceId: 1);
var instance = runner.Spawn(program, host);

Remarks

Game scripts use GameObjectHost. Explicit editor workflows use the scene-free host owned by EditorScriptSession, which refuses spatial access. FakeHost remains a test double. AGENTS.md rule 53 and docs/editor-foundation.md define the capability boundary.

Remarks

An undefined facing writes nothing rather than inventing a direction, which is the captain's answer to API-semantics row T04 on 2026-09-13. SetParent(TransformRelation, int, TransformRelation, int, bool)

Moves the named object to another parent, or to the scene root.

void SetParent(TransformRelation relation, int childIndex, TransformRelation parentRelation, int parentChildIndex, bool keepWorldPose)

Parameters

Type Name Description
TransformRelation
relation

Which object to reparent.
int
childIndex

Its child index, used only for Child.
TransformRelation
parentRelation

The destination. None is the scene root.
int
parentChildIndex

The destination's child index, used only for Child.
bool
keepWorldPose

True keeps the object's world position and rotation and writes the closest local scale it can, which is the default the captain chose for API-semantics row T06 on 2026-09-13; false keeps the object's local values and lets its world placement move. The scale is the half that can only be approximated: a parent that is rotated and scaled unevenly produces world scales no local scale reproduces.

Remarks

Reparenting does not replace the object's transform, so a host that caches one still holds the right object afterwards; docs/host-transform-cache.md states what that cache assumes.

Exceptions

LunyScriptUsageException

Either named object does not exist, or the destination is the object itself or one of its own descendants.
