Class SaveSchema

Namespace
CodeSmile.LunySave
Assembly
ApiSource.dll

What one kind of document holds: its version, its fields by name and kind, and the migration steps that convert an older stored version. Each method returns a new schema and leaves this one as it was, so a schema kept in a static readonly field never changes after it is built.

public sealed class SaveSchema
Expand Details ...
Inheritance
object
SaveSchema

Examples

// A Unity type holding a static field carries [NoAutoStaticsCleanup]: the schema never changes, so nothing resets it.
[NoAutoStaticsCleanup]
public sealed class Saves : MonoBehaviour
{
    static readonly SaveSchema Progress = new SaveSchema(2)
        .Number("BestScore").Text("PilotName", 64).Vector3("Position")
        .Migration(new ProgressVersion1To2());
}

Remarks

A field name is 1 to 64 letters, digits, dashes and underscores, case sensitive, and is the key stored in the file, so keep it when the C# that fills it is renamed. Each method checks what it can at once and throws a LunySaveException: a name given twice, a step from a version the schema cannot have, two steps from one version. A schema with no field, or whose steps leave a version without a step between the oldest one and the current one, is refused where it is first used, because a later call may still add the field or step.
