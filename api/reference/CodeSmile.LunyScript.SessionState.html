What a session is doing. Read through Net.IsConnected and reported by State.

public enum SessionState
Expand Details ...

Fields

Connected = 2

Connected, as host or as client.

Connecting = 1

A join is in flight. Not yet connected, and not an error.

Disconnected = 3

The session ended because the connection was lost rather than because EndSession was called. Distinct from Offline so a script can tell a player they were disconnected rather than silently showing a menu.

Offline = 0

No session. The starting state, and the state after EndSession.

Remarks

Connecting is its own state rather than a flavour of Offline, because a script that shows "connecting" and a script that shows "offline" are showing different things to a player, and rule 45 forbids collapsing them.
