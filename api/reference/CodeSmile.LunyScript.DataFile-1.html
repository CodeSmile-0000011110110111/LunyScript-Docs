A JSON file of one data schema, which Asset.Load(file).Into(data) reads into a Define.Data of that schema.

public readonly struct DataFile<THandle> where THandle : struct, ILunyScriptDataVariables

Type Parameters

THandle

The schema's generated Variables.

Expand Details ...

Examples

StatsFile = Bind.Data(WeaponStats.Schema).FromStreamingAssets("weapon.json");
On.Ready(Asset.Load(StatsFile).Into(Stats).As(LoadingStats));

Remarks

The file is read when the load runs, never at spawn, and names the same file for every object running the script. It has no Inspector field.
