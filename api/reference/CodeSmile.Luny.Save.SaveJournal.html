Class SaveJournal

The last requests LunySave ended in this process, newest last, without the values they saved or loaded: each request's place in the order of accepted requests, its kind, path, owner, schema, stored version, how it ended and the fields a load omitted. A support report reads it to explain which owner saved what and in which order after the callers let go of their requests.

Remarks

The journal keeps the last Capacity entries; an older entry is dropped when a new one is recorded, so a caller that needs a result for longer keeps the request. It empties when Play Mode starts or stops, with the paths whose owners that ends.
