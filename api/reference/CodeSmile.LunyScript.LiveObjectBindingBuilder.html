Struct LiveObjectBindingBuilder

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What Bind.Object().LiveRebind() returns: a binding that searches again while it has no object.

public readonly struct LiveObjectBindingBuilder
Expand Details ...

Examples

Guard = Bind.Object().WithTag("Enemy").LiveRebind();

Remarks

It has no MustExist: a binding that may find its object later cannot also require it at the start.
