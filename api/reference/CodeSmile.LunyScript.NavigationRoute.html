What Navigation.Route(operation) returns: four conditions on the route of the latest attempt a Navigation.MoveTo bound to that handle started.

public readonly struct NavigationRoute
Expand Details ...

Examples

var route = Navigation.Route(Chase);
On.FrameUpdate(If(route.IsPartial).Then(Alert.Set("Cannot reach the player")));

Remarks

Before the first attempt all four are false. A new attempt reads pending until its route is known; after the attempt ends, the last route state stays readable. A move the gateway refused before any route was asked for, such as one with no backend or an actor with no agent, reads false in all four. A read is a value, not a block: it can be kept in a local.
