Struct DebugFactory

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The Debug surface: blocks that write a line to the Console when they run. Log(string, string, int) writes an ordinary entry, Warn a warning and Error an error.

public readonly struct DebugFactory
Expand Details ...

Examples

On.Ready(Debug.Log("ready"), Debug.Log(Health));
On.FrameUpdate(If(Health < 20).Then(Debug.Warn("low health", Health)));

Remarks

It hides UnityEngine.Debug inside a script the same way Time hides UnityEngine.Time: inside a Script or an EditorScript, Debug means this one.

Each call builds a block, and the block writes each time it runs. A variable's value is read then, for the object the block runs on, so Debug.Log(Health) placed in On.FrameUpdate writes that object's health on every frame. The line is the message and value, then (Script: <script>, Object: <object>), then the line the block was written on as a link: Health = 15 (Script: PlayerScript, Object: Player). A variable shows its declared name; an expression such as Health + 5 has none and shows its value alone. Text is quoted.

The blocks write only where DEBUG is defined: the Editor and every development player. In a player built without it they read nothing and write nothing. An error line is a message, not a failure: the script keeps running.

Debug.Log("HP: " + Health) compiles, because C# joins any value to a string, and the string is made once while the script type is built, from the handle's description. Write Debug.Log("HP", Health) to log the value.
