Remarks

This assembly compiles only where Unity's AI module is enabled. Its assembly definition carries a version define, LUNY_NAVIGATION from com.unity.modules.ai 1.0.0 or newer, and a matching define constraint, which is the arrangement CodeSmile.LunyScript.Cinemachine uses for Cinemachine. NavMeshAgent is part of that built-in module. The AI Navigation package, com.unity.ai.navigation, adds the components that bake a navigation mesh; this provider needs a navigation mesh at run time and does not care how it was made.

Nothing here finds a route. Unity's agent asks the navigation mesh for the route, follows it with the speed, acceleration, stopping distance and avoidance the author configured, and reports what it knows. This provider translates those reports, which is what the settled contract-targeting-navigation answer asks for: "No new pathfinding engine".

An agent that cannot navigate is left alone. Unity writes an error of its own when a script calls SetDestination, ResetPath or isStopped on an agent that is inactive, disabled or off the navigation mesh, so every member checks isActiveAndEnabled and isOnNavMesh first and reports the reason instead.

A route reaches the destination, or it is partial. Unity moves a destination that is off the navigation mesh, such as a point inside a wall or on a ledge too small to keep, to the nearest point on the mesh, and calls the route to that point complete. This provider reports such a route as partial, because it does not reach the destination the script asked for, and a RequireComplete() move refuses it. Measured on 6000.7.0b1 in run navigation-smoke-01: a destination on an island top too small for the mesh became a floor point 1.8 units away, and Unity's pathStatus was PathComplete.

An end needs a known route and a known distance. The actor is at the end of its route when no route is being calculated, the route is not invalid, and remainingDistance is finite and at most stoppingDistance plus EndTolerance. Unity reports an unknown remaining distance as infinity, and the settled navigation lifecycle answer says that "unknown remaining distance is not a completion signal".

Fields

EndTolerance

How far beyond its stopping distance an actor may stand from the end of its route and still be at the end, in world units. An agent with automatic braking settles within a few thousandths of a unit of the end; this leaves room for that and for the rounding of the route's length.

public const float EndTolerance = 0.05

Remarks

A route Unity calls complete whose end lies further from destination than the agent's radius, measured across the ground, or further than the agent's height, measured up or down, is reported as partial: Unity moved a destination that is off the navigation mesh to the nearest point on it, and the route ends there.

Start(Object, Vec3)
