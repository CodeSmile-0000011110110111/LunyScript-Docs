Struct LeaderboardPage

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

A page of a leaderboard's entries a script reads, declared with Define.LeaderboardPage(name, rows): Leaderboard.Load(board).Into(page) fills it, top first, and Count, Rank(int, string, int), Score(int, string, int), PlayerName(int, string, int) and PlayerId(int, string, int) read it (C07 B). Each row is internal storage of the object, so a read allocates nothing and the debugger shows it.

public readonly struct LeaderboardPage
Expand Details ...

Examples

TopTen = Define.LeaderboardPage(nameof(TopTen), 10);
On.Ready(Leaderboard.Load(Weekly).Into(TopTen).As(LoadingBoard));
When.Leaderboard(LoadingBoard).Succeeded(Leader.Set(TopTen.PlayerName(0)), Best.Set(TopTen.Score(0)));

Remarks

A row is read by a constant index, 0 for the top row of the page; a row the last load did not fill reads rank 0, score 0 and empty texts. The page keeps what the last successful load wrote; a failed load writes nothing. The name and id are texts a script can also write, and the next load overwrites them.
