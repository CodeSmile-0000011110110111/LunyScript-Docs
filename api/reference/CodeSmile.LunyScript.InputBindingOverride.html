One binding override a backend reports for a local player's actions, or applies to them: which binding, and the control path it uses instead of the action asset's.

public readonly struct InputBindingOverride
Expand Details ...

Examples

var entry = new InputBindingOverride("Player/Fire/0c8e0f5a-8f7d-4c1b-9d52-0e4b5f4d8a11", "<Mouse>/rightButton");

Remarks

The key is the backend's own name for one binding, which a declared Settings document stores unchanged; InputSystemProvider writes map/action/binding-id and matches on the id. The core never reads inside a key, so a backend is free to choose one, as long as the same binding produces the same key after the game restarts.
