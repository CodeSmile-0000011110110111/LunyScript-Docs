Class SpawnRecipe

Namespace
CodeSmile.Luny.Spawn

An admitted, immutable spawn recipe: ordered phases of concurrent groups (the captain's Q16 answer), the signals a run accepts, and the content revision it came from. A run keeps the recipe it started with for its whole life, so an edited file takes effect in the next run (Q22).

Examples

var recipe = SpawnRecipe.From(new RecipeSpec("elite")
    .Phase(new PhaseSpec("fight")
        .SucceedWhenAll(PhaseRule.GroupsClear("elite", "reinforcements"))
        .Group(new GroupSpec("elite", "enemy.elite", "arena.center").Count(1))
        .Group(new GroupSpec("reinforcements", "enemy.melee", "arena.gates").Counts(3, 4, 5, 6)
            .Repeat(every: 8).MaxAlive(12).StopWhenEnded("elite")))).Require();

Remarks

Admission checks everything a run would otherwise meet: keys, unique ids, counts, times, retry policies, that every reference names a declared group or signal, and that every repeat group has a positive interval, a live cap and a stop, a signal, a source group or an elapsed bound on its phase, so no admitted recipe can schedule without end.
