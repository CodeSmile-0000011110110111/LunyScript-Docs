What Bind.Object() returns: an object binding that is complete once it is assigned or named. WithTag and Named set what the scene search looks for; MustExist and LiveRebind each end the choice of what happens when nothing is found.

public readonly struct ObjectBindingBuilder
Expand Details ...

Examples

Witch = Bind.Object();
Boss = Bind.Object().WithTag("Boss").Named("ThirdBoss");

Remarks

Without a filter the search looks for an object named like the declaration. Witch = Bind.Object(); looks for an object named Witch. WithTag and Named replace that criterion, and every one written must hold. An Inspector assignment is used as it is, whatever the filters say.

LiveRebind()

Searches again, before the script's next update, while the binding has no object: after it found nothing and after the object it found ended. An object the Inspector assigned is never replaced.

public LiveObjectBindingBuilder LiveRebind()

MustExist()

Refuses to start the script on an object whose first resolution finds nothing. A target that ends later leaves the binding unavailable, and the script keeps running.
