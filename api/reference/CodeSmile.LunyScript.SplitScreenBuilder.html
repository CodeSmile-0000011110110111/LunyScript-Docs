What View.SplitScreen(...) returns: a split screen over the whole screen with no shared view. It converts to the block, or takes Within(NumberValueBlock, NumberValueBlock, NumberValueBlock, NumberValueBlock) and then Shared(ObjectBinding).

Within(NumberValueBlock, NumberValueBlock, NumberValueBlock, NumberValueBlock)

Lays the views out within a part of the screen instead of the whole of it.

public SplitScreenWithinBuilder Within(NumberValueBlock x, NumberValueBlock y, NumberValueBlock width, NumberValueBlock height)

Parameters

Type Name Description
NumberValueBlock
x

The area's left edge, 0 at the left of the screen and 1 at the right.
NumberValueBlock
y

The area's bottom edge, 0 at the bottom of the screen and 1 at the top.
NumberValueBlock
width

How much of the screen's width the area takes.
NumberValueBlock
height

How much of the screen's height the area takes.

Returns

SplitScreenWithinBuilder

A builder that converts to the block and takes Shared(ObjectBinding).

Examples

On.Ready(View.SplitScreen(View1, View2).Within(0.33, 0, 0.67, 1));

Remarks

The four numbers are fractions of the screen, as View.For(view).SetViewport takes them, and are evaluated where the block runs. An area is refused when x or y is below 0, width or height is not above 0, x + width or y + height is above 1, or a number is not finite: a literal area when the script type is built, and an area read from variables when the block runs, reported once as an error with nothing laid out.

Exceptions

LunyScriptUsageException

A number is null, a literal area is not part of the screen, or the builder is a default one.

Examples

Remarks

The same area as the four-number form, with the position's X and Y as its left and bottom edges and the size's X and Y as its width and height, refused for the same reasons.
