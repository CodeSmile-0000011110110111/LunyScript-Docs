What a write request did on the service, the commit-status receipt of the settled answer C09 A: a failure keeps its classification, and this says whether the service may already hold the write.

public enum CloudCommit : byte
Expand Details ...

Fields

Confirmed = 2

The service confirmed the write.

None = 0

A read, or a write that has not ended.

NotSubmitted = 1

The write did not reach the service, or the service did not take it.

Unknown = 3

The write was sent and its outcome on the service is not known.

Examples

if (saving.Commit == CloudCommit.Unknown) ReloadBeforeRetrying();

Remarks

A read has None throughout. A write has None while it waits or is in flight, then Confirmed when the service confirmed it; NotSubmitted when it never reached a backend, or the backend reported Offline, Timeout, RateLimited, Denied or NotFound; and Unknown when the backend failed in a way it could not classify after the call was made, or the request was cancelled after it was sent. A request cancelled after sending that the backend later confirms becomes Confirmed. Nothing is ever resent because of this value.
