Class CloudData

Namespace
CodeSmile.Luny.Cloud
Assembly
ApiSource.dll

The data part of a CloudClient: one JSON value per key in the player's data, which the client reads and writes, and the game's published data, which it only reads.

public sealed class CloudData
Expand Details ...
Inheritance
object
CloudData

Examples

var saving = cloud.Data.Save(CloudAddress.PlayerData("Career"), "{\"Best\":12}");

Remarks

A value is stored and returned as it is; the client never reads its fields. The settled answers C18 A ("one stored value for the whole document") and C04 A (typed sources: a game data item is read only to the client).
