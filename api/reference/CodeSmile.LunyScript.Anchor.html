Enum Anchor

Namespace

One of the nine reserved HUD regions a Panel.Place call can occupy: four corners, four edges, and the centre.

Examples

var portrait = Panel.Place(PlayerPortrait).At(Anchor.TopLeft);

Remarks

The name is interned onto the HUD template as the UXML name of that region, so TopLeft looks up the element named TopLeft. UXML and USS own the region's geometry; this enum only selects which named region receives the cloned tree.
