Where a BindingCandidate is.

public enum BindingCaptureState
Expand Details ...

Fields

Canceled = 2

Escape, the gamepad's East button or Cancel() ended it with no change.

Captured = 1

A control was captured; Conflicts lists what it displaces, and the live controls are unchanged until the candidate is accepted.

Committed = 4

The candidate was accepted and its bindings applied.

Failed = 5

The Input System could not start the capture, or the action has no binding a capture can target.

Invalidated = 3

The player's device was lost, the person on the player changed, or the player's bindings changed elsewhere since the capture began; nothing changed.

Listening = 0

Waiting for the player to press a control on one of their own devices.

Examples

if (candidate.State == BindingCaptureState.Captured) ShowConflicts(candidate);
