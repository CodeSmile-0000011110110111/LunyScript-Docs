What Bind.Prefab(), Bind.Texture2D(), Bind.AudioClip(), Bind.AudioMixer(), Bind.AudioMixerGroup() and Bind.VisualTreeAsset() return: an input declaration that is complete once it is assigned or named.

public readonly struct AssetInputBuilder<TInput> where TInput : struct

Type Parameters

TInput

The handle the declaration produces, such as Texture2D.

Expand Details ...

Examples

Portrait = Bind.Texture2D();
Poster = Bind.Texture2D().FromResources("ApiExamples/StripePoster");
var banner = Bind.Texture2D().As("Banner");

Remarks

Assigning it declares the input. Portrait = Bind.Texture2D(); converts the chain into the TInput handle, and the property the generator writes for that line gives the input the member's name, which is its durable identity. .As(name) names it explicitly and is what a hand-written property or a local uses. A chain that is neither assigned nor named is refused when Build() finishes.

FromResources(key) names where the asset loads from when the object assigns nothing. The key is loaded once, while the script type is built. An Inspector assignment always wins over it.

A Texture2D or AudioClip input can name a file instead, with FromStreamingAssets, FromUserData or FromTemp. The file is read when Asset.Load runs on an object that assigns nothing, and a successful load puts the decoded PNG or WAV into that object's input. Until then the input holds its asset placeholder.
