The runtime ITextSink for a text variable declared with allocating storage: a bounded UTF-8 buffer on the heap, allowed to allocate when the content changes and not when the same content is written again.

Remarks

Fixed-capacity text still lives in FixedString slots. This sink is the fallback AGENTS.md rule 15 names for content above 4096 bytes, and it is also what a script uses when it declares allocating storage at a smaller bound. It is not networked: a build that tries to synchronise an allocating text variable is refused where the variable is declared.
