Struct SpawnBuilder

Namespace
CodeSmile.LunyScript

ApiSource.dll

What Object.Spawn(prefab) returns: a spawn with no placement yet. Add At(Vec3ValueBlock), ChildOf(string, string, int), Into(string, string, int) and ForPlayer(int, string, int) in any order, or use it as a block, which spawns the prefab at its own pose.

public readonly struct SpawnBuilder
Expand Details ...

Examples

On.Ready(Object.Spawn(Sentry));
On.Ready(Object.Spawn(Sentry).At(new Vec3(0.0, 1.0, 0.0)).ChildOf().Into("Guard"));

Remarks

The three builder structs are a typestate: this one offers At and no frame modifier, SpawnPlacedBuilder offers the two frame modifiers and no second At, and SpawnFramedBuilder offers neither. So Object.Spawn(p).InWorldSpace() and Object.Spawn(p).At(a).At(b) and Object.Spawn(p).At(a).InWorldSpace().InLocalSpace() are all compile errors rather than run-time checks; AGENTS.md rule 41 and the settled semantics-t08 answer, which asks for conflicting space clauses to be unavailable in typestate.

The implicit conversion is what AGENTS.md rule 42 asks for: every builder either converts to a block or registers its finish action before Build() returns, so an unfinished chain cannot silently drop its behaviour.

SpawnPlacedBuilder

A builder that can still take a frame, a parent and a name.

Examples

On.Ready(Object.Spawn(Sentry).At(new Vec3(0.0, 1.0, 0.0)));

Remarks

The expression is evaluated where this block runs, not where the runner applies the spawn, so a position read from a variable is that variable's value at the authored line. The coordinates are the parent's until InWorldSpace() says otherwise; with no parent the two are the same coordinates.

Exceptions

LunyScriptUsageException

position is null, or this builder is a default that no Object.Spawn(prefab) call produced.

SpawnBuilder

A builder that can still take a placement and a name.

Examples

On.Ready(Object.Spawn(Sentry).ChildOf());

Remarks

Omitting the name parents it to the object the script runs on, which is the same "self by omission" the rest of the Object surface uses. A named parent is an object this script produced, by Object.Create(name) or by another spawn's Into(string, string, int). A parent whose slot is empty when the spawn is applied leaves the produced object at the scene root and reports it.

Exceptions

LunyScriptUsageException

name is whitespace, this chain already names a parent, or this builder is a default.

Into(string, string, int)

Holds the produced object in this script's owned-object slot of that name, so later blocks can address it.

public SpawnBuilder Into(string name, string callerFilePath = null, int callerLineNumber = 0)

Parameters

Type Name Description
string
name

The name this script addresses the produced object by.
string
callerFilePath

Supplied by the compiler. Do not pass one.
int
callerLineNumber

Supplied by the compiler.

Returns

SpawnBuilder

A builder that can still take a placement and a parent.

Examples

On.Ready(Object.Spawn(Sentry).Into("Guard"));

Remarks

A held object is owned: it is destroyed when the instance that spawned it is despawned, by every path that despawns one, exactly as an Object.Create object is. A spawn with no Into is not held at all and outlives the script that spawned it.

The name addresses the slot and is not the produced object's name in the scene: a prefab already carries a name, which is the difference from Object.Create(name) where the name is both.

Exceptions

LunyScriptUsageException

name is null or whitespace, this chain already names one, another call already produces that name, or this builder is a default.
