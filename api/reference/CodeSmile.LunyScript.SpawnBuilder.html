Struct SpawnBuilder

What Object.Spawn(pool) returns: a checkout of one pooled object with no placement of its own yet. Add At(Vector3ValueBlock), ChildOf(string, string, int), Into(string, string, int), ForPlayer(int, string, int) and SurvivesCaller(string, int) in any order, finish with As(Operation) to observe the attempt, or use it as a block.

public readonly struct SpawnBuilder
Expand Details ...

Examples

On.Ready(Object.Spawn(Guards));
On.Ready(Object.Spawn(Guards).At(Portal).InRadius(5.0).Into("Escort").As(TakeGuard));

Remarks

Where it goes, in order of precedence: the call's own At, then the pool's SpawnAt, then the world position and rotation of the object this script runs on. A call's At replaces the pool's whole placement, spread included, so Object.Spawn(Guards).At(Ambush) is exact and draws no random offset.

The use is owned by the instance that spawned it, with or without Into(string, string, int), and goes back to its pool when that instance ends. SurvivesCaller(string, int) leaves it with the scene instead.

The four builder structs are a typestate, the way the create chain's three are: a shape exists only after At, and a frame modifier only once, so a second At, a shape with no centre and a conflicting frame pair are compile errors.

Remarks

The attempt succeeds when the object is out of the pool and placed, in the drain after this block. It fails as CapacityExhausted when the pool is at its hard cap, and as NotFound when a landmark placement cannot be read; a refused spawn produces nothing and fills no name.

Remarks

The name is an address and nothing else: the use is owned by this instance with or without it, and the object keeps the name the prefab gives it in the scene. When the use ends by any path, the name is emptied.

SurvivesCaller(string, int)

Lets the checked-out object outlive the instance that spawned it: it stays out of the pool until it despawns itself, something ends it, or its scene unloads.

public SpawnBuilder SurvivesCaller(string callerFilePath = null, int callerLineNumber = 0)

Parameters

Type Name Description
string
callerFilePath

Supplied by the compiler. Do not pass one.
int
callerLineNumber

Supplied by the compiler.

Returns

SpawnBuilder

A builder that can still take the clauses it could take before.

Examples

On.FrameUpdate(If(Health <= 0).Then(Object.Spawn(Pickups).SurvivesCaller(), Object.Destroy()));

Remarks

Without it, the use goes back to its pool when this instance ends. With it, Into(string, string, int) still addresses the use while this instance runs. A use that survives the caller cannot be a child of the caller, so ChildOf() with this clause is refused while the script type is built.

Exceptions

LunyScriptUsageException

This chain already says it, or this builder is a default.
