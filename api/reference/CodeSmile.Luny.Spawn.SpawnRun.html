Struct SpawnRun

Namespace
CodeSmile.Luny.Spawn
Assembly
ApiSource.dll

The handle of one run of a recipe in a SpawnSession. It carries the run's generation, so a handle kept after the run was released reads IsValid false and its commands are refused; it never reaches a later run in the same slot (the captain's Q41 answer: stale handles are refused).

public readonly struct SpawnRun
Expand Details ...

Examples

var run = session.Start(recipe, seed: 7);
session.Advance(0.1);
run.Raise("boss-stage-2");
if (run.Read().State == RunState.Succeeded) run.Release();

Remarks

Every command waits for the next boundary, in call order, including a command made during one.

Release()

Releases the run at the next boundary: a running run is cancelled first, which ends its objects with RunCancelled; a terminal run's remaining objects end with RunReleased; then the handle becomes stale. A terminal run keeps its objects and its result until it is released, so a game can show the scene as the run left it.

public bool Release()

Returns

bool

False for a stale handle.

Examples

run.Release(); run = session.Start(recipe, seed: 8);   // a restart is a fresh run

Divides the delays before this run's future cohorts by factor: a finite group's first delay and a repeat group's batch interval, for cohorts that start from the next boundary on. Spacing inside a cohort and every committed due time stay as they are (the captain's Q49 answer).
