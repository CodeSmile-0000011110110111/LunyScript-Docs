The Motion surface inside Build(): component-directed movement, force and relocation for the object a script runs on.

public readonly struct MotionFactory
Expand Details ...

Examples

On.FixedUpdate(Motion.MoveTo(Pad).AtSpeed(4.0));
On.FixedUpdate(Motion.AddForce(Thrust).InWorldSpace());
On.FixedUpdate(If(Pulse).Then(Motion.AddImpulse(Blast).AsExplosion(Hub, 6.0), Pulse.Set(false)));
On.Ready(Motion.TeleportTo(Spawn));
On.LateUpdate(Motion.FlockChildren().Towards(Goal));

Remarks

Motion is not Transform. Transform.MoveBy writes pose immediately, with no physics. Motion.MoveBy selects a CharacterController, a kinematic Rigidbody, or a direct transform, and refuses a dynamic Rigidbody. Dynamic bodies use AddForce(Vector3ValueBlock, string, int), AddImpulse(Vector3ValueBlock, string, int), SetVelocity(Vector3ValueBlock, string, int) and StopMotion(string, int), and an explosion is AddForce(strength) or AddImpulse(strength) followed by AsExplosion(center, radius). Relocation that is not traversed movement is TeleportTo(Vector3ValueBlock, string, int). Switching a Rigidbody between kinematic and dynamic is Body.MakeKinematic() and Body.MakeDynamic(). API-semantics M20.

Kinematic displacement, every physical input, and a Rigidbody teleport belong in On.FixedUpdate. Written in any other event they are reported once and ignored; they are not transferred to a later step. API-semantics M12.

FlockChildren(string, int) is the one call that moves the object's children rather than the object: it writes their positions once per frame from On.Update or On.LateUpdate, with no physics and no collision.

FlockChildren(string, int)

Moves the active direct children of the object this script runs on as one flock toward a goal, keeping them apart from each other. Incomplete until Towards names the goal.

public MotionFlockChildrenBuilder FlockChildren(string callerFilePath = null, int callerLineNumber = 0)

Parameters

Type Name Description
string
callerFilePath

Supplied by the compiler. Do not pass one.
int
callerLineNumber

Supplied by the compiler.

Returns

MotionFlockChildrenBuilder

A builder that takes Towards.

Examples

Goal = Bind.Object();
On.LateUpdate(Motion.FlockChildren().Towards(Goal));

Remarks

Written in On.Update or On.LateUpdate and run every frame. The first call captures the object's active direct children and their local positions; from then on the flock keeps each child's position itself, writes it to the child every frame, and reads no child position again, so a child something else moved is put back. Moving, turning or scaling this object carries the flock. Speed, spacing and range are world units. A frame without the call ends the flock, and the next call captures the children again. A child that is destroyed, deactivated or moved to another parent leaves the flock until then; one added or activated joins at the next capture. Only the position is written, and nothing collides.

One call per object per frame: a second call on the same object in the same frame, from any script and from either event, is reported once and ignored, and so is a call written in any other event.

LunyScriptUsageException

Supplied by the compiler. Do not pass one.
int

MotionFollowBuilder

A builder that takes WithinDistance.

Examples

Leader = Bind.Object();
Pursuit = Define.Operation(nameof(Pursuit));
On.Ready(Motion.Follow(Leader).WithinDistance(2).AtSpeed(4).As(Pursuit));
When.Motion(Pursuit).EnteredRange(Status.Set("Close"));

Remarks

A run that lasts until it is cancelled, the target is lost or the object is disabled: the attempt As binds stays pending while the object holds inside the range, so it moves again when the target leaves. The range, the speed and the target are read when the run starts; the target's position is read every frame. A step never takes the object closer to the target than the range. The mechanism is the one MoveTo(...).AtSpeed uses: a CharacterController or an object with neither component moves once per frame, a kinematic Rigidbody once per physics step and starts only in On.FixedUpdate, and a dynamic Rigidbody is refused. When.Motion(op).EnteredRange and .ExitedRange observe the range. docs/proposals/follow-and-lead.md is the family.

Exceptions

LunyScriptUsageException

target was never declared, or was declared by another script's Build(), or this surface was read outside Build().
