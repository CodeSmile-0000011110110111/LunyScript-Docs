The Motion surface inside Build(): component-directed movement, force and relocation for the object a script runs on.

public readonly struct MotionFactory
Expand Details ...

Examples

On.FixedUpdate(Motion.MoveTo(Pad).AtSpeed(4.0));
On.FixedUpdate(Motion.AddForce(Thrust).InWorldSpace());
On.Ready(Motion.TeleportTo(Spawn));

Remarks

Motion is not Transform. Transform.MoveBy writes pose immediately, with no physics. Motion.MoveBy selects a CharacterController, a kinematic Rigidbody, or a direct transform, and refuses a dynamic Rigidbody. Dynamic bodies use AddForce(Vec3ValueBlock, string, int), AddImpulse(Vec3ValueBlock, string, int), SetVelocity(Vec3ValueBlock, string, int) and StopMotion(string, int). Relocation that is not traversed movement is TeleportTo(Vec3ValueBlock, string, int). API-semantics M20.

Kinematic displacement, every physical input, and a Rigidbody teleport belong in On.FixedUpdate. Written in any other event they are reported once and ignored; they are not transferred to a later step. API-semantics M12.
