Remarks

A breakpoint hit inside a dispatch is recorded where it happens and delivered once, when that dispatch has completed: every script the dispatch runs still runs, the runner is idle again, and the Editor's pause then takes effect at the end of the frame. When several breakpoints hit in one dispatch the first is the pause and HitCount counts them all. This type is built when ReadPauses() is called; recording the hit allocated nothing.
