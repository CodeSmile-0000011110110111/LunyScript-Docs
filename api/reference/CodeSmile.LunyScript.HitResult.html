Struct HitResult

Namespace
CodeSmile.LunyScript

ApiSource.dll

The nearest collider one cast touched: what Define.Hit declares and a cast's Into(hit) writes.

public readonly struct HitResult
Expand Details ...

Examples

Ground = Define.Hit(nameof(Ground));
On.FixedUpdate(
    Collision.RayCast().InLocalSpace().Towards(-Vector3.Up).Length(1.1).Into(Ground),
    Grounded.Set(Ground.HasHit));

Remarks

Each object running the script holds its own result. A cast replaces the whole result each time its block runs; a miss, or an origin that names no object, empties it, and so does a pooled respawn. Before the first cast, HasHit is false and every other read is zero. A single hit leaves out every collider the shape starts inside. docs/proposals/collision-queries.md is the family.
