Remarks

A generated reader such as EnemyScript.At(target) returns it; a script cannot construct one. It has no mutator: another script's variable changes only through a request its owner handles. Each evaluation resolves the target again, to the running instance of the expected script type, and returns the zero vector when there is none; docs/proposals/script-communication.md is the contract. Evaluating it allocates nothing.
