BindEnabled(ConditionBlock, string, int)

Keeps this toggle enabled while enabled is true and disabled while it is false. The element is written once it resolves, and again on each frame where the condition's value changed. A bind is declared once in Build() and never placed in an event.

public void BindEnabled(ConditionBlock enabled, string callerFilePath = null, int callerLineNumber = 0)

Parameters

Type Name Description
ConditionBlock

A condition or a Flag, evaluated each frame with the script's other binds.
string
callerFilePath

Supplied by the compiler.
int
callerLineNumber

Supplied by the compiler.

Examples

Exceptions

LunyScriptUsageException

The handle is one Build() never assigned, enabled is null, or this element's enabled state already has a BindEnabled or a SetEnabled.

BindValue(ConditionBlock, string, int)

Keeps this toggle on while value is true and off while it is false. The toggle is written once it resolves, and again on each frame where the condition's value changed. A bind is declared once in Build() and never placed in an event.

public void BindValue(ConditionBlock value, string callerFilePath = null, int callerLineNumber = 0)

string
callerFilePath

Supplied by the compiler.
int
callerLineNumber

Supplied by the compiler.

Examples

Remarks

The write does not run When.UI(toggle).ValueChanged; a player's click does.
