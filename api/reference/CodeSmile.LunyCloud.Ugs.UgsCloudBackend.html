The Unity Gaming Services backend for the account, player data, game data and player files: Unity Authentication and Unity Cloud Save behind ICloudCall, so the client polls and nothing awaits. It moved here from the core's UgsCloudSaveProvider and keeps its sign-in and its failure classification.

Remarks

Needs the project linked to a Unity Cloud project (cloudProjectId and organizationId in ProjectSettings/ProjectSettings.asset). A sign-in initialises Unity Gaming Services and signs in anonymously unless a session is already signed in; a sign-out keeps the cached session; a delete deletes the Authentication account only (C22 A).

A value is stored as one JSON object under its key in the player data the client may write, Cloud Save's Default access class; a game data item is a key of a custom item; a file is a player file. Every failure is classified once from RequestFailedException.ErrorCode; the service decides when a request has timed out and this backend adds no deadline.
