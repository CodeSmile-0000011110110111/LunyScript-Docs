A block that produces a Flag for one object: a variable read or a literal.

Remarks

Flag is a distinct type from Number and stays that way. Making it a number the way Lua does would make If(alive) accept 0.5, which has no meaning, and would give up the compile-time check that the typed handle exists for. AGENTS.md section 5.
