Struct UiWorldPlacement

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What Panel.Place(uxml).Over() and At(position) return: a clone kept over a world point, and the name scope for elements inside it. Offset is optional and written once.

public readonly struct UiWorldPlacement
Expand Details ...

Examples

var plate = Panel.Place(NamePlate).Over();
plate.Label("health").BindText(Health);

Remarks

The placement is declared when Over() or At(position) is called, so this handle is not a block and is not placed in an event list. The clone is made when the object spawns and its panel has loaded, and it leaves the panel when the object despawns. docs/proposals/world-anchored-labels.md is the contract.
