Class SaveFields

Namespace
CodeSmile.LunySave
Assembly
ApiSource.dll

The stored fields of one document while a SaveMigration step converts them. Reads and writes a copy: nothing here reaches the stored file or a document a caller holds.

public sealed class SaveFields
Expand Details ...
Inheritance
object
SaveFields

Examples

fields.Rename("best", "BestScore");
fields.DefaultNumber("Coins", 0);
if (fields.TryGetNumber("seconds", out var seconds))
    fields.SetNumber("Minutes", seconds / 60.0);

Remarks

A field is read by the kind the reader asks for, because the file stores values, not kinds: a number reads with TryGetNumber(string, out double), true or false with TryGetFlag(string, out bool), a text with TryGetText(string, out string), an array of two, three or four numbers with TryGetVector2(string, out Vector2), TryGetVector3(string, out Vector3), TryGetVector4(string, out Vector4), TryGetQuaternion(string, out Quaternion) or TryGetColor(string, out Color), an array of four or six numbers with TryGetRect(string, out Rect) or TryGetBounds(string, out Bounds), an array of whole numbers with TryGetVector2Int(string, out Vector2Int), TryGetVector3Int(string, out Vector3Int), TryGetColor32(string, out Color32), TryGetRectInt(string, out RectInt) or TryGetBoundsInt(string, out BoundsInt), and an object of texts with TryGetTextMap(string, out KeyValuePair<string, string>[]). Names are case sensitive. A name written by a step uses letters, digits, dash and underscore, 1 to 64 of them, the rule SaveSchema applies; any other name throws, and the load fails as Unsupported.
