What an assembly's scripts are for, which LunyScriptAssemblyAttribute declares.

public enum AssemblyUsage : byte
Expand Details ...

Fields

Production = 0

The game's own scripts. Their singletons start when the game starts.

Sample = 1

Sample or example scripts. Their singletons start only where a sample includes them.

Test = 2

Test scripts. Their singletons start only where a test includes them.

Examples

[assembly: LunyScriptAssembly(AssemblyUsage.Sample)]

Remarks

Only a production assembly's singleton scripts start when a game starts. An assembly that carries no attribute is a production assembly, unless it references NUnit, which makes it a test assembly. docs/proposals/singleton-scripts.md is the contract.
