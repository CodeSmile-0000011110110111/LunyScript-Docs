Struct DefineFactory

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The Define surface inside Build(): declares a script's variables, operations and collection results, and hands back the typed handles the blocks are built from.

public readonly struct DefineFactory
Expand Details ...

Examples

Health = Define.Number(nameof(Health), 100);
TeamScore = Define.Number(nameof(TeamScore), 0).Shared();
MatchData = Define.Store();
LevelKills = Define.Number(nameof(LevelKills), 0).Shared(MatchData);

Remarks

Object-local has no modifier. .Shared() with no argument is the default store. A declared store is .Shared(MatchData), after MatchData = Define.Store();. Nested Define.Shared.Number is not this surface. Explicit Var.Define remains supported.

The debugger shows a named sequence as one folded row with its name, and a diagnostic names it the same way. Used as a block it does what its blocks would do written out in its place; in a concurrent group it is one child. A line assigned to a local or to a hand-written property gets no name and is refused when Build() ends; Sequence(...) is the spelling for a sequence without a name. This factory takes a params array, so the generated setter supplies the line; AGENTS.md rule 72. docs/proposals/sequences.md is the contract.

Exceptions

LunyScriptUsageException

The list is null, empty or holds a null, or this surface was read outside Build().
