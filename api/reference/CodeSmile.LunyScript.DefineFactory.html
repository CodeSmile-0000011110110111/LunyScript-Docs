Struct DefineFactory

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The Define surface inside Build(): declares a script's variables with the author spelling Round 06 settled, and hands back the typed handles the blocks are built from.

public readonly struct DefineFactory
Expand Details ...

Examples

Health = Define.Number(nameof(Health), 100);
TeamScore = Define.Number(nameof(TeamScore), 0).Shared();
LevelKills = Define.Number(nameof(LevelKills), 0).Shared(CurrentLevel);

Remarks

Object-local has no modifier. .Shared() with no argument is the default store. A named store is .Shared(CurrentLevel). Nested Define.Shared.Number is not this surface. Explicit Var.Define remains supported.
