Struct PoolPlacedBuilder

Namespace
CodeSmile.LunyScript

What SpawnAt returns: a pool declaration with a default placement, which can still spread over a disk or a sphere, take a frame, and take a hard cap and a prewarm count.

InRadius(double)

Spreads the object uniformly over a disk of that radius around the placement, on its X and Z axes.

public PoolShapedBuilder InRadius(double radius)

Parameters

Type Name Description
double
radius

The disk's radius, a finite number above zero.

Returns

PoolShapedBuilder

A builder that can still take a frame and the other clauses.

Examples

Object.Spawn(Guards).At(Portal).InRadius(5.0)

Remarks

The disk lies on the placement's own axes, the landmark's or the stated rotation's, unless InWorldSpace() selects the world's. A landmark's scale does not resize the radius. Each spawn draws two random numbers.

Exceptions

LunyScriptUsageException

radius is not a finite number above zero, or this builder is a default.

InWorldSpace()

Reads the position as world coordinates, and lays any shape on the world's axes.

public PoolFramedBuilder InWorldSpace()

Returns

PoolFramedBuilder

A builder that can still take the other clauses.

Examples

Remarks

On a landmark placement the pose is a world pose already, so this selects the world's axes for a shape and nothing else.

Exceptions

LunyScriptUsageException
