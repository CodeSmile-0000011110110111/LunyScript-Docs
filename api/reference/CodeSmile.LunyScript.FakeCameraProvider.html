A camera backend that records what it was asked to do, with no Cinemachine package, no camera and no scene.

Remarks

This is a second real implementation rather than a test mock, in the same way FakeNetworkProvider is: it applies the same rules the Cinemachine adapter applies - a view must be a view, a rig must be a rig, a group operation needs a group - and it keeps the resulting state so a test can read it back. It is what makes every camera block testable in Edit Mode, which is also what proves the blocks build and run with Cinemachine absent.

It decides what an object is by what the test registered, through RegisterView(Object), RegisterRig(Object) and RegisterTargetGroup(Object). An object nothing registered is neither, which is how the refusals are exercised.
