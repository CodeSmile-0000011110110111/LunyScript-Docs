Class SpawnCombatantResolver

The resolver a CodeSmile.LunyAttack.Unity.AttackQuery uses for spawned combatants: a collider belongs to the live actor of the SpawnCombatant on its object or its rigidbody's object, and otherwise to a CodeSmile.LunyCombat.Unity.CombatActorHost the way CodeSmile.LunyCombat.Unity.CombatActorResolver resolves it.
