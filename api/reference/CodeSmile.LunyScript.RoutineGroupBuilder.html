What InParallel(...) returns: a concurrent group with no ending clause yet.

public readonly struct RoutineGroupBuilder
Expand Details ...

Examples

On.Ready(Routine("Open").Run(InParallel(slideDoor, playSound)));

Remarks

Used as it is, the group runs every child and waits for all of them, reporting Succeeded only if every child succeeded and Failed otherwise; a failure does not stop it early. The two clause calls replace that with an early ending. docs/execution-model.md, "Shared outcomes and concurrent groups", is the contract this shape implements.

Properties

Canceled

A condition that is true once this group was cancelled before it produced a result. Cancellation is neither a success nor a failure, so Succeeded and Failed are both false for the same group.

public ConditionBlock Canceled { get; }

Property Value

ConditionBlock

Examples

var open = InParallel(slideDoor, playSound);
On.Ready(Routine("Open").Run(open, If(open.Canceled).Then(retry.Set(true))));

Failed

A condition that is true once this group has ended Failed. A group that was cancelled has no result, so neither this nor Succeeded is true for it; Canceled is what is true for that group.

public ConditionBlock Failed { get; }

Property Value

Examples

Succeeded

A condition that is true once this group has ended Succeeded, for the routine steps written after it.

Methods

UntilOneFinishes()

The first child to reach a natural result, of either kind, ends this group with that result. Among children that became eligible in the same frame, the earliest declared one wins.

public RoutineGroupEndingBuilder UntilOneFinishes()

Returns

RoutineGroupEndingBuilder

The group, with that ending clause.

Examples

var race = InParallel(reachExit, timeOut).UntilOneFinishes();

UntilOneSucceeds()

The first child to succeed ends this group Succeeded. A child that fails ends nothing on its own; the group ends Failed only when every child has failed.

public RoutineGroupEndingBuilder UntilOneSucceeds()

Returns

RoutineGroupEndingBuilder

The group, with that ending clause.

Examples
