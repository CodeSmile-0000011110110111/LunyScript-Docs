What Define.Data(value) returns: this script's own copy of a LunyScriptDataAttribute struct, complete once it is assigned or named. Every object running the script starts from value, and a JSON load into it starts from value again.

public readonly struct DataDefineBuilder<TValue, THandle> where TValue : struct where THandle : struct, ILunyScriptDataVariables

Type Parameters

TValue

The schema struct.

THandle

Its generated Variables.

Expand Details ...

Examples

Stats = Define.Data(new WeaponStats { Damage = 10, Cooldown = 0.4 });
On.Ready(Stats.Damage.Add(5));

Remarks

Assigning it declares the data: Stats = Define.Data(...) converts the chain into the struct's generated Variables, and the property the generator writes for that line names the declaration after the member. .As(name) names it explicitly, which a hand-written property or a local needs.

Methods

Declares the data under an explicit name. Its variables are named after it, such as Stats.Damage.
