Struct BoxOverlapBuilder

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What Collision.BoxOverlap() returns: a box overlap that takes its clauses in any order, each once, and is finished by Into.

public readonly struct BoxOverlapBuilder
Expand Details ...

Examples

On.FixedUpdate(Collision.BoxOverlap().Size(2, 1, 4).InLocalSpace().Into(Nearby));

Remarks

World space is the default. InLocalSpace() or InWorldSpace() names the frame and returns SpacedBoxOverlapBuilder, which offers every clause but a second space clause. docs/proposals/collision-queries.md is the family.

At(ObjectBinding, string, int)

Sets where the query stands: the world position of a bound object, read each time the query runs. The object also supplies the local axes.

public BoxOverlapBuilder At(ObjectBinding target, string callerFilePath = null, int callerLineNumber = 0)

Parameters

Type Name Description

int

Returns

BoxOverlapBuilder

This query, which takes further clauses.

Examples

On.FixedUpdate(Collision.BoxOverlap().Size(2, 1, 4).InLocalSpace().At(Muzzle).Into(Nearby));

Remarks

With InLocalSpace(), Offset, a Towards vector, Oriented and an omitted direction all use the object's rotation. A binding that holds no object clears the result; an object that is destroyed, in no loaded scene or inactive clears it and is reported once. This object's own colliders stay the ones ExcludeSelf() leaves out.

Exceptions

LunyScriptUsageException

This builder is a default that no verb produced, the query already has an origin, or target was not declared by this script's Build().
