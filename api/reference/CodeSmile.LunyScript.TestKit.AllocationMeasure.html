Remarks

There are two instruments and neither one works everywhere, which is why this class exists rather than a one-line helper.

  1. GC.GetAllocatedBytesForCurrentThread(). Gives a byte count. Present in the API surface on every backend, but measured returning a constant on Unity 6000.7.0a5's Mono 6.13.0, where every delta is therefore 0 including the delta across a deliberate 4096-byte array allocation. A 0 from this instrument on Mono means "not measured", not "did not allocate", and reading it as the latter would make every allocation test in this project pass for the wrong reason.
  2. The profiler's GC.Alloc recorder, UnityEngine.Profiling.Recorder. Gives an event count rather than bytes. Measured working on Mono in the Editor. Profiler markers are compiled out of a non-development player, so this instrument is unavailable there. This is the same mechanism Unity's own Is.Not.AllocatingGCMemory() constraint uses.
Measure(Action, int, int) uses whichever instruments are usable, records in the returned AllocationSample which of them observed an allocation, and IsUsable reports whether any measurement is possible at all on this runtime. A test asserts on Allocates; only a test that has checked ByteCounterUsable may assert on a byte count.

The verdict comes from every usable instrument, and neither instrument's zero is trusted alone. The byte counter's zero can mean "not measured", as it does on Mono. And BytesPerIteration is an average, so a single 32-byte allocation spread over 128 iterations averages to 0 while the profiler counts its event; that is why TotalBytes is kept undivided and why the verdict is true when either instrument observed an allocation.

This class deliberately does not reference the test framework, so a project can ship it in a player build.

Methods

Measure(Action, int, int)

Runs work warmupIterations times without measuring, then measuredIterations times with every usable instrument.

public static AllocationSample Measure(Action work, int warmupIterations = 16, int measuredIterations = 128)

Parameters

Type Name Description
Action
work

The work to measure. Pass a cached delegate; a delegate created at the call site allocates once, outside the measured region, but one created inside the work would be measured.
int
warmupIterations

Iterations run before measuring. At least one is required on every backend: the first call to a method allocates in the runtime's own structures, which is a one-time cost and not a property of the work.
int
measuredIterations

Iterations the figures cover. The byte figure is reported as a total across all of them, and divided by this only where a caller asks for a per-iteration figure.

Returns

AllocationSample

What was observed, and by which instrument.

Examples

var sample = AllocationMeasure.Measure(() => instance.SetHealth(10.0));
Assert.That(sample.Allocates, Is.False, sample.ToString());

Exceptions

LunyScriptUsageException

No instrument works on this runtime, so the question cannot be answered here at all; work is null; or warmupIterations or measuredIterations is less than one.
