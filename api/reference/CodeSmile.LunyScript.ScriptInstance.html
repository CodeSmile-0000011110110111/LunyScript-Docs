Class ScriptInstance

Namespace
CodeSmile.LunyScript

One object's state for one program: the slot arrays the program's layout asked for, and the host the blocks act on. The blocks themselves are shared by every instance of the program and hold no per-object state at all.

public sealed class ScriptInstance

Examples

var instance = runner.Spawn(program, host);
instance.SetNumber(health.NumberSlot, 100.0);

Remarks

"Swapping the context" means passing a different ScriptInstance to the same block object. Nothing is copied and nothing is rebound. See AGENTS.md rule 21 and docs/execution-model.md.

An instance is reusable: Rebind(IScriptHost) points it at another host and ResetToDefaults() puts every slot back to its declared starting value, both without allocating. That is what makes pooling a memory copy rather than a spawn.

ScriptInstance(ScriptProgram, IScriptHost)

Allocates the slot arrays the layout asks for and copies the declared defaults into them. This is the one allocation the spawn boundary permits, and its size is exactly what SlotBytes predicts plus one array header per SlotArrayCount.

CopyTextSlot(in TextSlot, in TextSlot)

Copies one text slot into another. Allocates nothing.

public void CopyTextSlot(in TextSlot destination, in TextSlot source)

Parameters

Type Name Description
TextSlot
destination

The slot written.
TextSlot
source

The slot read.

Examples

instance.CopyTextSlot(lastWinner.TextSlot, playerName.TextSlot);

Remarks

Copying a slot onto itself does nothing and leaves the text as it was. The check is required rather than tidy: SetText reaches FixedString.CopyFrom, which empties the destination before it appends the source, so a self-copy without this early return would clear the variable and report no error.

Exceptions

LunyScriptUsageException

The source text does not fit in the destination's declared capacity. The destination is left unchanged.

Parameters

Returns

The asset this object resolved that input to.

Type Parameters

The asset type the input was declared with.

Examples

var clip = behaviour.GetAsset(script.OpenSound);

Remarks

The value is never null and is always of the declared type. It was resolved when this object spawned, from what the host stored, then the input's declared source, then the asset placeholder for its type; an input that none of the three could supply refused the spawn, so an instance that exists has every input filled.

Exceptions

LunyScriptUsageException

The handle was never declared, or it addresses a slot this program does not have, which is what a handle borrowed from another script does.
