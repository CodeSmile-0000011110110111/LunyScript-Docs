Struct Viewport

Namespace
CodeSmile.Luny.Camera
Assembly
ApiSource.dll

A share of the screen in the unit square: 0 to 1 on both axes with 0 at the bottom left, the way Unity's Camera.rect reads it. A viewport of zero width or height is no share at all.

public readonly struct Viewport
