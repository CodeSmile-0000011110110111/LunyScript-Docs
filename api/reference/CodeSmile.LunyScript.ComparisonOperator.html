Which comparison a CodeSmile.LunyScript.NumberComparisonBlock performs.

public enum ComparisonOperator
Expand Details ...

Fields

Equal = 4

Left equals right. Compares two Double values exactly; see docs/execution-model.md on why exact comparison is what the API offers and what a user should write instead when a tolerance is wanted.

Greater = 0

Left is greater than right.

GreaterOrEqual = 1

Left is greater than or equal to right.

Less = 2

Left is less than right.

LessOrEqual = 3

Left is less than or equal to right.

NotEqual = 5

Left does not equal right.

Remarks

The operator is a literal field on the block rather than six separate block types, because "compare two numbers" is one behaviour with a parameter; AGENTS.md rule 22 allows a literal as a block field.
