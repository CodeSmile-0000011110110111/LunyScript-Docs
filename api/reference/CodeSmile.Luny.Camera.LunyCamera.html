Class LunyCamera

Namespace
CodeSmile.Luny.Camera
Assembly
ApiSource.dll

LunyCamera's entry type: it finds the view a camera, a rig or an object under them belongs to. A view is created or bound by a CameraHost, the one persistent owner, or by a LunyCoop session; the shots and layouts are CameraShot and ViewportLayout, and LunyData.Camera reads both from Luny/Camera/.
