LunyScript API Reference

Class CloudWatches

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The cloud watches a script writes inside Build() with When: When.Cloud, When.Account and When.Leaderboard. Each observes the attempt a start of its family bound to the handle, the same attempt When.Operation(handle) observes: both can be registered, and the runtime starts no second attempt (C02 A). A handle no start of the family binds is refused when Build() finishes.
