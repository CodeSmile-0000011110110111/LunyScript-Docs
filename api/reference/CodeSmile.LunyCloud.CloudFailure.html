Enum CloudFailure

Namespace
CodeSmile.LunyCloud
Assembly
ApiSource.dll

Why a cloud request failed, classified once by the client or the backend that answered, so no caller ever sees an exception type for a service outcome. The LunyScript adapter maps each value to the OperationFailure of the same name.

public enum CloudFailure : byte
Expand Details ...

Fields

CapacityExhausted = 9

The bounded score queue is full; the score was not queued.

Denied = 4

The service understood the call and refused it, or the key is one the service refuses.

Expired = 8

A waiting score whose board ended a season after the score was submitted; it was not sent (C24 A).

None = 0

No failure: the value while a request waits or is in flight, and after it succeeded.

NotFound = 5

The key, item, file, board or entry does not exist, or no C# source is registered for a file.

NotSignedIn = 2

No account is signed in, and this request does not sign one in: the player signed out or deleted the account, and no Account.SignIn followed.

Offline = 1

No usable network connection; the request did not reach the service.

RateLimited = 3

The service refused the call because too many were made; it did not take the request.

Timeout = 6

The backend gave up waiting for an answer. LunyCloud sets no deadline of its own; a timeout counts as not delivered, by the captain's rule of 2026-09-26.

Unknown = 7

A failure that maps to no narrower reason, a backend that threw or returned no call, or a service whose backend is not installed. The client logs the original text once.

Examples

if (saving.State == CloudRequestState.Failed && saving.Failure == CloudFailure.Offline) ShowOfflineNote();
