LunyScript API Reference

Struct RoutineBuilder

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What Routine(name) returns. Its one call, Run(params Block[]), takes the steps the routine runs in order and produces the block that starts an activation of it.

public readonly struct RoutineBuilder

Examples

On.Ready(Routine("Rescue").Run(InParallel(carry, callForHelp).UntilOneEnds()));

Remarks

The block Run(params Block[]) returns is where the routine is started, not where it runs: executing it starts one activation on the object the block ran against, and the runner advances that activation once per frame until its last step finishes. Starting an activation while one is already running replaces it, cancelling the first.

Methods

Run(params Block[])

The steps this routine runs, in the order they are written. Each one finishes before the next begins.

public Block Run(params Block[] steps)

Parameters

steps Block[]

The steps. An ordinary block is one step and finishes in the call that runs it; an ActionBlock, such as a group, is advanced once per frame until it reports a result.

Returns

Block

The block that starts one activation of this routine.

Examples

On.Ready(Routine("Patrol").Run(walkOut, waitAtPost, walkBack));

Exceptions

LunyScriptUsageException

The step list is null, holds a null, is empty, or this builder was never obtained from a script's own Routine(name) call.
