A Collision.SphereOverlap() whose frame has been named: every clause but a second space clause.

public readonly struct SpacedSphereOverlapBuilder
Expand Details ...

Examples

On.FixedUpdate(Collision.SphereOverlap().Radius(5).InLocalSpace().Into(Nearby));

Remarks

A separate type from SphereOverlapBuilder so that a second space clause does not compile, as a Transform verb's does; AGENTS.md rule 41.

At(ObjectBinding, string, int)

Sets where the query stands: the world position of a bound object, read each time the query runs. The object also supplies the local axes.

public SpacedSphereOverlapBuilder At(ObjectBinding target, string callerFilePath = null, int callerLineNumber = 0)

Parameters

Type Name Description

string

int

Supplied by the compiler.

Returns

SpacedSphereOverlapBuilder

This query, which takes further clauses.

Examples

On.FixedUpdate(Collision.SphereOverlap().Radius(5).InLocalSpace().At(Muzzle).Into(Nearby));

Remarks

With InLocalSpace(), Offset, a Towards vector, Oriented and an omitted direction all use the object's rotation. A binding that holds no object clears the result; an object that is destroyed, in no loaded scene or inactive clears it and is reported once. This object's own colliders stay the ones ExcludeSelf() leaves out.

Exceptions

LunyScriptUsageException

This builder is a default that no verb produced, the query already has an origin, or target was not declared by this script's Build().
