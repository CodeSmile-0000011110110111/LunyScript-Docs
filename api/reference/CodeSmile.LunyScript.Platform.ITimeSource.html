Interface ITimeSource

Namespace
CodeSmile.LunyScript.Platform
Assembly
ApiSource.dll

The only place LunyScript reads the passage of time. Blocks and the runner take an ITimeSource instead of calling UnityEngine.Time or System.DateTime.UtcNow directly.

public interface ITimeSource

Remarks

.NET 10 seam. The counterpart is System.TimeProvider, which does not exist in .NET Standard 2.1 and therefore cannot be used while Unity 6.7's Mono and IL2CPP backends are targets. When the product drops pre-Unity 7 support, the implementation of this interface becomes a wrapper over a TimeProvider and every caller stays unchanged. Replacing: UnityEngine.Time.deltaTime, UnityEngine.Time.time, System.DateTime.UtcNow, System.Diagnostics.Stopwatch.

Four reads, in two pairs. The first pair is the clock a game's own speed is measured on, so a time scale below one slows it and a pause stops it. The second pair is real time, which neither the scale nor a pause changes. A clock that is never scaled, such as the editor session's, answers both pairs with the same numbers, and that is a correct answer rather than a placeholder. IGameClock is what adds the scale and the pause; a clock that only reports time implements this interface alone.
