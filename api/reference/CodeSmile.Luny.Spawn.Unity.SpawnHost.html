Class SpawnHost

The scene host of LunySpawn: it owns one SpawnSession, advances it by game time once per frame, resolves a recipe's keys through its SpawnBindings asset and the scene's placements, places, pools and releases the objects, and ends every run with the scene (the captain's Q12 answer: one scene host with separately owned runs).

    [SerializeField] private SpawnHost m_Host;

    public void Open(SpawnRecipe recipe) => m_Run = m_Host.StartRun(recipe, this, seed: 7).Require();
    public void Close() => m_Run.Cancel();
}

Remarks

Runs are owned. StartRun(SpawnRecipe, Object, int) names the scene object that owns the run; when that object is destroyed, the run is cancelled at the next boundary. A paused game (time scale 0) advances nothing.

Participants. AddParticipant(Transform) and RemoveParticipant(Transform) keep the joined players: their count, 1 to 4, sets every cohort's authored total, and their positions keep arrivals at each binding's separation.

Objects. A binding is fresh by default and pooled when it says so (the captain's Q13 answer). Every object carries a SpawnedObject marker that reports a removal by anything other than the host, and every ISpawnParticipant on it begins and ends each use.
