Struct PanelFactory

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The Panel surface inside Build(): typed binds, Place of a UXML fragment, and Open/Close of a menu. It hides PanelRenderer inside a Script the same way Transform hides UnityEngine.Transform.

public readonly struct PanelFactory
Expand Details ...

Examples

var health = Panel.Label("health");
health.BindText(Text.Format("{0}% HP", Health));

Remarks

Authors never type PanelRenderer or VisualElement. The supported scene component is PanelRenderer. UIDocument is not probed. Runtime-only: a scene-free editor host reports once and writes nothing.
