Class CloudSaveGateway

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Owns every in-flight Cloud Save request for one ScriptRunner, keyed by the save key. Signs in when the first request arrives, queues requests made before the service is ready, coalesces duplicates, polls each operation once per frame, and classifies every failure once into an OperationFailure. No script and no block ever sees a Task or an exception type; AGENTS.md section 12.

Remarks

Coalescing, stated exactly. A save enqueued while one is in flight for the same key keeps the latest value and issues one follow-up save when the in-flight one completes, so a script that saves every frame produces one request at a time rather than one per frame. A load enqueued while one is pending for the same key joins it and starts nothing.

The pending path allocates nothing per frame. A request allocates when it is made and when its operation starts, which is the boundary AGENTS.md rule 31 names; a tick that only polls allocates nothing, and a tick with no provider or no requests returns immediately.

Outcomes are counters, read by the When.Cloud(key) watch blocks. Each completion advances the key's saved, loaded or failed counter; a watch block compares the counter against a shadow variable once per frame, the same polling shape When.Var(x).Changed has. A failed sign-in fails every queued request once, and every request made after it fails immediately with the sign-in's classified reason; there is no retry in this version, and docs/slice-decisions.md records that decision.

Remarks

A throwing provider cannot leave this method. Every call this gateway makes into ICloudSaveProvider and into the operations a provider returns is guarded, and a caught exception becomes OperationFailure.Unknown on the operation it belongs to, logged once with the original exception text. See the comment on TickSignIn for why.

A provider that returns no operation loses no request. A null is classified as OperationFailure.Unknown and logged once, so When.Cloud(key).Failed fires rather than nothing happening. Which records it is counted on follows the operation. A null from Save(string, double) or Load(string) reaches RecordMissingOperation and is counted once on that one key's record. A null from SignIn() reaches EndSignInAsFailed and then FailAllQueued and FailImmediately, so it is counted on every queued key's record rather than on one key's, the way a sign-in that failed is; docs/slice-decisions.md D5.16.

Examples

Remarks

The only provider code this method calls is Describe(), to name the provider in its log line and in that exception's message, and it is guarded: a provider whose Describe throws is named by its type instead, and the exception does not leave this method.

Exceptions

LunyScriptUsageException

provider is null.

LunyScriptUsageException

A provider was already named. A gateway talks to one backend for its lifetime; with domain reload disabled the default runner and its gateway are reset between Play sessions, so each session names its provider once.
