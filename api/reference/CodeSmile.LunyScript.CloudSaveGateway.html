Class CloudSaveGateway

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Owns every cloud upload, download and delete of a document one ScriptRunner's scripts start: signs in when the first request arrives, queues requests in the order their blocks ran, sends one request per document at a time, polls each operation once per frame, and completes each request's attempts with its classified outcome. No script and no block ever sees a Task or an exception type; AGENTS.md section 12.

Examples

runner.CloudGateway.UseProvider(new FileCloudSaveProvider(directory));

Remarks

Order and coalescing, stated exactly. Requests for one document run one at a time, in the order their blocks ran, so a download after an upload reads what the upload stored; uploads, downloads and deletes share that order, and requests for different documents do not wait for each other. A request is sent once the one before it for the same document has ended, whatever that ending was, with the values it captured when its block ran; a failed request is never sent again. An upload that finds the same object's upload of the same document still waiting replaces its captured values and joins its attempt; a download or a delete joins a waiting one of the same kind. That is the settled cloud-document-request-order A and the round 05 answer "queued requests continue".

A waiting request is removed without being sent when every attempt bound to it was cancelled before it started, which is what handle.Cancel() does; a download is also removed when none of its attempts is pending any more, and a download or a delete when its object despawned. An upload whose object despawned is still sent, because its values were captured.

Timing belongs to the provider. The gateway sets no deadline; the captain's words of 2026-09-26 are "we do not implement timeout ourselves, this is all handled by unity services package". A failed sign-in fails every queued request once, and every request made after it fails immediately with the sign-in's classified reason; there is no retry in this version, and docs/slice-decisions.md D5.3 records that decision.

The pending path allocates nothing per frame. A request allocates when its block runs and when it starts, which is the boundary AGENTS.md rule 31 names; a tick that only polls allocates nothing, and a tick with no request returns on its first line.

public void Tick()

Examples

gateway.Tick();

Remarks

A throwing provider cannot leave this method. Every call this gateway makes into ICloudSaveProvider and into the operations a provider returns is guarded, and a caught exception becomes OperationFailure.Unknown on the request it belongs to, logged once with the original exception text. A provider that returns no operation is classified the same way; docs/slice-decisions.md D5.12 and D5.16.

UseProvider(ICloudSaveProvider)

Names the backend this gateway talks to. Called once, by whoever owns the runner, before or after the first request; requests made before it are queued and dispatched once sign-in completes.

Remarks

The only provider code this method calls is Describe(), to name the provider in its log line and in that exception's message, and it is guarded: a provider whose Describe throws is named by its type instead, and the exception does not leave this method.

<p>
    <b>The supplied provider is replaced.</b> With the Cloud Save package installed, the default runner
    starts with <code>UgsCloudSaveProvider</code>, unless the project settings turn it off. A provider named here
    replaces it until it starts signing in, which it does at the first cloud request; requests queued
    before then go to the replacement. <code>docs/proposals/supplied-providers.md</code> is the contract.
</p>

Exceptions

LunyScriptUsageException

provider is null.

LunyScriptUsageException

A provider was already named, other than a supplied one that has not started signing in. A gateway talks to one backend for its lifetime; with domain reload disabled the default runner and its gateway are reset between Play sessions, so each session names its provider once.
