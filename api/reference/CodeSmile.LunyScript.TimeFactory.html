Struct TimeFactory

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The Time surface a script reads the game clock through, and the one place a script changes how fast that clock runs: Delta, Elapsed, Scale, IsPaused, SetScale(NumberValueBlock, string, int), Pause(string, int) and Resume(string, int).

public readonly struct TimeFactory

Examples

On.FrameUpdate(Age.Add(Time.Delta));
On.FrameUpdate(If(Health <= 0.0).Then(Time.Pause()));

Remarks

The scaled clock is the default and real time carries the word. Time.Delta is game time, so a game running in slow motion sees a smaller number and a paused game sees zero; Time.Delta.Unscaled() is real time, which neither the scale nor a pause changes. The modifier follows the verb and only the unusual case is written out, which is the same grammar a transform verb's frame uses. It applies to both readings and to nothing else here: a scale has no clock to choose, so Time.Scale and Time.IsPaused return types that carry no Unscaled and Time.Scale.Unscaled() does not compile.

Pausing sets the runner flag and zeros the time scale. Time.IsPaused reads the flag. Pausable scripts skip process events while it is set; WhenPaused and Always scripts keep ticking. On.FixedUpdate still does not run at scale zero, because Unity's fixed step is driven by game time. A pause menu declares SetProcessMode(Process.WhenPaused) and reads Time.Delta.Unscaled(). docs/execution-model.md, "Pause and the game clock", is the whole contract.

The scale is the game's, not this object's. One script pausing pauses everything, because that is what a time scale is. Nothing here is per object, and nothing here is synchronised: a peer that pauses its own game pauses only its own, and the network keeps ticking while it is paused, because the other peers are still playing.

This is the running game's clock. Every member is runtime-only, so a script built for an explicitly owned editor runner cannot use them; that runner's clock governs no game and has no scale to read or stop. EditorTime.Elapsed() is the editor session's own reading, and docs/editor-foundation.md owns that boundary.

Properties

Delta

How many seconds the previous frame took, in game time.

public TimeReadBlock Delta { get; }

Property Value

TimeReadBlock

Examples

On.FrameUpdate(Age.Add(Time.Delta));

Remarks

Scaled, so it is smaller in slow motion and zero while paused. Write Time.Delta.Unscaled() for the real-time frame length, which a pause does not change. This is the number a per-second rate is written with: Health.Add(-Drain * Time.Delta) loses Drain health per second whatever the frame rate is.

Elapsed

How many seconds of game time have passed since the run started.

public TimeReadBlock Elapsed { get; }

Property Value

TimeReadBlock

Examples

On.FrameUpdate(If(Time.Elapsed > 60.0).Then(Overtime.Set(true)));

Remarks

Scaled, so it stops advancing while the game is paused and advances at half speed at a scale of one half. Write Time.Elapsed.Unscaled() for real time, which keeps advancing while paused.

IsPaused

True while the runner paused flag is set, which is what Time.Pause writes.

public ConditionBlock IsPaused { get; }

Property Value

ConditionBlock

Examples

On.FrameUpdate(If(!Time.IsPaused).Then(Score.Add(1.0)));

Remarks

This is a condition, so it goes into If(...) and is negated with !. It reads the runner flag rather than testing whether the time scale is zero: Time.SetScale(0) stops the clock and does not set the flag.

Scale

How fast game time runs against real time: one at ordinary speed, one half in slow motion, zero while paused.

public NumberValueBlock Scale { get; }

Property Value

NumberValueBlock

Examples

On.FrameUpdate(If(Time.Scale < 1.0).Then(ShowSlowMotionBadge.Set(true)));

Pause(string, int)

Builds a block that stops game time, remembering the scale to come back to.

public Block Pause(string callerFilePath = null, int callerLineNumber = 0)

Parameters

callerFilePath string

Supplied by the compiler. Do not pass one.

callerLineNumber int

Supplied by the compiler.

Returns

Block

A block to place in an event list.

Examples

On.FrameUpdate(If(MenuOpen.IsTrue()).Then(Time.Pause()));

Remarks

Pausing an already paused game changes nothing. Pausable scripts skip process events while the flag is set; see this surface's own remarks and docs/execution-model.md.

Resume(string, int)

Builds a block that restarts game time at the last positive scale it was set to.

public Block Resume(string callerFilePath = null, int callerLineNumber = 0)

Parameters

callerFilePath string

Supplied by the compiler. Do not pass one.

callerLineNumber int

Supplied by the compiler.

Returns

Block

A block to place in an event list.

Examples

On.FrameUpdate(If(!MenuOpen.IsTrue()).Then(Time.Resume()));

Remarks

Resuming a game that is not paused changes nothing, so a resume written on every frame does not cancel a slow-motion scale another script set. The scale it comes back to is one when nothing set another.

LunyScriptUsageException

This factory was not obtained inside Build().

SetScale(NumberValueBlock, string, int)

Builds a block that sets the game's time scale.

public Block SetScale(NumberValueBlock scale, string callerFilePath = null, int callerLineNumber = 0)

Parameters

scale NumberValueBlock

The new scale: zero stops game time, one is ordinary speed, and a value above one runs the game faster than real time. A positive value is also what Resume(string, int) comes back to afterwards.

callerFilePath string

Supplied by the compiler. Do not pass one: it is what records the line of the script this block was written on.

callerLineNumber int

Supplied by the compiler.

Returns

Block

A block to place in an event list.

Examples

On.FrameUpdate(If(Bullets == 1.0).Then(Time.SetScale(0.25)));

Exceptions

LunyScriptUsageException

scale is null, or this factory was not obtained inside Build(). A scale that is negative, NaN or infinite is refused when the block runs, because an expression's value is not known until then.
