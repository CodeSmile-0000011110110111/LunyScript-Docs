Class CameraView

CodeSmile.Luny.Camera.Unity

One view: an output, the Unity Camera and its CinemachineBrain that render one picture, with the Cinemachine camera it shows, its share of the screen and the audience that sees it. A view is created by a CameraHost from a template, which the host owns and destroys when the view ends, or bound to an output another owner keeps, which ending the view leaves alone. UI places world labels and pointer rays through Output, and feedback reads Audience.

Remarks

Reads carry validity. A view that ended, or whose output was destroyed, as a scene unload destroys a bound camera, reads IsAvailable false, a null Output and None, and every command on it returns a refused CameraResult with Ended. A view created by the host keeps its identity across scene loads, because the host and its outputs persist.

Direct commands take over automatic control. SetViewport(Viewport) releases the automatic layout of the session that lays this view out, as one set: every other view keeps its rectangle. Show(CinemachineCamera) routes another rig to this output and leaves the layout in force. Releasing writes no earlier value back.
