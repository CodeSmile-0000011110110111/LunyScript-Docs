Interface IDocumentCodec

Namespace
CodeSmile.LunyScript.Platform
Assembly
ApiSource.dll

The only place LunyScript converts between a saved document and the values in a script's variable slots. The cloud-save provider and any future file provider both go through it.

public interface IDocumentCodec

Remarks

.NET 10 seam. The implementation today uses UnityEngine.JsonUtility, which is a Mono-era serializer with no support for dictionaries, no polymorphism and no way to fail loudly on an unknown key. The .NET 10 counterpart is System.Text.Json with a source-generated JsonSerializerContext, which is also the only form of it that survives managed code stripping at High and IL2CPP's ahead-of-time compilation. Replacing: UnityEngine.JsonUtility, System.Runtime.Serialization.
