Interface IAsyncOperation

Namespace
CodeSmile.LunyScript.Platform

One in-flight request owned by the services gateway. Script code never sees this type; it sees a status variable and an outcome event. This interface exists so that the gateway has exactly one place that knows how asynchronous work is represented.

public interface IAsyncOperation

Remarks

.NET 10 seam. The implementation today wraps System.Threading.Tasks.Task, which is what every Unity Gaming Services API returns. The .NET 10 counterparts are System.Threading.Tasks.ValueTask (no allocation for a synchronously completed call), System.Collections.Generic.IAsyncEnumerable for streamed results, and TimeProvider-based timeouts instead of Task.Delay. Replacing: Task, Task<T>, TaskCompletionSource, Task.Delay, async void handlers. Nothing in this codebase awaits on the main thread; the gateway polls IsComplete once per frame. See AGENTS.md section 9.
