A handle to one observable attempt. Declared with Operation.Define(nameof(X)) inside Build(); family start blocks bind it with .As(handle).

public readonly struct Operation
Expand Details ...

Examples

LoadingArena = Operation.Define(nameof(LoadingArena));
When.Operation(LoadingArena).Succeeded(Ready.Set(true));
When.Operation(LoadingArena).Failed(ShowError.Set(true));

Remarks

One handle tracks one attempt at a time. When.Operation(handle).Succeeded, .Failed and .Cancelled observe the current attempt's classified outcome. Cancellation is not a failure. A failure nobody watches is logged once per generation and classified reason.
