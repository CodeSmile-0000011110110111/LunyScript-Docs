Remarks

This builder does not convert to a block, so a chain without a goal does not compile where a block is expected; written as a statement it is refused when the script type is built. AGENTS.md rule 41.

Remarks

While the binding holds no object, or its object is destroyed or inactive, the members stop being attracted, keep their spacing, and slow to a stop; when the goal returns they are attracted again from where they are. A goal that is not in a loaded scene, such as a prefab asset, is reported once. Attraction is measured from each member's position to the goal's world position, in three dimensions.

Exceptions

LunyScriptUsageException

goal was never declared, or another script's Build() declared it, or this builder is a default that no verb produced.
