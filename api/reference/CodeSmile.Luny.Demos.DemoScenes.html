Class DemoScenes

Namespace
CodeSmile.Luny.Demos
Assembly
ApiSource.dll

The scene load a demo's menu asks for when the players move to another demo, such as from one lab to the next: the persistent hosts continue, so participants, Users, views and preferences continue, and the next scene's bootstrap adopts them. A return to the main menu is a separate transaction that ends the group.

CanLoad(string)

True when Load(string) can load the scene: in the Editor when the scene asset lies beside the active scene, in a player when the build's scene list holds it. A demo's scene-comparison command refuses with it.

Load(string)

Loads a scene in place of every loaded scene: in the Editor by its path beside the active scene, so an imported sample plays without a build's scene list, and in a player by name from the build's list.
