Examples

On.LateUpdate(If(Fuse <= 0.0).Then(Object.Despawn()));

Remarks

The no-argument form records a LifetimeRequest and the runner applies it after the current dispatch: it despawns the instance, which delivers On.Disabled and then On.Despawned while the object still exists, and destroys the object afterwards. The named form destroys the owned object immediately and empties its slot.
