The core's one entry point to navigation. Owns the INavigationProvider, one record per actor with the attempt that drives it and whether it is paused, and polls every driven actor once per frame before any instance runs. One per ScriptRunner.

Remarks

This is the navigation counterpart of CameraGateway, and the same shape for the same reason: the core may not reference a navigation package, so the core owns an interface and the gated assembly CodeSmile.LunyScript.Navigation implements it with Unity's NavMesh. docs/proposals/navigation.md is the family.

With no provider installed, every Navigation.MoveTo fails as Denied and the gateway says so once. Stop, Pause and Resume do nothing. That is what AGENTS.md section 12 asks of an absent optional adapter: the script still builds, spawns and runs.

One actor follows one route. A MoveTo on an actor that another pending attempt drives ends that attempt as cancelled. A MoveTo that repeats the pending request of its own operation - the same actor, destination and RequireComplete choice - coalesces, and any other MoveTo on a pending operation is the retarget the settled api-navigation-lifecycle answer asks for: the pending attempt ends as cancelled and the next generation starts.

A navigation attempt has no deadline. The settled deadline answer bounds service operations; a walk is not a request to a service, and its length depends on its route.

A record is created the first time an actor navigates, which allocates once. It is reused while the actor exists and freed at the first poll after the actor is destroyed. A coalesced repeat, a retarget, the poll and a report already written allocate nothing; AGENTS.md rule 29.

Methods

Tick()

Polls every actor an attempt drives, once. Called by the runner before any instance runs, so an attempt that ended since the last frame has advanced its counters when the watches that react to it run in this same tick. With no actor record this returns after one count check, and a poll allocates nothing.

public void Tick()

UseProvider(INavigationProvider)

Installs the backend. Installing another one replaces it: every navigation attempt still pending ends as cancelled, every actor is released by the previous backend, and every actor record, pause included, is dropped, because the records describe what the previous backend was told.
