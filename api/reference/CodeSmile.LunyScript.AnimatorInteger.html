A handle to one Int parameter of the Animator on the object a script runs on. Returned by Animator.Integer(name) at build time.

public readonly struct AnimatorInteger
Expand Details ...

Examples

var weapon = Animator.Integer("Weapon");
On.FrameUpdate(weapon.Set(Slot));
On.FrameUpdate(If(weapon.Value == 2.0).Then(Heavy.Set(true)));

Remarks

The authored value is still a Number, and Unity stores an Int32. A write that is not a finite whole number within Int32 is reported once per script type and leaves the parameter unchanged: 3.0 writes, and 3.8, NaN and both infinities do not. Math.Floor, Math.Ceiling, Math.Truncate and Math.Round convert a fractional number explicitly.
