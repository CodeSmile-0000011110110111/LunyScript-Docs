A declared message: a name without a payload that this script's On.Message handlers run on. A script sends it to its object's authority with Net.Send.ToAuthority(message), and C# on the object sends it with behaviour.Send(message).

public readonly struct Message
Expand Details ...

Examples

Ping = Define.Message();
On.Message(Ping, Pings.Add(1));

Remarks

Ping = Define.Message(); declares one. Its identity is the script type that declared it and its name. Only the declaring script handles and sends it; C# outside a script names it through the generated descriptor, PlayerScript.Messages.Ping. docs/proposals/declared-identity-handles.md is the contract.
