Class ColorValueBlock

Namespace
CodeSmile.LunyScript

The root of every colour expression: something that produces a Color when the block holding it runs. A Color value and a colour variable both convert to one, so a call that takes a colour takes either.

Remarks

This type calculates nothing: it carries a literal colour or reads a colour variable. The captain's answer of 2026-09-24 records that scripts do not calculate with colours.
