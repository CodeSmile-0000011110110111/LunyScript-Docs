Class CloudSaves

The typed hand-over between LunySave and LunyCloud for plain C#: Upload(CloudClient, string, SaveDocument) sends a captured SaveDocument to the player's Cloud Data, Download(CloudClient, string, SaveSchema) prepares a document a schema reads from it, and UploadGroup(CloudClient, string, SaveGroup) and DownloadGroup(CloudClient, string, SaveGroupSchema) do the same for a whole SaveGroup as one Cloud File, the archive a SaveGroupSlot stores.

Remarks

A capture, a request, a candidate. An upload copies the document's values when it is called and sends those, whatever the game changes afterwards, and records the signed-in player it was captured for. A download decodes, migrates and checks what arrived with the schema, exactly as a local load does, and hands back a candidate: nothing is applied to the game and nothing is saved on the device. The owner of the state checks the candidate against its own rules and the player it captured, adopts it, and saves it locally through its own slot when it chooses to.

Two outcomes stay two. A local save succeeding says nothing about an upload, and an upload succeeding says nothing about the device. Cloud keeps the request's order, timing, retries and remote commit, which Request shows; this hand-over starts no upload by itself.
