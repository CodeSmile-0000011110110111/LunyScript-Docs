A two-component spatial value: a stick deflection, a screen offset, a planar direction.

public struct Vector2

Examples

Remarks

The name is Unity's, and the namespace is LunyScript's. This type is CodeSmile.LunyScript.Vector2, kept apart from UnityEngine.Vector2 by its namespace, for the reason Vector3 gives.

The components are Single while Number is Double. That is the precision split the API semantics record carries, applied the same way Vector3 applies it. Every constructor, method and operator here takes and returns Double at its edges, so a script never writes an f suffix; the component fields hold the Single itself.

The components are public fields, so Unity saves them, for the reason and with the Single write Vector3 states: stick.Y = 0.5f.

A script variable of this type is written whole. WithX and WithY return a copy with one component changed, which is what the variable's Set takes; the variable handle has no writable component.
