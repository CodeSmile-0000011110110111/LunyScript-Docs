One extension block type an adapter registered, with the Unity package and minimum version that type needs.

public readonly struct AdapterRegistration
Expand Details ...

Examples

AdapterAdmission.Register(typeof(PuppetMasterDoSomethingBlock),
    "com.example.puppetmaster", "1.2.0", "PuppetMaster.LunyScript");

Remarks

This is adapter admission, not a listing of the public API. The implementation queue called it a registration catalog. An author never writes a catalog line in Build(); the adapter assembly calls Register(Type, string, string, string, string, int) once. docs/proposals/adapter-admission.md is the contract.
