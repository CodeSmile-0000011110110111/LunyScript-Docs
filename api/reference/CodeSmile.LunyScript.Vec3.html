A three-component spatial value: a position, a direction, a displacement or a scale.

public readonly struct Vec3
Expand Details ...

Examples

var spawn = new Vec3(0.0, 1.0, 0.0);
var raised = spawn.WithY(2.5);

Remarks

Why the name is Vec3 and not Vector3. A type called CodeSmile.LunyScript.Vector3 would be ambiguous with UnityEngine.Vector3 in every script carrying using UnityEngine;, which is nearly every script in a Unity project, and the C# compiler reports that as an error the script author cannot fix without writing an alias. The short name also leaves room for a Vec2 beside it.

The components are Single while Number is Double. That is the precision split the API semantics record carries: scalars use double, and spatial payload and spatial math use float, narrowing at the destination that declares it. Every member here takes and returns Double at its edges, so a script never writes an f suffix, and the narrowing happens in one place.

A component is replaced, never written. WithX, WithY and WithZ return a copy with one component changed, which is what a spatial variable's Set takes. There is no writable component handle; the API semantics board ruled that out on 2026-09-13.
