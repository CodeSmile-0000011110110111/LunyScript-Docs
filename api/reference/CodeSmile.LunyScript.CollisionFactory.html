Struct CollisionFactory

The Collision surface: seven verbs that ask the physics world what is in front of an object or around it, each writing into a result the script declared.

public readonly struct CollisionFactory
Expand Details ...

Examples

On.FixedUpdate(Collision.RayCast().InLocalSpace().Towards(-Vector3.Up).Length(1.1).Into(Ground));
On.FixedUpdate(Collision.SphereOverlap().Radius(5).InLocalSpace().Into(Nearby));

Remarks

A cast moves a ray, sphere, box or capsule along a direction and writes the nearest collider it touches into a HitResult, or every one into a HitsResult. An overlap tests a sphere, box or capsule where it stands and writes every collider it overlaps into an OverlapsResult. A query runs when its block runs, in any event, and sees each collider where the physics world last synchronized it. docs/proposals/collision-queries.md is the family.
