The Body surface inside Build(): observations of what physics actually did to the object this script runs on, and the switch of its Rigidbody between kinematic and dynamic.

public readonly struct BodyFactory
Expand Details ...

Examples

On.FixedUpdate(Travelled.Set(Body.PositionDelta));
On.Spawned(Body.MakeDynamic());
On.FixedUpdate(If(Expired).Then(Body.MakeKinematic()));

Remarks

A script type that never reads PositionDelta stores no previous position and is not walked after a physics step. Round 05 gated this observation at build time.

MakeKinematic(string, int) and MakeDynamic(string, int) run in On.FixedUpdate, and also in On.Created, On.Spawned, On.Ready, On.Enabled, On.Disabled and On.Despawned, which run once per lifecycle change. Both leave the body with no velocity. An object with no Rigidbody warns once per incarnation and nothing is switched.

Properties

PositionDelta

This body's world position after the last physics step, minus its world position after the step before that. Includes collision and other forces. Not the requested MoveBy vector.

Remarks

Runs in On.FixedUpdate, On.Created, On.Spawned, On.Ready, On.Enabled, On.Disabled and On.Despawned; written in any other event it is reported once and ignored. A body that is already dynamic also loses its velocity. An object with no Rigidbody warns once per incarnation. On.Spawned is where a pooled object that a previous use made kinematic gets its dynamic body back, before anything else reads it.

MakeKinematic(string, int)

Makes the object's Rigidbody kinematic, so forces, gravity and contacts stop moving it and only a kinematic move such as Motion.MoveBy does. A dynamic body first loses its linear and then its angular velocity, while it is still dynamic, so it stops where it is. Its collider stays enabled, so it still blocks and touches other bodies.

Remarks

A body that is already kinematic stays kinematic and gets no velocity write. An object with no Rigidbody warns once per incarnation. A pool resets no native state, so a script whose pooled object becomes kinematic writes MakeDynamic(string, int) in its On.Spawned.
