Every failure a service call can produce, classified once by the gateway so that no script and no block ever sees an exception type. See AGENTS.md section 9.

public enum OperationFailure
Expand Details ...

Fields

Denied = 4

The service understood the call and refused it. Not retried.

None = 0

No failure. The value while a request is pending and after it succeeded.

NotFound = 5

The key or resource does not exist. Not retried.

NotSignedIn = 2

The player is not signed in. The request is queued until sign-in completes.

Offline = 1

No usable network connection. The request is queued and replayed.

RateLimited = 3

The service refused the call because too many were made. Carries a retry delay.

Timeout = 6

No answer within the gateway's own deadline.

Unknown = 7

A failure the gateway could not classify. Logged with the original text.

Unreachable = 10

No route reaches a navigation destination: the route is invalid, or it is partial and the move required a complete one. The actor stopped where it was.

Unreadable = 8

A stored document exists and is not a readable document: not UTF-8, not JSON, or not in the document layout. Nothing was applied and the stored copy was not changed.

Unsupported = 9

A stored document is readable and cannot become the declared version: it is newer, no migration step starts from its version, a step rejected it, or the migrated result failed validation. Nothing was applied and the stored copy was not changed.
