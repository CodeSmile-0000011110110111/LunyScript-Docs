LunyScript API Reference

Interface IScriptObjectPooler

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The part of a host that can keep reusable copies of a prefab: a storage object in its scene, inactive entries under it, and the move of one entry out into the scene and back. A host that provides it declares RuntimeObjectPooling by implementing this interface; a host that does not cannot run a script containing an Object.Spawn block.

public interface IScriptObjectPooler
Expand Details ...

Examples

var storage = ((IScriptObjectPooler)caller).CreatePoolStorage("LunyScript pool Guards (WaveScript)");
var entry = ((IScriptObjectPooler)storage).CreatePoolEntry(prefab);

Remarks

One interface carries the calls made on three kinds of host, because one host type plays all three: the host of the script that spawns, which names the scene; the storage object, which produces entries; and an entry, which is checked out and returned. ObjectPools in the core decides which entry, when and for whom; this interface is the native part only.

The prefab is typed UnityEngine.Object rather than GameObject, so this file names no banned Unity type and AGENTS.md rule 24's type ban still holds.

Called on an entry host: moves the entry out of storage, parents it, places it, starts a new incarnation of every script on it that ran before, and activates it.

Parameters

Type Name Description
IScriptHost
parent

The host to parent the entry to, or null for the scene root.
SpawnPlacement
placement

Where the entry goes. It always names a position.

Remarks

The placement is written before anything on the entry observes the checkout. A placement that names no rotation turns the entry the way the prefab was turned when the entry was produced.
