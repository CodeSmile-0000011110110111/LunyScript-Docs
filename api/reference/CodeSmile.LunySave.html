LunyScript API Reference

Namespace CodeSmile.LunySave

Classes

LoadOperation

One Load(string, SaveSchema) or LoadStreamingAsset(string, SaveSchema): whether it is done, how it ended, the document it read, and which declared fields the stored copy could not give.

LocalSave

Saves and loads typed documents on this device, for plain C#: Save(string, SaveDocument) and Load(string, SaveSchema) in the player's writable data folder, LoadStreamingAsset(string, SaveSchema) from the read-only StreamingAssets folder the build ships. Every path is relative to the folder its call uses.

LunySaveException

A mistake in the C# that uses LunySave, raised where it was made: a path that is absolute, leaves its folder or uses a character a portable file name cannot hold, a schema whose migration steps leave a gap, a field the schema does not declare, or a document saved before every declared field holds a value. The message names the call and what to change.

SaveDocument

The values of one document of a SaveSchema: what Save(string, SaveDocument) writes and what a successful LoadOperation returns. Each declared field either holds a value or holds none.

SaveFields

The stored fields of one document while a SaveMigration step converts them. Reads and writes a copy: nothing here reaches the stored file or a document a caller holds.

SaveMigration

One consecutive step of a document's schema: converts a stored document of FromVersion into version FromVersion + 1. Registered with Migration(SaveMigration).

SaveOperation

One Save(string, SaveDocument): whether it is done, and how it ended.

SaveSchema

What one kind of document holds: its version, its fields by name and kind, and the migration steps that convert an older stored version. Each method returns a new schema and leaves this one as it was, so a schema kept in a static readonly field never changes after it is built.

Structs

SaveMigrationResult

What one SaveMigration step returns: the document was converted, or it was rejected with a reason.

Enums

SaveFailure

Why a SaveOperation or LoadOperation failed. None while the operation is pending and after it succeeded.
