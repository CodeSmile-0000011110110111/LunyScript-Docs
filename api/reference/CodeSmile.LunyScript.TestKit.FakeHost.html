A test double for IScriptHost: it answers the interface without a scene, a GameObject or a frame.

public sealed class FakeHost : IScriptHost, IScriptObjectLifetime, IScriptObjectSpawner, IScriptAssetInputs

Examples

var host = new FakeHost(instanceId: 1);
var instance = runner.Spawn(program, host);
host.IsAlive = false;   // simulates a destroy from outside the contract

Remarks

This is a test double, not a second host implementation. LunyScript is GameObject-only and GameObjectHost is the one real host; AGENTS.md rule 53. The interface exists so that every block can be asserted in Edit Mode in milliseconds, and this type is what makes that possible.

It ships in the test kit rather than in a test assembly, so that a user can hold their own blocks to the same tests the shipped blocks are held to.

LookAt(TransformRelation, int, double, double, double, double, double, double)

Turns the named object to face a world point, about a stated up direction.

public bool LookAt(TransformRelation relation, int childIndex, double x, double y, double z, double upX, double upY, double upZ)

Parameters

relation TransformRelation

Which object to turn.

childIndex int

Its child index, used only for Child.

x double

The world x of the point to face.

y double

The world y.

z double

The world z.

upX double

The x of the up direction to keep the object's up axis nearest.

upY double

The y of that direction.

upZ double

The z of that direction.

Returns

bool

False when the facing is undefined, in which case nothing was written: the point is where the object already stands, or the direction to it is parallel to the up direction, and there is no rotation the two describe. True when the object was turned.

Remarks

An undefined facing writes nothing rather than inventing a direction, which is the captain's answer to API-semantics row T04 on 2026-09-13. The object's forward axis ends up pointing at the point and its up axis is kept as near the up direction as the facing allows. Must allocate nothing; AGENTS.md rule 29.

Exceptions

LunyScriptUsageException

The named object does not exist.

SetParent(TransformRelation, int, TransformRelation, int, bool)

Moves the named object to another parent, or to the scene root.

public void SetParent(TransformRelation relation, int childIndex, TransformRelation parentRelation, int parentChildIndex, bool keepWorldPose)

Parameters

relation TransformRelation

Which object to reparent.

childIndex int

Its child index, used only for Child.

parentRelation TransformRelation

The destination. None is the scene root.

parentChildIndex int

The destination's child index, used only for Child.

keepWorldPose bool

True keeps the object's world position and rotation and writes the closest local scale it can, which is the default the captain chose for API-semantics row T06 on 2026-09-13; false keeps the object's local values and lets its world placement move. The scale is the half that can only be approximated: a parent that is rotated and scaled unevenly produces world scales no local scale reproduces.

Remarks

Reparenting does not replace the object's transform, so a host that caches one still holds the right object afterwards; docs/host-transform-cache.md states what that cache assumes.

Exceptions

LunyScriptUsageException

Either named object does not exist, or the destination is the object itself or one of its own descendants.
