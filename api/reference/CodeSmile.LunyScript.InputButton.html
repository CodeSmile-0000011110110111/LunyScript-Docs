A handle to one pressed-or-not action of one local player. Returned by Input.ForPlayer(player).Button(name) at build time; the members on it build blocks.

public readonly struct InputButton : IInputActionHandle
Expand Details ...
Implements
IInputActionHandle

Examples

var fire = Input.ForPlayer(0).Button("Fire");
When.Input(fire).Performed(Shots.Add(1.0));
On.FrameUpdate(If(fire.IsPressed).Then(Charge.Add(Time.Delta)));

Remarks

The handle is a declaration index and a name, not a value: the same handle reads the action's current state every time a block holding it runs. A declaration belongs to the script type, so every object running the script reads the same local player's action; docs/execution-model.md, "Player input".
