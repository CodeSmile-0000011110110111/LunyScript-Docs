A navigation backend with no navigation mesh: each registered actor has a position, a speed and a stopping distance, and moves in a straight line to the end of the route a test chose.

Examples

var navigation = new FakeNavigationProvider();
navigation.AddAgent(actor, new Vec3(0.0, 0.0, 0.0), 2.0);
navigation.SetRoute(island, NavigationRouteState.Partial, shore);
runner.NavigationGateway.UseProvider(navigation);

Remarks

This is a second real implementation rather than a test mock, in the same way FakeCameraProvider is: it answers every member of INavigationProvider with the rules the NavMesh adapter answers them with, and it is what makes every navigation block testable in every gate with no navigation mesh.

A test decides what the world is. AddAgent(Object, Vec3, double, double) registers an actor; an object nothing registered carries no agent. SetRoute(Vec3, NavigationRouteState, Vec3) decides which route a destination gets and where that route ends; a destination with no rule gets a complete route that ends at the destination. PendingReads is how many polls a new route stays pending. Advance(double) moves every actor that follows a known route and is not held, which is the part of a frame Unity's agent does by itself.
