Remarks

This type and StaticsGateControl are the only mutable statics allowed in the runtime assembly. The structural test that enforces "every static field is const or readonly" excludes the CodeSmile.LunyScript.Gates namespace by name, so that adding a mutable static anywhere else still fails.

[AutoStaticsCleanup] is Unity.Scripting.LifecycleManagement.AutoStaticsCleanupAttribute, which Unity 6000.7.0a5 documents as "Resets static variables automatically on entering or exiting Play mode with domain reload disabled". Its AttributeUsage allows Class, Struct, Field, Property and Event. It replaces the [RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.SubsystemRegistration)] reset method that earlier Unity versions required. See AGENTS.md section 7.

The type must be declared partial. Unity's code generator emits a second partial declaration of every type marked [AutoStaticsCleanup], holding the generated reset method, and a non-partial declaration fails to compile with error CS0260: Missing partial modifier on declaration of type. Measured on 6000.7.0a5; this is not stated in the attribute's own documentation.
