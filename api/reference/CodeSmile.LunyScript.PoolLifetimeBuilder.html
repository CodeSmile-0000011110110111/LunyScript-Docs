Struct PoolLifetimeBuilder

Namespace
CodeSmile.LunyScript

ApiSource.dll

What Lifetime(amount) returns on a pool declaration: the last clause, whose amount is seconds of game time unless a unit call names another unit.

public readonly struct PoolLifetimeBuilder
Expand Details ...

Examples

Shots = Define.Pool(nameof(Shots)).From(Shot).HardCap(32).Lifetime(1.5);
Sparks = Define.Pool(nameof(Sparks)).From(Spark).Prewarm(8).Lifetime(400).Milliseconds();

Remarks

Seconds is the default unit, so Lifetime(1.5) and Lifetime(1.5).Seconds() declare the same pool. A unit call finishes the declaration and returns the pool handle; a second unit and a clause after the lifetime do not compile.
