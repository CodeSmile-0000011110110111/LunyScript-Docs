Class EditorScript

Namespace
CodeSmile.LunyScript

The editor entry: a subclass whose Build() composes blocks that run in an EditorScriptSession. Game scripts subclass Script instead. A concrete EditorScript identifies the editor role without an attribute.

Examples

public sealed partial class ValidationScript : EditorScript
{
    [Variable] public Var<Number> Count { get; private set; }
    protected override void Build()
    {
        On.Ready(Count.Set(1.0));
        On.EditorUpdate(Count.Add(1.0));
    }
}

Remarks

This type is not selectable on LunyScriptBehaviour. The Inspector picker lists Script subclasses only. Shared factories (Var, Define, If, When, Math) come from ScriptBase. Frame, physics, transform, time and input factories stay on Script.
