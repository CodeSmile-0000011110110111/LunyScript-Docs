A handle to one variable of a script. Returned by Var.Define at build time; the operators and methods on it build blocks.

public readonly struct Var<T> where T : struct

Type Parameters

T

What the variable holds: Number, Flag, Text, Vec3, Rotation, Vec2 or a declared C# enum. AGENTS.md rule 12 makes Number the number type, so there is no Var<Int32> and no Var<Single>.

Expand Details ...

Examples

var post = Var.Define<Vec3>("post", new Vec3(3.0, 0.5, 0.0));
On.FrameUpdate(If(post.Y > 1.0).Then(post.Set(post.WithY(0.5))));

Remarks

The handle is an index, not a value: it says where the variable lives on every instance of the program, and the same handle reads a different number on every object running the script.

A handle is valid only inside the Build that declared it. It carries a slot index and a kind and nothing that identifies its program, so a handle from one script used in another script's Build addresses that other script's slot of the same index. Take a ScoreScript holding static Number Score at index 0, and a PickupScript whose own first variable is cooldown: writing On.Ready(ScoreScript.Score.Add(10.0)) inside PickupScript.Build adds 10 to every pickup's cooldown and never moves the score. Where the borrowed index is past the end of the borrowing program's array, ScriptInstance throws LunyScriptUsageException naming this cause; where it is within range, as here, nothing detects it. Declare each script's variables in its own Build.

A kind's operations are members of its handle. A Number, Flag or Text variable is declared as that handle type, which carries the arithmetic, ordering, truth and text members of its kind. This generic handle carries what Vec3, Vec2, Rotation and enum variables use, with Set and ==, so Here.Add(1.0) and Here + There on a Var<Vec3> are compile errors. A member it shares between those kinds, such as Z on a Var<Vec2> or == on a Var<Vec3>, compiles and throws LunyScriptUsageException while the script type is built, because C# 9 cannot restrict a member of a generic type to one instantiation of it. Build runs once per script type at launch, so a script that can throw one of these throws it on the first run. The Var<Number> that Var.Define<Number> returns converts to the Number handle, and so do Flag and Text: Number health = Var.Define<Number>("health", 100.0);. docs/slice-decisions.md D4.3 records the history.

operator == on a handle builds a condition block; it does not compare handles. Use Equals(object) to compare two handles.

Remarks

This and the members below it are one-line pass-throughs to the same members on Vec3ValueBlock and RotationValueBlock, and they exist because C# applies no user-defined conversion before a member access: without them, Spawn.Length would not compile even though Spawn converts to a spatial expression wherever one is expected.

The C# operators are the one part this cannot cover. Spawn * 2.0 does not compile, because operator lookup also runs on the operands' own types and neither is a spatial expression. Put the variable in a local of the expression type first - Vec3ValueBlock spawn = Spawn; - and the operators are available on it.

Exceptions

LunyScriptUsageException

This is not a Vec3 variable.
