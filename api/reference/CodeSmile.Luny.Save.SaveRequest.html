Remarks

A request is Pending until it ends, and the first end it reaches stays: a request that succeeded never turns failed or canceled afterwards. A request on an idle path ends inside the call that makes it. A request made while an earlier request for the same path waits, such as a script's save that runs in the next frame, is pending until the earlier one ended and then runs by itself, so nothing has to read it for it to progress. A pending request whose owner is destroyed ends as Canceled.

Nothing calls back: the code that holds a request reads it. Every request that ends is also recorded in Journal, without the values it saved or loaded.
