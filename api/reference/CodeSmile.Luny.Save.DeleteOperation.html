Remarks

A delete succeeded when nothing is stored at its path afterwards: the document and the copy an interrupted save left beside it are gone, and a path where nothing was stored counts as well, so a second delete succeeds too. A delete the file system refused fails as Unavailable or Unknown, and the document is still there.
