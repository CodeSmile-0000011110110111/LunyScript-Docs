Remarks

The file storage completes a delete inside the call that starts it, so IsDone is already true when Delete(string) returns. A delete succeeded when nothing is stored at its path afterwards: the document and the copy an interrupted save left beside it are gone, and a path where nothing was stored counts as well, so a second delete of the same path succeeds too. A delete the file system refused reports Unknown with the system's message, and the document may still be there.
