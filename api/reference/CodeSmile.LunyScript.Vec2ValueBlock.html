Class Vec2ValueBlock

CodeSmile.LunyScript

The root of every two-component spatial expression: something that produces a Vec2 when the block holding it runs.

public abstract class Vec2ValueBlock : IScriptNode

Remarks

Component replacement lives here rather than on a writable component handle, matching Vec3ValueBlock. There is no member on this type that writes anything.
