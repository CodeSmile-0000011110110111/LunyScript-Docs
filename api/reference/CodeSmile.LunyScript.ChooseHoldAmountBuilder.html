Struct ChooseHoldAmountBuilder

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

A Choose(subject).Highest(...).Hold(amount) chain: the Hold amount is seconds unless a unit call names another unit. Optional Bias(double, string, int) follows; used as a block it starts the selector.

public readonly struct ChooseHoldAmountBuilder
Expand Details ...

Examples

On.Ready(Choose("needs").Highest(Option(WorkScore).Then(Work)).Hold(1));
On.Ready(Choose("needs").Highest(Option(WorkScore).Then(Work)).Hold(1).Seconds().Bias(0.1));
