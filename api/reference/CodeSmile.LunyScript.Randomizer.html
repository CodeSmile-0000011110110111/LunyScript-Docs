A declared randomizer: a sequence of draws whose state lives on each instance of the script, which Random.Number().From(randomizer) and the other draws consume one sample of each time they run.

public readonly struct Randomizer
Expand Details ...

Examples

Loot = Define.Randomizer().Seed(42);
On.Ready(Random.Number().From(Loot).In(1.0, 100.0).Into(Roll));

Remarks

Loot = Define.Randomizer(); declares one whose seed the runner derives from its session seed, the instance's spawn index and the declared name, so two instances of the same script draw different sequences and renaming the declaration changes the sequence. Define.Randomizer().Seed(42) gives every instance the same repeatable sequence. A fresh incarnation, including a pooled object's next use, starts the sequence again. Give each purpose its own randomizer - loot, damage, cosmetics - so that one draw does not consume another's sample. docs/proposals/declared-identity-handles.md is the contract.
