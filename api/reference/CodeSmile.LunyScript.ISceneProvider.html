What a scene backend provides to SceneGateway: starting a load of one scene asset, ending one loaded instance, and reporting which scene instances are loaded. Script code never sees this type; it sees Scene.Load, Scene.Unload and When.Operation.

public interface ISceneProvider
Expand Details ...

Examples

runner.SceneGateway.UseProvider(new FakeSceneProvider());

Remarks

Two implementations exist. UnitySceneProvider calls Unity's SceneManager and is what the default runner uses. FakeSceneProvider is an in-memory list of scenes for tests, the same role FakeAssetLoadProvider has for asset loads. An Addressables scene provider would be a third, behind the same gateway.

A scene is named by its asset path, for example Assets/Scenes/Arena.unity, because that is what the Inspector stores for a scene input and what Unity loads by. The provider never receives a scene's file name alone.

The native Loaded and Unloaded phases do not come from the provider. Unity reports them through SceneManager.sceneLoaded and sceneUnloaded whichever call started the load, and the runner's driver forwards those two callbacks to the gateway.
