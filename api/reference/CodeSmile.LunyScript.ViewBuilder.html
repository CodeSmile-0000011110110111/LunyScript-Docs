SetCamera(AssetInput)

Builds a block that makes this view render one camera rig.

public Block SetCamera(AssetInput rig)

Parameters

Type Name Description
AssetInput
rig

The declared asset input holding the camera rig.

Returns

Block

A block to place in an event list.

Examples

On.Ready(View.For(Screen).SetCamera(ChaseRig));

Remarks

Selecting a rig replaces whatever the view was rendering, and the transition between the two is the authored Cinemachine blend rather than anything LunyScript decides. A second selection while a blend is running is Cinemachine's to resolve, for the same reason: the accepted design routes the camera through it rather than reimplementing it.

Exceptions

LunyScriptUsageException

The handle is one Build() never assigned, or the builder is a default one.
