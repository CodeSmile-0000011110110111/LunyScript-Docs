LunyScript API Reference

Struct MapHandle<TKey, TValue>

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

A handle to one fixed-capacity map declared with Define.Map<TKey, TValue>. Occupancy starts at zero. Existing-key assignment replaces the value and keeps insertion order.

public readonly struct MapHandle<TKey, TValue> where TKey : struct where TValue : struct

Type Parameters

TKey

Flag, finite Number, Text or a declared C# enum.

TValue

Number, Flag, Text or a declared C# enum.

Examples

Scores = Define.Map<Text, Number>(nameof(Scores), 8);
On.Ready(Scores.Set("wave", 0.0));
On.FrameUpdate(Hits.Set(Scores.At("wave")));
