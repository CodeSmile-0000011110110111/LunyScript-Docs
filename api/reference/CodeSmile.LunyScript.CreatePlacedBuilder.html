What Object.Create(prefab).At(...) returns: a create whose placement is stated and whose frame is still the default, the parent's.

public readonly struct CreatePlacedBuilder

Examples

On.Ready(Object.Create(Sentry).At(new Vector3(0.0, 1.0, 0.0)).InWorldSpace());

Remarks

The two frame modifiers live here and nowhere else, which is what makes a second At and a second frame clause compile errors.

Remarks

Omitting the name parents it to the object the script runs on, which is the same "self by omission" the rest of the Object surface uses. A named parent is an object this script produced, by Object.Create or Object.Spawn with Into(string, string, int). A builder that can still take a placement and a parent.

Examples

On.Ready(Object.Create(Sentry).Into("Guard"));

Remarks

The name is an address and nothing else. A copy is owned by the instance that created it whether or not Into is written; Into only lets later blocks name it, for example Object.Destroy(name). The name is not the produced object's name in the scene: a prefab copy keeps the name the prefab gives it.

Exceptions

LunyScriptUsageException

name is null or whitespace, this chain already names one, another call already produces that name, or this builder is a default.

SurvivesCaller(string, int)

Lets the produced object outlive the instance that created it: it ends with its scene, or when something ends it, rather than when this instance ends.

public CreatePlacedBuilder SurvivesCaller(string callerFilePath = null, int callerLineNumber = 0)

Parameters

Type Name Description
string
callerFilePath

Supplied by the compiler. Do not pass one.
int
callerLineNumber

Supplied by the compiler.

Returns

CreatePlacedBuilder

A builder that can still take the clauses it could take before.

Examples

On.FrameUpdate(If(Health <= 0).Then(Object.Create(Reward).SurvivesCaller(), Object.Destroy()));

Remarks

Without it, the copy is owned by this instance and destroyed when the instance ends, with or without Into(string, string, int). With it, the scene the copy is in holds that obligation, and Into(string, string, int) still lets this script address the copy while this instance runs. A copy that survives the caller cannot be a child of the caller, because a child is destroyed with its parent, so ChildOf() with this clause is refused while the script type is built.

Exceptions

LunyScriptUsageException

This chain already says it, or this builder is a default.
