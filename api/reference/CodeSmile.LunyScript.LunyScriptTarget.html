Which object a read of another script, a request or an event filter is about: a declared object binding, an object this script holds under a name, the script that sent the request running now, the object on the other side of the contact event running now, or the script whose create or spawn made this object.

public readonly struct LunyScriptTarget

Examples

Patient = Bind.Object();
var patient = EnemyScript.At(Patient);
var companion = EnemyScript.At(Object.Owned(Companion));

Remarks

A script rarely writes this type. A ObjectBinding converts to it, Object.Owned(owned) makes one for an owned object, Other converts to it, and Sender and SpawnedBy are one. The target is resolved each time a block that uses it runs, to the script running on that object at that moment, and only to an incarnation that is still running; a pooled object handed out again is a new incarnation that an old slot no longer names. docs/proposals/script-communication.md is the contract.
