Why one attempt to admit a member was refused, the Code of Refusal and LastRefusal. Each refusal waits the group's retry interval and counts against the member's deadline.

public enum SpawnRefusalCode : byte
Expand Details ...

Fields

BindingMissing = 4

The prefab or placement key is not bound, or its scene object is gone or inactive.

IntegrationRefused = 5

A component on the object refused the use, such as a Combat admission.

None = 0

No refusal.

PlacementBlocked = 3

The candidate pose failed the binding's placement checks.

PoolFull = 2

The prefab's pool holds its limit of allocated copies, none idle.

PopulationFull = 1

The session's live population is at its limit.
