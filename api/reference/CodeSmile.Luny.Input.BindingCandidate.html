A control one player pressed for one action, held as a candidate: the capture listens only on that player's own devices, leaves the live controls unchanged, and lists every binding the control would displace. The game, or LunyUI's settings page, then accepts it with Accept(BindingResolution) or stores it through LunyPrefs' input unit, or cancels it.

Remarks

Escape and the gamepad's East button cancel the capture and are never captured, so a player with a gamepad alone can always leave it. A capture ends as Invalidated when the player's device is lost, the person on the player changes, or the player's bindings change elsewhere; an accept after that is refused as Stale.

The edit unit an action belongs to, such as the default character controller's Aim with the mounted Lock, changes together: Unit lists the members that take the captured control too. A Replace never takes the last route of a protected action, and Keep Both is permitted only between actions the game declared shared.
