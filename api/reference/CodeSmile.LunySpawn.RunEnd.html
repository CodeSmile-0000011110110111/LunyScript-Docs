Why a run reached its terminal state; EndDetail names the signal or group.

public enum RunEnd : byte
Expand Details ...

Fields

Cancelled = 4

Its owner called Cancel() or Release().

Completed = 1

Its last phase's success condition held.

FailureSignal = 2

A failure signal latched; the detail is the signal's index.

None = 0

The run has not ended.

OwnerEnded = 5

The object that owns it ended (the captain's Q12 answer).

RequiredSpawnExpired = 3

A required member waited past its deadline; the detail is the group's index.

SessionEnded = 6

The session ended, as a scene unload ends its host.

Examples

if (read.End == RunEnd.FailureSignal) Console.WriteLine(read.Recipe.Signals[read.EndDetail]);
