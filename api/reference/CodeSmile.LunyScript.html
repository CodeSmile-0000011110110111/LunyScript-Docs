LunyScript API Reference

Namespace CodeSmile.LunyScript

Classes

AccountScripting

The Account verbs a script writes inside Build(): sign in, sign out and delete the cloud account, and Account.IsSignedIn() (C03, the captain's choice of the Account family on 2026-09-20; C22 A). Outcomes arrive through When.Account(handle).

ActionBlock

A block whose objective can take more than one frame, and which therefore reports ActionResult rather than simply running to completion.

ActivateObjectBlock

What Object.Activate() and Object.Activate(name) build: activates the object the script runs on, or one the script created.

AdapterAdmission

The package and version admission table for extension blocks and optional adapters.

AssetAttribute

Declares an asset input whose handle is assigned before Build, in declaration order.

AssetGateway

Owns in-flight Asset.Load attempts and owner-acquisition records for one ScriptRunner. Bound Inspector loads complete from the instance's already resolved input. Resources loads go through IAssetLoadProvider. Script code never sees a Task or an exception type; AGENTS.md rules 50 and 51.

AssetInputFileSources

The file sources of the two input kinds LunyScript can decode from a file: Bind.Texture2D() reads a PNG and Bind.AudioClip() reads a PCM WAV file. Any other kind has none of these methods, so Bind.Prefab().FromStreamingAssets(...) does not compile.

AssetLoadBlock

What Asset.Load(source).As(handle) builds: starts one asynchronous content acquisition bound to an operation handle. Completion yields an owned typed asset on that handle, or a classified failure. Failure does not fall through to an asset placeholder.

AssetPlaceholders

The asset placeholder every asset type falls back to when an input of that type is left unassigned, and the two ways one is configured.

AssetReleaseBlock

What Asset.Release(acquisition) builds: relinquishes this owner's acquisition. Bound consumers retain content they still need. Release does not destroy them and does not promise immediate physical reclamation.

AudioGateway

The runner-owned audio service: pooled one-shot voices, named bound-source control, and mixer writes. Bound playback on the object a script runs on lives on IScriptHost instead.

Block

One step of behaviour in a script. A block object is created once, when its script type is built, and is then shared by every object running that script; the per-object state it reads and writes lives in slots on the ScriptInstance passed to Execute(ScriptInstance).

CameraGateway

The core's one entry point to the camera. Owns the ICameraProvider, passes each authored operation to it, and reports a refused one once.

CloudDefinitions

The cloud declarations a script writes inside Build() with Define: a key of the player's data, a game data item, a player file, a leaderboard, and the page and entry a leaderboard read fills. LunyCloud adds them to the core's DefineFactory surface in namespace CodeSmile.LunyScript.

CloudGateway

The one place C# reaches the cloud client a runner's scripts use: which backends it talks to, where its score queue is kept, and the CloudClient itself for C# reads and diagnosis. The runner ticks the client once per frame, before any instance runs, so an outcome reaches the watches of the same frame.

CloudScripting

The Cloud verbs a script writes inside Build(): save, load and delete a declared document, a key of the player's data, a game data item or a player file, each bound to an operation handle with .As(handle), and Cloud.CommitIs, the commit status of a write. Outcomes arrive through When.Cloud(handle) and When.Operation(handle). AGENTS.md rule 50.

CloudWatches

The cloud watches a script writes inside Build() with When: When.Cloud, When.Account and When.Leaderboard. Each observes the attempt a start of its family bound to the handle, the same attempt When.Operation(handle) observes: both can be registered, and the runtime starts no second attempt (C02 A). A handle no start of the family binds is refused when Build() finishes.

ColorValueBlock

The root of every colour expression: something that produces a Color when the block holding it runs. A Color value and a colour variable both convert to one, so a call that takes a colour takes either.

CompilationFacts

What the compiler was told when this assembly was built. Read by tests and by the release gate, so that a claim about release behaviour can name the compilation it was measured in.

ConditionBlock

A block that answers true or false for one object. Passed to If(...) and combined with &, | and !.

CreateObjectBlock

What Object.Create(name) builds: creates a new, empty, active object owned by the instance that runs this block, and records it in the owned-object slot the build assigned to that name.

CreatePrefabObjectBlock

What Object.Create(prefab) and its chain build: produces a fresh copy of a declared prefab input, places it, parents it, and holds it in an owned-object slot when the chain named one.

DataSchema

The schema of one LunyScriptDataAttribute struct: which fields it has, and how a value of it becomes a script's variables. Scripts pass it to Bind.Data as WeaponStats.Schema, the static property the generator writes into the struct.

DataSchema<TValue, THandle>

The schema of the struct TValue, whose script variables are the generated handle THandle.

DeactivateObjectBlock

What Object.Deactivate() and Object.Deactivate(name) build: deactivates the object the script runs on, or one the script created.

DespawnObjectBlock

What Object.Despawn() and Object.Despawn(name) build: returns a pooled object to the pool it came from.

DestroyObjectBlock

What Object.Destroy() and Object.Destroy(name) build: permanently ends the object the script runs on, or one the script produced.

DiagnosticBuffer

Fixed-capacity, ordered storage shared by console and trace readers.

DiagnosticCatalog

Immutable catalog for one built program.

DiagnosticCommand

Caller-owned receipt. Terminal results survive target closure and are never replayed.

DiagnosticFault

Observed contained error or failed outer boundary, separate from enabled state.

DiagnosticLifetime

One live lifetime and the two names a person finds it by: its script and its object.

DiagnosticNode

Immutable declaration metadata; never contains a live block or delegate.

DiagnosticPause

One breakpoint hit that paused Play Mode.

DiagnosticProtocol

Local diagnostics protocol version. Current snapshots and optional action records are separate observations.

DiagnosticSnapshot

Caller-owned current state from an idle main-thread boundary, never execution history.

DiagnosticTrace

Explicit action capture for one instance lifetime. Disposal changes no script state.

DiagnosticVariable

One immutable declared variable, including whether it is internal storage.

DiagnosticWrite

The last change of one variable's value: which script, object and block changed it, and when.

DocumentFields

The stored fields of one document while a DocumentMigration step converts them. Reads and writes a copy: nothing here reaches a script's variables or the stored file.

DocumentMigration

One consecutive step of a document's schema: converts a stored document of FromVersion into version FromVersion + 1. Written in C#, registered in Build() with Define.Document(...).Migration(step).

EditorScript

The editor entry: a subclass whose Build() composes blocks that run in an EditorScriptSession. Game scripts subclass Script instead. A concrete EditorScript identifies the editor role without an attribute.

EnumValueBlock

The root of every enum expression: something that produces an integer code when the block holding it runs.

FakeAssetLoadProvider

An in-memory asset-load backend for tests: keys map to objects a test registered, a missing key fails as NotFound, and a registered object of another type fails as Denied. No Resources folder is required. AGENTS.md rule 52's shape applied to assets.

FakeCameraProvider

A camera backend that records what it was asked to do, with no Cinemachine package, no camera and no scene.

FakeInputProvider

An input backend that holds its actions and their values in memory, with no device, no window and no Input System package.

FakeNavigationProvider

A navigation backend with no navigation mesh: each registered actor has a position, a speed and a stopping distance, and moves in a straight line to the end of the route a test chose.

FakeNetworkProvider

A netcode backend that runs entirely in this process, with no network, no Editor and no Netcode for GameObjects. Two instances are paired with Pair(out FakeNetworkProvider, out FakeNetworkProvider) and each one's sends arrive in the other's queues.

FakeSceneProvider

An in-memory scene backend: a list of scene paths that count as in the build, a list of loaded scene instances, and loads and unloads that complete when the gateway ticks or when a test says so. It reports the native Loaded and Unloaded phases the way Unity's callbacks do.

FileLoadBlock

What Asset.Load(file).Into(destination).As(handle) builds: starts reading one declared text or JSON file and, when the read and the decoding succeed, writes the destination in one step.

FlagValueBlock

A block that produces a Flag for one object: a variable read or a literal.

GameObjectHost

The Collision queries of a GameObject's host: Unity's buffer-taking physics queries on the default physics scene, with each result copied into a CodeSmile.LunyScript.RawCollisionHit.

InputGateway

The core's one entry point to player input. Owns the IInputProvider, resolves each program's declared actions once, and answers the value reads and the occurrence tests the input blocks make.

InstanceLayout

How many slots of each kind one instance of a program owns, and what value each slot starts from. Built once per script type and never changed afterwards.

InteractionStyle

How a target's visual moves while players focus it: how far it rises, how much it grows, how fast it turns and how long it takes to blend in and out. An asset an Interaction.Target(...).Visual(child) script's Inspector assigns to its InteractionStyle input.

LeaderboardScripting

The Leaderboard verbs a script writes inside Build(): submit a score to a declared board, and read a page of its entries or one account's entry (C06 A, C07 B, C23 A). Outcomes arrive through When.Leaderboard(handle).

LunyScript

Finds the script an object runs, for ordinary C# code outside a script. The result is a LunyScriptReference<TScript> to one incarnation of that script.

LunyScriptAssemblyAttribute

Declares what the scripts of an assembly are for, so that a game start runs the singleton scripts of its production assemblies and none of a sample's or a test's.

LunyScriptBehaviour

Assigns one GameObject to one script type. This is the component a user adds; the script is named by an explicit field rather than by a type name written as a string.

LunyScriptContactBehaviour

Unity physics callbacks for one managed object whose script declared at least one of the six contact events. LunyScriptBehaviour adds this component only in that case, so an object whose script declares none of them is not subscribed.

LunyScriptContractException

Thrown when LunyScript observes that the lifecycle ownership contract was broken: the object running a script was destroyed, reparented or otherwise changed by native Unity API rather than by a LunyScript block.

LunyScriptDataAttribute

Marks a partial struct as a LunyScript data schema: a value shape a script declares its own copy of with Define.Data, binds from an Inspector-assigned asset with Bind.Data, and loads from a JSON file.

LunyScriptDataFieldAttribute

Marks a public field a script may read through a data input, or states the capacity of a text field in a LunyScriptDataAttribute schema.

LunyScriptDriverBehaviour

Ticks one ScriptRunner once per frame, and sweeps instances whose object a scene unload took away. Lives on a hidden object that LunyScriptRuntime creates; a user never adds this component.

LunyScriptException

The root of every exception LunyScript throws. Catch this to catch everything the product raised and nothing else.

LunyScriptInternalException

Thrown when LunyScript's own invariant was broken on a path a user cannot reach: a null or an impossible value inside the product's internals.

LunyScriptLog

The one place LunyScript writes to the Unity console. Unity log lines are formatted here; the LunyScript console reads the retained structured fields.

LunyScriptLogAreas

The area names the product's own log records carry, so that a reader and a debugging window see the same set of words rather than one spelling per call site.

LunyScriptRuntime

Holds the one ScriptRunner that LunyScriptBehaviour components share, and the hidden object that ticks it once per frame.

LunyScriptSingletonCatalog

The singleton scripts a player starts, which the build writes into its first scene on a hidden object.

LunyScriptUsageException

Thrown when script code asks LunyScript for something the API does not offer: a C# if around a condition block, an arithmetic operator on a text variable, a builder finished twice.

NavigationGateway

The core's one entry point to navigation. Owns the INavigationProvider, one record per actor with the attempt that drives it and whether it is paused, and polls every driven actor once per frame before any instance runs. One per ScriptRunner.

NetworkGateway

The core's one entry point to netcode. Owns the INetworkProvider, refuses the session calls that are a user mistake, and drains the provider's two queues once per tick. AGENTS.md rules 44 to 49.

NodeDescription

Collects named child nodes while building immutable program metadata.

NumberValueBlock

A block that produces a Number for one object: a variable read, a literal, or an arithmetic expression over other value blocks.

ReferencedColorBlock

A read of another script's Color variable.

ReferencedEnumBlock

A read of another script's enum variable.

ReferencedFlagBlock

A read of another script's Flag variable, which is also a condition.

ReferencedNumberBlock

A read of another script's Number variable.

ReferencedRotationBlock

A read of another script's Rotation variable.

ReferencedVector2Block

A read of another script's Vector2 variable.

ReferencedVector3Block

A read of another script's Vector3 variable.

ReleaseGate

Gate 4. Runs inside a standalone player built without DEBUG and asserts what only that build can show: that operator true and operator false on a condition block still throw, that the [Conditional] contract guards are gone, and that the two guards written out unconditionally are not.

ResourcesAssetLoadProvider

The Resources backend for Asset.Load of an Resource<T> key. The read happens inside the provider call, which is a start boundary, and the gateway observes the completed operation on its next poll. Blocks never name UnityEngine.Resources.

RotationValueBlock

The root of every orientation expression: something that produces a Rotation when the block holding it runs.

RunnerDiagnostics

Native diagnostics for one explicitly supplied local runner. Reads execute no authored logic.

SceneGateway

Owns in-flight Scene.Load and Scene.Unload attempts, the scene identities the runner's scripts declared, and one counter per identity and phase that the When.Scene* watches read. One per ScriptRunner. Script code never sees a Task, an AsyncOperation or an exception type; AGENTS.md rules 50 and 51.

SceneLoadBlock

What Scene.Load(scene).As(handle) and Scene.Load(scene).Additive().As(handle) build: starts one scene load bound to an operation handle. The handle succeeds when the destination is loaded and active, and fails with a classified reason otherwise.

SceneUnloadBlock

What Scene.Unload(scene).As(handle) builds: starts unloading the one loaded instance of a scene, bound to an operation handle. The handle succeeds when Unity has unloaded it.

Script

The runtime entry: a subclass whose Build() composes blocks that run on a game object. Editor workflows subclass EditorScript instead.

ScriptBase

Shared infrastructure for Script and EditorScript. One instance of a concrete subclass is compiled into one ScriptProgram, once, and every object running that script shares it.

ScriptBuildContext

The build-time half of the behaviour tree: each tree a Behavior(name).Root(node) declares, placed once, and where its starts are placed.

ScriptInstance

One object's state for one program: the slot arrays the program's layout asked for, and the host the blocks act on. The blocks themselves are shared by every instance of the program and hold no per-object state at all.

ScriptObservation

One C# observation of one variable of one script incarnation, returned by Observe(in Number, Action<double>) and its siblings. The caller owns it and ends it with Dispose().

ScriptProgram

One script type, built. Holds the immutable block tree, the On.* event table and the instance layout, and is shared by every object running that script.

ScriptRunner

How one script reaches another on this runner: resolving a target to the instance running on its object, delivering a request to one receiver and an event to its listeners, and the nesting limit both share.

SpawnObjectBlock

What Object.Spawn(pool) and its chain build: checks one entry out of a declared pool, places it, parents it, and holds it in an owned-object slot when the chain named one.

TextCapacities

Facts about TextCapacity that both the layout and the blocks need.

TextFormat

A text built at build time for a text variable's Set, or a Label's SetText or BindText: a parsed Text.Format call, which holds the literal pieces of the format, which value fills each hole and how many decimal places each number hole asks for, or a Text.Join of parts, each written while its condition holds.

TextLengths

Facts about TextLength that collection storage needs.

TimeReadBlock

What Time.Delta and Time.Elapsed return: a number expression reading one of the runner's two clocks, and the one place the clock choice is written.

TransformStreamInbox

Holds the transform streams that arrived since the last tick drained them, in one buffer the inbox owns. Every INetworkProvider uses one, so that the receive side of the stream is written once rather than once per backend.

UIGateway

The core's one entry point to UI Toolkit. Resolves declared names to VisualElement once per instance at spawn and again on panel reload, and answers the writes, reads and occurrence tests the UI blocks make.

UnitySceneProvider

The scene provider the default runner uses: Unity's SceneManager, loading and unloading scenes that are in the build.

VariableAttribute

Declares a variable whose handle is assigned before Build, in declaration order.

Vector2ValueBlock

The root of every two-component spatial expression: something that produces a Vector2 when the block holding it runs.

Vector3ValueBlock

The root of every spatial expression: something that produces a Vector3 when the block holding it runs.
