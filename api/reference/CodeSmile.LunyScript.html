LunyScript API Reference

Namespace CodeSmile.LunyScript

Classes

ActionBlock

A block whose objective can take more than one frame, and which therefore reports ActionResult rather than simply running to completion.

ActivateObjectBlock

What Object.Activate() and Object.Activate(name) build: activates the object the script runs on, or one the script created.

AdapterAdmission

The package and version admission table for extension blocks and optional adapters.

AssetAttribute

Declares an asset input whose handle is assigned before Build, in declaration order.

AssetGateway

Owns in-flight Asset.Load attempts and owner-acquisition records for one ScriptRunner. Bound Inspector loads complete from the instance's already resolved input. Resources loads go through IAssetLoadProvider. Script code never sees a Task or an exception type; AGENTS.md rules 50 and 51.

AssetLoadBlock

What Asset.Load(source).As(handle) builds: starts one asynchronous content acquisition bound to an operation handle. Completion yields an owned typed asset on that handle, or a classified failure. Failure does not fall through to an asset placeholder.

AssetPlaceholders

The asset placeholder every asset type falls back to when an input of that type is left unassigned, and the two ways one is configured.

AssetReleaseBlock

What Asset.Release(acquisition) builds: relinquishes this owner's acquisition. Bound consumers retain content they still need. Release does not destroy them and does not promise immediate physical reclamation.

AssetSource

Names the provider-qualified sources a declared asset input can load from.

AudioGateway

The runner-owned audio service: pooled one-shot voices, named bound-source control, and mixer writes. Bound playback on the object a script runs on lives on IScriptHost instead.

Block

One step of behaviour in a script. A block object is created once, when its script type is built, and is then shared by every object running that script; the per-object state it reads and writes lives in slots on the ScriptInstance passed to Execute(ScriptInstance).

CameraGateway

The core's one entry point to the camera. Owns the ICameraProvider, passes each authored operation to it, and reports a refused one once.

CloudSaveGateway

Owns every in-flight Cloud Save request for one ScriptRunner, keyed by the save key. Signs in when the first request arrives, queues requests made before the service is ready, coalesces duplicates, polls each operation once per frame, and classifies every failure once into an OperationFailure. No script and no block ever sees a Task or an exception type; AGENTS.md section 12.

CompilationFacts

What the compiler was told when this assembly was built. Read by tests and by the release gate, so that a claim about release behaviour can name the compilation it was measured in.

ConditionBlock

A block that answers true or false for one object. Passed to If(...) and combined with &, | and !.

CreateObjectBlock

What Object.Create(name) builds: creates a new, empty, active object owned by the instance that runs this block, and records it in the owned-object slot the build assigned to that name.

DeactivateObjectBlock

What Object.Deactivate() and Object.Deactivate(name) build: deactivates the object the script runs on, or one the script created.

DespawnObjectBlock

What Object.Despawn() and Object.Despawn(name) build: ends the object the script runs on, or destroys one the script created.

DiagnosticBuffer

Fixed-capacity, ordered storage shared by console and trace readers.

DiagnosticCatalog

Immutable catalog for one built program.

DiagnosticCommand

Caller-owned receipt. Terminal results survive target closure and are never replayed.

DiagnosticFault

Observed contained error or failed outer boundary, separate from enabled state.

DiagnosticNode

Immutable declaration metadata; never contains a live block or delegate.

DiagnosticProtocol

Local diagnostics protocol version. Current snapshots and optional action records are separate observations.

DiagnosticSnapshot

Caller-owned current state from an idle main-thread boundary, never execution history.

DiagnosticTrace

Explicit action capture for one instance lifetime. Disposal changes no script state.

DiagnosticVariable

One immutable declared variable, including whether it is internal storage.

DocumentFields

The stored fields of one document while a DocumentMigration step converts them. Reads and writes a copy: nothing here reaches a script's variables or the stored file.

DocumentMigration

One consecutive step of a document's schema: converts a stored document of FromVersion into version FromVersion + 1. Written in C#, registered in Build() with Define.Document(...).Migration(step).

EditorScript

The editor entry: a subclass whose Build() composes blocks that run in an EditorScriptSession. Game scripts subclass Script instead. A concrete EditorScript identifies the editor role without an attribute.

EnumValueBlock

The root of every enum expression: something that produces an integer code when the block holding it runs.

FakeAssetLoadProvider

An in-memory asset-load backend for tests: keys map to objects a test registered, a missing key fails as NotFound, and a registered object of another type fails as Denied. No Resources folder is required. AGENTS.md rule 52's shape applied to assets.

FakeCameraProvider

A camera backend that records what it was asked to do, with no Cinemachine package, no camera and no scene.

FakeInputProvider

An input backend that holds its actions and their values in memory, with no device, no window and no Input System package.

FakeNavigationProvider

A navigation backend with no navigation mesh: each registered actor has a position, a speed and a stopping distance, and moves in a straight line to the end of the route a test chose.

FakeNetworkProvider

A netcode backend that runs entirely in this process, with no network, no Editor and no Netcode for GameObjects. Two instances are paired with Pair(out FakeNetworkProvider, out FakeNetworkProvider) and each one's sends arrive in the other's queues.

FakeSceneProvider

An in-memory scene backend: a list of scene paths that count as in the build, a list of loaded scene instances, and loads and unloads that complete when the gateway ticks or when a test says so. It reports the native Loaded and Unloaded phases the way Unity's callbacks do.

FileCloudSaveProvider

The file-based Cloud Save provider: one file per key, under a directory the caller names. A first-class part of the product, not a test fixture; AGENTS.md rule 52. It is how every failure branch is tested without a network, and what makes the automated suite runnable with no credentials.

FlagValueBlock

A block that produces a Flag for one object: a variable read or a literal.

GameObjectHost

The runtime IScriptHost for a GameObject, as the blocks see it.

InputGateway

The core's one entry point to player input. Owns the IInputProvider, resolves each program's declared actions once, and answers the value reads and the occurrence tests the input blocks make.

InstanceLayout

How many slots of each kind one instance of a program owns, and what value each slot starts from. Built once per script type and never changed afterwards.

LunyScriptBehaviour

Assigns one GameObject to one script type. This is the component a user adds; the script is named by an explicit field rather than by a type name written as a string.

LunyScriptContactBehaviour

Unity physics callbacks for one managed object whose script declared at least one of the six contact events. LunyScriptBehaviour adds this component only in that case, so an object whose script declares none of them is not subscribed.

LunyScriptContractException

Thrown when LunyScript observes that the lifecycle ownership contract was broken: the object running a script was destroyed, reparented or otherwise changed by native Unity API rather than by a LunyScript block.

LunyScriptDriverBehaviour

Ticks one ScriptRunner once per frame, and sweeps instances whose object a scene unload took away. Lives on a hidden object that LunyScriptRuntime creates; a user never adds this component.

LunyScriptException

The root of every exception LunyScript throws. Catch this to catch everything the product raised and nothing else.

LunyScriptInternalException

Thrown when LunyScript's own invariant was broken on a path a user cannot reach: a null or an impossible value inside the product's internals.

LunyScriptLog

The one place LunyScript writes to the Unity console. Unity log lines are formatted here; the LunyScript console reads the retained structured fields.

LunyScriptLogAreas

The area names the product's own log records carry, so that a reader and a debugging window see the same set of words rather than one spelling per call site.

LunyScriptRuntime

Holds the one ScriptRunner that LunyScriptBehaviour components share, and the hidden object that ticks it once per frame.

LunyScriptUsageException

Thrown when script code asks LunyScript for something the API does not offer: a C# if around a condition block, an arithmetic operator on a text variable, a builder finished twice.

NavigationGateway

The core's one entry point to navigation. Owns the INavigationProvider, one record per actor with the attempt that drives it and whether it is paused, and polls every driven actor once per frame before any instance runs. One per ScriptRunner.

NetworkGateway

The core's one entry point to netcode. Owns the INetworkProvider, refuses the session calls that are a user mistake, and drains the provider's two queues once per tick. AGENTS.md rules 44 to 49.

NodeDescription

Collects named child nodes while building immutable program metadata.

NumberValueBlock

A block that produces a Number for one object: a variable read, a literal, or an arithmetic expression over other value blocks.

ReleaseGate

Gate 4. Runs inside a standalone player built without DEBUG and asserts what only that build can show: that operator true and operator false on a condition block still throw, that the [Conditional] contract guards are gone, and that the two guards written out unconditionally are not.

ResourcesAssetLoadProvider

The Resources backend for Asset.Load of an AssetSource.Resources key. The read happens inside the provider call, which is a start boundary, and the gateway observes the completed operation on its next poll. Blocks never name UnityEngine.Resources.

RotationValueBlock

The root of every orientation expression: something that produces a Rotation when the block holding it runs.

RunnerDiagnostics

Native diagnostics for one explicitly supplied local runner. Reads execute no authored logic.

SceneGateway

Owns in-flight Scene.Load and Scene.Unload attempts, the scene identities the runner's scripts declared, and one counter per identity and phase that the When.Scene* watches read. One per ScriptRunner. Script code never sees a Task, an AsyncOperation or an exception type; AGENTS.md rules 50 and 51.

SceneLoadBlock

What Scene.Load(scene).As(handle) and Scene.Load(scene).Additive().As(handle) build: starts one scene load bound to an operation handle. The handle succeeds when the destination is loaded and active, and fails with a classified reason otherwise.

SceneUnloadBlock

What Scene.Unload(scene).As(handle) builds: starts unloading the one loaded instance of a scene, bound to an operation handle. The handle succeeds when Unity has unloaded it.

Script

The runtime entry: a subclass whose Build() composes blocks that run on a game object. Editor workflows subclass EditorScript instead.

ScriptBase

Shared infrastructure for Script and EditorScript. One instance of a concrete subclass is compiled into one ScriptProgram, once, and every object running that script shares it.

ScriptBuildContext

The build-time half of the collection try grammar: declared results, the tries this build created, and the checks that run when Build() finishes.

ScriptInstance

One object's state for one program: the slot arrays the program's layout asked for, and the host the blocks act on. The blocks themselves are shared by every instance of the program and hold no per-object state at all.

ScriptObservation

One C# observation of one variable of one script incarnation, returned by Observe(in Number, Action<double>) and its siblings. The caller owns it and ends it with Dispose().

ScriptProgram

One script type, built. Holds the immutable block tree, the On.* event table and the instance layout, and is shared by every object running that script.

ScriptRunner

Owns the built programs, the live instances and the instance pool, and runs each event kind across every instance.

Scripts

Finds the script an object runs, for ordinary C# code outside a script. The result is a ScriptView<TScript> of one incarnation of that script.

SpawnObjectBlock

What Object.Spawn(prefab) and its chain build: produces an object from a declared prefab input, places it, parents it, and holds it in an owned-object slot when the chain named one.

TextCapacities

Facts about TextCapacity that both the layout and the blocks need.

TextFormat

A parsed Text.Format call: the literal pieces of the format, which value fills each hole, and how many decimal places each number hole asks for. Pass it to a text variable's Set.

TextLengths

Facts about TextLength that collection storage needs.

TimeReadBlock

What Time.Delta and Time.Elapsed return: a number expression reading one of the runner's two clocks, and the one place the clock choice is written.

TransformStreamInbox

Holds the transform streams that arrived since the last tick drained them, in one buffer the inbox owns. Every INetworkProvider uses one, so that the receive side of the stream is written once rather than once per backend.

UIGateway

The core's one entry point to UI Toolkit. Resolves declared names to VisualElement once per instance at spawn and again on panel reload, and answers the writes, reads and occurrence tests the UI blocks make.

UnitySceneProvider

The scene provider the default runner uses: Unity's SceneManager, loading and unloading scenes that are in the build.

VariableAttribute

Declares a variable whose handle is assigned before Build, in declaration order.

Vec2ValueBlock

The root of every two-component spatial expression: something that produces a Vec2 when the block holding it runs.

Vec3ValueBlock

The root of every spatial expression: something that produces a Vec3 when the block holding it runs.

Structs

AdapterRegistration

One extension block type an adapter registered, with the Unity package and minimum version that type needs.

AimedLookAtBuilder

A facing whose up direction has been named. It converts to a block and takes no further clause.

AnimatorFactory

AnimatorFlag

AnimatorInteger

A handle to one Int parameter of the Animator on the object a script runs on. Returned by Animator.Integer(name) at build time.

AnimatorNumber

A handle to one Float parameter of the Animator on the object a script runs on. Returned by Animator.Number(name) at build time; the members on it build blocks.

AnimatorTrigger

A handle to one Trigger parameter of the Animator on the object a script runs on. Returned by Animator.Trigger(name) at build time.

AnyPlayerInputFactory

What Input.AnyPlayer() returns: a shared button, read across every local player number the backend holds.

AssetFactory

The Asset surface inside Build(): starts and ends content acquisitions. Unity owns the asset. LunyScript owns the attempt, the owner-acquisition, and consumer retention.

AssetInput

One declared asset input with its type forgotten: what a surface takes when it accepts an input of any Unity type, such as the camera rig a view renders.

AssetInputAssignment

One row of the declared-input table a host component serializes: the name of a declared input and the asset this object assigns to it, or, for a scene input, the scene.

AssetLoadBuilder

What Asset.Load(source) returns: an unfinished acquisition that becomes a block when As(Operation, string, int) binds the operation handle. An unbound Load is refused when Build() finishes.

AssetSource<T>

One provider-qualified place a declared asset input loads from when the host assigns nothing.

Asset<T>

A handle to one asset input of a script. Returned by Bind.Asset at build time; reading the asset itself is an instance read, because the value belongs to the object and not to the script type.

AudioFactory

The Audio surface inside Build(): one-shot play, bound source control, and named mixer writes. It hides UnityEngine.AudioSource inside a Script the same way Transform hides UnityEngine.Transform.

AudioListenerHandle

What Audio.Listener returns.

AudioListenerTargetBuilder

What Audio.Listener.SetTarget(target) returns.

AudioListenerTargetDurationBuilder

What Audio.Listener.SetTarget(target).Over(amount) returns: a transition whose amount is seconds unless a unit call names another unit.

AudioMixerHandle

What Audio.Mixer(mixer) returns: named exposed-parameter writes.

AudioPlacedOneShotBuilder

A one-shot whose placement has been named. It converts to a block and takes no further placement clause.

AudioPlayOneShotBuilder

What Audio.PlayOneShot(clip) returns: a 2D one-shot, or one placement.

AudioSourceHandle

What Audio.For(source) returns: bound-source control on that object.

AudioVoice

What Audio.Voice(name) returns: one tracked one-shot.

AudioVoiceVolumeBuilder

What voice.SetVolume(value) returns.

AudioVoiceVolumeDurationBuilder

What voice.SetVolume(value).Over(amount) returns: a fade whose amount is seconds unless a unit call names another unit.

AudioWatchBuilder

What When.Audio(voice) returns. Each method registers blocks for one end of that tracked playback.

BindFactory

The Bind surface inside Build(): declares the assets a script needs and hands back the typed handles that read them.

BodyFactory

The Body surface inside Build(): observations of what physics actually did to the object this script runs on.

CameraFactory

The Camera surface inside Build(): what one camera rig tracks. It hides UnityEngine.Camera inside a Script the same way Transform hides UnityEngine.Transform.

CameraRigBuilder

What Camera.For(rig) returns: the rig's two tracking targets and its target group.

CameraTargetsBuilder

What Camera.For(rig).Targets returns: the five operations on a rig's group of tracked objects.

ChooseBiasedBuilder

A Choose chain that already has Bias. Optional Hold(Elapsed, string, int) follows.

ChooseBiasedHoldAmountBuilder

A Choose chain that has Bias and a Hold amount: the amount is seconds unless a unit call names another unit. Used as a block it starts the selector.

ChooseBuilder

What Choose(subject) returns. Its one call, Highest(params UtilityOption[]), names the scored options.

ChooseCompleteBuilder

A Choose chain that has both Bias and Hold. Used as a block it starts the selector.

ChooseHeldBuilder

A Choose chain that already has Hold. Optional Bias(double, string, int) follows.

ChooseHighestBuilder

A Choose(subject).Highest(...) chain. Optional Bias(double, string, int) and Hold(Elapsed, string, int) follow; used as a block it starts the selector.

ChooseHoldAmountBuilder

A Choose(subject).Highest(...).Hold(amount) chain: the Hold amount is seconds unless a unit call names another unit. Optional Bias(double, string, int) follows; used as a block it starts the selector.

CloudFactory

The Cloud surface inside Build(): builds the start blocks for Cloud Save. A start block enqueues and returns in the same call; the outcome arrives through When.Cloud(key), and, for a start bound with .As(handle), through When.Cloud(handle) and When.Operation(handle). AGENTS.md rule 50.

CloudLoadBuilder

What Cloud.Load(key) returns: an unbound load when it is used as a block, or a load that names the variable its value is written into after Into(Number).

CloudLoadIntoBuilder

What Cloud.Load(key).Into(target) returns: a load that becomes a block when As(Operation, string, int) binds the operation handle.

CloudSaveBuilder

What Cloud.Save(key, value) returns: an unbound save when it is used as a block, or a save bound to an operation handle after As(Operation, string, int).

CloudWatchBuilder

What When.Cloud(key) returns: registers blocks against one key's Cloud Save outcomes. Each registration declares a hidden counter-shadow variable at build time and is polled once per frame after On.FrameUpdate, the same shape When.Var(x).Changed has.

CollectionRead

A typed read of one collection entry: either At(index) or the current ForEach item. Each use reads the entry addressed by that expression, so a replacement of the current element is visible to the next read in the same body.

CollectionResult

The read-only, named outcome of one synchronous collection call. Declared with CollectionResult.Define(nameof(X)) inside Build() and produced by exactly one Slots.TryAdd(item).As(X). Used as a condition, it stands for Succeeded.

CollectionResultFactory

The CollectionResult surface inside Build(): declares a named result that one synchronous collection call produces.

CollectionTryBuilder

What Slots.TryAdd(item) returns: one synchronous collection call whose own outcome is read. It has two consumers and takes exactly one of them: If(Slots.TryAdd(item)) branches on the outcome, and As(CollectionResult, string, int) stores it in a CollectionResult.

CursorInputFactory

What Input.Cursor returns: lock and visibility as two independent writes on the machine cursor. Four local players share one cursor; this surface is not on Input.ForPlayer.

DebugFactory

The Debug surface: blocks that write a line to the Console when they run. Log(string, string, int) writes an ordinary entry, Warn a warning and Error an error.

DefineFactory

The Define surface inside Build(): declares a script's variables with the author spelling Round 06 settled, and hands back the typed handles the blocks are built from.

DiagnosticIdentity

Identifies one lifetime independently of pooled object reuse.

DiagnosticValue

A typed diagnostic value. Text is a caller-owned managed representation.

Document

A handle to one declared document: a named, versioned set of variables that Progress.Save and Progress.Load, or Settings.Save and Settings.Load, keep in the user's local storage. Declared with Define.Document(nameof(X)) inside Build().

DocumentDefineBuilder

What Define.Document(name) returns: a document being declared, which takes its version, its fields and its migration steps, then converts to the Document handle.

DocumentLoadBuilder

What Progress.Load(document) and Settings.Load(document) return: a load that becomes a block when As(Operation, string, int) binds the operation handle. An unbound load is refused when Build() finishes.

DocumentSaveBuilder

What Progress.Save(document) and Settings.Save(document) return: a save that becomes a block when As(Operation, string, int) binds the operation handle. An unbound save is refused when Build() finishes.

Elapsed

An elapsed duration written with a unit constructor: Seconds(1), Milliseconds(500), Minutes(2) or Hours(1).

EnumSlot

Where one declared C# enum variable lives on every instance of a program. Allocated at build time and never at run time.

FakeCameraProvider.TargetGroupEntry

One object in a rig's target group, with the weight and radius it was given.

Flag

A true-or-false variable of a script: a handle to one slot backed by bool storage, or a constant. Build() declares it, and its methods and operators build blocks.

FlagBindBuilder

What Bind.Flag returns. It converts to no handle; Shared is required.

FlagDefineBuilder

What Define.Flag returns: an object-local flag unless Shared is called.

FlagFactory

Declares flag variables. Inside a script, Flag in an expression means this member; in a declaration it is still the Flag type.

FlagSlot

Where one Flag variable lives on every instance of a program. Allocated at build time and never at run time.

ForEachListBuilder<T>

What ForEach(list) returns. Its only method is Do(Func<CollectionRead, Block>).

ForEachMapBuilder<TKey, TValue>

What ForEach(map) returns. Its only method is Do(Func<CollectionRead, CollectionRead, Block>).

GateFactory

The Gate surface: named, nested, runner-wide masks of suppressed categories.

IfBuilder

What If(condition) returns. Its only method is Then(params Block[]), so a condition without a consequence does not compile.

IfThenBuilder

What If(condition).Then(...) returns: either add an Else(params Block[]) or use it as a block, which the implicit conversion does.

InputButton

A handle to one pressed-or-not action of one local player. Returned by Input.ForPlayer(player).Button(name) at build time; the members on it build blocks.

InputFactory

The Input surface inside Build(): names the local player whose actions this script reads. It hides UnityEngine.Input inside a Script the same way Transform hides UnityEngine.Transform.

InputNumber

A handle to one single-axis action of one local player. Returned by Input.ForPlayer(player).Number(name) at build time.

InputRebindBuilder

What handle.Rebind() returns. Bind it with .As(operation) before Build() returns, or Finish refuses the chain naming this type and the authored line.

InputVector2

A handle to one two-axis action of one local player. Returned by Input.ForPlayer(player).Vector2(name) at build time.

InputVector3

A handle to one three-axis action of one local player. Returned by Input.ForPlayer(player).Vector3(name) at build time.

InputWatchBuilder

What When.Input(action) returns. Its three methods register the blocks that run on a frame where the action reported that occurrence.

ListDefineBuilder<T>

What Define.List returns: an empty list of the declared capacity.

ListHandle<T>

A handle to one fixed-capacity list declared with Define.List<T>. Occupancy starts at zero. The C# type is not List<T>, because that name collides with System.Collections.Generic.List.

LookAtBuilder

What LookAt returns: the facing, about the world up unless WithUp(NumberValueBlock, NumberValueBlock, NumberValueBlock, string, int) names another direction.

LunyScriptLogRecord

One thing LunyScript has to say, as structured fields rather than as a finished string.

MapDefineBuilder<TKey, TValue>

What Define.Map returns: an empty map of the declared capacity.

MapHandle<TKey, TValue>

A handle to one fixed-capacity map declared with Define.Map<TKey, TValue>. Occupancy starts at zero. Existing-key assignment replaces the value and keeps insertion order.

MaterialNumber

What Object.MaterialNumber(name) returns: one Float or Range property of a renderer's materials, declared by the name in the shader's Properties block. The members build the blocks that write it into the renderer's property block and remove it again.

MathFactory

The core numeric functions, written as Math.Abs(...) inside a script's Build(). Every member returns an expression that is evaluated each time the block holding it runs; none of them writes anything.

MigrationResult

What one DocumentMigration step returns: the document was converted, or it was rejected with a reason.

MotionDisplacementBuilder

MotionFaceTowardsBuilder

MotionFactory
