Enum SlotKind

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Which kind of slot a variable occupies. A slot kind is one array on ScriptInstance, so adding a kind is adding an array, a layout counter and a branch, and nothing else.

public enum SlotKind

Fields

Enum = 7

A declared C# enum slot. Storage is the enum's integer code as Int64, not a Number.

Flag = 2

A Flag slot.

Number = 1

A Number slot. AGENTS.md rule 12: this is the default number type.

Rotation = 5

An orientation slot holding a Rotation.

Text = 3

A fixed-capacity UTF-8 text slot. The capacity is part of the handle.

Undefined = 0

No slot, and the value a default(Var<T>) carries. A handle that Build() never assigned holds this kind, and every operation on it throws LunyScriptUsageException rather than addressing slot 0 of some other variable. This is why the three real kinds start at 1.

Vec2 = 6

A two-component spatial slot holding a Vec2.

Vec3 = 4

A three-component spatial slot holding a Vec3: a position, a direction, a displacement or a scale.
