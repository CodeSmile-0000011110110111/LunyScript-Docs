The root of every orientation expression: something that produces a Rotation when the block holding it runs.

Remarks

There is no member here that replaces one quaternion component. Three of the four components are not independent of the fourth, so replacing one alone produces a value that is not an orientation. The API semantics board ruled on 2026-09-13 that a rotation is changed through its constructors or through Compose(RotationValueBlock), and this type offers exactly those.
