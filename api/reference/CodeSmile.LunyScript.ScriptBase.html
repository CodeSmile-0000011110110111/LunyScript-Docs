Shared infrastructure for Script and EditorScript. One instance of a concrete subclass is compiled into one ScriptProgram, once, and every object running that script shares it.

Examples

public sealed partial class CountdownScript : Script
{
    [Variable(3)] public Var<Number> Health { get; private set; }
    [Variable(true)] public Var<Flag> Alive { get; private set; }
    protected override void Build()
    {
        On.FrameUpdate(If(Health > 0.0).Then(Health.Add(-1.0)).Else(Alive.Set(false)));
        When.Var(Alive).Changed(Health.Set(0.0));
    }
}

Remarks

Build() runs once per script type, before any object exists. It cannot read an inspector value, an object name or anything else about a particular object; declare a variable and fill it at spawn instead. AGENTS.md rule 25.

Calls made while Build() runs construct the shared Script program once per Script type. The blocks those calls return execute later, per event and per Script instance. Confusing those phases is the largest defect class in this design. AGENTS.md rule 43.

DefineAssets()

Assigns generated asset-input handles before Build, after the variables. Source-generated overrides call the base implementation first so inherited declarations keep their order.

protected virtual void DefineAssets()

Remarks

Written by the same generator that writes DefineVariables(). Use [Asset] properties in a partial Script subclass, or keep explicit Bind.Asset calls inside Build.

It is a second hook rather than more lines in the first because the two declare different things: a variable is storage this script owns and an asset input is a value an object supplies. Both run before Build(), which is what lets Build() use either.

InParallel(params Block[])

A concurrent group: every child advances each frame, in the order they are written, inside one step of a routine.

protected RoutineGroupBuilder InParallel(params Block[] children)

Parameters

Type Name Description
Block[]
children

The children, in declaration order.

Returns

RoutineGroupBuilder

The group, ready to be used as a routine step or given an ending clause.

Examples

On.Ready(Routine("Open").Run(InParallel(slideDoor, playSound)));

Remarks

As written, the group runs every child and waits for all of them, reporting Succeeded only if every child succeeded. UntilOneFinishes() and UntilOneSucceeds() replace that with an early ending, and OthersKeepRunning() follows either of those to keep the unfinished children running under the enclosing routine activation.

This factory takes a params array, so C# allows it no parameter after the children and it captures no authored line; AGENTS.md rule 72. The routine step that carries the group is what a diagnostic names.
