Examples

public sealed partial class CountdownScript : Script
{
    [Variable(3)] public Number Health { get; private set; }
    [Variable(true)] public Flag Alive { get; private set; }
    protected override void Build()
    {
        On.Update(If(Health > 0.0).Then(Health.Add(-1.0)).Else(Alive.Set(false)));
        When.Var(Alive).Changed(Health.Set(0.0));
    }
}

Remarks

Build() runs once per script type, before any object exists. It cannot read an inspector value, an object name or anything else about a particular object; declare a variable and fill it at spawn instead. AGENTS.md rule 25.

Calls made while Build() runs construct the shared Script program once per Script type. The blocks those calls return execute later, per event and per Script instance. Confusing those phases is the largest defect class in this design. AGENTS.md rule 43.

DefineAssets()

Assigns generated asset-input handles before Build, after the variables. Source-generated overrides call the base implementation first so inherited declarations keep their order.

protected virtual void DefineAssets()

Remarks

Written by the same generator that writes DefineVariables(). Use [Asset] properties in a partial Script subclass, or declare the inputs with Bind calls inside Build.

It is a second hook rather than more lines in the first because the two declare different things: a variable is storage this script owns and an asset input is a value an object supplies. Both run before Build(), which is what lets Build() use either.

InParallel(params Block[])

A concurrent group: every child advances each frame, in the order they are written, inside one step of a routine.

protected RoutineGroupBuilder InParallel(params Block[] children)

Parameters

Type Name Description
Block[]
children

The children, in declaration order.

Returns

RoutineGroupBuilder

The group, ready to be used as a routine step or given an ending clause.

Examples

On.Ready(Routine("Open").Run(InParallel(slideDoor, playSound)));

Remarks

As written, the group runs every child and waits for all of them, reporting Succeeded only if every child succeeded. UntilOneFinishes() and UntilOneSucceeds() replace that with an early ending, and OthersKeepRunning() follows either of those to keep the unfinished children running under the enclosing routine activation.

This factory takes a params array, so C# allows it no parameter after the children and it captures no authored line; AGENTS.md rule 72. The routine step that carries the group is what a diagnostic names.

A group belongs in a routine, another group, a Run body or a Choose option's action. Placed inside Then or Else, or directly in an event list, it is refused when the script type is built; inside Then or Else the refusal names the line of the If that holds it. LUNY007 reports the same placement at compile time where the group is written directly in the list.

Sequence(params Block[])

Several blocks held as one block. It runs them in the order they are written and does what they would do written out in its place.

protected Block Sequence(params Block[] blocks)

Parameters

Type Name Description
Block[]
blocks

The blocks, in the order they run.

Returns

Block

The sequence, as one block.

Examples

Remarks

In an event list, a Then or another list that runs every block at once, the sequence runs its blocks in that frame. As a step of a routine, a group, a Run body or a Choose option's action, each of its blocks finishes before the next begins, so a Wait inside it holds that owner, and in a concurrent group the sequence is one child. It reports Failed when one of its blocks did, and runs the rest of them first. Placed a second time it is a copy with progress of its own.

(a, b, c), a tuple of 2 to 9 blocks, is the same sequence. Define.Sequence declares one with a name, which the debugger shows. This factory takes a params array, so it captures no authored line; AGENTS.md rule 72. docs/proposals/sequences.md is the contract.

The builder, which is a step as it is or takes Seconds, Milliseconds, Minutes or Hours.

Examples

On.Ready(Routine("Door").Run(Opening.Set(true), Wait(3), Opening.Set(false)));
On.Ready(Routine("Blink").Run(Lamp.Set(true), Wait(500).Milliseconds(), Lamp.Set(false)));

Remarks

The wait counts game time from the moment the routine reaches it, and the amount is read then. Zero finishes at once; a negative amount, NaN or an infinity finishes at once and is reported as a warning. A wait belongs in a routine, a concurrent group or a Run body; placed inside Then or Else, or directly in an event list, it is refused when the script type is built, naming its line, and LUNY007 reports it at compile time where it is written directly in the list.
