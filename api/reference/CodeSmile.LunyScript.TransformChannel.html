Enum TransformChannel

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Which part of an object's transform a declaration synchronises. One channel is one declaration with one cadence, which is AGENTS.md rule 46 applied to the transform: a scale that never changes cannot share a payload with a position that changes every tick.

None = 0

The world position.

The world rotation.

Scale = 3

The local scale.

Remarks

Position and rotation are world space, scale is local space. Those are the three the replaced NetworkTransform carries and the three docs/netcode-bandwidth.md compares against it.
