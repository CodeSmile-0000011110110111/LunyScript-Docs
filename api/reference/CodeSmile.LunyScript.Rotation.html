An orientation in three dimensions, held as a unit quaternion.

public readonly struct Rotation
Expand Details ...

Examples

var facing = Rotation.Euler(0.0, 90.0, 0.0);
var reversed = facing.Inverse;

Remarks

The four components are readable and none of them is writable. Three of the four are not independent of the fourth: a quaternion that is not of length one is not an orientation, so writing one component alone produces a value that rotates and stretches. The API semantics board ruled on 2026-09-13 that a rotation is changed through its constructors or Compose(Rotation) rather than through its components.

An input that names no orientation produces Identity. A quaternion of length zero and one carrying a NaN or an infinity are both refused that way rather than stored, so nothing downstream reads a value that is not a rotation.

Euler(double, double, double) takes degrees and applies them in the order Z, then X, then Y, which is the order Unity's own euler-angle rotation uses, so a script that computes an orientation here and one that reads it off a transform agree.

Remarks

An orientation and its four negated components name the same orientation, so the angle between them is zero rather than 360. That is what "antipodal equality" means here, and a tolerance comparison is written a.AngleTo(b) <= tolerance.
