Enum DiskPlane

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The two axes a spawn's InRadius disk lies on. The default is XZ, the ground plane of a 3D scene; XY is the plane a 2D scene draws on.

public enum DiskPlane
Expand Details ...

Fields

XY = 1

The X and Y axes: a disk on the plane a 2D scene draws on.

XZ = 0

The X and Z axes: a disk on the ground plane of a 3D scene. The default.

YZ = 2

The Y and Z axes.

Examples

Object.Spawn(Guards).At(Portal).InRadius(5.0, DiskPlane.XY)

Remarks

The axes are the placement's own axes unless the chain says InWorldSpace(), which selects the world's. docs/proposals/prefabs-instantiation-and-pooling.md states which axes a placement has.
