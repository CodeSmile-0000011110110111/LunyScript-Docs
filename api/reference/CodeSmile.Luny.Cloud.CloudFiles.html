Class CloudFiles

Namespace
CodeSmile.Luny.Cloud
Assembly
ApiSource.dll

The file part of a CloudClient: player files, and the C# sources registered by name that produce a save's bytes and receive a load's. A LunyScript script names a registered file and never holds bytes (C20 B); C# may also pass bytes directly.
