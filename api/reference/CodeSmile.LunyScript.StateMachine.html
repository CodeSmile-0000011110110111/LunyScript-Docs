A flat state machine: one current state per object, transitions read in the order they were written, and the lists each state runs when it is entered, while it is current and when it is left.

public readonly struct StateMachine
Expand Details ...

Examples

(Phases, Calm, Angry) = Define.StateMachine(nameof(Phases)).WithStates(nameof(Calm), nameof(Angry));
Phases.Initial(Calm);
Phases.State(Angry).Enter(Speed.Set(3)).Exit(Speed.Set(1));
Phases.From(Calm).To(Angry).When(Health < 50);
On.Ready(Phases.Start());

Remarks

Declared with its states on one line inside Build(); the generator writes a property for the machine and one for each state. Every call on the handle is written inside Build(). Start() and Stop() return blocks, IsIn and IsRunning return conditions, and the rest declare the machine.

A pass runs on the machine's tick, the frame update unless InFixedUpdate(string, int) or InLateUpdate(string, int) is written. It reads the transitions first and does the current state's work only when none is chosen. docs/proposals/state-machine.md is the contract.

CascadeLimit(int, string, int)

The most state changes one pass commits. The default, 1, ends the pass at every change, and the new state's work runs in the next pass. Above 1 the pass continues with the new state, and stops before a change back to a state it already visited.
