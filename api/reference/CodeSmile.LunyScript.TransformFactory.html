The Transform surface inside Build(): where the object a script runs on is, how it is turned and scaled, what is above and below it in the hierarchy, and what it is parented to.

public readonly struct TransformFactory
Expand Details ...

Examples

On.Update(Transform.MoveBy(Step, 0.0, 0.0), Transform.RotateBy(0.0, 1.5, 0.0));
On.Ready(Transform.SetScale(2.0));
On.Ready(If(Transform.HasParent).Then(Transform.Unparent()));

Remarks

The blocks reach the object through IScriptHost, never through a UnityEngine.Transform; AGENTS.md rule 24. Every number parameter is a NumberValueBlock and every spatial parameter a Vector3ValueBlock, so a literal, a variable and an expression all work, through the implicit conversions those types declare.

Every verb that takes three numbers also takes one spatial value. MoveBy(Step) and MoveBy(Step.X, Step.Y, Step.Z) build the same block; a Vector3 carrying degrees holds them in the layout Rotation.ToEuler() returns.

A displacement is in the object's own frame and an absolute value names its frame in the verb. MoveBy(NumberValueBlock, NumberValueBlock, NumberValueBlock, string, int) and RotateBy(NumberValueBlock, NumberValueBlock, NumberValueBlock, string, int) act along the object's own oriented axes unless the builder they return is given InWorldSpace(); SetWorldPosition(NumberValueBlock, NumberValueBlock, NumberValueBlock, string, int) and SetLocalPosition(NumberValueBlock, NumberValueBlock, NumberValueBlock, string, int) say which frame they mean in their names. That is the captain's answer to API-semantics row T02 on 2026-09-13, and TransformSpace states why one word covers two frames.

Parent, Child(NumberValueBlock, string, int) and Root aim the same verbs at one step of the hierarchy around the object. They offer no further navigation of their own; TransformTargetFactory says why.

Builds a move of this object to a world position over a duration.

string

Supplied by the compiler; see MoveBy(NumberValueBlock, NumberValueBlock, NumberValueBlock, string, int).
int
callerLineNumber

Supplied by the compiler.

Returns

TransformToBuilder

A builder whose Over names the duration.

Examples

On.Update(Transform.MoveTo(3.0, 0.0, 0.0).Over(2.0));
On.Update(Transform.Child(0).MoveTo(3.0, 0.0, 0.0).Over(2.0));

Remarks

The first run captures the current pose, the destination and the duration. Each later run in a process event adds Time.Delta and writes the interpolated world position. Place it in On.Update. A script the pause system has stopped does not run this block. Over is required; without it this is not a block. Over(2) is two seconds, and a unit call such as Over(500).Milliseconds() names another unit. A destination that changes during the interpolation takes effect when it ends: the object arrives at the destination it captured, and the next run moves it from there.

A factor, not an amount: one leaves the axis unchanged, zero collapses it and a negative factor mirrors it. Repeated every frame it compounds, which is what makes it a growth rather than a step. There is no world modifier and no AddScale verb; that is the captain's answer to API-semantics row T03 on 2026-09-13.

Exceptions

LunyScriptUsageException

Any factor is null, or this surface was read outside Build().
