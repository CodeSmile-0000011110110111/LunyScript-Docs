LunyScript API Reference

Namespace CodeSmile.Luny.Demos

Classes

DemoBootstrap

A demo scene's entry into its persistent hosts: in its Awake, before the scene's other components, it finds every live DemoPersistent host and creates, from its prefabs, only the hosts of the ids that are missing, keeping them across scene loads. A scene opened directly creates every host; a scene loaded from another demo adopts the hosts that scene left, so participants, Users, views and preferences continue.

DemoPersistent

Marks a persistent host's root, such as a co-op, camera, player or preferences host, with an id; a DemoBootstrap creates a host only while no host of its id lives, so the hosts a previous scene left are adopted and none wakes twice.

DemoScenes

The scene load a demo's menu asks for when the players move to another demo, such as from one lab to the next: the persistent hosts continue, so participants, Users, views and preferences continue, and the next scene's bootstrap adopts them. A return to the main menu is a separate transaction that ends the group.

DemoStage

Builds a demo scene's stage under its stage root: nothing for Empty, a floor and a light for Static, and also four spawn points for Playable. A scene's Editor recipe calls it with its own root, so a rebuild replaces only that root's children and the scene's lesson objects stay where the recipe put them.
