Class DocumentFields

Namespace
CodeSmile.LunyScript

The stored fields of one document while a DocumentMigration step converts them. Reads and writes a copy: nothing here reaches a script's variables or the stored file.

public sealed class DocumentFields
Expand Details ...
Inheritance
object
DocumentFields

Examples

fields.Rename("best", "BestWave");
fields.DefaultNumber("Coins", 0);
if (fields.TryGetNumber("seconds", out var seconds))
    fields.SetNumber("minutes", seconds / 60.0);

Remarks

A field is read by the kind the reader asks for, because the file stores values, not kinds: a number reads with TryGetNumber(string, out double), true or false with TryGetFlag(string, out bool), a text with TryGetText(string, out string), and an array of three, four or two numbers with TryGetVec3(string, out Vec3), TryGetRotation(string, out Rotation) or TryGetVec2(string, out Vec2). Names are case sensitive. A name written by a step uses letters, digits, dash and underscore, 1 to 64 of them, the rule Define.Document(...).Field applies; any other name throws, and the load fails as Unsupported.
