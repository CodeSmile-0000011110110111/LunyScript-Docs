Class DemoPrompts

Namespace
CodeSmile.Luny.Demos.UI
Assembly
ApiSource.dll

The HUD's key prompts of the installed DemoSupport: one line per prompt, the control a player presses now and what it does, such as "Space Jump" for a keyboard player and "A Jump" for a gamepad player. A line follows the device the player uses and every accepted rebind, and hides while its player is absent or the action is missing.
