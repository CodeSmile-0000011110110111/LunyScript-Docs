The area names the product's own log records carry, so that a reader and a debugging window see the same set of words rather than one spelling per call site.

public static class LunyScriptLogAreas

Examples

LunyScriptLog.Info(LunyScriptLogAreas.Cloud, "signed in");

Remarks

An area is content, not format: LunyScriptLog owns the format and this owns the vocabulary. Code outside the product, such as a test or a project gate, passes its own area string rather than adding a constant here.

ReleaseGate and ProjectSettingsGate are read by Tools/run-tests.sh. That script greps the gate logs for the exact phrases "LunyScript release gate" and "LunyScript project settings gate", so changing either value silently changes what gate 4 and gate 5 report; AGENTS.md rule 60.
