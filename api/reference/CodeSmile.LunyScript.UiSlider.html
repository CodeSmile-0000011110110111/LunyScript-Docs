A handle to one named Slider, the UI Toolkit control a player drags to choose a number between the low and high values its UXML sets.

public readonly struct UiSlider : IUiElementHandle
Expand Details ...
Implements
IUiElementHandle

Examples

var volume = Panel.Slider("volume");
volume.BindValue(Volume);
When.UI(volume).ValueChanged(Volume.Set(volume.Value));

Remarks

The Slider keeps a single-precision value. A write converts the Number to that precision and the Slider clamps it to its range. Value reads it rounded to 7 significant digits, so a Number of up to 7 significant digits written to the Slider reads back exactly as written: 0.37 reads 0.37. A script's write does not run When.UI(slider).ValueChanged; a player's drag, key press or navigation does.
