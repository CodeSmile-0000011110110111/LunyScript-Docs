Finds the script an object runs, for ordinary C# code outside a script. The result is a LunyScriptReference<TScript> to one incarnation of that script.

Examples

var player = LunyScript.Find<PlayerScript>(behaviour);
if (player.IsRunning)
    healthLabel.text = $"{player.Read(player.Definition.Health):0}";

Remarks

A typed lookup returns an optional reference, and a script of another type is no match. After the script ended, a read through the reference throws, the way C# throws when it reads a destroyed Unity object or component; IsRunning answers whether a read will succeed. docs/proposals/typed-instance-view.md states the whole contract.

Code in another CodeSmile.* namespace writes the full name. Inside a namespace such as CodeSmile.MyGame, the name LunyScript is the namespace CodeSmile.LunyScript, so LunyScript.Find fails with CS0234 when using CodeSmile.LunyScript; is at the top of the file. Write CodeSmile.LunyScript.LunyScript.Find, or move the using directive inside the namespace block. Code in any other namespace, and in the global namespace, writes LunyScript.Find.

Find<TScript>(LunyScriptBehaviour)

Looks up the script target runs, when that script is a TScript.

public static LunyScriptReference<TScript> Find<TScript>(LunyScriptBehaviour target) where TScript : Script

Parameters

Type Name Description
LunyScriptBehaviour
target

The object's LunyScriptBehaviour. From a GameObject or a Collider, TryGetComponent(out LunyScriptBehaviour behaviour) reaches it.

Returns

LunyScriptReference<TScript>

A reference whose IsRunning is true when the object's script is running and is a TScript. When target is null or destroyed, before its Awake, after its script ended, and when its script is of another type, the reference matched nothing: its IsRunning is false and a read through it throws.

Type Parameters

TScript

The script type the caller expects. A script type derived from it matches too.

Examples

if (other.TryGetComponent(out LunyScriptBehaviour behaviour))
{
    var enemy = LunyScript.Find<EnemyScript>(behaviour);
    if (enemy.IsRunning) damage = enemy.Read(enemy.Definition.Damage);
}
