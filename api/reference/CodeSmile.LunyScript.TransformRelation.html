Which object a transform verb acts on, named relative to the object the script runs on.

public enum TransformRelation
Expand Details ...

Fields

Child = 3

One of that object's children, by index. Refused when the index is outside the child count.

None = 0

No object. As a reparent destination this is the scene root, which is what Transform.Unparent() asks for; as a verb's target it resolves to nothing and is refused.

Parent = 2

That object's parent. Refused when it has none.

Root = 4

The topmost object of that object's hierarchy, which is the object itself when it has no parent.

Self = 1

The object the script runs on.

Examples

host.ReadChildCount(TransformRelation.Self, 0);

Remarks

The hierarchy vocabulary is one step deep by design: Parent, Child and Root are reached from the object the script runs on and offer no further navigation of their own, so a chain cannot walk an arbitrary path. That is the "bounded hierarchy queries" of docs/positioning.md item C14 applied to this family. A named or bound object of any kind is not a relation and is not part of this version; it arrives with C14 itself.
