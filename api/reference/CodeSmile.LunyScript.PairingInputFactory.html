Struct PairingInputFactory

Namespace
CodeSmile.LunyScript

What Input.Pairing returns: the machine's pairing window. While it is open, a button press on a device no local player holds pairs that device with the lowest free local player number.

public readonly struct PairingInputFactory
Expand Details ...

Examples

On.Ready(Input.Pairing.Open());
On.FrameUpdate(If(Input.PlayerCount >= 2.0).Then(Input.Pairing.Close()));

Remarks

Pairing belongs to the machine, like the cursor: two scripts writing Open and Close in one frame end in the later write, and despawning the script that opened it does not close it. A player whose device is lost takes the next device pressed whether or not pairing is open. How many local players can pair is set where C# installs the backend, new InputSystemProvider(actions, 4); docs/proposals/local-player-pairing.md is the contract.
