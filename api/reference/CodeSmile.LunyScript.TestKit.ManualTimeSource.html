Remarks

This is a test double, not a second product surface, in the same way FakeHost is for IScriptHost. A running game uses UnityTimeSource, which reads Unity's own frame clock. Nothing here is a simulation of time: Advance(double) states how much real time the next tick took, and the clock applies its own scale to produce the game time that went with it.

Advance(double) is given real seconds. At the default scale of one the two pairs of reads are identical, which is what every test written before the scale existed relies on. At a scale of one half, advancing by one second adds one second to UnscaledElapsedSeconds and half a second to ElapsedSeconds; while paused it adds nothing to the scaled pair at all.
