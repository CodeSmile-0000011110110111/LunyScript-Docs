How a target's visual moves while players focus it: how far it rises, how much it grows, how fast it turns and how long it takes to blend in and out. An asset an Interaction.Target(...).Visual(child) script's Inspector assigns to its InteractionStyle input.

Examples

var style = ScriptableObject.CreateInstance<InteractionStyle>();
var lift = style.Lift; // 0.2 metres until the asset is edited

Remarks

Each spawn copies the asset's values, so a running object's copy can change without the asset changing: the Interaction Setup window does that in Play Mode, and its Apply to Style button is the one place that writes the asset. An object with no style assigned uses DefaultLift, DefaultScale, DefaultSpin and DefaultBlend. docs/proposals/interaction.md is the contract.
