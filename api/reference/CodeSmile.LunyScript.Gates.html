Namespace CodeSmile.LunyScript.Gates

Classes

StaticsGateControl

The control for StaticsGateProbe. Marked so that Unity does NOT reset it, which is what makes the gate meaningful: if both types came back at their initial values the test would also pass when a domain reload happened, and the gate would prove nothing.

StaticsGateProbe

Deliberately breaks the no-mutable-statics rule so that a test can prove Unity's automatic statics cleanup actually resets a mutable static between two Play Mode sessions.
