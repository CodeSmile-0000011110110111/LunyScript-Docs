Interface IScriptObjectSpawner

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The part of a host that can produce a new object from a prefab. A host that provides it declares RuntimeObjectSpawning by implementing this interface; a host that does not cannot run a script containing an Object.Spawn block, and the spawn of that script is refused with a message naming the missing service.

Examples

var spawner = (IScriptObjectSpawner)instance.Host;
var spawned = spawner.SpawnObject(prefab, null, SpawnPlacement.None);

Remarks

It is a third interface rather than one more member on IScriptObjectLifetime for the reason that one is a second interface beside IScriptHost: the scene-free editor host owned by EditorScriptSession has no scene to put an instance in, and a member it can only refuse would make every implementation carry one.

The prefab is typed UnityEngine.Object rather than GameObject, so this file names no banned Unity type and AGENTS.md rule 24's type ban still holds. What the core hands over is always what a declared prefab input resolved to, which the acquisition contract guarantees is a live GameObject.

Remarks

This allocates, and it is AGENTS.md rule 31's first boundary, spawn. The produced object runs whatever the prefab carries, so a prefab carrying a LunyScriptBehaviour spawns its own instance inside this call; that is why the runner applies an authored spawn after its dispatch rather than inside the block that asked for it.
