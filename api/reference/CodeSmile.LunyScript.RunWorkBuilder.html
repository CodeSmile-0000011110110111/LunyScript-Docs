What Run(body) returns. Qualifiers name a repetition count, a duration or a cadence; Start(string, int) starts one activation and Stop(string, int) interrupts it.

public readonly struct RunWorkBuilder
Expand Details ...

Examples

var pulse = Run(Hits.Add(1.0)).Over(3);
var burst = Run(Hits.Add(1.0)).For(5);
On.Ready(pulse.Start(), burst.Start());

Remarks

Declaration does not start work. Start() starts or restarts one activation; Stop() interrupts it. The runner advances a started activation once per frame. For counts activations and Over measures game time; Times() and Seconds() are their default units and may be left out.
