Where an authored Object.Spawn puts the object it produces, and in which frame those coordinates are read.

public readonly struct SpawnPlacement
Expand Details ...

Examples

var placement = SpawnPlacement.At(new Vec3(0.0, 1.0, 0.0), inWorldSpace: true);

Remarks

A placement carries values, not expressions. The position and rotation expressions are evaluated by SpawnObjectBlock where the block runs, so a placement built from a variable reads that variable at the line the author wrote and not at the moment the runner applies the spawn.

The default frame is the parent's. InWorldSpace is false unless the author wrote InWorldSpace(), and a spawn with no parent puts the object at the scene root, where the parent frame and the world frame are the same coordinates. The modifier is spelled the way the settled semantics-t02 answer of 2026-09-13 spells the transform family's, so a script carries one spelling for the frame and not two.

A component the author did not name is not written: a spawn that states a position and no rotation leaves the produced object turned the way the prefab is.
