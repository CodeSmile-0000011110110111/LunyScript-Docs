Remarks

All members or none. A save writes every member document into one new archive, flushes it and replaces the previous archive in one rename, so a load finds the members of one save together, and a failed save leaves the previous group as it was. A load reads every member and migrates each as its role's schema says; one member that cannot be read fails the whole load, and a single role the archive lacks fails it as Incomplete. A failed load never falls back to an older archive.

The acquisition, the order of requests and the owner's lifetime follow the rules of SaveSlot.
