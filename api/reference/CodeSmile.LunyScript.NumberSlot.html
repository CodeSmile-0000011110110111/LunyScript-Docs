Struct NumberSlot

CodeSmile.LunyScript

ApiSource.dll

Where one Number variable lives on every instance of a program. Allocated at build time and never at run time.

public readonly struct NumberSlot

Examples

var health = Var.Define<Number>("health", 100.0);   // health.Slot is a NumberSlot

Remarks

A slot handle is an index, not a reference: the same handle addresses a different value on every instance, which is what lets one immutable block tree serve every object running the script. See docs/execution-model.md.
