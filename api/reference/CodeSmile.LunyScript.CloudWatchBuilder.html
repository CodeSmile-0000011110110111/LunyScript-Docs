LunyScript API Reference

Struct CloudWatchBuilder

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What When.Cloud(key) returns: registers blocks against one key's Cloud Save outcomes. Each registration declares a hidden counter-shadow variable at build time and is polled once per frame after On.FrameUpdate, the same shape When.Var(x).Changed has.

public readonly struct CloudWatchBuilder

Examples

When.Cloud("progress").Loaded(progress, Cloud.Save("progress", progress + 1.0));
When.Cloud("progress").Saved(saved.Set(true));
When.Cloud("progress").Failed(saved.Set(false));

Methods

Failed(params Block[])

Registers blocks that run when an operation on this key fails, a save and a load alike. The gateway has already classified the reason and logged it once.

public void Failed(params Block[] blocks)

Loaded(Var<Number>, params Block[])

Registers blocks that run when a load of this key completes, after the loaded value has been written into into, so the blocks read the loaded value.

public void Loaded(Var<Number> into, params Block[] blocks)

Parameters

into Var<Number>

The Number variable the loaded value is written to.

blocks Block[]

The blocks, in order. May be empty when writing the variable is all the script wants.

Examples

When.Cloud("progress").Loaded(progress, progress.Add(1.0));

Exceptions

LunyScriptUsageException

into is not a Number variable.

LunyScriptUsageException

blocks contains null.
