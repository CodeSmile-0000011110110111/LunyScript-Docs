A block that answers true or false for one object. Passed to If(...) and combined with &, | and !.

Remarks

operator true and operator false return false, in every build. C# implements && and || with those operators. Returning false makes both sides of those spellings run, so they construct the same AND and OR nodes as & and |. Evaluation still short-circuits at run time. AGENTS.md rule 39.

A C# if or while around a condition block still throws, in release builds too: that path uses the implicit conversion to bool, which always raises LunyScriptUsageException. There is no #if DEBUG anywhere in this file. AGENTS.md rule 38. The release-gate player asserts that throw.
