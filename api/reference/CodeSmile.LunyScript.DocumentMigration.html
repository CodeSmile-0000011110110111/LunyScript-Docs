One consecutive step of a document's schema: converts a stored document of FromVersion into version FromVersion + 1. Written in C#, registered in Build() with Define.Document(...).Migration(step).

Examples

public sealed class CareerVersion1To2 : DocumentMigration
{
    public override Int32 FromVersion => 1;

    public override MigrationResult Migrate(DocumentFields fields)
    {
        fields.Rename("best", "BestWave");
        fields.DefaultFlag("Unlocked", false);
        return MigrationResult.Converted;
    }
}

Remarks

A load of a document stored at an older version runs every step from that version to the declared one, in order, on a copy of the stored fields. Migrate(DocumentFields) sees only that copy, through DocumentFields: no script variable changes until the whole chain has run and the result holds every declared field in a form it can hold. A step that returns Rejected(string) or throws fails the load as OperationFailure.Unsupported, and nothing is written, including the stored file. Migration never writes the upgraded document back; the next save does.

A step is shared by every object running the script and may run for several loads, so it keeps no state of its own between calls.

Examples

public override MigrationResult Migrate(DocumentFields fields)
{
    if (fields.TryGetNumber("seconds", out var seconds) == false)
        return MigrationResult.Rejected("the save has no play time");
    fields.SetNumber("minutes", seconds / 60.0);
    fields.Remove("seconds");
    return MigrationResult.Converted;
}
