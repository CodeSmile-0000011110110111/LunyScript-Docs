Class SaveField

Namespace
CodeSmile.Luny.Save
Assembly
ApiSource.dll

One named field a SaveSchema or SaveRecordSchema declares, with the SaveKind of its value. Declare each field once, in a static readonly field, and pass that object both to the schema and to every Set<T>(SaveField<T>, T) and TryGet<T>(SaveField<T>, out T), so the compiler checks the value's type where it is written.

Examples

static readonly SaveField<Double> BestScore = SaveField.Number("BestScore");
static readonly SaveField<String> PilotName = SaveField.Text("PilotName", 64);
static readonly SaveSchema Progress = new SaveSchema("demo.progress", 1, BestScore, PilotName);

document.Set(BestScore, 1200.0);
if (document.TryGet(PilotName, out var pilot)) m_PilotName = pilot;

Remarks

A field name is 1 to 64 letters, digits, dashes and underscores, case sensitive, and is the key stored in the file: keep it when the C# that fills it is renamed, and register a SaveMigration when it does change. A field object belongs to the schemas it was given to; a document refuses a field of the same name declared by another object, so a field of another schema is diagnosed where it is used.
