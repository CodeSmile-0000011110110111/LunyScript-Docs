Struct LeaderboardEntry

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

One account's entry of a leaderboard a script reads, declared with Define.LeaderboardEntry(name): Leaderboard.LoadEntry(board).Into(entry) fills it with this account's entry, or another player's with .ForPlayer(id) (C07 B). Its values are internal storage of the object, so a read allocates nothing and the debugger shows it.

public readonly struct LeaderboardEntry
Expand Details ...

Examples

Mine = Define.LeaderboardEntry(nameof(Mine));
When.Leaderboard(Submitting).Succeeded(Leaderboard.LoadEntry(Weekly).Into(Mine).As(ReadingMine));
On.Update(Place.Set(Mine.Rank));

Remarks

The entry keeps what the last successful read wrote. An account with no entry fails the read as NotFound and writes nothing.
