Interface ICloudAccountBackend

Namespace
CodeSmile.Luny.Cloud
Assembly
ApiSource.dll

The account service a backend provides: signing in, signing out and deleting the account. The client calls it on the main thread, one call at a time, and never while a data or leaderboard call is in flight for a sign-out or a delete.

public interface ICloudAccountBackend
Expand Details ...

Examples

var services = new CloudServices(account: myAccountBackend, data: fileBackend, leaderboards: fileBackend);

Remarks

Implemented by FileCloudBackend and, with the Cloud Save package installed, by UgsCloudBackend. Linking a login to an account is not part of this version (C21, deferred).
