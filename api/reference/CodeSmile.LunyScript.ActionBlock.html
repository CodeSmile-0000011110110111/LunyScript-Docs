Examples

internal sealed class CountDownBlock : ActionBlock
{
    private readonly NumberSlot m_Remaining;
    public override void Begin(ScriptInstance instance) => instance.SetNumber(m_Remaining, 3.0);
    public override ActionResult Advance(ScriptInstance instance)
    {
        instance.SetNumber(m_Remaining, instance.GetNumber(m_Remaining) - 1.0);
        return instance.GetNumber(m_Remaining) > 0.0 ? ActionResult.Running : ActionResult.Worked;
    }
}

Remarks

An ordinary Block does its work inside one Execute(ScriptInstance) call. An action is advanced once per frame by whatever owns it - a routine activation, or a concurrent group - until it reports Worked or Failed.

The per-object state of an action lives in slots, not in fields. One action object is shared by every object running the script, exactly as every other block is, so AGENTS.md rule 22 applies unchanged: declare the slots the action needs during Build() and read and write them through the ScriptInstance each call is given.

The owner calls Begin(ScriptInstance) once when the activation reaches this action, then Advance(ScriptInstance) once per frame while it reports Running, and Cancel(ScriptInstance) instead of any further advance when the activation is interrupted.
