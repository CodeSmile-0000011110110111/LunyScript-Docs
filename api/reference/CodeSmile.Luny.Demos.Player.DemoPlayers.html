Class DemoPlayers

Namespace
CodeSmile.Luny.Demos.Player
Assembly
ApiSource.dll

LunyPlayer's part of the installed DemoSupport's session: a return to the main menu ends play on every active seat before the local group ends, and stops at a seat whose end of play LunyPlayer refused; a new group selects the remembered User on seat one through CodeSmile.Luny.Player.LocalPlayers.Select(CodeSmile.Luny.Player.PlayerSeat, CodeSmile.Luny.Player.UserId), so the game admits control once Selection completed. Seats two to four start as guests unless the game selects Users for them.
