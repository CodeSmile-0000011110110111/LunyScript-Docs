Native diagnostics for one explicitly supplied local runner. Reads execute no authored logic.

public sealed class RunnerDiagnostics
Expand Details ...
Inheritance
object

Examples

var current = runner.Diagnostics.ReadCurrent(runner.Diagnostics.GetIdentity(instance));

Remarks

Caller-owned snapshots allocate only on explicit observation. Current-only Shallow coverage is the default. BeginTrace explicitly collects ordered action records; current snapshots do not contain historical values or a condition preview. Service work before a runtime provider is ready retains the existing gateway queue contract.
