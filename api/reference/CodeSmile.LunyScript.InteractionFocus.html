Struct InteractionFocus

Namespace
CodeSmile.LunyScript

What Interaction.Focus(activate) returns: this object as a focuser for the local player it is bound to. Each clause is optional and written once.

public readonly struct InteractionFocus
Expand Details ...

Examples

Interaction.Focus(Input.Button("Interact")).Pointer(Input.Vector2("Point")).InView(View).Within(4).Prompt(Prompt);

Remarks

The focuser is declared when Interaction.Focus is called, so this handle is not a block and is not placed in an event list. Without Pointer it always looks through the centre of its view; with it, it uses the pointer while its player holds the pointer device, and there is one pointer. docs/proposals/interaction.md is the contract.
