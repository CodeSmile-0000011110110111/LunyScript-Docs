One value crossing the network, typed rather than boxed.

public readonly struct NetworkValue
Expand Details ...

Remarks

A tagged struct rather than object, because AGENTS.md rule 26 forbids boxing a payload: boxing allocates on every event, and it throws away the compile-time check that a number is not written into a flag. Text is null for the two value kinds and is the one field that can allocate, which is why no cadence sends text every tick.
