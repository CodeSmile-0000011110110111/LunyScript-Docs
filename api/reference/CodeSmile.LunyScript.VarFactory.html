The Var surface inside Build(): declares a script's variables and hands back the typed handles the blocks are built from.

public readonly struct VarFactory
Expand Details ...

Examples

protected override void Build()
{
    var health = Var.Define<Number>("health", 100.0);
    var playerName = Var.DefineText("playerName");
}

Remarks

This is a build-time surface. Every call runs once per script type, before any object exists, and constructs part of the shared Script program, which is why it may allocate. The blocks returned during that build execute later, per event and per Script instance. AGENTS.md rule 43; rule 25 forbids reading anything about an object here.

DefineSyncedText(string, SyncCadence, TextCapacity)

Declares a text variable that every peer sees.

public Text DefineSyncedText(string name, SyncCadence cadence, TextCapacity capacity = TextCapacity.Bytes64)

Parameters

Type Name Description
string
name

The variable's name, which should come from nameof.
SyncCadence
cadence

How often it is sent. Required, per AGENTS.md rule 46: a synchronised variable whose cost nobody chose cannot be written. Text carries a managed string on the wire, so EveryTick is refused for it and Once is the usual choice.
TextCapacity
capacity

How many bytes it holds. Defaults to Bytes64, which is one cache line.

Returns

Text

The handle.

Examples

PlayerName = Var.DefineSyncedText(nameof(PlayerName), SyncCadence.Once);
Motto = Var.DefineSyncedText(nameof(Motto), SyncCadence.OnChange, TextCapacity.Bytes512);

Remarks

The cadence comes before the capacity, which is the opposite of the order the proposal wrote. C# allows no required parameter after an optional one, so a defaulted capacity and a required cadence can only be written in this order. It is also the order DefineSynced<T>(string, SyncCadence, T) already uses: the name, then the cadence, then the one thing that has a sensible default.

Exceptions

LunyScriptUsageException

The cadence is unset, the cadence is EveryTick, or the name is taken.

DefineText(string, TextCapacity)

Declares a text variable and how many bytes it holds.

public Text DefineText(string name, TextCapacity capacity = TextCapacity.Bytes64)

Parameters

Type Name Description
string
name

The name, used in diagnostics. Unique within the script.
TextCapacity
capacity

How many bytes the variable holds. Defaults to Bytes64, which is 64 bytes of storage and 61 usable bytes, because 64 bytes is a common cache-line size. AGENTS.md rule 15: the capacity is still declared per variable, so pass a smaller or larger one when the content is known to be shorter or longer than 61 bytes.

Returns

Text

The typed handle.

Examples

var playerName = Var.DefineText("playerName");                       // 64 bytes, 61 usable
var chatLine = Var.DefineText("chatLine", TextCapacity.Bytes512);    // 512 bytes, 509 usable

Exceptions

LunyScriptUsageException

The name is already taken.
