A handle to one AudioMixerGroup input of a script: a group of an audio mixer the object's Inspector assigns. Returned by Bind.AudioMixerGroup() at build time, or assigned before Build() by [Asset] on the property.

public readonly struct AudioMixerGroup

Remarks

This is LunyScript's type, with Unity's name. A script imports only CodeSmile.LunyScript, so AudioMixerGroup there is this handle and the script compiles without an engine reference. The Inspector field accepts a UnityEngine.Audio.AudioMixerGroup, and C# on the object reads the assigned asset with LunyScriptBehaviour.GetAsset. A file that imports both namespaces writes UnityEngine.Audio.AudioMixerGroup for Unity's type.

The declared name is the input's durable identity. A value stored on a host is matched to the input by that name. A generated property gives the input its member's name, and .As(name) names it explicitly. Renaming it orphans what a scene stored for the old name.

No asset placeholder exists for a mixer group, so an object that assigns none and names no source refuses to spawn.

A handle is valid only inside the Build that declared it, for the reason Var<T> states: it carries a slot index and nothing that identifies its program.
