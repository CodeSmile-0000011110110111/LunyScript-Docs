The account part of a CloudClient: explicit sign-in, sign-out and account delete, and the account state. Each call returns a request that waits until every request before it ended, and that every request made after it waits for.

Methods

Delete()

Deletes the signed-in Authentication account once the requests before it ended, then signs out. Its documents, files, leaderboard entries and protected items stay on the service, unreachable by the deleted account; delete documents and files first with Delete(in CloudAddress) and Delete(string). The account's queued scores end as NotSignedIn.

public CloudRequest Delete()

Returns

CloudRequest

The request.

Examples

var deleting = cloud.Account.Delete();

SignIn()

Restores the cached session, or creates an anonymous account when there is none. Succeeds at once while signed in, joins a sign-in in flight, and after a failed sign-in tries again.

public CloudRequest SignIn()

Returns

CloudRequest

The request.

Examples

SignOut()

Signs out once the requests before it ended, keeping the cached session, so the next sign-in is the same account. Requests made afterwards fail as NotSignedIn until the next SignIn(); queued scores keep waiting for their account.

public CloudRequest SignOut()

Returns

CloudRequest

The request; it succeeds when the client signed out.
