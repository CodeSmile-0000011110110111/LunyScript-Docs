What a navigation backend knows about the route an actor follows. Script code reads it through Navigation.Route(operation).

public enum NavigationRouteState
Expand Details ...

Fields

Complete = 2

The route reaches the destination.

Invalid = 4

No route reaches anything.

None = 0

No route: nothing was asked, or the route was cleared.

Partial = 3

The route ends at the reachable point closest to the destination, which is not the destination.

Pending = 1

The route is being calculated.

Examples

if (reading.Route == NavigationRouteState.Pending) return;

Remarks

A partial route ends at the reachable point closest to the destination. An invalid route reaches nothing. The settled contract-targeting-navigation answer names these states; docs/proposals/navigation.md is the family.
