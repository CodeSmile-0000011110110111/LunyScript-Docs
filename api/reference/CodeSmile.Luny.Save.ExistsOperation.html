Remarks

A successful check carries Exists true or false: false on a first run, true for any file at the path, readable or not. A check the file system refused, or one whose path leads through a linked folder, fails as Unavailable, so a Continue button can tell a new game from storage it cannot read.

Properties

Exists

True when the check succeeded and found a file at the path; false otherwise, so read Succeeded to tell "not there" from "not known".
