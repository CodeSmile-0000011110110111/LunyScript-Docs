Enum InputActionResolution

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Why an input action declaration did or did not resolve to a configured action.

public enum InputActionResolution

Fields

NoProvider = 1

No input backend is installed, so nothing can be resolved.

NoSuchPlayer = 4

The local player the declaration names is not present.

NotFound = 2

The configured action asset has no action of that name for that local player.

Resolved = 0

The backend has an action of that name and of the declared kind.

WrongValueKind = 3

An action of that name exists but produces a different kind of value.

Examples

if (resolution != InputActionResolution.Resolved) Report(...);

Remarks

A declaration that does not resolve reads its kind's resting value - not pressed, zero, the zero vector - and is reported once, naming the script and the action. The object still spawns: an action name a project has not configured yet is a wiring mistake the author fixes in the action asset, and refusing every object of that script would hide every other thing the script does.
