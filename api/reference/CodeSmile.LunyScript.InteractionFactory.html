Struct InteractionFactory

Namespace
CodeSmile.LunyScript

The Interaction surface inside Build(): declares this object a target players can focus and use, or a focuser that looks for targets for the local player its object is bound to, and reads and changes both.

public readonly struct InteractionFactory
Expand Details ...

Examples

Interaction.Target("Pick up").Visual(Visual).Effect(Glow);
On.Interacted(Interaction.Disable(), Object.Destroy());

Remarks

Runtime-only. The runner arbitrates once per frame, before any script's On.Update: which target each focuser sees, which targets gained their first or lost their last focuser, and which activations are delivered in which order. docs/proposals/interaction.md is the contract.
