Fields

Error = 2

Something failed.

Info = 0

Something happened that a user may want to see and that is not a problem.

Warning = 1

Something a user probably wants to change, which did not stop the operation.

Remarks

The three values map onto UnityEngine.Debug.Log, LogWarning and LogError, which is the only place the mapping is written; see LunyScriptLog.
