Struct AnimatorTrigger

CodeSmile.LunyScript

A handle to one Trigger parameter of the Animator on the object a script runs on. Returned by Animator.Trigger(name) at build time.

public readonly struct AnimatorTrigger
Expand Details ...

Examples

var jump = Animator.Trigger("Jump");
When.Input(jumpButton).Performed(jump.Set());
On.Disabled(jump.Reset());

Remarks

A trigger is an occurrence, not a stored Flag. Set() is Unity SetTrigger, which the Animator consumes at its next evaluation, and Reset() is Unity ResetTrigger. There is no Value. A Set() placed in On.FrameUpdate sets the trigger again on every frame. To send a trigger across the network, send a message and set the trigger in On.Message on every peer.
