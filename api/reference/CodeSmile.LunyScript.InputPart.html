A handle to one part of an action's composite binding, such as the Up key of a W A S D Move. Returned by handle.Part(name) at build time.

public readonly struct InputPart : IInputActionHandle
Expand Details ...
Implements
IInputActionHandle

Examples

var up = Input.ForPlayer(0).Vector2("Move").Part("Up");
When.UI(UpRow).Activated(up.Rebind().As(RebindUp));
On.Update(UpKey.Set(up.BoundControl));

Remarks

A part is not read: its action's handle reads the composite's value. What a part offers is its own binding, for a settings row: Rebind(string, int) captures a control for this part only, BoundControl shows the path it uses, and ResetBinding(string, int) returns it to the action asset's path.
