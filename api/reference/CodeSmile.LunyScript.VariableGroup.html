A declared variable group: object-local variables that one Reset(group) block writes back to the values their Define lines declared.

public readonly struct VariableGroup
Expand Details ...

Examples

RunState = Define.Group();
Hits = Define.Number(nameof(Hits)).In(RunState);
On.Event(RestartPressed).Do(Reset(RunState));

Remarks

RunState = Define.Group(); declares one, and .In(RunState) on a Define line puts that variable in it. Reset(RunState) resets the variables of the object the block runs on; every other object running the script keeps its own. A group belongs to the script that declares it and has no generated descriptor. docs/proposals/variable-groups.md is the contract.
