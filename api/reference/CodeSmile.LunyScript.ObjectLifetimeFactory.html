The Object surface inside Build(): builds the blocks that create, spawn, activate, deactivate and end objects this script owns, and the blocks that hide, show and tint an object and write its material Number properties.

public readonly struct ObjectLifetimeFactory
Expand Details ...

Examples

Shield = Define.Object();
On.Ready(Object.Create(Shield));
On.Disabled(Object.Deactivate(Shield));
On.Update(If(Health <= 0.0).Then(Object.Destroy()));

Remarks

The type is not called ObjectFactory, because UnityEditor.ObjectFactory already exists and this project's editor assembly uses it; two types of that name in scope make the editor assembly fail to compile. The script-facing surface is still written Object, which is what the settled contract-object-lifecycle answer names, and the type name is never written in a script.

Self by omission. Omitting the target acts on the object the script runs on. Passing a declared OwnedObject acts on the object this same script produced into it.

Two verbs make an object and two end one, in pairs. Create makes a fresh object - an empty one into a declared owned object, or a copy of a prefab - and Destroy(OwnedObject, string, int) ends it for good. Spawn(Pool, string, int) checks a reusable object out of a declared pool, and Despawn(OwnedObject, string, int) returns it. Destroy(OwnedObject, string, int) also ends a pooled object, which takes it out of its pool. Every produced object is owned by the instance that produced it unless its chain wrote SurvivesCaller(), and all of them fill the same declared owned objects, so one owned object is produced by one call and addressed by the rest of this surface. DespawnAll(Pool, string, int) returns every use of one pool that this instance owns, and IsEnding reads whether this object's end has been asked for and has not happened yet.

The visual members - Hide, Show, IsVisible, SetColor, ResetColor, MaterialNumber and For - change how the object is drawn and leave it running. They write through the renderer's property block, so no material asset changes. docs/proposals/visual-presentation.md is their contract.

The blocks reach the object through IScriptObjectLifetime, never through a UnityEngine.GameObject; AGENTS.md rule 24. A host that does not implement that interface cannot run a script containing these blocks, and the spawn is refused rather than the block failing later.

IsEnding

A condition: whether the end of the object this script runs on has been asked for and has not happened yet.

public ConditionBlock IsEnding { get; }

Property Value

ConditionBlock

A condition block.

Examples

On.Disabled(If(Object.IsEnding).Then(Ended.Inc()));

Remarks

A despawn or destroy that a block asks for is applied after the current dispatch, so blocks can still run on the object between the request and the end: later blocks of the same list, the object's own On.Update after its owner's Object.DespawnAll ran earlier in the frame, and a request another script sends it in the same event. True from the request until the object's scripts have ended: after this script's own Object.Despawn() or Object.Destroy(), after an owner's Object.Despawn(owned), Object.Destroy(owned) or Object.DespawnAll(pool) that returns or ends this object, and in the On.Disabled and On.Despawned the end delivers. False in the On.Disabled that Object.Deactivate() delivers, and false again when a later Object.Activate() or Object.Deactivate() in the same dispatch replaces this script's own despawn or destroy. A pool's Lifetime returns a use at the start of a frame tick, so it is true only in that use's On.Disabled and On.Despawned. It reads the object this script runs on; a script on a child of an ending object reads true from its own On.Disabled for that end.

Remarks

The copy is made after the current dispatch, not where the block is written. A prefab can carry a LunyScriptBehaviour, and producing such an object runs its Awake inside the call, which re-enters the runner; the runner refuses that during dispatch. So a copy held with Into(name) is in its slot from the next event onward, not from the next line. docs/execution-model.md states the order.

The copy is owned by the instance that created it, with or without Into, and is destroyed when that instance ends. SurvivesCaller() hands it to its scene instead. Object.Destroy(owned) ends a held copy; a copy is never despawned, because no pool holds it. Spawn(Pool, string, int) is the call that reuses objects.

The placement frame is the parent's, and InWorldSpace() selects world coordinates, which is the spelling the transform family uses; the settled semantics-t02 answer of 2026-09-13. With no parent the two frames are the same coordinates.

Exceptions

LunyScriptUsageException

prefab is a handle this script's Build() never declared.

Remarks

The uses are the ones this object's own end would return for that pool: spawned by this object's script and not handed to the scene with SurvivesCaller(). A use it returns is available only to a spawn recorded after its return finished, the rule every return follows: in an event the runner dispatches, the return finishes after the event's blocks, so a spawn later in the same list takes another entry, grows the pool or is refused at the hard cap. A spawn recorded in the same dispatch is applied after this block and stays out. With no use out the block does nothing.

Spawn(Pool, string, int)

Starts a checkout of one reusable object from a declared pool, which the returned builder can place, parent, hold, hand to the scene and bind to an attempt.

Examples

On.Ready(Object.Spawn(Guards));
On.Ready(Object.Spawn(Guards).At(Portal).InRadius(5.0).Into(Escort).As(TakeGuard));

Remarks

The checkout is applied after the current dispatch, for the reason Create(Prefab, string, int) states. The pool reuses an idle entry when it has one and grows below its hard cap when it has none; at the cap the spawn is refused, and the chain's As(handle) observes that.

The first checkout of an entry starts its scripts and delivers On.Created and then On.Spawned. Every later checkout delivers On.Spawned alone, with every variable back at its declared start. Native state the previous use changed is the script's to reset in On.Spawned.

The use is owned by the instance that spawned it, with or without Into, and goes back to its pool when that instance ends. Object.Despawn returns it earlier; Object.Destroy removes it from its pool for good.

Exceptions

LunyScriptUsageException

pool was never declared, or another script's Build() declared it.
