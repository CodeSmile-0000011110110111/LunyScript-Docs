Struct ObjectLifetimeFactory

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The Object surface inside Build(): builds the blocks that create, activate, deactivate and end objects this script owns.

public readonly struct ObjectLifetimeFactory

Examples

On.Ready(Object.Create("Shield"));
On.Disabled(Object.Deactivate("Shield"));
On.FrameUpdate(If(Health <= 0.0).Then(Object.Despawn()));

Remarks

The type is not called ObjectFactory, because UnityEditor.ObjectFactory already exists and this project's editor assembly uses it; two types of that name in scope make the editor assembly fail to compile. The script-facing surface is still written Object, which is what the settled contract-object-lifecycle answer names, and the type name is never written in a script.

Self by omission. Omitting the name acts on the object the script runs on. Passing a name acts on an object Create(string, string, int) created under that name, in this same script.

Create(string, string, int) and Spawn(Prefab, string, int) are the two calls that produce an object, and they are not the same call. Create(string, string, int) takes no asset and produces a bare, empty object under a name. Spawn(Prefab, string, int) produces one from a declared prefab input, and its chain places it, parents it and optionally holds it under a name. Both fill the same owned-object slot, so one name is produced by one of the two and addressed by the rest of this surface.

The blocks reach the object through IScriptObjectLifetime, never through a UnityEngine.GameObject; AGENTS.md rule 24. A host that does not implement that interface cannot run a script containing these blocks, and the spawn is refused rather than the block failing later.

Builds a block that activates an object: the one this script runs on, or one this script created.

Parameters

The name its Create(string, string, int) used, or null for the object this script runs on.

callerFilePath string

Supplied by the compiler. Do not pass one: it is what records the line of the script this block was written on.

callerLineNumber int

Supplied by the compiler.

Returns

Block

A block to place in an event list.

Examples

On.Enabled(Object.Activate("Shield"));
On.Disabled(Object.Activate());

Remarks

Omitting the name acts on the object the script runs on. That form records a LifetimeRequest, and the runner applies it after the current dispatch, which is what delivers On.Enabled between event invocations rather than inside one. Activating an already-active object delivers nothing.

Passing a name acts on the object Create(string, string, int) created under it, and takes effect where it is written, because an owned object runs no LunyScript and raises no observation. A name for which the slot is empty is left alone.

Exceptions

LunyScriptUsageException

name is whitespace. A name no Create(string, string, int) in this script uses is refused when Build() finishes.

Remarks

Owned means the API owns its lifetime: the object is destroyed when the instance that created it is despawned, by every path that despawns one. The name is both what the object is called in the scene and how the other calls on this surface address it; a scene object's name is one of the three kinds of literal AGENTS.md exempts from the nameof rule, because no C# member carries it.

Exceptions

LunyScriptUsageException

Despawn(string, string, int)

Builds a block that ends an object: the one this script runs on, or one this script created.

public Block Despawn(string name = null, string callerFilePath = null, int callerLineNumber = 0)

Parameters

name string

The name its Create(string, string, int) used, or null for the object this script runs on.

callerFilePath string

Supplied by the compiler.

callerLineNumber int

Supplied by the compiler.

Returns

Block

A block to place in an event list.

Examples

On.LateUpdate(If(Fuse <= 0.0).Then(Object.Despawn()));
On.Despawned(Object.Despawn("Shield"));

Remarks

Omitting the name ends the object the script runs on. That form records a LifetimeRequest, and the runner applies it after the current dispatch: it despawns the instance, which delivers On.Disabled and then On.Despawned while the object still exists, and destroys the object afterwards. Despawning an instance that is already despawned delivers nothing.

Passing a name destroys that owned object and empties its slot, where it is written. A slot that is already empty is left alone: the owner's own despawn empties every slot, so despawning an owned object twice is ordinary rather than a failure.

Exceptions

LunyScriptUsageException

name is whitespace.

Spawn(Prefab, string, int)

Starts a spawn: builds an object from a declared prefab input, which the returned builder can place, parent and hold.

public SpawnBuilder Spawn(Prefab prefab, string callerFilePath = null, int callerLineNumber = 0)

Parameters

prefab Prefab

The declared prefab input to produce an object from. Declared with [Asset] public Prefab X { get; private set; } or with Bind.Prefab.

callerFilePath string

Supplied by the compiler. Do not pass one: it is what records the line of the script this block was written on.

callerLineNumber int

Supplied by the compiler.

Returns

SpawnBuilder

A builder that takes a placement, a parent and a name, and converts to a block.

Examples

On.Ready(Object.Spawn(Sentry));
On.Ready(Object.Spawn(Sentry).At(new Vec3(0.0, 1.0, 0.0)).ChildOf().Into("Guard"));

Remarks

The spawn takes effect after the current dispatch, not where it is written. A prefab can carry a LunyScriptBehaviour, and producing such an object runs its Awake inside the call, which re-enters the runner; the runner refuses that during dispatch. So an object held with Into(name) is in its slot from the next event onward, not from the next line. SpawnObjectBlock states the mechanism and docs/execution-model.md states the order.

A spawn with no Into is not held by anything. It is produced, placed, and then the script has no further hold on it: it is not destroyed when this instance despawns and this script cannot address it again. A spawn with Into(name) is owned, exactly as an Create(string, string, int) object is, and Object.Despawn(name) ends it.

The placement frame is the parent's, and InWorldSpace() selects world coordinates, which is the spelling the transform family uses; the settled semantics-t02 answer of 2026-09-13. With no parent the two frames are the same coordinates.

Exceptions

LunyScriptUsageException

prefab is a handle this script's Build() never declared.
