Class CloudClient

Namespace
CodeSmile.Luny.Cloud

One game's client of the cloud services: the account, player and game data, player files and leaderboards, reached through Account, Data, Files and Leaderboards. Every call returns a CloudRequest at once; Tick(), called once per frame on the main thread, sends each request in its turn, polls the backends, and ends each request with a classified outcome. No caller ever sees a task or an exception for a service outcome.

Examples

cloud.Tick();   // every frame

Remarks

Order. Requests for one address run one at a time in the order they were made, whatever the one before ended with; requests for different addresses do not wait for each other. A failed request is never sent again. A sign-out and an account delete wait until no request is in flight, and requests made after them wait until they ended, so work admitted under one account is never sent under another.

Sign-in. The first request made while signed out starts a sign-in, unless the player signed out or deleted the account since; then requests fail as NotSignedIn until SignIn(). A failed sign-in fails every waiting request with its reason, and every later one at once, until a sign-in succeeds.

Timing belongs to the backends. The client sets no deadline; "we do not implement timeout ourselves, this is all handled by unity services package" (the captain, 2026-09-26). Before services are named, requests wait.

A backend that throws cannot leave Tick(). Every call into a backend, a call it returned, an ICloudText, an ICloudFileSource or an observer is guarded; a throw ends that request as Unknown, logged once with the exception text.

Allocation. Making a request allocates it; a tick that only polls allocates nothing, and a tick with nothing to do returns on its first line.

Tick()

Sends every request whose turn came, polls every one in flight, ends each one that has an outcome and tells its observer, then advances the score queue. Call it once per frame on the main thread. With nothing waiting or in flight it returns on its first line and allocates nothing.

Remarks

The only backend code this calls is Describe, for the log line, and it is guarded.

Exceptions

LunyCloudException

services is null, or services were already named, other than supplied ones before a sign-in started. A client talks to one set of backends for its lifetime.
