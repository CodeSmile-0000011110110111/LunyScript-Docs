The object in the scene a script runs on, as the Unity object an adapter acts on. A host that has one implements this interface.

public interface IScriptSceneObject

Examples

var actor = host is IScriptSceneObject scene ? scene.SceneObject : null;

Remarks

It is a separate interface rather than another member on IScriptHost for the reason IScriptTrackingTarget is one: the scene-free editor host has no scene object, and a member on the main interface would make every host claim it has one. The navigation family reads it for a Navigation.MoveTo with no .For(actor), and hands the object to the installed INavigationProvider, which knows what it carries.

The type is UnityEngine.Object. The core may not name Unity's object model outside GameObjectHost; AGENTS.md rule 24. GameObjectHost answers with its GameObject.
