Struct MotionFlockBuilder

Namespace
CodeSmile.LunyScript

A Motion.FlockChildren() with its goal. It converts to a block, and takes each of AtSpeed(NumberValueBlock, string, int), Within(NumberValueBlock, string, int) and Separation(NumberValueBlock, string, int) at most once, in any order.

public readonly struct MotionFlockBuilder
Expand Details ...

Examples

On.LateUpdate(Motion.FlockChildren().Towards(Goal));
On.LateUpdate(Motion.FlockChildren().Towards(Goal).Within(6).Separation(0.8).AtSpeed(5));

Remarks

Without AtSpeed the speed is 2 world units per second, without Separation the preferred spacing is 1 world unit, and without Within the goal attracts from any distance. Each number is evaluated every time the block runs; a literal that is out of range is refused when the script type is built. A second AtSpeed, Within or Separation on one chain is refused when the script type is built.

Remarks

Moving, turning or scaling the root carries the flock and adds to this. At 0 the members stay where they are and the flock keeps writing them there.

Exceptions

unitsPerSecond is null or a literal that is negative or not finite, the chain already has a speed, or this builder is a default that no verb produced.

Examples

Remarks

Members closer than this push apart. The spacing is soft: attraction can press members a little closer, and nothing stops a member passing through another object.

Exceptions

LunyScriptUsageException

spacing is null or a literal that is not above zero or not finite, the chain already has a spacing, or this builder is a default that no verb produced.
