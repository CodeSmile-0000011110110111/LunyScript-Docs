Struct SaveCompressionPolicy

Whether a save states how to store its document. A default value states nothing. Uncompressed and Compressed state the two representations this version writes.

public readonly struct SaveCompressionPolicy
Expand Details ...

Examples

m_Slot.Save(document, SaveCompressionPolicy.Uncompressed);

Remarks

A save that states nothing writes plain JSON when the path is empty or already holds plain JSON. When the path holds a compressed document, that save fails as Unstated and leaves the file as it was. Stating Uncompressed or Compressed replaces either representation.
