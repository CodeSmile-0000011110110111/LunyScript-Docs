Class SaveGroup

Namespace
CodeSmile.Luny.Save
Assembly
ApiSource.dll

The documents of one group of a SaveGroupSchema: one document per single role, at most one per optional role, and any number per keyed role, each under its key. Save(SaveGroup) stores them as one archive; a successful GroupLoadOperation returns one.

public sealed class SaveGroup

Examples

var group = new SaveGroup(Slot);
group.Set(World, worldDocument);
foreach (var player in m_Players)
    group.Set(Players, player.Key, player.Document());
var saving = m_Slot.Save(group);

Remarks

A save stores exactly the members the group holds: build the group from the complete current state, every player and world included, because a keyed member a previous save stored and this group lacks is removed by the save. Each document is of its role's schema; a save copies every document's values when it is accepted.
