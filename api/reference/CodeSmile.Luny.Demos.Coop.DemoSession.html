The installed DemoSupport's session integration over a LunyCoop host: the main menu's Multiplayer starts a new local group and opens the roster, and Exit returns to the main menu through one transaction. The transaction runs the game's save, the integrations' steps, such as LunyNet's Leave and LunyPlayer's end of play, then ends the group by disabling the co-op host, which ends the session with every participant's departure, and then opens the game's main menu.

Remarks

A failed step keeps the transaction where it stopped: the menu shows why, and Exit again retries that step without repeating the ones that succeeded. A failed save may be abandoned only where the game permits it, after a confirmation that names what is lost. While a return is unresolved, Multiplayer stays disabled.

A new group is a new session, so every participant's id, view and HUD lines are fresh; persistent camera, player and preferences hosts continue. Back from a roster that began at the main menu, before a game started, ends that group the same way without a confirmation. The game binds Play and calls EnsureGroup() from it.
