LunyScript API Reference

Namespace CodeSmile.LunyScript.TestKit

Classes

AllocationMeasure

Measures whether a piece of work allocates managed memory, and how much. Ships with the product so that a user can hold their own blocks to the rule the shipped blocks are held to.

FakeHost

A test double for IScriptHost: it answers the interface without a scene, a GameObject or a frame.

ManualTimeSource

A clock a test advances by hand, so that a rate-capped SyncCadence, a scaled read or a pause can be tested against stated amounts of time rather than against however long a frame happened to take.

NetworkProviderConformance

The part of the INetworkProvider contract every implementation must meet before a session starts, written once so that two implementations cannot answer it differently without a test saying so.

PlayerTestHeartbeat

One on-disk heartbeat a supervising agent can read to tell a slow test run from a dead one, without opening the player window.

RuntimeReport

Names the runtime a test is executing on, so that a measurement recorded in docs/allocation-baseline.md can never be attributed to the wrong backend.

TestGroups

Named test groups a run can exclude by name through Tools/run-tests.sh.

Structs

AllocationSample

What one allocation measurement observed, and with which instrument. Carries the instrument because the two instruments this project has are not both available on every runtime, and a figure recorded without naming its instrument cannot be compared with another run's. Where an allocation was observed, Instrument names the instruments that observed it rather than every instrument that was usable.

PlayerTestHeartbeatRecord

One heartbeat sample: when it was written, which test is running, and how far the run has got.
