A declared routine: the name of one sequential routine, which Routine(handle).Run(steps) opens and which a diagnostic and the runtime inspector call it by.

public readonly struct Routine
Expand Details ...

Examples

Patrol = Define.Routine();
On.Ready(Routine(Patrol).Run(walkOut, waitAtPost, walkBack));

Remarks

Patrol = Define.Routine(); declares one; the declaration starts no work. Routine(Patrol).Run(...) builds the block that starts it, once per declaration. Each instance runs its own activation of each place that block is written. docs/proposals/declared-identity-handles.md is the contract.
