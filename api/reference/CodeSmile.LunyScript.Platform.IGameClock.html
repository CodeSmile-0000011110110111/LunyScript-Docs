Interface IGameClock

Namespace
CodeSmile.LunyScript.Platform

A clock that drives a running game, so it carries the game's time scale and can be paused as well as read. Time.Scale, Time.IsPaused, Time.SetScale, Time.Pause and Time.Resume reach the clock through this interface.

Remarks

Why this is separate from ITimeSource. Every clock can report how much time passed; only a clock that governs a game's speed can be asked to change it. The editor session's clock reports elapsed edit-time seconds and governs no game, so it implements ITimeSource alone and a script that pauses the game cannot run on an editor runner. UnityTimeSource and TestKit.ManualTimeSource implement this one.

This clock's pause is a time scale of zero, and resume restores the last positive scale this clock was set to. Time.IsPaused reads the runner flag, not this property: Time.Pause sets the flag and calls Pause(), and Time.SetScale(0) calls SetScale(double) without setting the flag. A scale set outside this clock - Unity's own Time.timeScale written by other code - changes what Scale reports and does not change what Resume() restores, because this clock did not set it.

.NET 10 seam. ITimeSource's row in AGENTS.md section 4 is unchanged by this interface: System.TimeProvider replaces the reading half, and the scale and the pause stay the engine's, because no BCL type carries a game time scale.

How fast game time runs against real time. One is ordinary speed, one half is slow motion, and zero is paused.

Methods

Pause()

Stops game time by setting the scale to zero. The scale to come back to is remembered. Pausing an already paused clock changes nothing.

void Pause()

Resume()

Restarts game time at the last positive scale this clock was set to, which is one when none was. Resuming a clock that is not paused changes nothing.

void Resume()

SetScale(double)

Sets the time scale. A positive value is also what Resume() will restore afterwards.

void SetScale(double scale)
