The core's one entry point to player input. Owns the IInputProvider, resolves each program's declared actions once, and answers the value reads and the occurrence tests the input blocks make.

Remarks

This is the input counterpart of NetworkGateway and is deliberately the same shape, because it has the same problem: the core may not reference the Input System package, so the core owns an interface and a separate, package-gated assembly implements it. The ownership board's P01 row is what authorises that adapter, and it is the only place in the product where the package is named.

Resolution happens once per program, not once per object. A declaration carries a local player index and a name, both written in Build(), so every object running the script resolves to the same configured action. ResolutionsFor(ScriptProgram) returns the one array of backend identifiers that program's instances share; the array is re-resolved in place when the provider changes, so an instance that already holds it keeps reading the right actions.

Nothing here is per frame except the reads. Each read is one array index and one call into the backend, and allocates nothing; AGENTS.md rule 29.

A declaration that does not resolve is reported once and reads its resting value. The report names the script, the declaration and why, at error severity, once per declaration per program, for the reason the asset inputs report once: the mistake is in the script's wiring or in the action asset, so a thousand objects say so once.

ResolutionsFor(ScriptProgram)

The backend identifiers this program's declared actions resolved to, in declaration order. Resolved the first time the program is asked for, and re-resolved in place when the provider changes.

public int[] ResolutionsFor(ScriptProgram program)

Parameters

program ScriptProgram

The program whose declarations to resolve.

Returns

int[]

One identifier per declaration, Unresolved where it did not resolve. An empty array for a program that declares no action.

Examples

var ids = runner.InputGateway.ResolutionsFor(program);

Remarks

Called once per spawn and never per frame. The returned array belongs to the gateway and is shared by every instance of the program, because a declaration's player and name are the same for all of them.
