On.Application: what Unity reported about the application as a whole, rather than about one object.

public readonly struct OnApplicationFactory

Examples

On.Application.Paused(Music.Set(0.0));
On.Application.Quitting(Progress.Set(0.0));

Remarks

Unity's own callbacks carry a Boolean: OnApplicationPause(true) and OnApplicationPause(false) are one method. Each is its own event here, the way Gained(params Block[]) and Lost(params Block[]) are two events, because a script registers blocks and has no parameter to test.

All five are delivered to every enabled instance, because that is who Unity delivers OnApplicationPause, OnApplicationFocus and OnApplicationQuit to. LunyScript re-implements none of that; AGENTS.md rule 54. Which of them a platform raises, and how often, is Unity's answer and not LunyScript's: the editor raises focus changes that a built player does not.
