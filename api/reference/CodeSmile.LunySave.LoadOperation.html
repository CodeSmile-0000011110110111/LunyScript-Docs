Remarks

A load from the player's data folder, and from StreamingAssets on a platform where that folder is a local folder, completes inside the call that starts it. On Android and the web StreamingAssets is read with a web request, and the load completes in a later frame; IsDone turns true when it has, and reading any property finishes it then. Nothing calls back: the code that holds the operation reads it, so an object destroyed before a load completes is never handed its result.

A load that fails hands back no document. A load that succeeds hands back a SaveDocument holding every field the stored copy could give; Omitted(string) names the others, which hold no value, so the caller's own values for them stay as they were. A stored copy of an older version is migrated first, and must then give every field, or the load fails as Unsupported. A load never writes the stored file.
