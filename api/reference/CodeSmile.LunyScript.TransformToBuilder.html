What MoveTo, RotateTo and ScaleTo return: the destination, waiting for the duration.

public readonly struct TransformToBuilder
Expand Details ...

Examples

On.FrameUpdate(Transform.MoveTo(3.0, 0.0, 0.0).Over(2.0));

Remarks

This builder converts to no block. A duration interpolator without a duration would be an immediate write, which SetWorldPosition, SetWorldRotation and SetScale already are. Over is required; AGENTS.md rules 41 and 42.
