Struct CollectionResult

The read-only, named outcome of one synchronous collection call. Declared with CollectionResult.Define(nameof(X)) inside Build() and produced by exactly one Slots.TryAdd(item).As(X). Used as a condition, it stands for Succeeded.

Remarks

It starts not-run, with Succeeded and Failed both false. Each time the bound call runs, it stores that call's own outcome, which the result keeps across frames until the bound call runs again. Every object running the script has its own result, and a pooled object that is reused starts not-run again. Reading the result performs no collection call, so a read placed before the bound call in the same event sees the previous outcome. A loop that runs the bound call leaves its last outcome; a loop that never runs it leaves the outcome it had before.

This is a synchronous result, which is a different category from Operation: the call has finished when the block that runs it returns, so there is no pending state, no deadline, no generation and no When.* watch.
