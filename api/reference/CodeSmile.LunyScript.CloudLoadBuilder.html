What Cloud.Load(key) returns: an unbound load when it is used as a block, or a load that names the variable its value is written into after Into(Var<Number>).

public readonly struct CloudLoadBuilder
Expand Details ...

Examples

On.Ready(Cloud.Load("progress").Into(Progress).As(LoadingProgress));

Remarks

An unbound load delivers its value through When.Cloud(key).Loaded(into, ...). A load bound with .Into(target).As(handle) writes the loaded value into target and then completes the handle's attempt, which is the Cloud.Load(source).Into(target).As(attempt) order the recorded cloud design uses.

Methods

Into(Var<Number>)

Names the variable the loaded value is written into, before the handle's attempt succeeds. A failed load writes nothing.
