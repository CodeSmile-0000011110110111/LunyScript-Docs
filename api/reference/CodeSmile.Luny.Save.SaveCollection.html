Class SaveCollection

Namespace
CodeSmile.Luny.Save
Assembly
ApiSource.dll

A folder of the player's data folder whose saves List(SaveCollection) lists, and the kinds of save stored there, each recognized by its file extension: documents of a SaveSchema and groups of a SaveGroupSchema. Each method returns a new collection and leaves this one as it was.

Examples

static readonly SaveCollection Slots = new SaveCollection("savegames")
    .Documents(".sav", Progress)
    .Groups(".save", SlotGroup);

Remarks

A listing covers the files directly in the folder whose names end in a declared extension; files of other names, the copy a save writes first and the folders inside are not listed. To list another folder, such as each user's, declare a collection per folder.
