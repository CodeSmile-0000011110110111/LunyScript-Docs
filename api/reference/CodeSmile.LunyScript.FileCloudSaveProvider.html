The file-based Cloud Save provider: one file per key, under a directory the caller names. A first-class part of the product, not a test fixture; AGENTS.md rule 52. It is how every failure branch is tested without a network, and what makes the automated suite runnable with no credentials.

Remarks

Every operation completes synchronously, inside the provider call; the gateway observes the outcome on its next per-frame poll, so a script sees the same event sequence it sees against a real service, one or more frames later rather than hundreds. Values are written in the invariant culture with the round-trip format, so a load returns exactly the Double that was saved.

Keys are case sensitive, on every file system. Save("Level1", 1.0) and Save("level1", 2.0) hold two separate values and Load("Level1") returns 1.0, on Windows and macOS as well as on Linux, which is how Unity Cloud Save behaves; docs/slice-decisions.md D5.14 records the decision and the file name it produces.
