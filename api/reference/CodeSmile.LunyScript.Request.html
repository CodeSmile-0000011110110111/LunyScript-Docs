A request a script accepts: work another script asks this script's object to do, which this script's On.Request handlers perform, check or refuse.

public readonly struct Request
Expand Details ...

Examples

Heal = Define.Request();
On.Request(Heal, If(Health >= 100).Then(Reject()));
On.Request(Heal, Health.Add(25));

Remarks

Heal = Define.Request(); declares one, and the generated property names it. Another script names it through the generated descriptor, EnemyScript.Requests.Heal, and sends it with Request(target, EnemyScript.Requests.Heal). Its identity is the script type that declared it and its name, so an unrelated script that declares its own Heal declares a different request. docs/proposals/script-communication.md is the contract.
