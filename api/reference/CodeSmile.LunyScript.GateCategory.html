Enum GateCategory

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Systems a named gate may suppress for every script on the runner. Only input and camera exist as mute-able gateways in this version.

[Flags]
public enum GateCategory
Expand Details ...

Fields

Camera = 2

Camera writes are ignored.

Input = 1

Input reads return their resting value and every occurrence is false.

None = 0

Suppress nothing.

Examples

On.Ready(Gate.Open("SceneLoad", GateCategory.Input | GateCategory.Camera));

Remarks

A gate does not skip scripts. Pause is a separate system: Time.Pause never opens a gate, and Gate.Open never sets the paused flag.
