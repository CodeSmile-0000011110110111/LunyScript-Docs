What a navigation backend reports about one actor when NavigationGateway polls it once per frame: whether it can navigate, its route, whether it moves, and whether it reached the end of its route.

public readonly struct NavigationReading
Expand Details ...

Examples

return new NavigationReading(NavigationAgentState.Ready, NavigationRouteState.Complete, true, false);

Remarks

An end is reported only when the route and the remaining distance are known. The round 10 navigation board settled that "unknown remaining distance is not a completion signal", so a backend that cannot tell how far the actor still has to go reports ReachedEnd false.
