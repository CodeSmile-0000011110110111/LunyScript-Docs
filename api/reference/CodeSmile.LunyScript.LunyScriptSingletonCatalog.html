Build a player whose production assemblies declare a singleton script; its first scene carries one hidden object with this component.

Remarks

This is how a player finds its singletons without reflection. The Editor build step reads the list from the Editor's type cache and stores one script object per singleton type here; Unity's serializer recreates them when the scene loads, and its Awake hands them to CodeSmile.LunyScript.LunyScriptSingletons before the game start reads the list. Nothing adds this component by hand, and a scene in the project never holds one: the build step adds it to the copy of the scene the build writes. docs/proposals/singleton-scripts.md is the contract.
