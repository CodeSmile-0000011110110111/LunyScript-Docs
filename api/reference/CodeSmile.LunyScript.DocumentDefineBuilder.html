Struct DocumentDefineBuilder

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What Define.Document(name) returns: a document being declared, which takes its version, its fields and its migration steps, then converts to the Document handle.

public readonly struct DocumentDefineBuilder
Expand Details ...

Examples

Career = Define.Document(nameof(Career)).Version(2)
    .Field(nameof(BestWave), BestWave)
    .Field(nameof(Unlocked), Unlocked)
    .Migration(new CareerVersion1To2());

Remarks

Every call is checked while Build() runs. What needs every line first is checked when it finishes: the document lists at least one field, no field is a synchronised variable, and the migration steps run from the oldest one registered to the version before Version(int, string, int) without a gap. A builder that never becomes a handle is refused then as well. docs/proposals/local-documents.md is the contract.
