LunyScript API Reference

Struct ObjectHandle

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What Object.For(target) returns: the renderer on one declared GameObject input, with the visual members the Object surface has for the object the script runs on.

public readonly struct ObjectHandle
Expand Details ...

Examples

var shield = Object.For(Shield);
On.Message("ShieldUp", shield.Show(), shield.SetColor(0.3, 0.6, 1, 0.5));
On.Message("ShieldDown", shield.Hide());

Remarks

A handle is a value, not a block: it can be kept in a local and used in several events. Every object running the script addresses the object its own Inspector assigns to that input. The lifetime operations and Transform are not on this handle.

Properties
