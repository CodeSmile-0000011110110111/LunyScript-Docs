An in-memory scene backend: a list of scene paths that count as in the build, a list of loaded scene instances, and loads and unloads that complete when the gateway ticks or when a test says so. It reports the native Loaded and Unloaded phases the way Unity's callbacks do.

Examples

var scenes = new FakeSceneProvider();
scenes.AddToBuild("Assets/Scenes/Menu.unity", "Assets/Scenes/Arena.unity");
scenes.MarkLoaded("Assets/Scenes/Menu.unity");
runner.SceneGateway.UseProvider(scenes);

Remarks

It exists so every scene-flow behaviour can be tested without a scene on disk. The same role FakeAssetLoadProvider has for asset loads. It follows the Unity provider's rules: a path that is not in the build fails as NotFound, a replacement unloads every loaded instance before the destination is loaded, and the last loaded scene cannot be unloaded.

With CompletesOnTick true, the default, everything started before a gateway tick completes at the start of that tick, which is the frame a Unity load of a small scene completes in. Set it false to hold operations pending and complete them with CompletePending().
