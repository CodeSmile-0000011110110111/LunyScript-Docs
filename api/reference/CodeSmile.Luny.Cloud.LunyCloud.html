Class LunyCloud

Namespace
CodeSmile.Luny.Cloud
Assembly
ApiSource.dll

LunyCloud's entry type: CreateClient(ICloudClock, ICloudLog, int) makes the CloudClient that is one game's client of the cloud services, the signed-in player's account, the player's data and files, the game's read-only data and leaderboards. It forwards to the CloudClient constructor; the caller installs the services with UseServices(CloudServices) and calls Tick() once per frame. A scene's CloudHost owns and ticks a client for C# with no script, and a LunyScript script reaches its runner's client through its Cloud, Account and Leaderboard verbs.
