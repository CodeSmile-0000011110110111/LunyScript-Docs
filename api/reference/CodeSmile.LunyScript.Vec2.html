A two-component spatial value: a stick deflection, a screen offset, a planar direction.

public readonly struct Vec2
Expand Details ...

Examples

var stick = new Vec2(1.0, 0.0);
var raised = stick.WithY(1.0);

Remarks

Why the name is Vec2 and not Vector2. The same reason Vec3 is not Vector3: a type called CodeSmile.LunyScript.Vector2 would be ambiguous with UnityEngine.Vector2 in every script carrying using UnityEngine;.

The components are Single while Number is Double. That is the precision split the API semantics record carries, applied the same way Vec3 applies it. Every member here takes and returns Double at its edges, so a script never writes an f suffix.

A component is replaced, never written. WithX and WithY return a copy with one component changed, which is what a spatial variable's Set takes.
