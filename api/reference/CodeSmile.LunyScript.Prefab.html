A handle to one prefab input of a script. Returned by Bind.Prefab() at build time, or assigned before Build() by [Asset] on the property; what the input holds is an instance read, because the value belongs to the object and not to the script type.

public readonly struct Prefab

Remarks

A prefab input refuses a GameObject that is not a prefab. A scene object assigned to an input a script copies from is a mistake that shows up as a duplicated scene object rather than as a message. A value the host assigned that is not a prefab asset is refused at spawn, and the input then resolves as if nothing had been assigned. A scene object is what ObjectBinding binds.

Object.Create and Define.Pool take this type and no other input kind, so passing an AudioClip or an ObjectBinding to them does not compile.

The declared name is the input's durable identity: a value stored on a host is matched to an input by that name. A generated property gives the input its member's name, and .As(name) names it explicitly. Renaming it orphans what a scene stored for the old name.

A handle is valid only inside the Build that declared it, for the reason Var<T> states: it carries a slot index and nothing that identifies its program.
