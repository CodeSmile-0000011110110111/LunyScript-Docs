Remarks

A user never adds this component. The six methods exist because Unity discovers physics callbacks by method presence on a MonoBehaviour, and putting them on LunyScriptBehaviour would invoke them on every managed object that has a collider.

Unity requires this class to live in a file of the same name, which is why the Collider parameter of the trigger callbacks is not in GameObjectHost.cs. The structural test exempts this type for that reason. AGENTS.md rule 24.

The other collider is copied onto the instance as primitives for the raise, then cleared. Unity's Collision is not stored. Stay fires every fixed step, so this path must allocate nothing of its own. Unity still allocates the Collision argument it passes into the three collision callbacks. The Collider argument of the trigger callbacks is a reference to a component that already exists.
