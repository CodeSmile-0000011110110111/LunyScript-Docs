Struct CameraRigBuilder

Namespace
CodeSmile.LunyScript

ApiSource.dll

What Camera.For(rig) returns: the rig's two tracking targets and its target group.

public readonly struct CameraRigBuilder
Expand Details ...

Examples

On.Ready(Camera.For(ChaseRig).Follow(), Camera.For(ChaseRig).LookAt(Marker));

Remarks

Each tracking verb comes in two forms, the way the object lifetime verbs do: the no-argument form tracks the object this script runs on, and the form taking a declared input tracks the object that input holds.

Properties

Targets

The rig's group of tracked objects, which is how one view frames several objects at once.

public CameraTargetsBuilder Targets { get; }

Property Value

CameraTargetsBuilder

A builder whose five methods change the group.

Examples

On.Ready(Camera.For(ArenaRig).Targets.Add(Avatar, 1.0, 0.5));

Exceptions

LunyScriptUsageException

The builder is a default one.
