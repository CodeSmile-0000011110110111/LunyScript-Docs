Class CloudQueueFile

Namespace
CodeSmile.LunyCloud.Unity
Assembly
ApiSource.dll

Keeps the score queue in the player's data folder through LunySave, so "a Submit that cannot be sent waits in a bounded queue on the device, survives a restart" (2026-09-09): one version 1 LunySave document whose Queue text field holds the queue's JSON, written with LunySave's replace-by-rename at each change of the queue.

Remarks

LunyScript's default runner uses one at DefaultPath when it is given the supplied services; a CloudClient a game creates uses one when it is named with UseQueueStore(ICloudQueueStore).
