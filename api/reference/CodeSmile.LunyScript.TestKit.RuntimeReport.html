Class RuntimeReport

Namespace
CodeSmile.LunyScript.TestKit
Assembly
ApiSource.dll

Names the runtime a test is executing on, so that a measurement recorded in docs/allocation-baseline.md can never be attributed to the wrong backend.

public static class RuntimeReport
Inheritance
object
RuntimeReport

Remarks

The Unity 6.7 Editor runs Mono in every mode, including Play Mode, so a CoreCLR result can only come from a player build. This type is what makes that checkable inside the test rather than assumed from the command line that started it. See AGENTS.md section 3.

The runtime's own description of itself, for example ".NET 10.0.0" under CoreCLR or "Mono 6.x" under Mono. Read from RuntimeInformation.FrameworkDescription, which is the runtime's answer rather than a compile-time define.
