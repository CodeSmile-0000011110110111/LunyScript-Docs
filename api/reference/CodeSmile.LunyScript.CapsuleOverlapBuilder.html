Struct CapsuleOverlapBuilder

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What Collision.CapsuleOverlap() returns: a capsule overlap that takes its clauses in any order, each once, and is finished by Into.

public readonly struct CapsuleOverlapBuilder
Expand Details ...

Examples

On.FixedUpdate(Collision.CapsuleOverlap().Height(2).Radius(0.5).InLocalSpace().Into(Nearby));

Remarks

World space is the default. InLocalSpace() or InWorldSpace() names the frame and returns SpacedCapsuleOverlapBuilder, which offers every clause but a second space clause. docs/proposals/collision-queries.md is the family.

Examples

Remarks

With InLocalSpace(), Offset, a Towards vector, Oriented and an omitted direction all use the object's rotation. A binding that holds no object clears the result; an object that is destroyed, in no loaded scene or inactive clears it and is reported once. This object's own colliders stay the ones ExcludeSelf() leaves out.
