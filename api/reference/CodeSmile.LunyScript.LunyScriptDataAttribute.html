Marks a partial struct as a LunyScript data schema: a value shape a script declares its own copy of with Define.Data, binds from an Inspector-assigned asset with Bind.Data, and loads from a JSON file.

Remarks

The generator reads this attribute at compile time and writes three members into the struct: the static Schema property that Bind.Data takes, the Variables handle type whose properties are the script's variables for each field, and the generated LunyScriptSchema that copies a value into those variables without reflection. Every public instance field is part of the schema, in declaration order, and has to be a number, a bool, a declared C# enum, a Vector3, Vector2 or Rotation, a string, or another [LunyScriptData] struct. Any other field type is reported as LUNY001. docs/proposals/custom-data-and-file-inputs.md has the contract.
