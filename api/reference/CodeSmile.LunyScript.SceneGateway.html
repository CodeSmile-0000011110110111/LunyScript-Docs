Class SceneGateway

Namespace

Owns in-flight Scene.Load and Scene.Unload attempts, the scene identities the runner's scripts declared, and one counter per identity and phase that the When.Scene* watches read. One per ScriptRunner. Script code never sees a Task, an AsyncOperation or an exception type; AGENTS.md rules 50 and 51.

Remarks

A start may allocate. A tick with nothing in flight, and a tick that only polls, allocate nothing; AGENTS.md rule 31 applied to this gateway.

A scene identity is interned once, when an object that declares it spawns. The asset path the host stored becomes a small number that the instance keeps in a hidden slot, so every later read, including every watch on every frame, is an array index.

A load whose requester stopped waiting is cleaned up, not rolled back. When the requester cancels, is superseded, times out or despawns while an additive load is still in flight, the native load is allowed to finish and the exact scene instance it produced is then unloaded. That is the settled api-scene-cancel-cleanup answer: the requester observes its own outcome, and a host cleanup owner handles the late completion. A replacement load is never cleaned up: it released every loaded scene when it started, so its destination is the only scene there is.
