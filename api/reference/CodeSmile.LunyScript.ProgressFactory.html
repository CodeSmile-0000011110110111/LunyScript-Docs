The Progress surface inside Build(): saves a document among the user's progress in local storage, and loads it back. Quest flags, counters, unlocks and the best wave belong here; Settings keeps configuration.

public readonly struct ProgressFactory

Examples

On.Ready(Progress.Load(Career).As(LoadingCareer));
When.Var(BestWave).Changed(Progress.Save(Career).As(SavingCareer));

Remarks

A save and a load are each one attempt on an operation handle, bound with .As, which is required. The start block returns in the same call; the storage work runs when the next frame update begins, so When.Operation(handle) observes the outcome one frame later. A load writes every loaded field before the attempt succeeds. The first of Progress and Settings to name a document keeps it; naming it with the other is refused. docs/proposals/local-documents.md is the contract.

Load(Document, string, int)

Starts loading the document. A stored copy at an older version is migrated first; then every field it holds is written together, and the attempt succeeds. A document never saved fails as NotFound, and every field keeps its value.
