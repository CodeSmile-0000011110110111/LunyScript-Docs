The Animator surface inside Build(): typed handles to the parameters of the Animator Controller on the object the script runs on. It hides UnityEngine.Animator inside a Script the same way Transform hides UnityEngine.Transform.

public readonly struct AnimatorFactory
Expand Details ...

Examples

var speed = Animator.Number("Speed");
On.FrameUpdate(speed.Set(Speed));

Remarks

The controller, its clips, blend trees and transitions stay in Unity. A script reads and writes the parameters that controller already declares: Number is Unity Float, Integer is Unity Int, Flag is Unity Bool, and Trigger is Unity Trigger.

A declaration belongs to the script type: the name and the kind are written in Build(), and every object running the script addresses that parameter on its own Animator, which is looked up when the object spawns. A missing Animator, a missing parameter and a parameter of another kind are each reported once per script type; the handle then reads 0 or false and its writes do nothing, and the object still runs.

Play, CrossFade, layer weights, state events, root motion, IK and a named Animator on another object are not on this surface. docs/proposals/animation.md is the family.
