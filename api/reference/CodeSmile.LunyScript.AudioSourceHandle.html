What Audio.For(source) returns: bound-source control on that object.

public readonly struct AudioSourceHandle
Expand Details ...

Examples

var motor = Audio.For(MotorSource);
On.Ready(motor.Play());

Properties

IsPlaying

Whether the bound resource is playing. False while it is paused, stopped, or the object has no AudioSource.

Property Value

ConditionBlock

Examples

Exceptions
