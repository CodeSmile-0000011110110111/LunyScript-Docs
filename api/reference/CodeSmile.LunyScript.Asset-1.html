A handle to one asset input of a script. Returned by Bind.Asset at build time; reading the asset itself is an instance read, because the value belongs to the object and not to the script type.

public readonly struct Asset<T> where T : Object

Type Parameters

T

The Unity asset type this input accepts. An input declared as Asset<GameObject> cannot be satisfied by a Texture2D, in the Inspector or from a stored entry.

Expand Details ...

Examples

[Asset] public Asset<AudioClip> OpenSound { get; private set; }
var clip = behaviour.GetAsset(script.OpenSound);

Remarks

The handle is an index and a name, not a value: it says where the asset lives on every instance of the program, and the same handle reads a different object on every object running the script.

The declared name is the input's durable identity. A value stored on a host is matched to an input by that name, which is why the name comes from nameof and why renaming a declared input orphans what a scene stored for the old name.

A handle is valid only inside the Build that declared it, for the reason Var<T> states: it carries a slot index and nothing that identifies its program.
