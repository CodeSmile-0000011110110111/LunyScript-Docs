A declared voice: one tracked one-shot per instance, which Audio.PlayOneShot(clip).Into(voice) fills and which Stop, Pause, Detach, SetVolume and When.Audio(voice) address.

public readonly struct AudioVoice
Expand Details ...

Examples

Alarm = Define.Voice();
On.Ready(Audio.PlayOneShot(AlarmClip).At(doorPosition).Into(Alarm));
On.Message(CancelAlarm, Alarm.Stop());

Remarks

Alarm = Define.Voice(); declares one. It starts with no playback. Each instance tracks its own playback, a later Into on the same voice tracks the newer one, and the playback ends with its owner unless Detach lets it finish. docs/proposals/declared-identity-handles.md is the contract.
