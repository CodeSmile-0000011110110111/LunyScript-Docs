The Account verbs a script writes inside Build(): sign in, sign out and delete the cloud account, and Account.IsSignedIn() (C03, the captain's choice of the Account family on 2026-09-20; C22 A). Outcomes arrive through When.Account(handle).

Remarks

The first cloud request of a session signs in by itself; an explicit sign-in is how a menu signs in first, and how a script tries again after a failed sign-in. After Account.SignOut() or a successful Account.Delete(), requests fail as NotSignedIn until the next Account.SignIn(). Account requests wait for every cloud request before them, and every request after them waits for them. User, the local profile, is not part of this surface, and linking a login (C21) is deferred.

Delete(AccountFactory, string, int)

Starts deleting the signed-in Authentication account, which signs out when it succeeds. Only the account is deleted (C22 A): delete the documents and files first with Cloud.Delete; leaderboard entries and protected items stay on the server. The account's queued scores end as NotSignedIn.

SignOut(AccountFactory, string, int)

Signs out once the cloud requests before it ended, keeping the cached session, so the next sign-in is the same player. Requests made afterwards fail as NotSignedIn until the next sign-in; queued scores keep waiting for their account.
