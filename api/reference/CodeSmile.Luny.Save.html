LunyScript API Reference

Namespace CodeSmile.Luny.Save

Classes

ContentFiles

A game's authored content files, in two named places LunySave chooses: the project's Luny folder beside Assets, which the Editor reads and writes, and StreamingAssets/GameData.luny, the uncompressed archive of that folder a player reads. Every path is relative to the Luny folder, such as "Encounter/room-breach.json".

ContentReadOperation

One read of a game's content files: from the project's Luny folder in the Editor, or from StreamingAssets/GameData.luny in a player. It holds every JSON file it read, in ordinal path order, and the paths it skipped.

DeleteOperation

One Delete(string): whether it is done, and how it ended.

LoadOperation

One Load(string, SaveSchema) or LoadStreamingAsset(string, SaveSchema): whether it is done, how it ended, the document it read, and which declared fields the stored copy could not give.

LocalSave

Saves and loads typed documents on this device, for plain C#: Save(string, SaveDocument), Load(string, SaveSchema), Exists(string) and Delete(string) in the player's writable data folder, LoadStreamingAsset(string, SaveSchema) from the read-only StreamingAssets folder the build ships. Every path is relative to the folder its call uses.

LunySave

LunySave's entry type: Create() makes the LocalSave that saves, loads, tests and deletes typed documents at paths relative to the player's data folder. It forwards to the LocalSave constructor; ContentFiles holds the content files of the project's Luny folder and GameData.luny.

LunySaveException

A mistake in the C# that uses LunySave, raised where it was made: a path that is absolute, leaves its folder or uses a character a portable file name cannot hold, a schema whose migration steps leave a gap, a field the schema does not declare, or a document saved before every declared field holds a value. The message names the call and what to change.

SaveDocument

The values of one document of a SaveSchema: what Save(string, SaveDocument) writes and what a successful LoadOperation returns. Each declared field either holds a value or holds none.

SaveFields

The stored fields of one document while a SaveMigration step converts them. Reads and writes a copy: nothing here reaches the stored file or a document a caller holds.

SaveMigration

One consecutive step of a document's schema: converts a stored document of FromVersion into version FromVersion + 1. Registered with Migration(SaveMigration).

SaveOperation

One Save(string, SaveDocument): whether it is done, and how it ended.

SaveSchema

What one kind of document holds: its version, its fields by name and kind, and the migration steps that convert an older stored version. Each method returns a new schema and leaves this one as it was, so a schema kept in a static readonly field never changes after it is built.

Structs

ContentArchiveResult

What WriteArchive() did: whether Assets/StreamingAssets/GameData.luny now holds the project's content, how many files and bytes it holds, and why it was not written.

ContentFile

One JSON content file a ContentReadOperation read: its path relative to the content folder, with '/' between names, and its text.

SaveMigrationResult

What one SaveMigration step returns: the document was converted, or it was rejected with a reason.

Enums

SaveFailure

Why a SaveOperation, LoadOperation or DeleteOperation failed. None while the operation is pending and after it succeeded.
