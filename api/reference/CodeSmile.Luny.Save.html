LunyScript API Reference

Namespace CodeSmile.Luny.Save

Classes

ContentFiles

A game's authored content files, in two named places LunySave chooses: the project's Luny folder beside Assets, which the Editor reads and writes, and StreamingAssets/GameData.luny, the archive of that folder a player reads. Every path is relative to the Luny folder, such as "Encounter/room-breach.json". The archive stores each entry unless ProjectSettings/LunyGameDataArchive.txt says Deflate. The JSON files in the Luny folder stay as they were written.

ContentReadOperation

One read of a game's content files: from the project's Luny folder in the Editor, or from StreamingAssets/GameData.luny in a player. It holds every JSON file it read, in ordinal path order, and the paths it skipped.

DeleteOperation

One Delete() or Delete(): whether nothing is stored at the path afterwards.

DocumentPaths

Existing relative document locations and filename construction shared by module save adapters.

ExistsOperation

One Exists() or Exists(): whether a load would find something at the path, without reading it.

GroupLoadOperation

One Load(): where it stands, how it ended, and the group it read.

LoadOperation

One Load() or LoadStreamingAsset(MonoBehaviour, string, SaveSchema): where it stands, how it ended, the document it read, and which declared fields the stored copy could not give.

LocalSave

Saves and loads typed documents on this device, for plain C#. Acquire(MonoBehaviour, string, SaveSchema) binds a path in the player's writable data folder, a SaveSchema and the MonoBehaviour that owns them into a SaveSlot, which saves, loads, tests and deletes that one document; AcquireGroup(MonoBehaviour, string, SaveGroupSchema) does the same for a SaveGroupSlot, several documents saved as one archive. LoadStreamingAsset(MonoBehaviour, string, SaveSchema) reads a document the build ships, List(SaveCollection) lists the saves of a folder, and Journal keeps the last requests for a support report.

LunySave

LunySave's entry type: Create() makes the LocalSave that saves, loads, tests and deletes typed documents at paths relative to the player's data folder. It forwards to the LocalSave constructor; ContentFiles holds the content files of the project's Luny folder and GameData.luny.

LunySaveException

A mistake in the C# that uses LunySave, raised where it was made: a path that is absolute, leaves its folder or uses a character a portable file name cannot hold, a schema whose migration steps leave a gap, a field the schema does not declare, or a document saved before every declared field holds a value. The message names the call and what to change.

RecordParts

Encodes named saved-record parts with a format line and character-counted text.

SaveCollection

A folder of the player's data folder whose saves List(SaveCollection) lists, and the kinds of save stored there, each recognized by its file extension: documents of a SaveSchema and groups of a SaveGroupSchema. Each method returns a new collection and leaves this one as it was.

SaveDocument

The values of one document of a SaveSchema: what Save(SaveDocument) writes and what a successful LoadOperation returns. Each declared field either holds a value or holds none.

SaveField

One named field a SaveSchema or SaveRecordSchema declares, with the SaveKind of its value. Declare each field once, in a static readonly field, and pass that object both to the schema and to every Set<T>(SaveField<T>, T) and TryGet<T>(SaveField<T>, out T), so the compiler checks the value's type where it is written.

SaveFieldList

A list inside a stored document while a SaveMigration step converts it: the values it holds by index, read by the kind the step asks for, and changed in place. TryGetList(string, out SaveFieldList) and SetList(string) return one.

SaveField<T>

A SaveField whose value is of the C# type T: what Set<T>(SaveField<T>, T) takes and TryGet<T>(SaveField<T>, out T) returns for it.

SaveFields

The stored fields of one document while a SaveMigration step converts them. Reads and writes a copy: nothing here reaches the stored file or a document a caller holds.

SaveGroup

The documents of one group of a SaveGroupSchema: one document per single role, at most one per optional role, and any number per keyed role, each under its key. Save(SaveGroup) stores them as one archive; a successful GroupLoadOperation returns one.

SaveGroupSchema

What one group of documents holds: its family and its roles. A SaveGroupSlot saves a SaveGroup of this schema as one archive file, so every document of the group is replaced together or none is, and a load reads them all or fails.

SaveGroupSlot

One acquired group: a path in the player's data folder where a SaveGroup of one SaveGroupSchema is stored as one archive, and the MonoBehaviour that owns the acquisition. AcquireGroup(MonoBehaviour, string, SaveGroupSchema) makes it.

SaveJournal

The last requests LunySave ended in this process, newest last, without the values they saved or loaded: each request's place in the order of accepted requests, its kind, path, owner, schema, stored version, how it ended and the fields a load omitted. A support report reads it to explain which owner saved what and in which order after the callers let go of their requests.

SaveKind

What a stored value is: a number, a flag, a text, a Unity value, an exact 64-bit whole number, or a record, list, map or optional value built from those. A SaveField pairs a name with a kind; a list, map or optional kind names the kind of its values. SaveKind<T> carries the C# type a set takes and a read returns.

SaveKind<T>

A SaveKind whose values are of the C# type T: what Set<T>(SaveField<T>, T) takes and TryGet<T>(SaveField<T>, out T) returns for a field of it.

SaveListEntry

One save a SaveListing found: its path and name, whether it is a document or a group, and the metadata it holds, or why that could not be read.

SaveListing

One List(SaveCollection): the saves stored directly in a SaveCollection's folder, each with the metadata it holds or why that could not be read.

SaveMigration

One consecutive step of a document's schema: converts a stored document of FromVersion into version FromVersion + 1. Registered with Migration(SaveMigration).

SaveOperation

One Save(SaveDocument) or Save(SaveGroup): where it stands and how it ended.

SaveOptional

Makes a SaveOptional<T> that holds a value, with its type taken from the value.

SaveRecord

The values of one record of a SaveRecordSchema: what a record field, or a list or map of records, holds. Set every declared field before the document holding it is saved.

SaveRecordSchema

What one record holds: a name for messages and the fields every record of it holds. A record has no version of its own; the version of the document that holds it covers it. A Record(SaveRecordSchema) kind, a Record(string, SaveRecordSchema) field and a list or map of records use it.

SaveRequest

What every LunySave request has: the path it named, where it stands (State), and why it did not succeed (Refusal). SaveOperation, LoadOperation, ExistsOperation, DeleteOperation, GroupLoadOperation and SaveListing are requests.

SaveRole

One role of a SaveGroupSchema: a name, the SaveSchema of its documents, and how many it holds. Declare each role once, in a static readonly field, and pass that object to the group schema and to every Set(SaveRole, SaveDocument) and TryGet(SaveRole, out SaveDocument).

SaveSchema

What one kind of document holds: its schema family, its version, its fields, the migration steps that convert an older stored version, and whether it reads documents of format 1, which name no family. Each method returns a new schema and leaves this one as it was, so a schema kept in a static readonly field never changes after it is built.

SaveSlot

One acquired document: a path in the player's data folder, the SaveSchema every document saved there follows, and the MonoBehaviour that owns the acquisition. Acquire(MonoBehaviour, string, SaveSchema) makes it; every consumer of the document is handed this one slot.

Structs

ContentArchiveResult

What WriteArchive() did: whether Assets/StreamingAssets/GameData.luny now holds the project's content, how many files and bytes it holds, and why it was not written.

ContentFile

One JSON content file a ContentReadOperation read: its path relative to the content folder, with '/' between names, and its text.

SaveCompressionPolicy

Whether a save states how to store its document. A default value states nothing. Uncompressed and Compressed state the two representations this version writes.

SaveJournalEntry

One ended request in the SaveJournal: metadata only, never a saved value.

SaveMigrationResult

What one SaveMigration step returns: the document was converted, or it was rejected with a reason.

SaveOptional<T>

A value of an optional field, element or record member: a value, or none, which is stored as JSON null. The default value holds none. Of<T>(T) makes one that holds a value.

SaveRefusal

Why a LunySave request did not succeed: a SaveFailure code, a sentence in the system's or LunySave's words, and the relative path the request named. The default value is no refusal.

Enums

ContentArchiveCompression

How GameData.luny stores each content file. None stores the bytes. Deflate stores them with the ZIP Deflate method. The build reads this from ProjectSettings/LunyGameDataArchive.txt.

SaveCompression

How a typed runtime save stores its JSON. None is plain UTF-8 JSON, which a save writes when it states no policy. Deflate stores that JSON in the version 1 encoding frame.

SaveFailure

Why a LunySave request was refused: the code of its SaveRefusal. None while the request is pending and after it succeeded.

SaveRoleKind

How many documents a SaveRole holds in a group.

SaveState

Where a LunySave request stands. A request is Pending until it ends, and then stays in the state it ended in.
