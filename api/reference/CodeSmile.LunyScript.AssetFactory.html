Struct AssetFactory

The Asset surface inside Build(): starts and ends content acquisitions. Unity owns the asset. LunyScript owns the attempt, the owner-acquisition, and consumer retention.

public readonly struct AssetFactory
Expand Details ...

Examples

EnemyContent = Operation.Define<Prefab>(nameof(EnemyContent));
On.Ready(Asset.Load(EnemyPrefab).As(EnemyContent));
When.Operation(EnemyContent).Succeeded(Object.Spawn(EnemyContent), Asset.Release(EnemyContent));
When.Operation(EnemyContent).Failed(ShowError.Set(true));

Remarks

Asset.Load(source).As(handle) is asynchronous and binds the shipped operation-attempt surface. Asset.Release(acquisition) relinquishes this owner's hold. Bound consumers retain content they still need. Asset.Load does not load a scene.

This factory coexists with the already-shipped Asset<T> handle, the way Task coexists with Task<T>.
