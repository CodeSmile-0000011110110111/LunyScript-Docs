Remarks

On a field of a partial class, usually a ScriptableObject, the generator writes a reader that copies the field's value without reflection. Bind.Number().FromDataField("SomeValue") reads a numeric field by its name, and Bind.Data(WeaponStats.Schema) reads the one field whose type is that schema. The asset keeps its values: each object copies them into its own variables when it spawns.

On a string field of a schema, Capacity names how many bytes the field's Text variable holds. A string field without the attribute holds 64 bytes, as Define.Text does.
