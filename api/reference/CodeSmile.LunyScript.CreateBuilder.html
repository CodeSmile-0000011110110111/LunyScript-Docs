Struct CreateBuilder

Namespace
CodeSmile.LunyScript

What Object.Create(prefab) returns: a fresh copy of a prefab with no placement yet. Add At(Vector3ValueBlock), ChildOf(string, string, int), Into(string, string, int), ForPlayer(int, string, int) and SurvivesCaller(string, int) in any order, or use it as a block, which creates the copy at the prefab's own pose.

public readonly struct CreateBuilder
Expand Details ...

Examples

On.Ready(Object.Create(Sentry));
On.Ready(Object.Create(Sentry).At(new Vector3(0.0, 1.0, 0.0)).ChildOf().Into("Guard"));

Remarks

The three builder structs are a typestate: this one offers At and no frame modifier, CreatePlacedBuilder offers the two frame modifiers and no second At, and CreateFramedBuilder offers neither. So Object.Create(p).InWorldSpace() and Object.Create(p).At(a).At(b) and Object.Create(p).At(a).InWorldSpace().InLocalSpace() are all compile errors rather than run-time checks; AGENTS.md rule 41 and the settled semantics-t08 answer, which asks for conflicting space clauses to be unavailable in typestate.

The copy is owned by the instance that created it, with or without Into: it is destroyed when that instance ends. SurvivesCaller(string, int) hands it to the scene instead.

The implicit conversion is what AGENTS.md rule 42 asks for: every builder either converts to a block or registers its finish action before Build() returns, so an unfinished chain cannot silently drop its behaviour.

A builder that can still take a placement and a parent.

Examples

Remarks

The name is an address and nothing else. A copy is owned by the instance that created it whether or not Into is written; Into only lets later blocks name it, for example Object.Destroy(name). The name is not the produced object's name in the scene: a prefab copy keeps the name the prefab gives it.

Exceptions

LunyScriptUsageException

name is null or whitespace, this chain already names one, another call already produces that name, or this builder is a default.

Examples

On.Ready(Object.Create(Sentry).ChildOf());
When.Player(2).Paired(Object.Create(Avatar).NearPlayer(1, 2).ForPlayer(2).Into("Guest2"));

Remarks

ChildOf cannot parent to itself. Omitting the name parents the produced object to the object the script runs on, which is the same "self by omission" the rest of the Object surface uses. A named parent is an object this script produced, by Object.Create or Object.Spawn with Into(string, string, int). A parent whose slot is empty when the create is applied leaves the produced object at the scene root and reports it.

Exceptions

LunyScriptUsageException

name is whitespace, this chain already names a parent, or this builder is a default.

LunyScriptUsageException

The player number is negative, the radius is null or a literal that is not a finite number above zero, or this builder is a default.

SurvivesCaller(string, int)

Lets the produced object outlive the instance that created it: it ends with its scene, or when something ends it, rather than when this instance ends.

public CreateBuilder SurvivesCaller(string callerFilePath = null, int callerLineNumber = 0)

Parameters

Type Name Description
string
callerFilePath

Supplied by the compiler. Do not pass one.
int
callerLineNumber

Supplied by the compiler.

Returns

CreateBuilder

A builder that can still take the clauses it could take before.

Examples

On.Update(If(Health <= 0).Then(Object.Create(Reward).SurvivesCaller(), Object.Destroy()));

Remarks

Without it, the copy is owned by this instance and destroyed when the instance ends, with or without Into(string, string, int). With it, the scene the copy is in holds that obligation, and Into(string, string, int) still lets this script address the copy while this instance runs. A copy that survives the caller cannot be a child of the caller, because a child is destroyed with its parent, so ChildOf() with this clause is refused while the script type is built.

Exceptions

LunyScriptUsageException

This chain already says it, or this builder is a default.
