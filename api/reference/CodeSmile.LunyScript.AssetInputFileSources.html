LunyScript API Reference

Class AssetInputFileSources

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The file sources of the two input kinds LunyScript can decode from a file: Bind.Texture2D() reads a PNG and Bind.AudioClip() reads a PCM WAV file. Any other kind has none of these methods, so Bind.Prefab().FromStreamingAssets(...) does not compile.

Examples

Portrait = Bind.Texture2D().FromStreamingAssets("portrait.png");
Chime = Bind.AudioClip().FromTemp("chime.wav");
On.Ready(Asset.Load(Chime).As(LoadingChime));
When.Operation(LoadingChime).Succeeded(Audio.PlayOneShot(Chime));

Remarks

A file source is the input's declared source. An object whose Inspector assigns the asset uses that asset, and Asset.Load acquires it as it acquires any assigned input. On an object that assigns nothing, the input holds its asset placeholder until Asset.Load(input) reads and decodes the file; a successful load puts the decoded texture or clip into that object's input and makes it the load's result. The file is never read at spawn, because a read can take several frames and on Android and WebGL the packaged files are reachable only through a web request.
