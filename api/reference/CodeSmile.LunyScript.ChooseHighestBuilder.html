A Choose(subject).Highest(...) chain. Optional Bias(double, string, int) and Hold(Elapsed, string, int) follow; used as a block it starts the selector.

public readonly struct ChooseHighestBuilder

Examples

On.Ready(Choose("needs").Highest(Option(WorkScore).Then(Work)).Bias(0.1).Hold(Seconds(1)));
