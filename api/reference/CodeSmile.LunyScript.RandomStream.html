A named random stream declared inside Build(). Mutable state lives on the instance; this handle is an index, the same way a variable handle is.

public readonly struct RandomStream
Expand Details ...

Examples

var loot = Random.Stream("loot", 42);
On.Ready(Random.Number().From(loot).In(1.0, 100.0).Into(Roll));

Remarks

Two streams with the same name and the same explicit seed produce the same sequence, on every instance and every backend. A stream declared without a seed derives one from the runner's session seed, the instance's spawn index and the stream name, so two instances of the same script do not share a sequence unless a test supplied the seed.
