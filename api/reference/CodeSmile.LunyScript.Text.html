A text literal written in a script, and the type argument that makes a text variable Var<Text>.

public readonly struct Text
Expand Details ...

Examples

var playerName = Var.DefineText("playerName");
On.Ready(playerName.Set("Player One"));   // the String becomes a Text here

Remarks

A Text is a build-time value only. It carries a managed System.String, which is what a literal in C# source is, and it is converted into the block's fixed-capacity storage while the script type is built. No slot ever holds one and no block ever creates one, so the managed string never reaches the run-time path. The run-time storage is a Unity.Collections.FixedString chosen by the variable's declared TextCapacity.

The implicit conversion from String is deliberate and does not contradict AGENTS.md rule 40, which forbids an implicit conversion from String to a variable block so that Debug.Log("msg" + variable) cannot silently become one. This conversion produces a literal value, not a block.

Format(string, params TextArgument[])

Builds a text value out of a format and the values that fill its holes, for a text variable's Set.

public static TextFormat Format(string format, params TextArgument[] arguments)

Parameters

Type Name Description
string
format

The text to write, with {0} where the first value goes, {1} the second, and so on. A number hole may ask for a fixed number of decimal places, written {0:2}. A literal brace is written {{ or }}.
TextArgument[]
arguments

One value per hole: a number, a flag or a text variable. Literals of those kinds convert on their own.

Returns

TextFormat

The parsed format, which a text variable's Set takes.

Examples

On.FrameUpdate(Label.Set(Text.Format("{0:1}/{1} hp", Health, MaxHealth)));

Remarks

What a number hole prints. With no decimal count, up to six decimal places with trailing zeros removed, so a whole number prints with no decimal point at all. With a count, exactly that many places, rounding a midpoint to the nearer even digit the way Math.Round does. NaN prints as NaN and an infinity as Infinity or -Infinity. A magnitude at or above 9,000,000,000,000,000,000 is printed through Unity's own single-precision formatter, which is the one case where the printed digits are not the Double's.

What a flag hole prints is true or false. A text hole copies the variable's bytes in.

The format is parsed once per script type, inside Build(). Writing the result per frame appends into a buffer the size of the destination variable and allocates nothing; text that does not fit the destination is refused the same way Set refuses a literal that is too long.

Exceptions

LunyScriptUsageException

The format is null or malformed, an argument is null or carries no value, or a hole names an argument that was not passed.
