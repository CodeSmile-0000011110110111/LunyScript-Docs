What Audio.PlayOneShot(clip) returns: a 2D one-shot, or one placement.

public readonly struct AudioPlayOneShotBuilder
Expand Details ...

Examples

On.CollisionEnter(Audio.PlayOneShot(ImpactClip).At(hitPosition));

Remarks

At(Vec3ValueBlock) and AttachedTo(AssetInput) each return a type that offers neither, so a second placement clause does not compile.
