Interface ICloudSaveProvider

Namespace
CodeSmile.LunyScript

What a Cloud Save backend provides to the CloudSaveGateway: sign-in, and the upload, download and delete of one whole document, each returned as an operation the gateway polls once per frame. Script code never sees this type; it sees start blocks and outcome events. AGENTS.md section 12.

public interface ICloudSaveProvider
Expand Details ...

Examples

runner.CloudGateway.UseProvider(new FileCloudSaveProvider(directory));

Remarks

Two implementations exist. FileCloudSaveProvider stores one file per document and is a first-class part of the product, because it is how every failure branch is tested without a network; AGENTS.md rule 52. UgsCloudSaveProvider in CodeSmile.LunyScript.Services wraps Unity Gaming Services.

A document is one stored value under its key, the settled answer "One stored value for the whole document". The value is the document's JSON text in the layout Progress writes; a provider stores and returns it and never interprets its fields.

A key is case sensitive, and every implementation must hold it that way. Level1 and level1 are two keys carrying two values, which is how Unity Cloud Save behaves; docs/slice-decisions.md D5.14 records the decision and what FileCloudSaveProvider does to keep it on a case-insensitive file system.

The provider owns request timing. The gateway sets no deadline; a provider that gives up on a request completes its operation with OperationFailure.Timeout.
