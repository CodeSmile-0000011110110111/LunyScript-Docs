What a Cloud Save backend provides to the CloudSaveGateway: sign-in, a save and a load, each returned as an operation the gateway polls once per frame. Script code never sees this type; it sees start blocks and outcome events. AGENTS.md section 12.

public interface ICloudSaveProvider
Expand Details ...

Examples

runner.CloudGateway.UseProvider(new FileCloudSaveProvider(directory));

Remarks

Two implementations exist. FileCloudSaveProvider stores one file per key and is a first-class part of the product, because it is how every failure branch is tested without a network; AGENTS.md rule 52. UgsCloudSaveProvider in CodeSmile.LunyScript.Services wraps Unity Gaming Services.

A key is case sensitive, and every implementation must hold it that way. Level1 and level1 are two keys carrying two values, which is how Unity Cloud Save behaves; docs/slice-decisions.md D5.14 records the decision and what FileCloudSaveProvider does to keep it on a case-insensitive file system.
