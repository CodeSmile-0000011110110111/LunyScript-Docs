Struct LeaderboardEntryBuilder

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

What Leaderboard.LoadEntry(board).Into(entry) returns: an entry read that becomes a block when As(Operation, string, int) binds the operation handle, optionally writing the entry's public details into a document with WithDetails(Document, string, int) first. An unbound read is refused when Build() finishes.

As(Operation, string, int)

Binds the read to an operation handle. The attempt succeeds after the entry, and the details document when one is named, are written; an account with no entry fails as NotFound with nothing written.

WithDetails(Document, string, int)

Writes the entry's public details, the document a Submit sent with .With, into a document's fields, with the version, migration and omission rules every document load has. An entry with no details writes nothing.
