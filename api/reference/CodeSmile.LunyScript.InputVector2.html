A handle to one two-axis action of one local player. Returned by Input.ForPlayer(player).Vector2(name) at build time.

public readonly struct InputVector2 : IInputActionHandle
Expand Details ...
Implements
IInputActionHandle

Examples

var move = Input.ForPlayer(0).Vector2("Move");
On.FrameUpdate(Direction.Set(move.Value));

Remarks

Its value is a Vec3 whose third component is zero, because this version has no two-component value type. Read the two components with .Value.X and .Value.Y.
