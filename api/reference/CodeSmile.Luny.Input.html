LunyScript API Reference

Namespace CodeSmile.Luny.Input

Classes

BindingPart

One part of a composite binding, such as up of a 2D vector bound to four keys: the control it uses, its reset and its rebinding.

ButtonAction

A player's button action: IsPressed, its phases, and its analogue press as Value.

LocalInput

The input of the players on one machine, read from an Input System action asset: each player's actions as typed handles, the phases each action received in the frame that is running, the pairing of devices to players, interactive rebinding, and the binding overrides a game stores.

LunyInput

LunyInput's entry type: Create(InputActionAsset) makes the LocalInput that reads one machine's players from an Input System action asset. Each overload forwards to the LocalInput constructor with the same parameters; the caller disposes the result.

LunyInputException

A mistake in the C# that uses LunyInput, raised where it was made: a missing action asset, a player count below one, an action or composite part the asset does not have, or a LocalInput used after it was disposed. The message names the call, the player and what to change.

NumberAction

A player's one-number action, such as a trigger or a throttle axis, read as Value.

PlayerAction

One player's action, found by name in the action asset: whether it is pressed, the phases it received in the frame that is running, the control it is bound to, and its rebinding. ButtonAction, NumberAction, Vector2Action and Vector3Action add the value.

RebindCapture

One interactive rebind: the Input System listening for the control a player presses next, which then becomes the binding of an action or of one composite part. Rebind() and Rebind() start one.

Vector2Action

A player's two-component action, such as a stick or a 2D vector of four keys, read as Value.

Vector3Action

A player's three-component action, read as Value.

Structs

BindingOverride

One binding whose control path differs from the action asset's: which binding, and the path it uses instead. What ReadOverrides(List<BindingOverride>) lists and ApplyOverrides(IReadOnlyList<BindingOverride>, List<BindingOverride>) applies, so a game can store a player's rebound controls and apply them again later.

InputPlayer

One player of a LocalInput: whether somebody holds the index, their actions as typed handles, leaving, and their binding overrides. A view that allocates nothing, so reading it every frame is free.

Enums

ActionKind

What a player action produces, which decides how its value is read and which actions of the action asset may be found as it.

ActionLookup

Whether TryFind(string, ActionKind, out PlayerAction) found an action of the asked kind, and why not when it did not.

PairingResult

What a pairing request did: OpenPairing(), ClosePairing() and Leave().

RebindStatus

Where one RebindCapture is. Listening is the one state that changes later; every other state is final.
