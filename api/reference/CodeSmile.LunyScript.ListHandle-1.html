Struct ListHandle<T>

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

A handle to one fixed-capacity list declared with Define.List<T>. Occupancy starts at zero. The C# type is not List<T>, because that name collides with System.Collections.Generic.List.

public readonly struct ListHandle<T> where T : struct

Type Parameters

T

Number, Flag, Text or a declared C# enum.

Expand Details ...

Examples

Slots = Define.List<Number>(nameof(Slots), 4);
On.Ready(Slots.Add(1.0), Slots.Add(2.0));
On.FrameUpdate(Equipped.Set(Slots.At(0)));

TryAdd(NumberValueBlock, string, int)

Appends a Number when Count is below capacity, as a try whose own outcome If branches on or .As stores. A full list, or a list a ForEach is visiting, refuses the call and leaves its content unchanged.

public CollectionTryBuilder TryAdd(NumberValueBlock value, string callerFilePath = null, int callerLineNumber = 0)

Parameters

Type Name Description
NumberValueBlock
value

The Number to append. It is evaluated once each time the try runs.
string
callerFilePath

Supplied by the compiler. Do not pass one.
int
callerLineNumber

Supplied by the compiler.

Returns

CollectionTryBuilder

A try that If(...) or .As(result) consumes once.

Examples

On.Ready(If(Slots.TryAdd(item)).Then(Hits.Add(1.0)).Else(ShowFull.Set(true)));
On.Ready(Slots.TryAdd(item).As(Added), If(Added).Then(Hits.Add(1.0)));

Exceptions

LunyScriptUsageException

value is null, or this list does not store Number.
