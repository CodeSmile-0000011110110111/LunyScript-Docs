Struct OperationFactory

The Operation surface inside Build(): declares a handle with one observable attempt at a time.

public readonly struct OperationFactory
Expand Details ...

Examples

LoadingArena = Operation.Define(nameof(LoadingArena));
InternetTime = Operation.Define<TimeReply>(nameof(InternetTime));

Remarks

Family start blocks bind the handle with .As(handle). This surface does not start native work. Scene flow, local requests and web calls each bind their own start to the handle they declare here.
