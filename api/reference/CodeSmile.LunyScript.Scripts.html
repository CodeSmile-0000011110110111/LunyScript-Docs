Finds the script an object runs, for ordinary C# code outside a script. The result is a ScriptView<TScript> of one incarnation of that script.

Examples

var player = Scripts.Find<PlayerScript>(behaviour);
if (player.Exists)
    healthLabel.text = $"{player.Read(player.Definition.Health):0}";

Remarks

This is the settled contract-instance-access answer: a typed lookup returns an optional view, and a script of another type returns no match. docs/proposals/typed-instance-view.md states the whole contract, including what a view does after its script despawns.

Methods

Find<TScript>(LunyScriptBehaviour)

Looks up the script target runs, when that script is a TScript.

public static ScriptView<TScript> Find<TScript>(LunyScriptBehaviour target) where TScript : Script

Parameters

Type Name Description
LunyScriptBehaviour
target

The object's LunyScriptBehaviour. From a GameObject or a Collider, TryGetComponent(out LunyScriptBehaviour behaviour) reaches it.

Returns

ScriptView<TScript>

A view whose Exists is true when the object's script is running and is a TScript. It is false when target is null or destroyed, before its Awake, after its script was despawned, and when its script is of another type.

Type Parameters

TScript

The script type the caller expects. A script type derived from it matches too.

Examples

if (other.TryGetComponent(out LunyScriptBehaviour behaviour))
{
    var enemy = Scripts.Find<EnemyScript>(behaviour);
    if (enemy.Exists) damage = enemy.Read(enemy.Definition.Damage);
}
