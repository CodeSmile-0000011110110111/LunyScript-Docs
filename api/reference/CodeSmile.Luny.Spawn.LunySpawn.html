LunyScript API Reference

Class LunySpawn

Namespace
CodeSmile.Luny.Spawn
Assembly
ApiSource.dll

LunySpawn's entry type: Admit(RecipeSpec) validates a recipe, HostIn(Scene) finds the scene's SpawnHost, which runs recipes over the scene's placements, CreateSession(ISpawnWorld, SpawnSessionOptions) makes a session over a world of the caller's own, and TryGetUse(GameObject, out SpawnUse) finds the current use of an object in the scene. Each call forwards to the type that does the work, such as From(RecipeSpec).

Examples

var recipe = LunySpawn.Admit(new RecipeSpec("wave").Phase(new PhaseSpec("first"))).Require();
var start = LunySpawn.HostIn(gameObject.scene).StartRun(recipe, this, seed: 7);

Remarks

It lives in the Unity layer, so it can name the scene's host. Code in an assembly with No Engine References calls From(RecipeSpec) and the SpawnSession constructor directly.
