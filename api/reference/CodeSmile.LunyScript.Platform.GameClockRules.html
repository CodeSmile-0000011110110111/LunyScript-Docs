Remarks

Three places ask the same question about the same value - SetTimeScaleBlock, which is the path a script author reaches, and the SetScale(double) implementations of UnityTimeSource and TestKit.ManualTimeSource, which a game's or a test's own C# reaches - so the rule and its wording live here rather than in three copies that could drift. The block adds the authored line it captured; the two clocks have none to add.

Remarks

NaN fails the first comparison, because every comparison with NaN is false; infinity passes it, which is why the second test is there and not redundant.
