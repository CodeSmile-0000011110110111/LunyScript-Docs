What When.Player(n) and When.Player() return. Its four methods register the blocks that run when this script sees a local player pair, leave, lose a device or get it back.

public readonly struct PlayerWatchBuilder
Expand Details ...

Examples

When.Player(1).Paired(Status.Set("Player 2 is in"));
When.Player().Lost(Status.Set("Reconnect your controller"));

Remarks

Each watch compares what this instance last saw with the players of the frame, once per frame after the frame-update blocks, the way When.Var(x).Changed does. An instance that spawns after a player paired runs Paired for that player on its first tick, so a script in a scene loaded later still sees the players who paired earlier. A player who paired and left while the script was not ticking runs neither. docs/proposals/local-player-pairing.md, "When the four watches run", is the contract.

When.Player() with no number watches the local player bound to the object the script runs on, which is set by Object.Spawn(prefab).ForPlayer(n) or by the object's Local Player field. An object bound to nobody runs none of the four.
