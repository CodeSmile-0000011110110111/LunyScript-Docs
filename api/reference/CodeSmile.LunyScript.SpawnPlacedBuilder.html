What Object.Spawn(prefab).At(...) returns: a spawn whose placement is stated and whose frame is still the default, the parent's.

public readonly struct SpawnPlacedBuilder
Expand Details ...

Examples

On.Ready(Object.Spawn(Sentry).At(new Vec3(0.0, 1.0, 0.0)).InWorldSpace());

Remarks

The two frame modifiers live here and nowhere else, which is what makes a second At and a second frame clause compile errors.

SpawnPlacedBuilder

A builder that can still take a placement and a name.

Examples

On.Ready(Object.Spawn(Sentry).ChildOf());

Remarks

Omitting the name parents it to the object the script runs on, which is the same "self by omission" the rest of the Object surface uses. A named parent is an object this script produced, by Object.Create(name) or by another spawn's Into(string, string, int). A parent whose slot is empty when the spawn is applied leaves the produced object at the scene root and reports it.

Exceptions

LunyScriptUsageException

name is whitespace, this chain already names a parent, or this builder is a default.

InLocalSpace()

States the default frame explicitly: the placement is read in the parent's coordinates.

Returns

SpawnFramedBuilder

A builder that can still take a parent and a name.

Examples

Remarks

It changes nothing a spawn without it does. It exists because the settled semantics-t02 answer says the default may be stated explicitly, and because a script that mixes framed and unframed spawns reads better when both say which frame they mean.

Into(string, string, int)

Holds the produced object in this script's owned-object slot of that name, so later blocks can address it.

SpawnPlacedBuilder

A builder that can still take a placement and a parent.

Examples

On.Ready(Object.Spawn(Sentry).Into("Guard"));

Remarks

A held object is owned: it is destroyed when the instance that spawned it is despawned, by every path that despawns one, exactly as an Object.Create object is. A spawn with no Into is not held at all and outlives the script that spawned it.

The name addresses the slot and is not the produced object's name in the scene: a prefab already carries a name, which is the difference from Object.Create(name) where the name is both.

Exceptions

LunyScriptUsageException

name is null or whitespace, this chain already names one, another call already produces that name, or this builder is a default.
