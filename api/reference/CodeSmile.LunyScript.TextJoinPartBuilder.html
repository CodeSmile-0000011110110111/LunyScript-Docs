public readonly struct TextJoinPartBuilder
Expand Details ...

Examples

On.Update(Augments.Set(Text.Join(", ").Part(RingVolley, "Ring volley").Part(MineLayer, "Mine layer")));

Remarks

Each time the joined text is written, every part's condition is tested once, in the order the parts were written, and the text of each part whose condition holds is written, with the separator between two written parts. A part whose condition holds is written even when its text is empty. Else names the text written when no condition holds; a join without one writes the empty text then. A join goes wherever a Text.Format goes: a text variable's Set, a Label's or TextField's SetText and BindText, and the text of another join's part.

A builder can be continued more than once: each continuation keeps its own parts after the ones they share, the way two ElseIf chains continued from one If do.
