What one catalog node's block last did in one lifetime, recorded when the block ran. Reading it re-evaluates nothing.

public readonly struct DiagnosticNodeOutcome
Expand Details ...

Examples

var tookThen = snapshot.NodeOutcomes[node.Id].Kind == DiagnosticRecordKind.BranchTrue;

Remarks

Kind is ActionStarted for a step that returned Running and has not finished, ActionCompleted for a block that returned, BranchTrue or BranchFalse for an If that returned after running that branch, and ActionFailed for a block that propagated a failure. A node whose block has not run in this lifetime has HasRun false and every other member at its default.
