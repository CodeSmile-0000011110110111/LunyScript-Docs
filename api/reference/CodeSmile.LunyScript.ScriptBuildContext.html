Remarks

Typestate refuses a wrong input kind and an unfinished chain where it is written. It cannot refuse a copied builder or prove where a block ends up, so three rules are checked here: a try has one consumer, the block its consumer returns is placed exactly once, and a result has exactly one producer. All of this runs once per script type; nothing here runs per frame.
