Enum NavigationAgentState

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

Whether an actor can navigate, as a navigation backend reports it. Every value other than Ready is a reason a Navigation.MoveTo attempt fails as OperationFailure.Denied.

public enum NavigationAgentState
Expand Details ...

Fields

AgentDisabled = 3

The actor's agent, or the actor itself, is disabled or inactive.

Missing = 1

There is no actor: the object was destroyed, or nothing was assigned.

NoAgent = 2

The actor carries no navigation agent.

NotOnSurface = 4

The actor's agent does not stand on a navigation surface, so no route can start where it is.

Ready = 0

The actor has an agent that can take a destination now.

Examples

if (provider.Start(actor, destination) != NavigationAgentState.Ready) return;

Remarks

A backend answers this from what it can see on the actor. Unity's NavMesh backend answers it from the actor's NavMeshAgent: whether there is one, whether it is active and enabled, and whether it stands on a navigation mesh.
