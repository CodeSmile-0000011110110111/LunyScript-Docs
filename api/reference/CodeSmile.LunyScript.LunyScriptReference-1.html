One incarnation of a script, referenced from ordinary C# code: its compiled definition, reads of the variables it declared, and observations of their changes. Find<TScript>(LunyScriptBehaviour) returns it.

public readonly struct LunyScriptReference<TScript> where TScript : Script

Type Parameters

TScript

The script type the lookup asked for.

Expand Details ...

Examples

var player = LunyScript.Find<PlayerScript>(behaviour);
if (player.IsRunning)
    healthLabel.text = $"{player.Read(player.Definition.Health):0}";

Remarks

A reference identifies one incarnation. It records the runner that runs the script and the instance's generation, so a pooled instance respawned onto another object is a different incarnation and this reference never reads it.

A read after the script ended throws LunyScriptUsageException, the way C# throws when it reads a destroyed Unity object or component. IsRunning and IsObjectSpawned are the checks a caller makes first; neither throws.

There is no write through a reference. A C# caller changes another script's state by asking it to, with Send(string).

Properties

Definition

The compiled script object, whose variable properties hold the handles this reference reads. It stays set after the incarnation ends, and is null for a reference that matched no script.

public TScript Definition { get; }

Property Value

TScript

Examples

var health = player.Read(player.Definition.Health);

Remarks

It is the object whose Build() ran, which Script also returns after Awake. A new PlayerScript() is not a definition: its properties were never assigned.

IsObjectSpawned

True while the object this reference's script runs on is spawned or created, and false once the object is despawned or destroyed.

public bool IsObjectSpawned { get; }

Property Value

bool

Examples

m_HealthBar.SetActive(player.IsObjectSpawned);

Remarks

Every despawn in this version also destroys the object, so this becomes false at the same moment as IsRunning, on every path. It is false for a reference that matched no script.

IsRunning

True while the script this reference was taken of runs on its object, from the object's creation until the object is destroyed. Every read and every Observe succeeds while it is true and throws once it is false.

public bool IsRunning { get; }

Property Value

bool

Examples

if (player.IsRunning) health = player.Read(player.Definition.Health);

Remarks

It stays true while the object is deactivated and while the game is paused. It becomes false when Unity destroys the object; when an authored Object.Destroy() takes effect, which ends the script and destroys the object, before Unity removes the object at the end of the frame; and when the runner's session ends, which leaving Play Mode does. It stays false after the pooled instance is respawned as a later incarnation. It is false for a reference that matched no script.
