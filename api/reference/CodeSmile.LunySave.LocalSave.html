Saves and loads typed documents on this device, for plain C#: Save(string, SaveDocument) and Load(string, SaveSchema) in the player's writable data folder, LoadStreamingAsset(string, SaveSchema) from the read-only StreamingAssets folder the build ships. Every path is relative to the folder its call uses.

Remarks

Two folders, both chosen by the platform. The writable folder is Application.persistentDataPath, the one place Unity guarantees a player may write on every platform, and the read-only folder is Application.streamingAssetsPath, which holds the build's copy of Assets/StreamingAssets. Save("savegames/001.sav", document) writes <persistentDataPath>/savegames/001.sav. There is no call that writes to StreamingAssets, takes an absolute path, or reads a file's bytes: CodeSmile.LunySave.SavePath refuses a path that is absolute or leaves its folder, and every read returns a document of a SaveSchema.

What a save guarantees. A save writes the whole document to a copy beside the file, flushes it, and replaces the file in one rename, so a failure leaves the previous copy as it was. A load reads the file, runs the schema's migration steps on a copy of an older version, and checks every declared field before it hands back a document; it never writes the file. A save and a load from the data folder complete inside the call.

Reads Application.persistentDataPath and Application.streamingAssetsPath at its first call, so that call is on the main thread, in Awake or later. LunyScript's Progress and Settings documents are stored through the same writer, codec and migration rules, under <persistentDataPath>/LunyScript.

Methods

Load(string, SaveSchema)

Reads the document stored at path in the player's data folder.

public LoadOperation Load(string path, SaveSchema schema)

Parameters

Type Name Description
string
path

A relative path such as "savegames/001.sav".
SaveSchema
schema

What the document holds; an older stored version is migrated to it.

Returns

LoadOperation

The load; it has ended when this returns. NotFound when nothing is stored there.

Examples

var loading = m_Saves.Load("savegames/001.sav", Progress);

Exceptions

LunySaveException

The path is refused, or the schema is null, declares no field or leaves a gap in its steps.

LoadStreamingAsset(string, SaveSchema)

Reads a document the build ships at path in StreamingAssets, such as default settings or a level's starting state. Names are compared case sensitively on every platform.

public LoadOperation LoadStreamingAsset(string path, SaveSchema schema)

Parameters

SaveSchema

What the document holds; an older stored version is migrated to it.

Returns

LoadOperation

The load. It has ended when this returns where StreamingAssets is a local folder, and in a later frame on Android and the web.
