Remarks

This is not a listing of the public API. The implementation queue called it a registration catalog. An adapter calls Register(Type, string, string, string, string, int) once per block type it adds, naming the Unity package and the minimum version that type needs. An author never writes a catalog line in Build().

Admission is checked at spawn, in the same ValidateCapabilities pass that already refuses a host that cannot provide the program's services. A missing package or a version older than the registered minimum raises LunyScriptUsageException and the instance is not created, so no registered block runs and no null-reference path is reached. The check is not on the per-frame path.

The registered version is a minimum. An installed package newer than the declared version is admitted, including a later major such as Unity 7's 6.7.0 against a 1.8.0 minimum. That is the same rule Unity's versionDefines expression uses.

Input and Cinemachine keep the provider-absence path they already have: their author-facing blocks live in core, and with no provider they report once and do nothing while the script still spawns. Do not register those core blocks here; this table is for extension block types the adapter itself adds.

The dictionaries are readonly statics and this type is [NoAutoStaticsCleanup] because adapter assemblies register from a static constructor that does not run again when domain reload is off. Clearing the table on Play Mode exit would drop those registrations for the next Play session. Tests call Clear() between cases.

Register(Type, string, string, string, string, int)

Records that a block type needs a Unity package at a stated minimum version. The adapter assembly calls this once; a script's Build() does not.

public static void Register(Type blockType, string packageId, string minimumVersion, string owner, string callerFilePath = null, int callerLineNumber = 0)

Type Name Description

string

Examples

Exceptions

LunyScriptUsageException

A parameter is missing, the type is not a concrete LunyScript node, the version string is not numeric, or the same type was already registered with a different package, version or owner.
