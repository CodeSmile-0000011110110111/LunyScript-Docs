Remarks

One enum serves both shapes deliberately: every function in the API semantics board's C01 answer has two documented forms, an expression that computes a value and a write that stores the result back into the variable it read, and both forms must mean the same thing. NumberMath is where each one is computed, once.

The four arithmetic entries are here as well as on ArithmeticOperator, and the two tables are not redundant. ArithmeticOperator is what the C# operators + - * / % build, where both operands are written at the call site; this table is what a write applies to the variable's own value, where the first operand is the slot and is never written down. Health.Subtract(1.0) and Health.Set(Health - 1.0) reach the same arithmetic through the two tables.
