Struct AssetInput

One declared asset input with its type forgotten: what a surface takes when it accepts an input of any Unity type, such as the camera rig a view renders.

public readonly struct AssetInput

Examples

On.Ready(Camera.For(ChaseRig).Follow(Avatar));

Remarks

An Asset<T> converts to one of these on its own, so a script writes Camera.For(ChaseRig) and never names this type. It exists because the surfaces that take an object rather than an asset - a view, a camera rig, something a camera tracks - accept whichever Unity type the author declared, and a generic parameter on every one of those members would buy nothing: the type is not what they check, the backend is.

The declared type is still enforced where it matters, when the object spawns: Asset<T> is what the Inspector draws a field of, and a stored value of another type is refused there. This conversion forgets the type after that check has already happened.
