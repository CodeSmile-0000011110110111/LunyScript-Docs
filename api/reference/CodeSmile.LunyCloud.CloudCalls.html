Class CloudCalls

Namespace
CodeSmile.LunyCloud

ApiSource.dll

Calls that were already complete when they were made: what a backend returns when it did its work inside the call, as FileCloudBackend does. The client observes the outcome at its next poll, so a caller sees the same order of events it sees against a service.

Remarks

A completed call is immutable, so a backend may keep one successful call and return it every time, as FileCloudBackend does; this type holds no static instance, because the domain owns no static state.
