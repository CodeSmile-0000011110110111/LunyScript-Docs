Interface ICloudCall

Namespace
CodeSmile.Luny.Cloud
Assembly
ApiSource.dll

One backend call in flight, which the client polls once per Tick() and never awaits. A backend wraps whatever its service hands back, a task or a callback, behind this interface; a backend that did its work inside the call returns a completed one from CloudCalls.

public interface ICloudCall

Examples

public ICloudCall DeleteData(in CloudAddress address) => m_Done;

Remarks

IsComplete is read once per tick until it is true; Failure is read once after that. Both are read on the main thread. A call that throws from either is classified Unknown and logged once with the exception text, and is not polled again.

Properties

Failure

Why the call failed, or None when it succeeded. Read only once IsComplete is true.

Examples

IsComplete

True once the call has an outcome.

Property Value

bool

Examples

Problem

The service's own words for a failure, such as an exception message, or null. The client writes it into the failure's log line and keeps it on Problem, so a failure an agent reads names its cause. Read only once IsComplete is true.

string Problem { get; }

Property Value

string

Examples
