What Scene.Unload(scene).As(handle) builds: starts unloading the one loaded instance of a scene, bound to an operation handle. The handle succeeds when Unity has unloaded it.

Remarks

The identity is the instance, not the asset name. With no instance of that scene loaded the attempt fails as NotFound. With two or more loaded it fails as Denied and unloads none, because the scene asset does not say which one was meant. The last loaded scene cannot be unloaded, which is also Denied.
