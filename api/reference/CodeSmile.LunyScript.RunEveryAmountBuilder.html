Struct RunEveryAmountBuilder

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

A Run(body).Every(amount) chain: a cadence in seconds unless a unit call names another unit. Start(string, int) runs it indefinitely; For(NumberValueBlock, string, int) and Over(NumberValueBlock, string, int) add a count or a duration bound.

public readonly struct RunEveryAmountBuilder
Expand Details ...

Examples

var tick = Run(Hits.Add(1.0)).Every(3);
var burst = Run(Hits.Add(1.0)).Every(0.5).For(5);
On.Ready(tick.Start(), burst.Start());
