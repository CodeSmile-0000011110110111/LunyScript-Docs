Whether TryFind(string, ActionKind, out PlayerAction) found an action of the asked kind, and why not when it did not.

public enum ActionLookup
Expand Details ...

Fields

Found = 0

The action was found and produces the asked kind.

NoSuchPlayer = 1

The player has no actions: nobody holds that player index in a setup whose players come from PlayerInput components, the index is beyond what the setup holds, or the LocalInput was disposed.

NotFound = 2

The player's actions have no action of that name.

WrongKind = 3

The action of that name produces another kind of value.

Examples

if (input.Player(1).TryFind("Fire", ActionKind.Button, out var fire) == ActionLookup.Found) { }
