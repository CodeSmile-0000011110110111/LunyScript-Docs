Struct AudioFactory

Namespace
CodeSmile.LunyScript
Assembly
ApiSource.dll

The Audio surface inside Build(): one-shot play, bound source control, and named mixer writes. It hides UnityEngine.AudioSource inside a Script the same way Transform hides UnityEngine.Transform.

public readonly struct AudioFactory
Expand Details ...

Examples

On.CollisionEnter(Audio.PlayOneShot(BreakClip));
On.Ready(Audio.Play());

Remarks

A one-shot plays on a runner-owned pooled voice. A bound source is the AudioSource already on an object. Mixer writes are a third surface. docs/proposals/audio.md is the family.
