What one condition or value node says about a snapshot's stored values, or why a snapshot cannot say. Preview(DiagnosticNode) computes it from the snapshot's own copy of the values, without running any block or script code.

public readonly struct DiagnosticPreview
Expand Details ...

Examples

var live = snapshot.Preview(node); var label = live.IsAvailable ? live.Value.Flag.ToString() : live.UnavailableReason;

Remarks

A condition's value is a Flag. A preview is what the node would say at the boundary the snapshot was read at; the node outcome in NodeOutcomes is what the script's own run recorded, which can be older.
