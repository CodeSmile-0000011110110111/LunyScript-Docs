Struct IfBuilder

Namespace
CodeSmile.LunyScript

What If(condition) returns. Its only method is Then(params Block[]), so a condition without a consequence does not compile.

public readonly struct IfBuilder
Expand Details ...

Examples

On.FrameUpdate(If(health > 0.0).Then(health.Add(-1.0)).Else(alive.Set(false)));

Remarks

The two builder structs are a typestate: If(...) offers only Then, and IfThenBuilder offers only Else and the conversion to a block. Collapsing them into one type to shorten a call site would turn a compiler error into a run-time check; AGENTS.md rule 41.
