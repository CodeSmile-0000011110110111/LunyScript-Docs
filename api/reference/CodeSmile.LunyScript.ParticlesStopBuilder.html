Struct ParticlesStopBuilder

Namespace
CodeSmile.LunyScript

What Stop() returns: the stop that ends emission and lets living particles die, when it is used as a block, or the stop that also removes them after AndClear().

public readonly struct ParticlesStopBuilder
Expand Details ...

Examples

On.Message("Douse", Particles.Stop());
On.Message("Extinguish", Particles.Stop().AndClear());

Remarks

A builder that is neither used as a block nor finished with .AndClear() is refused when Build() finishes.

Methods

AndClear()

Stops emission and removes the living particles at once, which is Unity Stop(true, StopEmittingAndClear).

public Block AndClear()

Returns

Block

A block to place in an event list.

Examples

On.Disabled(Particles.For(MuzzleFlash).Stop().AndClear());

This builder is a default that no Stop() call produced.
