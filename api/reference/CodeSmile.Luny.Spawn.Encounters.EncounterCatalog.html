Class EncounterCatalog

CodeSmile.Luny.Spawn.Encounters

ApiSource.dll

Every encounter of one admitted database revision, each an admitted SpawnRecipe that names the revision it came from. EncounterData reads it from the database's Encounter/ folder, one file per encounter (the captain's Q20 answer), and the game queries it through LunyData without reading JSON. It is the CodeSmile.Luny.Data.DefinitionCatalog<TDefinition> of LunySpawn's module of the game database, so CodeSmile.Luny.Data.DefinitionCatalog<TDefinition>.Get(string) and CodeSmile.Luny.Data.DefinitionCatalog<TDefinition>.TryGet(string, out TDefinition) find an Encounter by its id, and CodeSmile.Luny.Data.DefinitionCatalog<TDefinition>.Get(string) throws a LunySpawnException for an id no encounter has.
