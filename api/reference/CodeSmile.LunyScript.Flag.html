Struct Flag

A true-or-false variable of a script: a handle to one slot backed by bool storage, or a constant. Build() declares it, and its methods and operators build blocks.

public readonly struct Flag
Expand Details ...

Examples

Alive = Flag.Define(nameof(Alive), true);
On.FrameUpdate(If(Alive).Then(Health.Add(Time.Delta)));

Remarks

A Flag is a handle, not the value. Each object running the script keeps its own slot. Writing Flag Always = true; makes a constant input that has no slot, and a write to it is refused while the script type is built. A partial script declares a flag on one line inside Build(), and the generator writes the property: Alive = Flag.Define(nameof(Alive), true);.
