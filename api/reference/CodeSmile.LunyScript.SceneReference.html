A handle to one scene input of a script: the typed scene identity that Scene.Load, Scene.Unload and the When.Scene* watches take. Returned by Bind.Scene at build time, or assigned before Build() by [Asset] on the property.

public readonly struct SceneReference

Examples

Remarks

The scene is assigned in the Inspector, not written as a string. The host's declared-input table draws a scene field for this input, stores the scene asset's path and GUID, and the runner resolves that path when the object spawns. A script never names a scene by its file name, which is the settled contract-reference-kinds answer: a typed scene identity, and no UnityEngine.Object cast in script values.

An unassigned scene input has no placeholder. Substituting a scene would change what the game is, so the settled binding-default catalog lists a scene reference among the types that get none. The object still spawns, the missing assignment is reported once per script type, and a Scene.Load of it fails as OperationFailure.NotFound.

The identity is the scene asset. Two inputs on two scripts that are assigned the same scene name the same identity, so a watch on one observes a load started through the other. Scene.Unload ends the one loaded instance of that asset and refuses when two are loaded, because the asset name alone cannot say which one was meant.

A handle is valid only inside the Build that declared it, for the reason Var<T> states: it carries a slot and nothing that identifies its program.
