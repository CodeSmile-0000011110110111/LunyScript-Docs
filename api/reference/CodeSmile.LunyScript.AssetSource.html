Names the provider-qualified sources a declared asset input can load from.

public static class AssetSource
Inheritance
object
AssetSource

Examples

AssetSource.Resources<AudioClip>("Sounds/Door");

Remarks

A key is validated where it is written, at build time, rather than on the first spawn; CodeSmile.LunyScript.AssetKeys is the one place that happens.

Methods
