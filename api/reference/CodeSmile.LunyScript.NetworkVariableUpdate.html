Remarks

VariableIndex is a declaration index and not a slot index, and that is a correctness requirement rather than a naming preference. Slot indices are per kind, so the first Number variable and the first Flag variable are both slot 0 and a receiver given only a slot index cannot tell them apart; a text slot needs its TextCapacity as well, which a single index cannot carry either. Both peers run the same script type and therefore the same list of synchronised declarations, so the position in that list names the variable exactly, in one integer, with no kind on the wire.
