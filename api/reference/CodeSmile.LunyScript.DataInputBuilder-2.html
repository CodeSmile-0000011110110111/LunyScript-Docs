What Bind.Data(schema) returns: an Inspector data input, or with a From... call a JSON file of that schema.

public readonly struct DataInputBuilder<TValue, THandle> where TValue : struct where THandle : struct, ILunyScriptDataVariables

Expand Details ...

Examples

Balance = Bind.Data(WeaponStats.Schema);
StatsFile = Bind.Data(WeaponStats.Schema).FromStreamingAssets("weapon.json");

Remarks

Assigned as it is, it declares an Inspector input. The object's LunyScript Behaviour shows a field that accepts a data asset, and when the object spawns, before On.Ready, the one LunyScriptDataFieldAttribute field of that schema on the asset is copied into this object's variables. The asset keeps its values. An object that assigns nothing refuses to spawn, because rules data has no placeholder.

FromStreamingAssets, FromUserData and FromTemp name a JSON file instead, which Asset.Load(file).Into(data) reads into a Define.Data of the same schema.
