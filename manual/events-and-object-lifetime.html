Events and object lifetime

Register blocks against an event and they run whenever that event is raised on this object:

using CodeSmile.LunyScript;

public sealed partial class Hazard : Script
{
    [Variable(100)] public Var<Number> Health { get; private set; }

    protected override void Build() =>
        On.TriggerEnter(If(Other.HasTag("Spike")).Then(Health.Subtract(10)));
}

Add the component, give the spike a Spike tag and a trigger collider, and the object loses ten health each time it enters one.

What On does

On.* is the registration surface. Each call takes one or more blocks and returns nothing, so an On.* call is a statement in Build() rather than a value you can pass on. Registering the same event twice appends blocks; the second call keeps the first call’s blocks.

A script that registers none of the six contact events is never subscribed to Unity’s physics callbacks at all, so a script that only moves costs nothing on the physics side.

Lifecycle events

Event When it runs
On.Created(block, ..) Once, at the first bind to a host object, after declared inputs are resolved and before Ready.
On.Ready(block, ..) Once per spawn, before this object’s first update of any kind.
On.Enabled(block, ..) Once per disabled-to-enabled transition. Unity’s first OnEnable raises it, so on a scene object it runs before Ready.
On.Disabled(block, ..) Once per enabled-to-disabled transition.
On.Despawned(block, ..) Once, while the object and its host are both still valid. 
On.Created(Serial.Set(NextSerial));
On.Ready(Health.Set(100), Powered.Set(true));
On.Enabled(Enables.Inc());
On.Disabled(Disables.Inc());
On.Despawned(Despawns.Inc());

A pooled object that respawns onto the same host raises Ready again and leaves Created alone.

Tick events

Event When it runs
On.FrameUpdate(block, ..) Once per frame while enabled, subject to the script’s process mode.
On.FixedUpdate(block, ..) Zero or more times per frame, before FrameUpdate.
On.LateUpdate(block, ..) After every object’s FrameUpdate and after variable watches. 
On.FrameUpdate(Age.Add(Time.Delta), Transform.RotateBy(0, 0, 35 * Time.Delta));
On.FixedUpdate(Motion.AddForce(0, 0, 12).InLocalSpace());
On.LateUpdate(Readout.Set(Text.Format("age {0:1} s", Age)));

Physics work belongs in On.FixedUpdate; see Motion for which calls require it. Variable watches are polled between FrameUpdate and LateUpdate, so a watch never fires from inside On.FixedUpdate.

Contact events, and the collider you touched

Six events cover collision and trigger contact. Inside any of them, Other reads the collider on the far side.

On.CollisionEnter(Impacts.Inc());
On.CollisionStay(If(Other.HasTag("Player")).Then(Pushing.Set(true)));
On.CollisionExit(Pushing.Set(false));
On.TriggerEnter(If(Other.IsTrigger).Then(InVolume.Set(true)));
On.TriggerStay(Dose.Add(Time.Delta));
On.TriggerExit(InVolume.Set(false));
Read What it gives
Other.WorldPosition The other collider’s position, as a Vec3.
Other.WorldPositionX / Y / Z One component of that position, as a number.
Other.Layer The other collider’s layer, as a number.
Other.IsTrigger Whether the other collider is a trigger.
Other.HasTag(tag) Whether the other collider carries that tag. 
On.TriggerStay(
    HitPoint.Set(Other.WorldPosition),
    HitX.Set(Other.WorldPositionX),
    HitLayer.Set(Other.Layer),
    If(Other.IsTrigger).Then(Volumes.Inc()),
    If(Other.HasTag("Player")).Then(PlayerInside.Set(true)));

Other is readable while a contact event is running. Reading it from a tick event throws LunyScriptUsageException when the block runs. Other.HasTag compiles to Unity’s CompareTag and allocates nothing; a blank tag is refused while Build() runs.

On.CollisionStay and On.TriggerStay run on every fixed step while contact lasts. On.TriggerStay needs Unity’s contact-pair setting that generates stay callbacks for triggers.

Application, authority and messages

On.Application.Paused(Autosave.Set(true));
On.Application.Resumed(Autosave.Set(false));
On.Application.FocusGained(Focused.Set(true));
On.Application.FocusLost(Focused.Set(false));
On.Application.Quitting(Time.Resume());

On.Authority.Gained(Driving.Set(true));
On.Authority.Lost(Driving.Set(false));

On.Message("RequestReady", IsReady.Set(true));

On.Application.* events are delivered to every enabled object. The editor raises focus changes that a built player may leave out, and an operating system that terminates an application may skip Quitting.

On.Message receives what another peer sent with Net.Send.ToAuthority. Spell the message name with nameof so the two move together, and see Networking and cloud save for the sending side. Two On.Message calls naming the same message append; a send with no matching On.Message in the same script is refused while Build() runs.

Creating and removing objects

Object produces and disposes of game objects that this script owns.

Object.Create(name)
Object.Spawn( { prefab | handle } )
    [ .At(position [ , rotation ]) ]
    [ .InWorldSpace() | .InLocalSpace() ]
    [ .ChildOf( [ name ] ) ]
    [ .Into(name) ]
Object.Activate( [ name ] )
Object.Deactivate( [ name ] )
Object.Despawn( [ name ] )

[Asset] public Prefab Sentry { get; private set; }

protected override void Build()
{
    On.Ready(Object.Create("Marker"));
    On.Message("PostGuard",
        Object.Spawn(Sentry).At(new Vec3(0, 0.8, 0)).ChildOf().Into("Guard"));
    On.FrameUpdate(If(Health <= 0).Then(Object.Despawn()));
}

Object.Create(name) makes an empty object immediately. It carries no script, this object owns it, and it is destroyed when this object despawns.

Object.Spawn takes a declared Prefab input or a succeeded Operation<Prefab> handle; see Assets and operations for both. At places it, ChildOf with no name parents it to this object, and Into(name) keeps the result in a named slot so Activate, Deactivate and Despawn can name it later. Leave At out and the prefab keeps its own pose; leave ChildOf out and the object goes to the scene root.

Activate, Deactivate and Despawn with a name act on an owned object immediately. With no name they act on this object after the current dispatch finishes, so the rest of the block list still runs. Object.Despawn() on this object produces On.Disabled, then On.Despawned, and then destroys the host.
